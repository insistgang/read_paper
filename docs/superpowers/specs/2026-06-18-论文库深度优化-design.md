## 关键架构事实 (决定做法)

1. **笔记 frontmatter `primary_topic` 是分类真源** — `generate_topic_index.py:collect_from_notes()` 读它建 03-Literature 页; `paper_topics.json` 只是 notes 不存在时的 fallback。
2. **`classify_papers.py` 是 keyword 分类器 = bug 源**, 重跑会按文件名重新分错。**修分类 = 改笔记 frontmatter, 绝不重跑 keyword 分类器。**
3. 笔记结构 = 顶部段 (摘要/背景/贡献/方法/实验/局限 + 人工区 个人评论/人工复核记录) + `# 论文精读` 12 节块 (包在 `<!-- AI_READING_NOTE_START/END -->` 标记内)。

## 每篇笔记优化契约 (subagent)

输入: `02-Notes/Papers/<stem>.md` + `.paper-cache/extracts/<stem>.txt` (+ 必要时 PDF)。

1. 修 `## 摘要`: 还原乱码英文 (补空格/接连字符/剔图轴数字), 给忠实中英摘要。
2. 核对+加深顶部段 (背景/贡献/方法/实验/局限), 严格对照提取文本, **不编造数字**。
3. 重写 `# 论文精读` 12 节块 (保留标记), 准确有深度。
4. 核对分类: 判断正确 `primary_topic`, **只返回建议**, 不直接改 json (避免并发竞争)。
5. 返回结构化裁决供第二轮对抗校验。

## 安全护栏 (硬约束)

- 🔒 绝不改 frontmatter 人工字段 (`rating`/`human_reviewed`/`review_basis`/`date_added`/`human_reviewed_at`)。
- 🔒 绝不改 `## 个人评论` / `## 人工复核记录` 正文。
- 🔒 绝不把 `human_reviewed` 设 true; 保持 `ai_generated: true`。
- 🔒 绝不动 4 篇人工精读笔记: `1608.03981v1`, `1-s2.0-S2590123024016360-main`, `(GRN)ConvNeXtV2`, `(UIB)MobileNetV4`。
- 🔒 保持 frontmatter 必填契约 (title/pdf/primary_topic/status/date_added/tags + 推荐字段)。
