### 5.1 基于图像的目标检测方法
1.  **纯图像的单目3D检测**：直接从2D图像回归3D框参数。分为基于锚点（如M3D-RPN）和无锚点（如SMOKE, FCOS3D）两类。**核心困难**是深度估计误差大(p.1770-1771)。
2.  **基于深度估计的单目3D检测**：先通过深度估计网络（如MonoDepth）生成深度图，再结合图像进行3D检测。有两种路径：**基于深度图像**（如MultiFusion）和**基于伪激光雷达**（如Pseudo-LiDAR），后者将深度图转为点云再用点云检测器(p.1771)。
3.  **基于先验引导的单目3D检测**：引入物体形状、类别等先验知识来约束3D框的生成，解决病态问题。如Mono3D++，ROI-10d(p.1771)。
4.  **基于多视角图像的BEV检测**：将多视角环视图像转换到统一的鸟瞰图（BEV）空间进行感知。代表是**BEVFormer**系列，通过注意力机制将多视角特征聚合到BEV平面，再进行检测和分割(p.1771-1772)。

### 5.2 基于点云的目标检测方法
1.  **基于点的方法**：直接处理原始点云。关键模块是**点云采样**（如最远点采样）和**局部特征学习**（如使用邻近点）。代表：PointNet++, PointRCNN, 3DSSD。**优势**是精度高，**劣势**是实时性在大规模场景下难以保证(p.1772-1773)。
2.  **基于体素的方法**：将点云划分为规则的3D体素网格。代表：**VoxelNet**（开创性工作，使用VFE模块）、**SECOND**（引入稀疏卷积提升速度）、**PointPillars**（将体素进一步简化为柱体，极大提升效率）(p.1773)。
3.  **基于BEV的方法**：将点云投影到鸟瞰图。可分为**BEV前特征提取**（先体素化再投影，如PV-RCNN）和**BEV后特征提取**（直接投影到BEV再提取特征，如MV3D, PointPillars也可归为此类）(p.1773-1774)。
4.  **基于距离图像的方法**：将点云投影为2D距离图（每个像素存深度）。**优势**是信息密集、可用2D卷积；**劣势**是易受遮挡和尺度变化影响。代表：RangeDet, LaserNet(p.1774)。

### 5.3 融合点云和图像的目标检测方法
论文按融合阶段分类：
1.  **前期融合（数据级融合）**：在特征提取早期就将图像信息（如语义分割结果）融入点云数据，形成“图像增强的点云”，再输入点云检测器。**结构**：图像分支提取语义特征 -> 融合到点云分支 -> 增强后的点云输入检测器。**缺点**是延迟高(p.1774, p.1774图7)。
2.  **深度融合（特征级融合）**：在点云检测器的中间阶段（如骨干网络、RoI阶段）融合图像特征。**结构**：并行的图像和点云特征提取器 -> 在中间层进行特征交互与融合 -> 融合后的特征送入后续网络。**挑战**是处理异构特征，保留各自有效信息(p.1774, p.1774图8)。
3.  **后期融合（决策级融合）**：独立的图像和点云检测器分别做出检测决策，然后对结果进行融合（如通过非极大值抑制、投票、学习一个融合模型）。**结构**：独立的图像检测器与点云检测器 -> 分别输出检测框 -> 决策级融合生成最终结果(p.1775, p.1775图9)。

1.  **前期融合（数据级融合）**：在特征提取早期就将图像信息（如语义分割结果）融入点云数据，形成“图像增强的点云”，再输入点云检测器。**结构**：图像分支提取语义特征 -> 融合到点云分支 -> 增强后的点云输入检测器。**缺点**是延迟高(p.1774, p.1774图7)。
2.  **深度融合（特征级融合）**：在点云检测器的中间阶段（如骨干网络、RoI阶段）融合图像特征。**结构**：并行的图像和点云特征提取器 -> 在中间层进行特征交互与融合 -> 融合后的特征送入后续网络。**挑战**是处理异构特征，保留各自有效信息(p.1774, p.1774图8)。
3.  **后期融合（决策级融合）**：独立的图像和点云检测器分别做出检测决策，然后对结果进行融合（如通过非极大值抑制、投票、学习一个融合模型）。**结构**：独立的图像检测器与点云检测器 -> 分别输出检测框 -> 决策级融合生成最终结果(p.1775, p.1775图9)。
