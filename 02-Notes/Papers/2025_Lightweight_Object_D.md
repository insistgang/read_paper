## 研究背景与动机

- **为什么要做**：人工智能与嵌入式系统的结合革新了实时监控，特别是在应急响应和灾难管理中。无人机搭载轻量目标检测算法可提供宝贵的空中视角。然而，在像树莓派这样的资源受限边缘设备上实现准确、快速的检测仍是一个挑战。
- **之前方法的问题**：传统目标检测框架（如Faster R-CNN）准确但推理慢、计算要求高，不适合边缘部署。现代实时检测器（如YOLOv3、YOLOv5-small）虽高效，但在面向电池供电的嵌入式平台时，仍有通过模型压缩技术（如量化）进一步优化的空间。
- **核心矛盾**：在**检测准确性**与**计算效率（推理速度、模型大小、功耗）** 之间取得平衡，以满足实时推理、能效和内存占用严格的嵌入式部署需求。
## 关键贡献

1.  **创建了一个领域专用数据集**：由于缺乏公开的无人机视角紧急图像数据集，作者自行构建并标注了一个包含10,820张图像、涵盖7类紧急物体的空中紧急响应数据集。
2.  **系统比较了两种轻量模型**：在自建数据集上，对YOLOv4-Tiny和YOLOv5-small进行了全面的性能比较，不仅关注精度指标（mAP， F1），更强调了系统级指标（推理时间、FPS、模型大小、功耗）。
3.  **验证了后训练量化技术的有效性**：成功将YOLOv4-Tiny模型从FP32量化为INT8，在模型大小从22.5MB降至6.4MB（降幅71%）的同时，仅引入微小的精度损失和推理时间增加。
4.  **在实际边缘硬件上进行了验证**：在树莓派5上部署并测试了量化模型，使用USB功率计测量实际功耗，证明了其在真实嵌入式环境下的低功耗特性（平均功耗降低59%以上）。
5.  **建立了一个基准评估框架**：为在时间敏感、计算受限的环境中选择轻量级检测模型提供了一个可复现的基准框架。
## 方法

- **整体框架**：研究流程包括：自定义数据集准备 -> 模型选择与训练（YOLOv4-Tiny 和 YOLOv5-small） -> 模型评估与对比 -> 选定最优模型（YOLOv4-Tiny） -> 应用后训练量化 -> 在边缘设备（树莓派5）上评估量化模型的性能和功耗。
- **输入输出**：
    - **输入**：分辨率统一为416×416像素的RGB空中图像。
    - **输出**：物体的类别、边界框坐标和置信度分数。
- **关键模块与架构**：
    - **YOLOv4-Tiny**：选用此模型是因为其作为YOLOv4的压缩版本，在检测精度和计算效率之间取得了良好平衡。
        - **骨干网络（Backbone）**：CSPDarknet53-tiny，用于提取层次化特征。
        - **颈部模块（Neck）**：PANet（路径聚合网络），用于特征融合。
        - **检测头（Head）**：在两个不同尺度上预测边界框和类别概率。
    - **对比模型YOLOv5-small**：基于PyTorch实现，精度略高但模型尺寸和计算需求相对更大。
- **训练方式**：
    - 两个模型使用相同配置从头训练。
    - **关键超参数**：批量大小16，学习率0.001（带余弦衰减），优化器SGD，损失函数为二元交叉熵（目标性和分类）和均方误差（边界框回归）。
    - 采用早停和基于验证损失的模型检查点策略以防止过拟合。
- **推理流程与量化机制**：
    - **量化方法**：后训练静态量化。使用ONNX Runtime工具进行。
    - **量化步骤**：1) 将PyTorch模型转换为ONNX格式；2) 使用100张代表性图像生成校准数据；3) 通过ONNX Runtime API应用静态量化；4) 保存为INT8 ONNX文件。
    - **作用机制**：将模型权重和激活值从32位浮点数（FP32）转换为8位整数（INT8），从而大幅减少内存占用并利用硬件的INT8计算单元加速推理。
- **与已有方法的差异**：
    - 相较于依赖通用公开数据集的先前工作，本文**自建了针对性更强的紧急响应数据集**。
    - 研究不仅比较模型精度，**更系统地评估了FPS、功耗等对边缘部署至关重要的指标**，并进行了**真实的嵌入式硬件验证**。
## 实验

- **使用的数据集**：自建的**空中紧急响应数据集**，包含10,820张标注图像，涵盖救护车、警车、消防车、着火车、车祸、拖车和翻倒车7个类别。图像来自无人机视频、在线航空数据集和合成增强数据。数据集按80%训练、10%验证、10%测试划分。
- **对比方法**：YOLOv5-small。
- **评价指标**：mAP@0.5， 精确率（Precision）， 召回率（Recall）， F1分数， 推理时间， FPS， 模型大小， 平均功耗（W）。
- **主实验结果**：
    - **模型对比（FP32精度）**：
        - **YOLOv5-small**：mAP@0.5 87.1%， F1 0.88， 推理时间43ms， FPS 15.8， 模型大小22.5MB， 功耗46.3W。
        - **YOLOv4-Tiny**：mAP@0.5 85.6%， F1 0.84， 推理时间39ms， FPS 25.6， 模型大小14.5MB， 功耗33.8W。
        - **结论**：YOLOv5-small精度略高，但YOLOv4-Tiny在速度、模型大小和功耗上优势明显。
    - **量化结果（YOLOv4-Tiny INT8 vs FP32）**：
        - **模型大小**：从22.5MB降至**6.4MB**（降幅71%）。
        - **推理时间**（树莓派5）：从25.5ms增至28.2ms（增加2.7ms）。
        - **功耗**（树莓派5）：平均功耗从33.67W降至**13.85W**（降幅59%），最大功耗从63.43W降至22.34W（降幅65%），RMS功耗从41.06W降至14.92W。
