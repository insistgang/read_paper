## 研究背景与动机

- **为什么做**：红外图像能突出热目标但缺乏细节，可见光图像细节丰富但易受环境影响。融合两者可获得信息更全面的图像，广泛应用于目标追踪、自动驾驶等领域。
- **之前方法的问题**：
    1.  **传统方法**（如多尺度变换、稀疏表示）：严重依赖人工设计的特征提取和融合规则，特征通用性差。
    2.  **基于深度学习的方法**：特别是基于CNN的方法，由于卷积操作的局部感受野限制，**无法有效提取图像中的全局上下文信息**；同时，常见的简单特征拼接策略会导致**融合过程不充分，信息丢失**。
- **核心矛盾**：如何同时有效地提取图像的局部细节信息和全局结构信息，并在此基础上设计一个能充分融合这些互补信息的机制。
## 关键贡献

1.  **设计了基于通道注意力的视觉Transformer模块**：将多头转置注意力（MDTA）模块与通道注意力（SE）模块串联，组成用于提取全局特征的Transformer模块。MDTA通过在通道维度计算自注意力，解决了自注意力计算量随图像尺寸呈平方增长的问题。
2.  **构建了局部-全局特征提取模块（LGFE）**：将CNN与所设计的视觉Transformer并联。CNN分支（类似DenseNet）提取局部细节特征，Transformer分支提取全局上下文特征，使最终特征兼具通用性和全局性。
3.  **提出了分组渐进式融合模块（GPF）**：将输入特征图在通道维度分组，先对同组特征进行初步融合，再通过一种渐进残差结构逐步融合不同组的特征。这种分层结构能在融合过程中体现多尺度性，减少信息丢失。
4.  **设计了端到端的无监督训练策略**：采用结构相似性损失、均方误差损失和感知损失的组合作为总损失函数，从像素、结构和特征三个层面约束融合图像与源图像的一致性。
5.  **在多个数据集上取得SOTA性能**：在TNO和RoadScene数据集上，本文方法在NMI、QNICE、AG、SD等多个指标上超越了6种主流对比方法，定性结果也显示其能更好地突出红外目标、保留细节纹理并提升对比度与清晰度。
## 方法

- **整体框架**：如图1所示，网络为端到端结构。输入为配对的红外图像和可见光图像，输出为融合图像。两条独立且参数不共享的支路分别处理两种模态的图像。每条支路先通过卷积块提取浅层特征，然后通过**局部-全局特征提取模块（LGFE）** 获得深层特征，再将两个支路的特征送入**分组渐进式融合模块（GPF）** 进行融合，最后通过解码器（三个卷积块）生成融合图像。
- **输入输出**：输入为原始红外和可见光图像对。输出为单通道（文中未明确说明，但融合图像通常为灰度或伪彩色）的融合图像。
- **关键模块**：
    1.  **局部-全局特征提取模块（LGFE）**：
        - **局部细节分支**：采用密集连接（DenseBlock）结构，每一层的输入是之前所有层输出的拼接，用于学习原始的、细粒度的纹理细节。
        - **全局结构信息分支**：核心是**视觉Transformer**。它由**MDTA模块**和**SE模块**串联构成。
            - **MDTA（多头转置注意力）**：输入特征图`X`，通过1x1卷积和3x3深度可分离卷积生成Q、K、V。关键操作是**在通道维度上计算自注意力**：将Q和K变形后相乘，得到通道间的相关性矩阵`A∈R^{C×C}`，而不是空间上的`HW×HW`矩阵，从而大幅降低计算复杂度。输出是通道间全局依赖加权后的特征。
            - **SE（通道注意力）**：对MDTA的输出进行全局平均池化和两层卷积（含激活函数），生成通道权重，再对特征进行加权，进一步强化通道维度上的显著特征。
    2.  **分组渐进式融合模块（GPF）**：
        - **输入**：两个支路的LGFE输出特征图`Y_I`和`Y_V`。
        - **过程**：
            1.  将`Y_I`和`Y_V`通过1x1卷积后，沿通道维度平均分为`s`组（文中s=4），得到`Y_I^i`和`Y_V^i`。
            2.  对每组i，将`Y_I^i`和`Y_V^i`拼接后通过一个卷积块`Conv_i`，得到该组的初步融合特征`z_i`。
            3.  进行**渐进融合**：`Z_1 = z_1`；对于`i=2`，`Z_i = Conv_i^F(cat(z_i, z_{i-1}))`；对于`i>2`，`Z_i = Conv_i^F(cat(z_i, Z_{i-1}))`。这里`Z_{i-1}`包含了前`i-1`组已融合的信息。
            4.  最终将所有`Z_i`拼接，得到融合特征`M`。
        - **直观解释**：该模块不是简单地将所有特征拼接融合，而是先分组处理，再通过一个类似残差的连接（`cat(z_i, Z_{i-1})`）进行跨组信息交换和逐步融合，使得融合过程更充分，并隐含了多尺度感受野的融合。
- **训练方式**：
    - **损失函数**：总损失`L_T = L_S + λ1 L_M + λ2 L_P`（`λ1=10, λ2=1`）。
        - `L_S`（结构相似性损失）：计算融合图像`I_F`与红外`I_I`和可见光`I_V`的结构相似性。
        - `L_M`（均方误差损失）：仅计算`I_F`与`I_I`之间的像素级MSE，以重点保留红外像素强度信息。
        - `L_P`（感知损失）：利用预训练VGG-19提取的多个特征图，计算`I_F`分别与`I_I`、`I_V`在特征空间的MSE。
    - **训练数据**：从TNO数据集中选20对，裁剪成128x128图像块，得到30360对训练数据。
    - **优化器**：Adam，初始学习率0.0001，自适应学习率下降。
- **推理流程**：输入一对红外和可见光图像，直接通过前向传播得到融合图像，无需后处理。
- **与已有方法的差异**：
    1.  **特征提取**：与纯CNN方法（如DenseFuse）相比，增加了全局特征提取能力；与在空间维度做自注意力的Transformer方法（如CGTF, SwinFusion）相比，本文在**通道维度**计算自注意力，计算效率更高，且对输入尺寸更灵活。
    2.  **特征融合**：摒弃简单的拼接或加权平均，采用**分组渐进式融合**，融合更充分。
    3.  **训练范式**：端到端无监督训练，直接优化像素、结构和感知损失，无需预先训练分类网络或手动设计融合规则。

        - **全局结构信息分支**：核心是**视觉Transformer**。它由**MDTA模块**和**SE模块**串联构成。
            - **MDTA（多头转置注意力）**：输入特征图`X`，通过1x1卷积和3x3深度可分离卷积生成Q、K、V。关键操作是**在通道维度上计算自注意力**：将Q和K变形后相乘，得到通道间的相关性矩阵`A∈R^{C×C}`，而不是空间上的`HW×HW`矩阵，从而大幅降低计算复杂度。输出是通道间全局依赖加权后的特征。
            - **SE（通道注意力）**：对MDTA的输出进行全局平均池化和两层卷积（含激活函数），生成通道权重，再对特征进行加权，进一步强化通道维度上的显著特征。
    2.  **分组渐进式融合模块（GPF）**：
        - **输入**：两个支路的LGFE输出特征图`Y_I`和`Y_V`。
        - **过程**：
            1.  将`Y_I`和`Y_V`通过1x1卷积后，沿通道维度平均分为`s`组（文中s=4），得到`Y_I^i`和`Y_V^i`。
            2.  对每组i，将`Y_I^i`和`Y_V^i`拼接后通过一个卷积块`Conv_i`，得到该组的初步融合特征`z_i`。
            3.  进行**渐进融合**：`Z_1 = z_1`；对于`i=2`，`Z_i = Conv_i^F(cat(z_i, z_{i-1}))`；对于`i>2`，`Z_i = Conv_i^F(cat(z_i, Z_{i-1}))`。这里`Z_{i-1}`包含了前`i-1`组已融合的信息。
            4.  最终将所有`Z_i`拼接，得到融合特征`M`。
        - **直观解释**：该模块不是简单地将所有特征拼接融合，而是先分组处理，再通过一个类似残差的连接（`cat(z_i, Z_{i-1})`）进行跨组信息交换和逐步融合，使得融合过程更充分，并隐含了多尺度感受野的融合。
- **训练方式**：
    - **损失函数**：总损失`L_T = L_S + λ1 L_M + λ2 L_P`（`λ1=10, λ2=1`）。
        - `L_S`（结构相似性损失）：计算融合图像`I_F`与红外`I_I`和可见光`I_V`的结构相似性。
        - `L_M`（均方误差损失）：仅计算`I_F`与`I_I`之间的像素级MSE，以重点保留红外像素强度信息。
        - `L_P`（感知损失）：利用预训练VGG-19提取的多个特征图，计算`I_F`分别与`I_I`、`I_V`在特征空间的MSE。
    - **训练数据**：从TNO数据集中选20对，裁剪成128x128图像块，得到30360对训练数据。
    - **优化器**：Adam，初始学习率0.0001，自适应学习率下降。
- **推理流程**：输入一对红外和可见光图像，直接通过前向传播得到融合图像，无需后处理。
- **与已有方法的差异**：
    1.  **特征提取**：与纯CNN方法（如DenseFuse）相比，增加了全局特征提取能力；与在空间维度做自注意力的Transformer方法（如CGTF, SwinFusion）相比，本文在**通道维度**计算自注意力，计算效率更高，且对输入尺寸更灵活。
    2.  **特征融合**：摒弃简单的拼接或加权平均，采用**分组渐进式融合**，融合更充分。
    3.  **训练范式**：端到端无监督训练，直接优化像素、结构和感知损失，无需预先训练分类网络或手动设计融合规则。
