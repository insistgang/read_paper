## 摘要

本文提出了一种名为CGT（CNN-GRU Transformer）的网络入侵检测方法，该方法首先通过融合了邻域清理规则、边界合成少数类过采样和Wasserstein生成对抗网络的NBW模型对不平衡数据集进行平衡处理，然后利用CNN-GRU模块同时提取空间与序列特征，并结合改进的Transformer编码器来建模特征间全局关系，从而显著提升了入侵检测的性能。
## 研究背景与动机

- **为什么要做**：随着网络技术（尤其在军事和物联网领域）的发展，网络攻击日益频繁和复杂。入侵检测系统（IDS）是保障网络安全的重要主动防御手段。然而，现实网络流量中正常数据远多于攻击数据（即类别不平衡），这导致基于传统机器学习或深度学习的检测模型倾向于忽略数量少的攻击类别（如U2R），但这些少数类攻击的正确检测对安全至关重要。
- **之前方法的问题**：现有研究尝试通过采样方法（如随机欠采样、SMOTE）解决数据不平衡问题，但存在缺陷。例如，随机采样可能丢失多数类中的重要信息；SMOTE算法在边界处生成样本可能引入噪声或导致“边缘分布”问题。同时，常用的循环神经网络（如BiLSTM）主要关注时序特征，但对网络流量中同样重要的局部空间特征（由卷积神经网络CNN擅长提取）捕捉不足，且参数量较大。
- **核心矛盾**：需要一种既能有效平衡少数类与多数类数据（避免信息丢失和噪声引入），又能同时高效提取数据空间特征和时序特征，进而捕获复杂特征间关联的入侵检测方法，以应对复杂网络环境下的攻击检测挑战。
## 关键贡献

1.  **提出NBW（Neighbourhood-cleaning-rule Borderline-SMOTE WGAN）数据平衡处理模型**：该模型融合了NCR欠采样、Borderline-SMOTE过采样和WGAN生成对抗网络，能够自动学习少数类数据分布，生成多样化且质量较高的攻击样本，避免传统采样方法的信息丢失和边缘分布问题。
2.  **设计CNN-GRU特征提取模块**：将卷积神经网络（CNN）与门控循环单元（GRU）并行结合，CNN用于提取网络流量数据的局部空间特征，GRU用于捕捉时序依赖关系，实现了对数据空间和时序信息的同步提取。
3.  **改进Transformer模块并融合**：仅使用Transformer的编码器部分，并对其参数进行调整以适应一维网络流量数据，通过多头自注意力机制建立不同特征之间的长距离依赖关系。
4.  **构建CGT（CNN-GRU Transformer）入侵检测模型**：将NBW数据平衡、CNN-GRU特征提取、改进的Transformer和MLP分类器整合为一个端到端的模型，在NSL-KDD数据集上验证了其有效性。
5.  **实验证明方法有效性**：在二分类和五分类任务上，经过NBW平衡数据后训练的CGT模型，在准确率、召回率、F1分数等多个指标上均优于未平衡的CGT模型及其他传统机器学习和深度学习模型。
## 方法

- **整体框架**：如图1所示，整个方法分为两大部分：**NBW数据平衡处理**和**CGT模型训练与推理**。原始训练集先经过NBW模型生成平衡数据集，再输入CGT模型进行训练；测试集则直接输入训练好的CGT模型进行推理。
- **输入输出**：
    - **输入**：原始网络流量样本，每个样本由43种特征构成的一维向量。
    - **输出**：二分类（正常/异常）或多分类（Normal, DOS, Probing, R2L, U2R）结果。
- **关键模块与连接**：
    1.  **NBW数据平衡模块**（p.21-22）：
        - **流程**：原始数据 `(X, Y)` → **NCR欠采样**（移除多数类中的噪声/边缘样本）→ **Borderline-SMOTE过采样**（仅在少数类的Danger区域样本附近生成新样本）→ 得到 `(X_n,s, Y)`。
        - **WGAN增强**：将 `(X_n,s, Y)` 中真实少数类样本 `(X_r, Y_m)` 与随机噪声 `X_N` 输入WGAN的**生成器（Generator）** 和**判别器（Discriminator）** 进行对抗训练。训练完成后，生成器能生成高质量的合成少数类样本 `(X_g, Y)`。
        - **输出**：将 `(X_n,s, Y)` 和 `(X_g, Y)` 合并，得到平衡后的最终训练数据集 `Data`。
    2.  **CGT特征提取与分类模块**：
        - **CNN-GRU模块**（p.22）：
            - **并行结构**：平衡数据 `Data` 中的一个样本向量 `X` 分两条路径并行处理。
            - **CNN路径**：`X` 通过一个包含两个卷积层（后接批归一化和ReLU激活）的卷积块，提取**局部空间特征**。
            - **GRU路径**：将 `X` 在时间维度转置后，输入两个GRU层，提取**时序依赖特征**。
            - **融合**：将CNN和GRU输出的特征图进行降维并**拼接（concat）**，形成融合了时空信息的特征表示。
        - **改进的Transformer编码器模块**（p.23）：
            - **作用**：接收CNN-GRU拼接后的特征，利用**多头自注意力机制**捕获特征之间的全局依赖关系。
            - **关键机制**：计算Query (Q), Key (K), Value (V) 之间的点积注意力：`Attention(Q,K,V) = softmax(QK^T / sqrt(d_K)) V`。多头注意力将Q, K, V通过线性变换投影到多个子空间并行计算，再拼接结果，增强了模型对不同表示子空间的学习能力。
            - **改进**：仅使用编码器部分，并调整参数以适应输入维度。前馈神经网络中，隐藏层神经元数设为输入层的两倍，并使用GELU激活函数以增强非线性表达能力。
        - **MLP分类模块**（p.24）：由两个全连接层和一个Dropout层组成。Dropout层用于防止过拟合。最后通过Softmax回归器输出各类别的概率。
- **训练与推理**：
    - **训练**：使用**Adam优化器**更新模型参数。超参数经过调优确定，如batch_size=64，learning_rate=0.001，Dropout=0.5，注意力头数=16等（见表4）。
    - **推理**：测试样本依次通过NBW处理（若为原始数据则跳过此步，但本文实验使用平衡后的数据训练，测试集未说明是否经过NBW）、CNN-GRU模块、Transformer编码器、MLP模块，最终得到分类结果。
- **与已有方法的差异**：
    - 相比于只使用LSTM/BiLSTM的模型，CGT通过CNN显式地提取了空间特征。
    - 相比于只使用CNN或只使用Transformer的模型，CGT结合了GRU的时序建模能力和Transformer的全局关系建模能力。
    - 相比于传统的SMOTE过采样，NBW模型结合了WGAN，能生成更真实、多样的少数类样本。
- **论文类型特化**：本文属于**检测类**方法。其**backbone**为CNN-GRU与Transformer编码器的组合，**head**为MLP+Softmax分类器。核心创新在于融合了处理不平衡数据的预处理模块（NBW）和同时具备空间-时序-全局注意力特征提取能力的混合主干网络（CGT），旨在解决入侵检测中**数据类别不平衡**和**多类型特征提取**两个关键问题。
## 实验

- **数据集**：**NSL-KDD**数据集。训练集使用**KDDTrain+_20Percent**（20%的样本，便于快速实验），测试集使用**KDDTest+**（共22,544条数据）。数据包含41种特征和1种标签，标签分为5类：Normal, DOS, Probing, R2L, U2R。原始训练集类别严重不平衡（如U2R仅52个样本），测试集不平衡情况不同（表1）。
- **对比方法**：传统机器学习模型：LR, KNN, DT, AB, RF, SVM。将这些模型分别在**原始数据**和**NBW平衡后的数据**上进行训练，与本文的CGT和NBW+CGT进行比较。
- **评价指标**：准确率（Acc）、查准率（Pre）、召回率（Rec）、F1分数（F1）。
- **主实验结果**（表5）：
    - **数据平衡的有效性**：所有模型（包括CGT）在使用NBW平衡后的数据训练后，性能均显著提升。例如，LR模型的二分类准确率从72.8%提升至84.7%（提升约12%）。
    - **模型有效性**：在平衡数据上，**NBW+CGT模型表现最佳**。
        - **二分类任务**：准确率 **93.4%**，召回率 **96.8%**，F1分数 **94.3%**。相较于次优的NBW+LR模型（F1 86.5%），F1分数提升了约7.8个百分点。
        - **五分类任务**：准确率 **82.5%**，召回率 **65.5%**，F1分数 **69.1%**。相较于次优的NBW+RF模型（F1 53.7%），F1分数提升了约15.4个百分点。
- **消融实验**：论文通过对比“未使用NBW的CGT”与“使用NBW的CGT”以及其他模型，间接证明了NBW数据平衡模块和CGT模型架构两个核心组件的有效性。**PDF文本中未找到更细致的、移除单个模块（如去掉GRU或Transformer）的消融实验**。

## 局限

1.  **U2R类检测难题未根本解决**：尽管使用了NBW模型，但U2R类的检测效果在多分类中仍然最差（从混淆矩阵图4可见，大量U2R样本被误判为Normal）。这说明对于极度稀缺（原始52个样本）且特征复杂的攻击类型，单纯的数据增强可能不够，需要结合少数类学习、代价敏感学习或异常检测等其他策略。
2.  **实验不够全面**：实验仅在NSL-KDD一个经典数据集上进行，该数据集相对老旧（1999年）。未在更新、更接近真实现代网络环境的数据集（如CICIDS2017, UNSW-NB15）上验证模型的泛化能力。
3.  **计算成本未探讨**：模型融合了CNN、GRU、Transformer和WGAN，结构相对复杂，训练和推理的计算成本可能较高。论文未讨论模型的效率问题，如参数量、训练时间、是否适合实时检测等。
4.  **特征工程缺失**：论文在结论中提到“实验并未对样本的特征进行提取选择”。直接使用原始41个特征可能包含冗余或不相关信息，影响模型性能和效率。
5.  **复现风险**：论文提供了部分超参数，但WGAN的训练细节、NCR和Borderline-SMOTE的具体应用阈值等关键实现细节可能不完整，给精确复现带来挑战。
## 个人评论

1.  **系统性的解决方案**：论文没有只关注模型架构或只关注数据问题，而是将**数据平衡处理（NBW）** 与**特征提取模型（CGT）** 有机结合，提出了一个针对类别不平衡入侵检测问题的系统性解决方案。这种“数据+模型”协同优化的思路值得借鉴。
2.  **NBW数据平衡模型的构建逻辑**：NBW模型的设计思路清晰：先用NCR和Borderline-SMOTE进行“粗处理”以提升数据质量并初步平衡，再利用WGAN进行“精生成”以创造高质量、多样化的少数类样本。这种分阶段、利用不同技术优势的融合策略，为解决不平衡学习问题提供了具体范例。
3.  **混合特征提取架构的启示**：CNN-GRU并行提取空间和时序特征，再用Transformer建模全局关系，这种架构组合充分利用了不同神经网络的优势，对于处理像网络流量这样兼具局部相关性和序列依赖性的数据非常有效。这启发研究者可以打破单一网络类型的限制，进行创新性的模块组合。

        - **WGAN增强**：将 `(X_n,s, Y)` 中真实少数类样本 `(X_r, Y_m)` 与随机噪声 `X_N` 输入WGAN的**生成器（Generator）** 和**判别器（Discriminator）** 进行对抗训练。训练完成后，生成器能生成高质量的合成少数类样本 `(X_g, Y)`。
        - **输出**：将 `(X_n,s, Y)` 和 `(X_g, Y)` 合并，得到平衡后的最终训练数据集 `Data`。
    2.  **CGT特征提取与分类模块**：
        - **CNN-GRU模块**（p.22）：
            - **并行结构**：平衡数据 `Data` 中的一个样本向量 `X` 分两条路径并行处理。
            - **CNN路径**：`X` 通过一个包含两个卷积层（后接批归一化和ReLU激活）的卷积块，提取**局部空间特征**。
            - **GRU路径**：将 `X` 在时间维度转置后，输入两个GRU层，提取**时序依赖特征**。
            - **融合**：将CNN和GRU输出的特征图进行降维并**拼接（concat）**，形成融合了时空信息的特征表示。
        - **改进的Transformer编码器模块**（p.23）：
            - **作用**：接收CNN-GRU拼接后的特征，利用**多头自注意力机制**捕获特征之间的全局依赖关系。
            - **关键机制**：计算Query (Q), Key (K), Value (V) 之间的点积注意力：`Attention(Q,K,V) = softmax(QK^T / sqrt(d_K)) V`。多头注意力将Q, K, V通过线性变换投影到多个子空间并行计算，再拼接结果，增强了模型对不同表示子空间的学习能力。
            - **改进**：仅使用编码器部分，并调整参数以适应输入维度。前馈神经网络中，隐藏层神经元数设为输入层的两倍，并使用GELU激活函数以增强非线性表达能力。
        - **MLP分类模块**（p.24）：由两个全连接层和一个Dropout层组成。Dropout层用于防止过拟合。最后通过Softmax回归器输出各类别的概率。
- **训练与推理**：
    - **训练**：使用**Adam优化器**更新模型参数。超参数经过调优确定，如batch_size=64，learning_rate=0.001，Dropout=0.5，注意力头数=16等（见表4）。
    - **推理**：测试样本依次通过NBW处理（若为原始数据则跳过此步，但本文实验使用平衡后的数据训练，测试集未说明是否经过NBW）、CNN-GRU模块、Transformer编码器、MLP模块，最终得到分类结果。
- **与已有方法的差异**：
    - 相比于只使用LSTM/BiLSTM的模型，CGT通过CNN显式地提取了空间特征。
    - 相比于只使用CNN或只使用Transformer的模型，CGT结合了GRU的时序建模能力和Transformer的全局关系建模能力。
    - 相比于传统的SMOTE过采样，NBW模型结合了WGAN，能生成更真实、多样的少数类样本。
