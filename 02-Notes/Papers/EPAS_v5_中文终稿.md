## 摘要

本文提出了一个名为E-PAS v5的隐私保护事件触发平均共识框架，通过结合截断高斯机制的本地差分隐私（TGM-LDP）、自回归预测和自适应事件触发机制，在保证ε-差分隐私的前提下，显著降低了分布式共识的通信能耗与碳排放（εglobal=1.0时，MSE=0.047，能耗降低39.4%，碳排放为138 t CO₂/百万用户/年）。
## 研究背景与动机

- **为什么要做**：AI与物联网（IoT）的广泛应用导致计算与通信能耗剧增，分布式传感器网络（DSN）作为关键基础设施，其低能耗运行至关重要。在数据融合与共识过程中，节点间的原始数据交换存在隐私泄露风险。
- **之前方法的问题**：
    - 传统隐私保护方法（如Nozari等人的LDP）会导致估计误差（MSE）随时间增长，因为加入的隐私噪声方差可能随时间累积而增大（T* = Ω(1/(ε²δ²))）。
    - 传统事件触发或周期性通信方法可能无法兼顾隐私保护和能效优化。
- **核心矛盾**：需要在**隐私保护强度**、**通信能耗/碳排放**和**共识精度（MSE）**三者之间取得平衡。论文旨在设计一个系统框架，同时优化这三个相互制约的目标。
## 关键贡献

1.  **提出了E-PAS v5框架**：一个集成了四个核心模块的隐私保护事件触发平均共识算法：TGM-LDP（隐私）、ECP（能耗感知预测）、ACG（自适应增益）和AET（自适应事件触发）。
2.  **提供了严格的理论分析**：证明了在满足特定条件下，算法的MSE以指数速率收敛，并给出了隐私预算εtotal,i ≤ εglobal的证明。
3.  **证明了遍历性保证**：通过引入Birkhoff遍历定理，确保了事件触发机制在系统稳定后具有确定性的触发频率上界（fi ≤ 1/(K_max + M_step/θ*)），从而避免了“芝诺行为”。
4.  **展示了显著的效率提升**：仿真实验表明，在全局隐私预算εglobal=1.0时，E-PAS相比Privacy-aware方法，MSE从>5.0降至0.047，能耗从12800降至1410（单位未明确，p.4），实现了通信事件数和能耗的大幅降低。
5.  **实现了碳排放量化**：结合能效模型，将能耗降低直接换算为碳排放减少（约138 t CO₂/百万用户/年）。
6.  **提出了新的隐私-能耗-精度权衡分析**：通过公式(17)揭示了能耗比δE对MSE的影响，即δE→0时MSE收敛，δE→1时MSE发散。
## 方法

- **整体框架**：E-PAS v5框架如下图所示（论文中图1），包含TGM-LDP、ECP、ACG、AET四个核心模块，分别负责隐私保护、状态预测、控制增益计算和通信事件触发。
- **输入输出**：输入为各节点i的本地状态xi(t)；输出为经过隐私保护和事件触发优化后，各节点对网络平均状态的一致估计。
- **关键模块与连接**：
    1.  **TGM-LDP模块**：对节点原始状态xi添加截断高斯噪声wi，生成隐私保护状态˜xi = xi + wi。噪声方差σ²i(t)由隐私参数εi(t)和截断边界B决定（公式(2): σ²i(t) = C²i/(2ε²i(t) * 1/R(B/σi))），其中R(z)=Φ(z)-Φ(-z)，当B≥3σi时，R≈0.997，隐私损失<0.3%。
    2.  **ECP模块**：采用自回归（AR）模型对邻居节点的历史隐私状态进行预测，得到预测值ˆxj(t)，以减少通信。同时，AR模型的使用引入了额外的估计误差νj(t)（公式(3)）。
    3.  **ACG模块**：基于预测的邻居状态与本地隐私状态的差异，自适应地计算控制输入ui(t)（公式(5)）。共识增益κi(t)根据本地隐私噪声方差、通信延迟和能耗进行动态调整（公式(6)）。
    4.  **AET模块**：定义了两个事件触发条件：状态变化超过阈值（公式(7)）或超过最大等待时间K_max（公式(8)）。只有触发事件时，节点才广播其隐私状态。阈值θi(t)也进行自适应调整。
- **与已有方法的差异**：
    - 相比Nozari等人的纯LDP方法，E-PAS通过AR预测和事件触发机制，显著减少了通信次数和能耗。
    - 相比传统的事件触发共识，E-PAS集成了强隐私保护（ε-LDP）和能效优化。
    - 引入Birkhoff遍历定理来严格分析事件触发频率，是方法上的一个理论创新点。
## 实验

- **数据集**：合成网络。节点数N ∈ {50, 100, 200, 500}。网络拓扑包括Erdős–Rényi图（连接概率p=0.3）和Watts–Strogatz小世界图（平均度6，重连概率0.1）。
- **对比方法**：
    1.  Periodic：周期性通信。
    2.  Standard ET：标准事件触发。
    3.  Privacy-aware：仅考虑隐私（TGM-LDP）和AR预测。
    4.  Energy-aware：仅考虑能耗优化（无隐私保护）。
    5.  E-PAS：本文方法。
- **评价指标**：均方误差（MSE）、通信事件数、能耗。能耗模型考虑了通信开销（PTX+PRX）和计算开销（隐私噪声和输入控制）。
- **主实验结果**（N=100, εglobal=1.0）：
    - **MSE**：E-PAS为0.047±0.006，远低于Privacy-aware的>5.0。
    - **通信事件数**：E-PAS为1410±95，而Privacy-aware为12800±340，Periodic为15000。
    - **能耗**：E-PAS为0.394，Privacy-aware为0.923。
- **消融实验**：
    - 研究了最大等待时间K_max和能耗比δE对MSE的影响（图6）。结果表明存在最优的K_max值，且MSE随δE的增加而增加。
    - 验证了AR预测误差上界Lx，实验测得值（≈0.025）与理论值（0.028）接近（图5）。
- **泛化实验**：在不同网络规模（N=50,100,200,500）下，E-PAS的MSE保持稳定（从0.052到0.039），且通信事件占比均低于91.2%（p.4, 表II）。
- **鲁棒性测试**：在40%的高丢包率和300ms的延迟下，E-PAS的MSE为0.097，仍能保持稳定共识（p.5, 图7）。
## 局限

1.  **假设依赖**：理论分析依赖于网络连通性（存在λ2(¯L)>0）、扰动有界（∥di∥≤dmax）和噪声有界（|wi|≤B）等假设，在实际异构或高度动态网络中可能受限。
2.  **实验数据**：所有实验均在合成数据上进行，未在真实传感器网络或物联网设备上验证。模型中的能耗参数（PTX, PRX）和隐私参数（C）需要针对具体硬件设定。
3.  **计算开销**：AR预测和事件触发检测本身会引入额外的计算和存储开销，论文中未详细评估这部分开销对资源受限节点的影响。
4.  **参数调优**：框架包含多个可调参数（如K_max, λ1, λ2, λ3, θmin等），如何为不同应用场景设定最优参数是一个挑战。
5.  **扩展性**：当前分析针对静态网络拓扑。对于节点加入/离开或链路频繁变化的动态拓扑场景，其性能需要进一步研究。
