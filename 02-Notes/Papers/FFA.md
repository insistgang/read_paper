## 研究背景与动机

- **为什么要做**: 图像去雾是计算机视觉的基础任务，有雾图像会导致后续高级视觉任务（如分类、检测）性能下降。基于物理模型的方法（如暗通道先验DCP）依赖先验假设，容易失效；而早期的深度学习方法简单地将通道和像素特征同等对待。
- **之前方法的问题**: 1) 先验方法在场景物体颜色接近大气光或先验假设不成立时效果不佳。2) 现有的CNN去雾网络未考虑雾在图像中分布不均匀（薄雾与厚雾区域）以及不同颜色通道特征重要性不同这两个关键事实，导致网络资源分配不合理，限制了其表征能力。
- **核心矛盾**: **雾的不均匀分布**与**现有网络对特征和像素的平等对待**之间的矛盾。作者希望网络能自适应地关注更重要的信息（如厚雾区域、关键通道）。
## 关键贡献

1.  **提出了端到端的特征融合注意力网络 (FFA-Net)**：该网络在单图像去雾任务上，在定量和定性上都以显著优势超越了先前最好的方法。
2.  **提出了特征注意力 (FA) 模块**：该模块创新性地结合了**通道注意力 (CA)** 和**像素注意力 (PA)** 机制，使网络能以不同权重对待不同的通道特征和像素区域，特别增强了对厚雾像素和重要通道信息的关注。
3.  **提出了由局部残差学习和特征注意力组成的基础块结构**：局部残差连接允许薄雾区域或低频信息绕过主网络，使网络主体专注于更有效的信息，同时结合FA模块提升网络能力。
4.  **提出了基于注意力的特征融合 (FFA) 结构**：该结构能保留浅层特征信息并传递到深层，最关键的是，它能利用FA模块自适应地学习不同层级特征的权重，实现比直接指定权重更好的融合效果。
## 方法

- **整体框架**：如图2所示，FFA-Net的输入是**有雾图像**。它首先经过一个**浅层特征提取**部分，然后进入**N个组结构 (Group Architecture)**，每个组结构的输出通过**跳跃连接**传递。所有组结构的输出在通道维度拼接后，通过**特征融合注意力模块**进行自适应加权融合。融合后的特征进入**重建部分**（两层卷积），并与输入图像通过**全局残差学习**相加，最终输出**无雾图像**。
- **输入输出**：输入为一张有雾的RGB图像，输出为恢复后的无雾RGB图像。
- **关键模块**：
    1.  **特征注意力 (FA) 模块**（图3）：
        - **通道注意力 (CA)**：通过全局平均池化聚合每个通道的空间信息得到通道描述符，再通过两层卷积（带ReLU和Sigmoid）学习通道权重 `CAc`，与输入特征 `Fc` 相乘得到加权后的通道特征 `Fc*`。公式：`gc = Hp(Fc)`，`CAc = σ(Conv(δ(Conv(gc))))`，`Fc* = CAc * Fc` (p.4)。
        - **像素注意力 (PA)**：将通道加权后的特征 `Fc*` 送入两层卷积学习空间像素权重 `PA`（形状为1xHxW），再与 `Fc*` 相乘，得到FA模块最终输出 `F̃`。公式：`PA = σ(Conv(δ(Conv(Fc*))))`，`F̃ = Fc* * PA` (p.4)。直观上，PA使网络更关注厚雾区域和图像边缘纹理等高频信息（图4）。
    2.  **基础块结构**（图6）：由多个**局部残差学习**连接和一个**FA模块**构成。局部残差允许次要信息（薄雾、低频）直接绕过卷积层，使主网络专注于提取关键特征。
    3.  **组结构与全局残差学习**：一个组结构包含 **B个基础块**，基础块之间通过局部残差连接。整个网络有**G个组结构**。在所有组结构输出融合后，通过一个重建网络（卷积层），并与原始输入进行**全局残差学习**来生成最终结果。
    4.  **特征融合注意力 (FFA)**：将G个组结构的输出在通道维度拼接，然后利用一个独立的**FA模块**学习出针对这个拼接特征的**通道和像素权重**，对拼接特征进行加权融合，再送入重建部分。这使得网络能保留浅层信息，并让深层网络更关注重要特征。
- **模块连接方式**：FA模块插入在每个基础块内部；基础块堆叠成组结构；组结构之间通过跳跃连接传递原始特征；所有组结构的输出汇聚到FFA结构。
- **训练方式**：
    - **损失函数**：使用L1损失，即输出与清晰图像Ground Truth之间的平均绝对误差 (p.5)。
    - **优化器**：Adam优化器 (β1=0.9, β2=0.999)。
    - **学习率策略**：采用余弦退火策略，学习率从初始值 `1e-4` 随训练步数余弦衰减至0 (p.6)。
    - **数据增强**：随机旋转（90， 180， 270度）和水平翻转。
- **推理流程**：给定一张有雾图像，直接输入训练好的FFA-Net，端到端地输出去雾后的图像，无需估计中间的大气光或透射图。
- **和已有方法的差异**：与DehazeNet、MSCNN等先估计透射图再复原的方法不同，FFA-Net是**端到端直接恢复**无雾图像。最关键的区别在于，FFA-Net引入了**FA和FFA机制**，能够**自适应地**根据特征通道和图像像素的雾分布情况分配不同的计算权重，而之前的网络（如AOD-Net、GCANet）则平等处理所有特征。
## 实验

- **使用的数据集**：主要使用 **RESIDE** 去雾基准数据集。训练集为 **Indoor Training Set**（1399张清晰图，13990张合成雾图）。测试集为 **Synthetic Objective Testing Set (SOTS)**，包含**500张室内**和**500张室外**合成雾图。此外，还使用了**真实雾图**进行主观评估 (p.6)。
- **对比方法**：DCP, AOD-Net, DehazeNet, GFN, GCANet (p.6)。
- **评价指标**：**PSNR**（峰值信噪比）和 **SSIM**（结构相似性）。
- **主实验结果**（表1）：
    - 在**SOTS室内测试集**上：FFA-Net的PSNR达到 **36.39 dB**，SSIM达到 **0.9886**，将之前最好的GCANet的PSNR（30.23 dB）提升了超过6 dB。
    - 在**SOTS室外测试集**上：FFA-Net的PSNR达到 **33.57 dB**，SSIM达到 **0.9840**。
    - 定性结果（图8）显示，FFA-Net在恢复图像细节（如远处的塔、纹理、边缘）和颜色保真度上明显优于其他方法。
- **消融实验**（表2）：
    - 仅使用FA模块：PSNR为 **30.28 dB**。
    - 使用FA+局部残差学习(LRL)：PSNR提升至 **31.16 dB**。
    - 使用FA+LRL+特征融合注意力(FFA)：PSNR进一步提升至 **32.44 dB**。
    - 按完整配置（更多组/块）训练后，PSNR可达 **35.77 dB**。实验证明每个提出的关键组件都对性能提升有贡献。
- **泛化实验**：在真实雾图上的测试结果（图8）表明，FFA-Net能有效处理真实场景，恢复出更自然、细节更丰富的图像。

## 局限

1.  **数据依赖**：模型主要在**合成雾图**上训练和测试，虽然有真实雾图测试，但其在真实世界复杂、多变雾气条件下的泛化能力未得到充分验证。
2.  **计算成本**：网络包含多个FA模块和基础块（G=3， B=19），虽然效果好，但**计算量和参数量可能较大**。论文未提供相关的效率对比数据（如FLOPs、运行时间），这对实际部署是一个需要考虑的因素。
3.  **假设的局限性**：方法本质上仍依赖于大气散射模型（尽管是端到端隐式学习），在雾的物理模型不成立的极端场景（如非均匀雾、雾霾混合）下可能失效。
4.  **消融实验设置**：消融实验使用了较小的图像块（48x48）和更少的训练步数（3e5），与完整实验的输入尺寸（240x240）和训练步数（5e5/1e6）不同，可能无法完全反映各组件在最终模型中的贡献程度。
## 个人评论

1.  **问题洞察精准**：深刻指出了“雾分布不均匀”和“通道特征重要性不同”这两个被先前CNN方法忽略的关键问题，并以此为出发点设计网络，这种从问题本质出发的思维方式值得学习。
2.  **注意力机制的有效整合与设计**：没有单一使用空间或通道注意力，而是设计了**FA模块**将两者串联（先通道后像素），形成了更强的特征选择能力。这种组合和顺序的设计思路对改进其他视觉任务的特征提取有启发。
3.  **局部残差与注意力结合**：基础块结构将局部残差（信息分流）与注意力（信息聚焦）结合，是一个巧妙的设计，既保证了训练稳定性，又提升了网络的表征能力。
4.  **自适应的特征融合**：**FFA结构**让网络自己学习如何融合不同层级的特征权重，这比人工指定或简单拼接更智能、更有效。这一思想可以泛化到其他需要融合多尺度或多层级特征的任务中（如检测、分割）。
5.  **端到端的简洁框架**：尽管模块设计复杂，但整体框架是清晰的端到端映射，易于理解和复现，为后续研究提供了一个强基线。
