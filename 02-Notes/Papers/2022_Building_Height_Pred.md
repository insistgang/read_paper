## 摘要

> **清理后英文原摘要**（据 PDF 提取文本修复空格与连字符）：
> Extracting building heights from satellite images is an active research area used in many fields such as telecommunications, city planning, etc. Many studies utilize DSM (Digital Surface Models) generated with lidars or stereo images for this purpose. Predicting the height of the buildings using only RGB images is challenging due to the insufficient amount of data, low data quality, variations of building types, different angles of light and shadow, etc. In this study, we present an instance segmentation-based building height extraction method to predict building masks with their respective heights from a single RGB satellite image. We used satellite images with building height annotations of certain cities along with an open-source satellite dataset with the transfer learning approach. We reached the bounding box mAP 59, the mask mAP 52.6, and the average accuracy value of 70% for buildings belonging to each height class in our test set.

## 研究背景与动机

- **为什么要做**：土地覆盖测绘（landcover mapping）在电信、城市规划、交通等领域有广泛应用，其中"从遥感图像计算建筑高度"是一个重要子问题。传统方式需要人工携带测量仪器实地踏勘，成本高；且建筑会随时间拆建，地图很快过时。随着遥感与深度学习视觉方法发展，可在卫星图上快速、低成本地完成检测与分割。
- **之前方法的问题**：由于公开的建筑高度信息稀缺，针对建筑高度预测的研究"只有屈指可数的几项（only a handful）"。大多数高度预测研究使用立体图像或 DSM 来获取深度信息。而从单目（monocular）RGB 图像提取高度更有价值（无需额外数据源），但更难：深度信息依赖卫星与光照角度、随时间变化的阴影、以及大物体对小物体的遮挡等。此外，已有大量建筑提取工作采用**语义分割**，只能在像素级预测掩码，无法区分同类别的不同实例；相邻建筑的语义掩码相连，可能被当作单个建筑处理，导致错误的 3D 建模（需阈值化、连通域分析等后处理才能逐栋识别）。
- **核心矛盾 / 假设**：论文的核心假设是——只要给定足够大的"建筑高度图像数据集"，模型即可在上述困难（光照、阴影、遮挡）下学会预测建筑高度。即如何在缺乏直接深度信息、且数据质量与数量有限的单张 RGB 卫星图像中，有效学习并推断出**实例级**的建筑高度类别。

## 关键贡献

1.  **首个将实例分割用于建筑高度预测的方案**：论文在文献综述中明确指出"未发现任何使用实例分割同时做建筑与高度预测的研究"。本文以 Mask R-CNN 为框架，使模型同时输出建筑实例的边界框、掩码与高度类别（而非仅做建筑/背景的二类分割或像素级高度回归）。
2.  **面向真实卫星标注的数据清洗流程**：针对原始数据中的三类问题——重叠标注、错误/缺失标注、标注偏移——分别设计处理方法：(a) 用"交集 / 各标注面积之比取最大值"的改进重叠度量来合并重叠标注（保留最高的那栋）；(b) 用 Unet++ 语义分割模型自动过滤错位/不完整标注（缺失比例 >50% 则丢弃整图）。
3.  **两阶段迁移学习策略**：先在地理分布广泛的开源建筑数据集（Miyazaki 数据集）上预训练单类建筑实例分割模型，再在私有 3 类高度数据集上微调，以缓解模型泛化性差与高度数据不足的问题。
4.  **考虑过检测与欠检测的评估方式**：借鉴 Özdemir 等人 [10] 的目标检测评估方法，在计算混淆矩阵时不只统计一对一匹配，还把"一对多 / 多对一"且组合后 IOU 超过阈值的预测也算作正确，更贴近业务容错需求。

## 方法

**整体框架**：以 **Mask R-CNN** 为核心架构。这是基于两阶段 Faster R-CNN 的目标检测/实例分割框架，在分类与边界框回归分支之外并行增加分割分支，可对每个候选区域同时输出边界框、类别与像素级掩码。实现基于开源 **mmdetection**（PyTorch）库。

**输入输出**：
- **输入**：512×512 像素的 RGB 卫星图像切片。
- **输出**：对每个检测到的建筑物，输出**边界框**、**实例分割掩码**以及**高度类别**（0m–15m、15m–40m、40m+ 三类）。

**预处理（2.1–2.3，论文重点之一）**：
1.  **重叠标注合并**：高层建筑（摩天楼、广场等）的"楼顶高峰区域"会被标成短高度、其余部分标成更高的高度，同一区域同时被标为两种高度会降低精度。直接用 IOU 判断重叠不可靠（对尺寸悬殊的标注，IOU 过小会失效），故改用"交集面积 / 各自标注面积之比并取最大值"来判断是否重叠，将重叠的多个标注合并到最高的那个。
2.  **错位/不完整标注过滤**：数据量达数万张，无法人工筛查。先训练一个单类 **Unet++** 建筑语义分割模型，对全量数据做推理，计算每个预测建筑与每个标注之间的 IOU，若缺失预测或缺失标注的比例 >50% 则丢弃该图。
3.  **过检测/欠检测处理**：部分小建筑被成组标注，若逐栋检测会被判错；反之成组建筑可能被预测为单栋。为此引入过检测（一个物体多个预测）与欠检测（多个物体一个预测）的判定：对 1-对-1 不匹配的情况，把同类别且 IOU>0 的标注合并为新物体，再与预测计算 IOU，超过阈值则也算正确。

**骨干网络**：初期为追求速度用 **ResNet-50**；经超参数优化后改用 **ResNeXt-101**，其性能优于 ResNet-50，作为最终骨干。

**RPN 锚框调整**：卫星图中建筑相对整图占比远小于 MS-COCO 中的物体，故**增加锚框数量并加入更小尺度的锚框**，将 RPN 的默认 scales 参数由 [8] 改为 [2, 4, 8, 16, 32]。预训练与微调阶段均做此调整。

**训练 / 迁移学习（2.4）**：
1.  **预训练**：在开源单类建筑数据集（Miyazaki [12]）上训练 Mask R-CNN。编码器以 **MS-COCO 权重**为起点，**仅冻结 ResNeXt 编码器的第一层**，其余层全部训练。开源数据集的语义分割标注先切成 512×512，再用自适应阈值化 + 连通域分析转换为实例分割标注。
2.  **微调**：用预训练权重初始化，在私有 3 类高度数据集上微调；此阶段**冻结整个编码器（encoder）**，仅训练网络其余层。
3.  **迁移学习目的**：私有数据仅覆盖有限区域，单独训练泛化差；借助地理变化大、标签质量高且能区分相邻建筑的开源数据，学习不同光照条件与建筑类型下的通用建筑特征，提升跨区域泛化。

> 说明：论文未显式给出具体损失函数公式（沿用 Mask R-CNN 标准的分类 + 框回归 + 掩码损失），也未列出学习率、迭代步数等具体超参数数值，仅提到做过超参数优化——PDF 文本未明确。

**与已有方法的差异**：不同于用 U-Net 做像素级高度回归（如 Karatsiolis [8]、Liu [9]，以 RMSE/MAE 损失估计连续高度），本文用实例分割框架区分每个独立建筑实例并赋予离散高度类别，而非输出连续的像素级高度值。

## 实验

- **使用的数据集**：
    - **公开数据集（Miyazaki [12]）**：原始为 18127 张 1024×1024 航拍图，来自 7 个国家，含像素级建筑标注。本文只取其中 **4 个国家**（日本、泰国、肯尼亚、莫桑比克），切成 512×512 后约 **20000 张**切片，用于预训练单类建筑实例分割模型。
    - **私有高度数据集**：来自 **5 个城市**的 **744 张** 5000×6000 高分辨率卫星图，含每栋建筑的分割掩码与高度值。切成 512×512 网格切片后用于训练/测试。高度分 **3 类**（≤15m、15–40m、>40m），类别边界经直方图分析后选定以平衡类间数量；原始数据转为 COCO 标注格式。
- **评价指标**：
    - **mAP**：在 IOU=0.5 阈值下，分别计算边界框 mAP 与分割掩码 mAP。
    - **混淆矩阵**：统计各高度类别的准确率及与其他类别（含背景）的混淆，并结合过/欠检测判定。
- **主实验结果**（在某城市随机选取的 1200 张测试图上）：
    - **边界框 mAP（IOU=0.5）= 59**，**掩码 mAP（IOU=0.5）= 52.6**。
    - 三类高度准确率：≤15m 为 **73%**、15–40m 为 **71%**、>40m 为 **65%**（整体约 70%）。
    - 错误多发生在相邻类别之间：例如 ≤15m 类有 8% 被误判为 15–40m，但**无一被误判为 >40m**；假阳性预测最集中于 ≤15m 类，模型对该类最易混淆。
    - **混淆矩阵（Table 1，行=真值，列=预测）**：
      - 0m–15m → [73%, 8%, 0%, 背景18%]
      - 15m–40m → [16%, 71%, 5%, 背景6%]
      - 40m+ → [1%, 23%, 65%, 背景9%]
      - 背景 Background → [88%, 9%, 2%, 0%]（即大量背景被误预测为 0m–15m 类，是主要假阳性来源）
- **消融实验/泛化实验/效率信息**：论文提到对比过 ResNet-50 与 ResNeXt-101（后者更优）并做过超参数优化，但未给出系统的消融表、跨城市泛化定量结果，也未报告 FPS / 参数量 / 计算量——PDF 文本未明确。

## 局限

1.  **缺乏与基线方法的定量对比**：论文未与语义分割回归（如引用的 U-Net 高度回归）或其他实例分割架构做并列对比实验，难以量化 Mask R-CNN 在该任务上的相对优势。

## 个人评论

1.  **问题定义的迁移价值**：把"实例分割"这一强视觉任务用于遥感属性预测（高度估计），为"检测 + 属性分类"类问题提供了清晰的多任务建模范例——用离散类别替代连续回归，工程上更易训练、评估也更直观。
2.  **数据清洗的实用工程**：重叠标注合并（改进重叠度量）、Unet++ 自动过滤错位标注、过/欠检测判定，这些处理真实低质量卫星标注的方法对任何遥感数据工程都有直接参考意义，甚至比模型本身更值得借鉴。
3.  **迁移学习范式的实证**：在目标域数据稀缺时，用一个地理多样、标签质量高的相关公开数据集预训练，再小样本微调，是提升泛化的有效路径；预训练只冻结首层、微调冻结整个编码器的"分阶段冻结"细节也颇具参考性。
4.  **评估贴近业务**：引入过/欠检测的容错评估，比纯 mAP 更能反映实际部署性能——这是从工业界（华为团队）视角带来的务实考量。
5.  **批判**：作为预印本，论文工程描述清楚但科学严谨性不足——无基线对比、无消融表、无显著性或多城市泛化的量化结论，"假设足够大数据即可学好高度"基本未被验证；背景假阳性偏高也提示当前方案离实用尚有距离。

## 4. 核心贡献
1.  首个将实例分割同时用于建筑提取与高度预测的方案（文献综述称未见同类工作），以 Mask R-CNN 输出实例边界框、掩码与高度类别。

3.  两阶段迁移学习：地理多样的开源建筑数据集（Miyazaki [12]）预训练 → 私有 3 类高度数据集微调。
4.  借鉴 Özdemir [10] 的过/欠检测评估，把组合后 IOU 达阈值的一对多/多对一预测也计为正确，贴近业务容错。

## 5. 方法详解
**架构**：Mask R-CNN（两阶段 Faster R-CNN + 并行掩码分支），实现基于 mmdetection（PyTorch）。
**输入/输出**：输入 512×512 RGB 切片；对每栋建筑输出边界框、实例掩码、高度类别（≤15m / 15–40m / >40m）。
**预处理（论文重点）**：
- *重叠标注*：高层建筑楼顶被标短、其余标高，同区域双标会降精度；IOU 对尺寸悬殊标注失效，改用"交集 / 各自标注面积取最大值"判定重叠并合并到最高标注。
- *错位/缺失标注*：先训练单类 Unet++ 语义分割模型，对全量数据推理，按预测与标注的 IOU 计算缺失比例，>50% 则弃图。
- *过/欠检测*：成组小建筑或被合并的预测会被一对一匹配判错；对 1-对-1 不匹配，合并同类 IOU>0 的标注成新物体再与预测算 IOU，超阈值即算对。
**骨干**：先用 ResNet-50（快），超参优化后改用更优的 ResNeXt-101。
**RPN 锚框**：因卫星图建筑占比远小于 MS-COCO 物体，增多并加小锚框，scales 由 [8] 改为 [2,4,8,16,32]（预训练与微调都改）。
**迁移学习**：
- 预训练在 Miyazaki 单类建筑集上，编码器以 MS-COCO 权重起步，**仅冻结 ResNeXt 第一层**，其余层训练；开源语义标注经自适应阈值 + 连通域分析转为实例标注，并切 512×512。
- 微调在私有 3 类高度集上，**冻结整个编码器**，只训其余层。
- 目的：私有数据区域单一、泛化差，用地理多样、标签质量高的开源数据学通用建筑特征以提升跨区域泛化。
**未明确**：具体损失公式（沿用 Mask R-CNN 标准多任务损失）、学习率/迭代步数等超参数数值——PDF 文本未明确。

- **数据集**：
    - 公开 Miyazaki [12]：原 18127 张 1024×1024、7 国；本文取 4 国（日、泰、肯尼亚、莫桑比克），切片约 20000 张 512×512，用于预训练。
