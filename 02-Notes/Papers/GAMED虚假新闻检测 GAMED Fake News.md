## 研究背景与动机

*   **为什么要做：** 多模态虚假新闻（结合文本和图像）日益泛滥，严重操纵公众舆论。传统检测方法存在明显不足，急需新方法来应对。
*   **之前方法的问题：**
    1.  **融合有效性依赖静态建模：** 现有方法过度依赖基础融合技术和预训练模型的静态特征，难以捕捉文本与视觉元素间的细微互动，且易造成特征抑制。
    2.  **过度依赖一致性：** 许多方法仅关注模态间的一致性检测，忽略了判别性特征的补充作用，而造假者已学会绕过此类一致性检测模型。
    3.  **可解释性差：** 决策过程的黑盒特性使得各模态的贡献不透明，阻碍了模型解释，也影响用户信任。
    4.  **缺乏知识整合：** 未充分利用外部真实世界知识来辅助模型理解复杂上下文。
*   **核心矛盾：** 如何突破静态特征建模和单一一致性检测的局限，动态、可解释地利用每个模态的判别性特征与跨模态协同作用，以提升检测鲁棒性和准确性。
## 关键贡献

1.  **提出模态解耦建模范式：** 不同于基于一致性学习或单纯融合的方法，GAMED通过解耦建模，挖掘跨模态协同潜力来提升检测性能。
2.  **设计MMoE-Pro专家网络：** 升级传统MMoE，引入**token注意力机制**并放松了softmax约束的门控机制，使其能更灵活地跨任务和跨模态动态分配计算资源，进行特征选择和精炼。
3.  **结合AdaIN进行分布自适应调整：** 将专家网络的粗粒度预测结果转换为用于**自适应实例归一化（AdaIN）** 的统计参数（均值与标准差），从而动态调整各模态特征的分布，优先处理最相关和可靠的信息。
4.  **引入外部语义知识：** 利用预训练语言模型（如ERNIE 2.0）编码的结构化（知识图谱）和非结构化语义知识，增强模型理解假新闻复杂关系和上下文的能力。
5.  **提出否决投票分类机制：** 结合阈值和置信度，设计了一种新颖的投票决策系统，能动态管理各模态预测的贡献与冲突，提高了决策过程的透明度和可解释性。
6.  **验证有效性：** 在Fakeddit和Yang两个公开数据集上，GAMED的性能优于近期提出的SOTA模型。
## 方法

*   **整体框架：** GAMED是一个模态解耦的端到端流程，如图1所示。主要分为四个阶段：特征提取、专家评审与意见、分布调整、否决投票。
*   **输入与输出：**
    *   **输入：** 新闻文本 `T` 和配对图像 `I`。
    *   **输出：** 新闻为假或为真的二分类结果。
*   **关键模块及连接：**
    1.  **特征提取模块：**
        *   **图像模式特征 (`f_ip`)**：使用 Inception-ResNet-v2 (IRNv2) 并加入 **BayarConv** 滤波器作为早期层，以捕捉篡改痕迹（如伪影、光照、纹理不一致）。
        *   **图像语义特征 (`f_is`)**：使用 ViT 结合掩码自编码器 (MAE) 模型，并辅以**数据增强**（旋转、翻转、缩放），提取图像的全局和局部语义信息，增强鲁棒性。
        *   **文本特征 (`f_t`)**：使用 **ERNIE 2.0** 模型提取。该模型能建模句子级关系并蕴含大规模语义知识图谱信息，有助于评估文本与图像的一致性以及分析事实和实体关系。
    2.  **专家评审与意见模块 (MMoE-Pro)：** 这是核心的注意力与专家模块。
        *   **机制：** 模拟专家评审。每个模态的特征 (`f_is`, `f_t`) 以及它们的融合特征 (`f_mm`) 分别输入各自的 MMoE-Pro 网络。
        *   **Token 注意力：** 对于输入特征 `f` 中的每个 token，通过一个共享权重的 MLP `A` 计算重要性分数 `α_i`，并进行归一化得到 `β_i`。特征被聚合成加权和 `˜f = Σ β_i · token_i`，实现动态评估不同输入特征的重要性。
        *   **改进门控机制：** 放松传统 MMoE 门控中的 softmax 约束（允许权重为负或大于1），直接从原始分数计算权重 `w_{t,i}(f)`，用于确定每个专家 `i` 对任务 `t` 的贡献。最终输出 `r = MMoE-Pro_t(f) = Σ w_{t,i}(˜f) · E_i(f)`。
        *   **输出：** 各模态精炼后的特征 `r`，以及粗粒度预测 `O = MLP(r)`。
    3.  **分布调整模块 (AdaIN)：**
        *   **机制：** 将上一阶段的粗粒度预测 `O` 通过 `sigmoid` 函数和 MLP 网络，生成用于 AdaIN 的统计参数：均值 `μ = MLP_μ(sigmoid(O))`，标准差 `σ = MLP_σ(sigmoid(O))`。
        *   **调整公式：** `e = σ(r - μ_r)/σ_r + μ`。其中 `μ_r` 和 `σ_r` 是输入特征 `r` 的均值和标准差。
        *   **关键创新：** 对于一致性学习（consistency learning）的预测输出 `O`，使用 `(1 - sigmoid(O))` 来反转，从而调整“不相关”特征 `r_x` 的分布。论文认为，不相关信息（如煽情语言、复杂修辞）本身也是检测假新闻的线索，因此解耦了相关性与一致性，并利用不相关性作为协同补充。
    4.  **否决投票模块：**
        *   **输入：** 各模态经 AdaIN 调整后的增强特征 `e_is, e_t, e_mm` 被拼接成 `e_mix`，再次经过 MMoE-Pro 精炼得到 `r_mix` 和 `O_mix`。输入投票模块的是所有模块的预测输出 (`O_is, O_t, O_mm`) 以及 `O_mix`。
        *   **机制：** 定义高、低置信度阈值 `θ_high` 和 `θ_low`。将每个预测 `O_i` 转换为置信度 `P_i = sigmoid(O_i)`，并以 `P_mix = sigmoid(O_mix)` 为初始基准。通过迭代应用以下规则更新 `P_mix`：
            *   **规则2 (替换):** 若某模块置信度 `P_i` 同时大于 `θ_high` 和 `P_mix`，则用 `P_i` 替换 `P_mix`。
            *   **规则3 (忽略并重考虑):** 若 `P_i < θ_low` 且属于多数类，则忽略该多数类的所有输出，并重新考虑所有模块中置信度最高的输出。
            *   **规则4 (保持):** 若置信度在阈值之间，则保持 `P_mix` 不变。
        *   **最终决策：** 基于更新后的 `P_mix` 做出最终分类。
*   **训练方式：** 使用二元交叉熵损失 `L_{BCE}` 和 AdamW 优化器。损失函数基于各模块的粗粒度预测 `O_i` 计算（见算法1第17行）。整体训练是端到端的。
*   **推理流程：** 喂入一对文本和图像，依次经过特征提取、MMoE-Pro 评审、AdaIN 分布调整、特征拼接、二次精炼、否决投票，最终输出分类结果。
*   **与已有方法的差异：**
    *   与基于一致性学习或融合的方法（如EANN, BMR, LEMMA）不同，GAMED侧重于**模态解耦**和**判别性特征增强**。
    *   相比传统 MMoE，MMoE-Pro 引入了 **token 级注意力** 并放松了门控约束，增强了特征选择的灵活性。
    *   创造性地将 **AdaIN** 用于根据粗粒度预测动态调整特征分布，并特别设计了利用“不相关”特征的机制。
    *   提出的 **否决投票机制** 相比简单的平均或求和融合，提供了更动态、可解释的决策逻辑。

3.  **结合AdaIN进行分布自适应调整：** 将专家网络的粗粒度预测结果转换为用于**自适应实例归一化（AdaIN）** 的统计参数（均值与标准差），从而动态调整各模态特征的分布，优先处理最相关和可靠的信息。
4.  **引入外部语义知识：** 利用预训练语言模型（如ERNIE 2.0）编码的结构化（知识图谱）和非结构化语义知识，增强模型理解假新闻复杂关系和上下文的能力。
5.  **提出否决投票分类机制：** 结合阈值和置信度，设计了一种新颖的投票决策系统，能动态管理各模态预测的贡献与冲突，提高了决策过程的透明度和可解释性。
6.  **验证有效性：** 在Fakeddit和Yang两个公开数据集上，GAMED的性能优于近期提出的SOTA模型。

## 5. 方法详解
*   **整体框架：** GAMED是一个模态解耦的端到端流程，如图1所示。主要分为四个阶段：特征提取、专家评审与意见、分布调整、否决投票。
*   **输入与输出：**
    *   **输入：** 新闻文本 `T` 和配对图像 `I`。
    *   **输出：** 新闻为假或为真的二分类结果。
*   **关键模块及连接：**
    1.  **特征提取模块：**
        *   **图像模式特征 (`f_ip`)**：使用 Inception-ResNet-v2 (IRNv2) 并加入 **BayarConv** 滤波器作为早期层，以捕捉篡改痕迹（如伪影、光照、纹理不一致）。
        *   **图像语义特征 (`f_is`)**：使用 ViT 结合掩码自编码器 (MAE) 模型，并辅以**数据增强**（旋转、翻转、缩放），提取图像的全局和局部语义信息，增强鲁棒性。
        *   **文本特征 (`f_t`)**：使用 **ERNIE 2.0** 模型提取。该模型能建模句子级关系并蕴含大规模语义知识图谱信息，有助于评估文本与图像的一致性以及分析事实和实体关系。
    2.  **专家评审与意见模块 (MMoE-Pro)：** 这是核心的注意力与专家模块。
        *   **机制：** 模拟专家评审。每个模态的特征 (`f_is`, `f_t`) 以及它们的融合特征 (`f_mm`) 分别输入各自的 MMoE-Pro 网络。
        *   **Token 注意力：** 对于输入特征 `f` 中的每个 token，通过一个共享权重的 MLP `A` 计算重要性分数 `α_i`，并进行归一化得到 `β_i`。特征被聚合成加权和 `˜f = Σ β_i · token_i`，实现动态评估不同输入特征的重要性。
        *   **改进门控机制：** 放松传统 MMoE 门控中的 softmax 约束（允许权重为负或大于1），直接从原始分数计算权重 `w_{t,i}(f)`，用于确定每个专家 `i` 对任务 `t` 的贡献。最终输出 `r = MMoE-Pro_t(f) = Σ w_{t,i}(˜f) · E_i(f)`。
        *   **输出：** 各模态精炼后的特征 `r`，以及粗粒度预测 `O = MLP(r)`。
    3.  **分布调整模块 (AdaIN)：**
        *   **机制：** 将上一阶段的粗粒度预测 `O` 通过 `sigmoid` 函数和 MLP 网络，生成用于 AdaIN 的统计参数：均值 `μ = MLP_μ(sigmoid(O))`，标准差 `σ = MLP_σ(sigmoid(O))`。
        *   **调整公式：** `e = σ(r - μ_r)/σ_r + μ`。其中 `μ_r` 和 `σ_r` 是输入特征 `r` 的均值和标准差。
        *   **关键创新：** 对于一致性学习（consistency learning）的预测输出 `O`，使用 `(1 - sigmoid(O))` 来反转，从而调整“不相关”特征 `r_x` 的分布。论文认为，不相关信息（如煽情语言、复杂修辞）本身也是检测假新闻的线索，因此解耦了相关性与一致性，并利用不相关性作为协同补充。
    4.  **否决投票模块：**
        *   **输入：** 各模态经 AdaIN 调整后的增强特征 `e_is, e_t, e_mm` 被拼接成 `e_mix`，再次经过 MMoE-Pro 精炼得到 `r_mix` 和 `O_mix`。输入投票模块的是所有模块的预测输出 (`O_is, O_t, O_mm`) 以及 `O_mix`。
        *   **机制：** 定义高、低置信度阈值 `θ_high` 和 `θ_low`。将每个预测 `O_i` 转换为置信度 `P_i = sigmoid(O_i)`，并以 `P_mix = sigmoid(O_mix)` 为初始基准。通过迭代应用以下规则更新 `P_mix`：
            *   **规则2 (替换):** 若某模块置信度 `P_i` 同时大于 `θ_high` 和 `P_mix`，则用 `P_i` 替换 `P_mix`。
            *   **规则3 (忽略并重考虑):** 若 `P_i < θ_low` 且属于多数类，则忽略该多数类的所有输出，并重新考虑所有模块中置信度最高的输出。
            *   **规则4 (保持):** 若置信度在阈值之间，则保持 `P_mix` 不变。
        *   **最终决策：** 基于更新后的 `P_mix` 做出最终分类。
*   **训练方式：** 使用二元交叉熵损失 `L_{BCE}` 和 AdamW 优化器。损失函数基于各模块的粗粒度预测 `O_i` 计算（见算法1第17行）。整体训练是端到端的。
*   **推理流程：** 喂入一对文本和图像，依次经过特征提取、MMoE-Pro 评审、AdaIN 分布调整、特征拼接、二次精炼、否决投票，最终输出分类结果。
*   **与已有方法的差异：**
    *   与基于一致性学习或融合的方法（如EANN, BMR, LEMMA）不同，GAMED侧重于**模态解耦**和**判别性特征增强**。
    *   相比传统 MMoE，MMoE-Pro 引入了 **token 级注意力** 并放松了门控约束，增强了特征选择的灵活性。
    *   创造性地将 **AdaIN** 用于根据粗粒度预测动态调整特征分布，并特别设计了利用“不相关”特征的机制。
    *   提出的 **否决投票机制** 相比简单的平均或求和融合，提供了更动态、可解释的决策逻辑。
