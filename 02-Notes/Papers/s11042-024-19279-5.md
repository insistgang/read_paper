## 摘要

本文提出了一种名为BBD的混合方法，通过结合GeoServer/TileCache处理海量卫星影像切片、YOLO系列/DETR进行建筑检测、以及SAM进行边界分割，并采用微调优化策略，实现了高精度的建筑地理空间边界提取。
## 研究背景与动机

- **为什么要做**：违建建筑危害公共安全与环境，而传统人工实地测量建筑边界效率极低，难以应对海量数据。卫星遥感技术是解决方案，但其影像数据量巨大（压缩后可达21GB），传统计算机和深度学习方法无法直接处理。
- **之前方法的问题**：
    1. **处理规模问题**：现有深度学习方法主要处理标准尺寸图像，无法直接应用于TB级的巨大卫星影像。
    2. **任务完整性问题**：现有研究或仅做建筑检测（无精确边界），或做分割但未提供真实的地理空间坐标。
    3. **图像切分导致的信息损失**：使用TileCache等工具将大图切成小图（如256x256）后，建筑物可能被分割到多个图块中，导致检测模型无法识别完整的建筑对象。
- **核心矛盾**：如何在标准计算设备上，处理超出内存和计算能力的海量卫星影像，同时还能精确地提取每个建筑的地理轮廓。
## 关键贡献

1.  **提出了BBD两阶段混合框架**：创新性地将“建筑检测”与“建筑边界分割”解耦为两个阶段，先用检测模型定位建筑，再用分割模型精确勾勒边界，使结果更清晰。
2.  **解决了海量卫星影像处理难题**：利用开源的GeoServer和TileCache软件，将无法直接处理的巨大卫星影像预先切割成带有地理坐标的瓦片小图，使深度学习模型能够处理。
3.  **提出了微调优化策略**：针对TileCache切割导致建筑被分割的问题，对检测模型（YOLOv5， DETR， YOLO-NAS）和分割模型（RefineNet）进行了微调，显著提升了模型对不完整建筑对象的识别能力。
4.  **进行了全面的模型组合探索**：系统比较了YOLOv5、DETR、YOLO-NAS三种检测模型与SAM分割模型的不同组合效果，并同时评估了直接进行建筑分割的RefineNet模型的性能。
## 方法

- **整体框架**：BBD方法主要包含三个关键阶段：海量数据预处理、建筑目标检测、建筑边界分割。其流程为：巨大卫星影像 -> (GeoServer + TileCache) -> 带地理坐标的瓦片小图 -> (YOLOv5/DETR/YOLO-NAS检测) -> 建筑目标及其包围盒 -> (SAM分割) -> 建筑多边形边界。
- **输入输出**：
    - **输入**：无法直接处理的、压缩后可达21GB的巨大卫星影像。
    - **输出**：带有精确地理空间坐标（经纬度）的建筑物及其多边形边界轮廓。
- **关键模块**：
    1.  **数据预处理模块（GeoServer + TileCache）**：GeoServer作为地图服务器发布影像服务，TileCache将影像切割成标准的z/x/y格式的256x256瓦片图像，并记录每个瓦片的世界地理坐标。这是使深度学习模型能够处理海量数据的基础。
    2.  **建筑检测模块**：采用三种先进的目标检测模型：
        - **YOLOv5**：单阶段检测器，速度快，本文选用PyTorch实现的V5版本。
        - **DETR**：基于Transformer的端到端检测器，无需锚框和NMS后处理。
        - **YOLO-NAS**：通过神经架构搜索（NAS）自动优化的YOLO模型，性能优于YOLOv6和v8。
    3.  **建筑边界分割模块**：使用**SAM**，一个在超过10亿个图像掩码上训练的大规模分割模型，对检测到的建筑包围盒内的区域进行精细分割，输出多边形边界。
    4.  **对比基线模块**：同时评估了**RefineNet**模型，该模型直接对瓦片图像进行建筑语义分割，跳过了检测阶段。
- **模块连接与训练/推理流程**：
    - 首先用TileCache对原始大图进行离线切割，生成带坐标的训练/测试瓦片数据集。
    - 使用切割后的图像数据集，分别训练YOLOv5、DETR、YOLO-NAS检测模型，以及RefineNet分割模型。
    - **微调优化**：针对瓦片切分导致建筑不完整的问题，对上述所有模型进行微调（Fine-tuning），以提升其在切割后图像上的性能。
    - 推理时，对目标区域瓦片图像，先用微调后的检测模型得到建筑包围盒，再将该区域输入SAM进行边界分割。
- **与已有方法的差异**：
    - **处理对象不同**：传统方法处理标准图像，BBD通过预处理管道处理海量卫星影像。
    - **任务设计不同**：许多现有研究只做检测或只做分割，BBD将两者结合为“检测-分割”流水线，旨在同时获得建筑位置和精确边界。
    - **强调地理定位**：BBD的最终输出与地理坐标绑定，这是许多纯视觉方法所缺乏的。
## 实验

- **使用的数据集**：PDF文本中**未明确说明**使用的具体公开数据集名称，但描述了数据源为“huge size satellite imagery”。
- **对比方法**：
    - 检测模型内部对比：YOLOv5， DETR， YOLO-NAS。
    - 分割模型内部对比：SAM（基于检测结果） vs. RefineNet（直接分割）。
    - 微调前后性能对比。
- **评价指标**：主要采用**F1分数**（F1 Score）和**交并比**（IoU）。

    - 在边界分割性能上，**YOLO-NAS检测 + SAM分割**的组合取得了最佳IoU值：**0.912**。

## 局限

1.  **数据集局限性**：实验未在多个公开标准数据集上验证，结果的可复现性和泛化性存疑。
2.  **计算成本与复杂性**：流程涉及多个软件和多个深度学习模型（检测+分割），整个系统的部署、维护和计算成本可能较高，不如端到端模型简洁。
3.  **对预处理的强依赖**：性能严重依赖于TileCache的切图质量和预设的缩放层级（z level），如果建筑物跨越多个图块，即使微调也可能无法完美解决。
4.  **假设依赖**：方法假设目标建筑在卫星图像中具有清晰可辨的视觉特征，对于被树木严重遮挡、或与背景极其相似的建筑，效果可能不佳。
5.  **实验细节缺失**：提供的文本片段未包含模型具体配置、训练细节、数据集划分、更详细的对比实验（如与SOTA方法对比），降低了部分结论的可信度。
