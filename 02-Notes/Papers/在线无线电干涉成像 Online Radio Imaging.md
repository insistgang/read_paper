## 研究背景与动机

- **为什么做**：以平方公里阵列（SKA）为代表的新一代射电望远镜将产生海量数据（例如SKA第一阶段数据率估计约**5太比特每秒**），标志着无线电天文学进入“大数据”时代。这给传统的成像逆问题求解带来了前所未有的**数据存储和计算成本**挑战。
- **之前方法的问题**：现有的主流成像方法，如CLEAN及其变体、基于压缩感知（CS）的稀疏正则化方法，虽然能获得良好的重建保真度，但它们本质上都是**离线方法**。这些方法必须**先完整存储整个观测期内获得的所有可见度数据，然后才能开始处理**。在大数据背景下，这种“先存储后处理”的模式在存储和计算上变得困难甚至不可行。
- **核心矛盾**：**数据采集的“流式”特性**与**现有成像算法对“批处理”的依赖**之间的矛盾。作者旨在设计一种能够“边观测边成像”的在线处理方法，以解决存储瓶颈并加速重建流程。
## 关键贡献

1.  **提出了一种通用的在线优化框架**，专门用于求解如稀疏正则化在内的凸优化问题，并将其应用于无线电干涉成像的逆问题求解。
2.  **设计了具体的在线成像算法**，该算法在每次迭代中仅处理最新到达的一个数据块（visibilities block），并在处理后立即释放其存储空间，使存储需求始终维持在单个数据块的大小。
3.  **从理论上证明了所提在线算法的收敛性**，表明其最终能收敛到与离线方法相同解的邻域。
4.  **分析了在线方法在存储需求和计算效率上的优势**，指出在数据采集结束时，在线方法已近似完成重建，而离线方法才刚刚开始。
5.  **验证了在线方法能达到与离线方法非常相似的重建保真度**，在实践中证明了其有效性。

## 方法

- **整体框架**：方法遵循“数据分块-在线处理-迭代重建”的流程（如图1所示）。在数据观测期间，算法循环执行：检查观测是否完成 -> 加载新数据块 -> 处理该数据块 -> 释放存储 -> 用新信息更新当前重建图像 -> 以更新后的图像为起点等待下一个数据块。
- **输入与输出**：输入是按时间顺序到达的可见度数据流 y，这些数据被分组成 B 个块（y₁, y₂, ..., y_B）。输出是在整个观测完成后，基于所有数据块生成的重建图像 x*。
- **关键模块与数学机制**：
    1.  **问题建模**：基于贝叶斯框架，将成像问题表述为最大后验（MAP）估计。对于独立同分布高斯噪声，MAP估计等价于求解一个包含**数据保真项**和**正则化项**的凸优化问题。本文聚焦于使用 `ℓ₁` 范数作为正则项来促进稀疏性，对应的无约束优化问题为：
        `x_map = argmin_x [μ * ||Ψ^† x||₁ + ||y - Φ x||²₂ / (2σ²)]` （分析形式）
        其中，Ψ 是稀疏变换字典，Φ 是测量算子，μ 是平衡参数。
    2.  **问题的可分性**：由于观测数据 y 和测量算子 Φ 被自然地按数据块分割（y = [y₁^T, ..., y_B^T]^T， Φ = [Φ₁^T, ..., Φ_B^T]^T），数据保真项（||y - Φ x||²）可以分解为各数据块对应项的和：`g(x) = Σ_{k=1}^{B} g_k(x)`。
    3.  **在线前向后向算法**：这是核心迭代机制。标准的离线前向后向算法每次迭代需要使用**所有**数据块的梯度信息。而在线版本在迭代第 i 次，当只收到前 b 个数据块时，仅使用这些已到数据块的梯度 `rgb_1(x^(i))`。其迭代公式为：
        `x^(i+1) = prox_{λ^(i) f} ( x^(i) - λ^(i) * rgb_1(x^(i)) )`
        其中 `prox` 是近端算子，`λ^(i)` 是步长。当新的数据块到达时，算法继续迭代，梯度和更新基于更新的（当前可用的）数据块集合。
    4.  **与已有方法的差异**：
        - **与离线方法（如标准CS）差异**：离线方法存储所有数据，每次迭代使用全局梯度；在线方法仅需存储当前数据块，使用局部梯度。
        - **与经典在线梯度下降差异**：经典在线优化（如在线镜像下降）用于不同的协议（如对抗性设置），而本文的方法将**在线数据获取模式**与**求解特定逆问题的凸优化算法**相结合，是针对成像问题定制的。
- **训练方式**：本文方法**不需要预先训练**。它是一种优化算法，直接在观测数据上执行迭代重建。
- **推理流程**：推理即在线重建过程，如框架图所示，在数据流驱动下迭代进行。
