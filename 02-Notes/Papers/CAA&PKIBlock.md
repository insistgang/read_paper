## 研究背景与动机

- **为什么要做**：遥感图像（RSI）中的目标检测面临物体尺度差异巨大（从足球场到车辆）和依赖周围环境上下文信息等独特挑战。
- **之前方法的问题**：
    - 为扩大感受野，一些方法使用**大核卷积**，但这会引入大量**背景噪声**，不利于小目标检测。
    - 另一些方法使用**扩张卷积**来扩大感受野，但可能导致特征表示**过于稀疏**，丢失细粒度细节。
- **核心矛盾**：如何在不引入背景噪声或产生稀疏特征表示的情况下，为尺度变化巨大的目标**自适应地捕获足够丰富且局部与全局兼顾的上下文信息**。
## 关键贡献

1.  **提出了PKINet骨干网络**：一个专门为遥感目标检测设计的、轻量且强大的特征提取骨干网络。
2.  **提出了多尺度无扩张卷积（PKI模块）**：通过并行不同尺寸的深度可分离卷积核（不使用扩张），提取多尺度密集纹理特征，自适应融合以捕获局部上下文。
3.  **提出了上下文锚点注意力（CAA）模块**：利用全局平均池化和一维条带卷积捕获远距离像素间的依赖关系，增强中心区域特征，从而捕获长程上下文信息。
4.  **提出了一种轻量化的网络设计范式**：通过策略性地使用深度可分离卷积和一维卷积，在保持强大特征提取能力的同时，有效控制模型参数量和计算量。
5.  **在四个主流遥感检测基准上验证了有效性**：在DOTA-v1.0， DOTA-v1.5， HRSC2016和DIOR-R数据集上均取得了具有竞争力的性能。
## 方法

- **整体框架**：PKINet是一个类似VGG/ResNet的四阶段特征提取骨干。每个阶段采用**跨阶段部分（CSP）结构**，输入被分成两路：一路经过一个简单的前馈网络（FFN），另一路经过一系列**PKI Block**。两路的输出最后拼接并经过1x1卷积融合。
- **输入输出**：输入为遥感图像，输出为四个不同尺度的特征图（`(Cl, H/2^(l+1), W/2^(l+1))`， `l=0,1,2,3`），用于下游的目标检测头。
- **关键模块**：
    - **PKI模块**：每个PKI Block的核心，是一个Inception风格的模块。它首先用一个3x3卷积提取局部特征`L`，然后并行使用4个不同尺寸（`k(m) = (m+1)*2+1`， 即5x5, 7x7, 9x9, 11x11）的深度可分离卷积提取多尺度上下文特征`Z`。所有特征相加后，通过一个1x1卷积进行通道融合，得到输出`P`。此过程**不使用扩张卷积**。
    - **CAA模块**：与PKI模块串联在PKI Block中。首先对输入进行全局平均池化和1x1卷积得到局部区域特征。然后，通过两个连续的深度可分离**条带卷积**（1×k_b 和 k_b×1）来近似一个大的2D卷积核，以捕获长程依赖。条带卷积核尺寸`k_b = 11 + 2 * l`（`l`为阶段索引），随网络深度增加。生成的注意力权重`A`经过Sigmoid后，与PKI模块的输出`P`进行元素相乘和相加，实现特征增强。
- **模块连接**：在一个PKI Block内，输入特征`X`先经过**PKI模块**得到`P`，再将`X`送入**CAA模块**生成注意力图`A`，`A`用于增强`P`，得到`Fattn`。`Fattn`再通过1x1卷积得到该Block的最终输出。
- **数学公式/机制直观解释**：
    - PKI模块：`P = Conv1x1( L + Z1 + Z2 + Z3 + Z4 )`。直观上，它用小核看细节，多个大核看不同范围的“视野”，最后把所有信息融合起来。
    - CAA模块：`Fattn = (A ⊙ P) + P`。直观上，`A`是一个“关注度地图”，告诉网络在特征图`P`上哪些空间位置更重要，然后通过乘法和加法对这些区域进行增强。
- **训练方式**：两阶段训练。首先在ImageNet-1K数据集上进行**300个epoch的预训练**。然后，将预训练好的PKINet作为骨干网络，接入具体的目标检测器（如Oriented RCNN），在遥感数据集上进行端到端的微调。
- **推理流程**：图像输入PKINet骨干，提取多尺度特征图，这些特征图被送入后续的检测头（如特征金字塔网络、分类/回归头）进行目标定位和分类。
- **和已有方法的差异**：与主要竞品LSKNet相比，**核心区别有两点**：1) PKINet不使用扩张卷积，避免了稀疏特征；2) PKINet引入了独立的CAA模块来显式建模长程上下文依赖，而LSKNet主要依赖大核卷积。
