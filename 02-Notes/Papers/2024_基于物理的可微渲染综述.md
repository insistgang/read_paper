## 研究背景与动机

- **为什么要做**：随着虚拟现实、自动驾驶等领域的发展，需要从图像中高精度地重建三维世界。主流的逆向渲染框架（“分析式合成”）依赖于通过梯度下降优化场景参数来最小化渲染图像与目标图像的差异。这一过程的核心前提是**必须能够计算正向渲染输出图像关于输入参数的梯度**，这催生了可微渲染技术。
- **之前方法的问题**：传统的正向渲染（如光栅化）流水线本身是不可微的，尤其是存在大量不连续现象（如物体边缘、遮挡边界）。早期的可微渲染方法要么效率低下，要么梯度计算不正确，难以处理复杂的真实世界光传输现象（如镜面反射/折射边界）。
- **核心矛盾**：**梯度计算的正确性与计算效率之间的矛盾**。正确求解梯度需要处理复杂的边界积分项（由函数定义域随参数变化和函数本身不连续引起），这引入了额外的、与传统渲染流水线差异较大的计算，导致效率降低。同时，渲染函数的高度非线性也使得基于梯度的优化容易陷入局部最优，影响鲁棒性。

## 方法

- **整体框架**：本文作为综述，其“方法”即是对该领域技术体系的梳理。核心框架基于“生成式分析”（分析-合成）逆向渲染范式，可微渲染是其正向过程的核心。技术链条为：**场景参数 → （可微）正向渲染 → 生成图像 → 与目标图像计算损失 → 反向传播梯度 → 优化场景参数**。
- **输入输出**：对于可微渲染算法本身，输入是场景参数（几何、材质、光源、相机参数），输出是渲染图像及其关于输入参数的梯度。
- **关键模块与数学解释**：
    1.  **梯度分解**：核心公式为 ∂πI = ∫_χ ∂πf dx + ∫_{∂χ} f ∂πx·n̂ dx。第一项（内部积分）可复用正向渲染的蒙特卡洛方法。第二项（边界积分）是难点，源于被积函数 f 在定义域 χ 的边界 ∂χ 上对参数 π 的不连续性。
    2.  **边界积分计算**：
        - **边缘采样**：直接在不连续的边界（如物体轮廓、阴影边界）上进行采样。直观但效率低，且难以找到所有边界（如镜面反射边界）。
        - **重参数化**：通过变量替换或构建变换场，将边界积分转化为基于面积采样的积分。例如，利用散度定理将边界积分 ∮_{∂χ} ... 转换为面积分 ∬_{χ'} ∇ω·(...) dω，从而与传统的面积采样兼容，效率更高且通常无偏。
    3.  **针对不同参数的微分**：对于材质参数，导数通常连续，不涉及边界积分。对于几何参数（尤其是网格、SDF），导数在物体边缘不连续，必须正确处理边界积分。
    4.  **效率优化**：采用针对微分分布的重要性采样、边界样本池重用（ReSTIR）、辐射度反向传播算法等来降低方差和内存开销。
- **训练方式**：在逆向渲染应用中，整个流程是一个优化过程。场景参数是优化变量，渲染损失（如L1/L2 Loss）是目标函数，可微渲染提供的梯度用于指导梯度下降法（如Adam）更新参数。
- **和已有方法的差异**：相比于不可微的渲染方法（如传统光栅化、部分基于学习的神经渲染），本综述强调的方法严格遵循物理定律，旨在计算精确的梯度。相比于早期可微渲染方法，现代方法（特别是基于路径空间和重参数化的）在处理复杂光路和边界不连续性上更正确、更高效。
