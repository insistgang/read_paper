## 摘要

**英文原摘要(据 PDF 提取文本整理, 修复空格与连字符)**:

> The rapid proliferation of malware variants poses a serious threat to network security, and accurately and quickly identifying these variants is a key aspect of security defense. Existing research leverages the advantages of end-to-end deep learning models for detection; however, the models are computationally expensive and have limitations in performance, making practical deployment challenging. Therefore, a GMA (byte stream GLCM, assembly instruction Markov, API) image dataset based on color coding and data mapping is built, which maximizes feature information retention while ensuring lightweight data scaling. A lightweight malware detection model, MTFKD (Malware Texture Feature Classification based on Knowledge Distillation), is proposed, which applies a knowledge distillation strategy to reduce model complexity, integrates an efficient multi-scale attention mechanism with the atrous spatial pyramid pooling to enhance feature expression, and employs an improved Random Forest algorithm to enhance classification efficiency. Experiments demonstrate that the proposed model achieves 99.49% detection accuracy with significantly reduced complexity, greatly enhancing the model's practical applicability and generalization.

## 研究背景与动机

- **为什么要做**: 据 Kaspersky 报告, 2024 年其每日检测到的全球新增恶意软件近 50 万个; Gartner 预测 2025 年全球信息安全支出将超 1.5 万亿元 (较 2024 年增长 15.1%)。恶意软件编辑者通过加密、混淆、操作码重排等手段不断生成变种, 使传统基于签名/特征的检测方法难以识别, 因而有效检测恶意软件具有重要现实意义。
- **之前方法的问题**: 1) 大多研究使用单一特征将恶意软件转换为灰度图等形式, 或对多个特征图像简单组合, 忽略了恶意代码间的特征依赖关系, 难以有效检测变种; 2) 端到端深度学习模型复杂度较高, 对计算资源与数据集需求大、性能开销大, 难以在资源受限环境下部署。
- **核心矛盾**: **检测准确性**与**模型轻量化(低计算资源消耗)** 之间的矛盾。作者旨在构建既能全面捕捉恶意软件多维度特征、又能将模型规模与计算成本控制在较低水平的检测方法。
- **相关工作脉络(引言所列)**: Cui 等将恶意代码转为灰度图 + CNN 自动提取分类; Xing 等用自编码器对灰度图分类(仅全局信息, 对变种适应性低); Dhanya 等基于 Dalvik 字节码生成 Markov 图像 + CNN 检测 IoT Android 恶意软件(良性/恶意区分准确度 99.41%, 但未考虑上下文关联); 王金伟等结合 N-gram + TF-IDF 构建 DenseNet88_CBAM; Vasan 等用色彩映射将灰度图转彩色图并微调 CNN; 轩勃娜等(文献[11])用多特征组合生成 RGB 图像并改进 CNN(但模型规模较大)。

## 关键贡献

1.  **构建 GMA 图像数据集**: 提取恶意软件三类特征纹理——二进制字节流灰度共生矩阵(byte stream GLCM)图像、汇编指令 Markov 图像和 API 调用序列图像, 基于 RGB 颜色编码技术重构到三通道, 生成数据映射后的可视化特征集 GMA。三个 256×256 单通道灰度图分别映射到 R/G/B, 在丰富信息视角的同时, 数据规模比直接应用单通道图像的组合缩减了 2/3。
2.  **设计 MTFKD 轻量化检测框架**: 引入解耦知识蒸馏(DKD)技术, 将知识由复杂教师网络(ResNeXt-50)迁移至轻量学生网络(MobileNetV2), 实现模型规模的精简与压缩。
3.  **结合 EMA 与 ASPP 强化特征表达**: 在深度特征抽取网络中集成高效多尺度注意力机制(EMA)与空洞空间金字塔池(ASPP), 避免特征信息损失或冗余。
4.  **采用改进随机森林分类器**: 将深度网络仅作为特征提取器, 后接改进随机森林(IRF), 用加权投票(代替简单投票)整合多棵决策树预测, 增强优异决策树影响、削弱劣质决策树负面作用, 进一步降低计算资源消耗并提升检测速度。

## 方法

- **整体框架**: MTFKD 框架(图 5)包括**恶意软件深度特征抽取模块**与**恶意软件分类模块**。前者基于 DKD 在大规模模型与轻量模型间迁移知识、提取 GMA 图像深度特征; 后者利用随机森林的并行计算特性提升对变种的分类效率与响应速度。
- **输入输出**: 输入为提供 .byte 与 .asm 两种文件格式的恶意软件样本; 输出为所属恶意软件家族类别(共 9 类)。
- **关键模块与连接**:
    1.  **可视化特征集生成(GMA)**:
        - **API 调用序列特征(图 1)**: 基于相似性聚类将功能相似的 API 归类并分组到有限数量的动态链接库; 用词嵌入将 API 序列转向量, 计算余弦相似度生成相似度矩阵, 采用 **K 均值聚类**实现 API 分组。对分组后的单个 API 聚类名称按字母依次做 ASCII 值编码并转十进制(ASCII 范围 32~126, 编码后落在 [0,255]), 直接映射为像素值, 生成 API 灰度图像。
        - **汇编指令 Markov 特征(图 2)**: 从 .asm 文件提取操作码与操作数, 按寄存器类型标记操作数, 对相同功能操作码合并归类(如 Mov/Movq/Movd 合并)。经统计筛选**将汇编指令缩减至 255 个**, 剩余部分(约 0.04%)统一归为第 256 个, 按出现概率从高到低编码(范围 0~255)。假设 Markov 链 P(t_{i+1}|t_0,…,t_i)=P(t_{i+1}|t_i), 由公式(1) 计算一步转移概率 P_{m,n}=f(m,n)/Σf(m,n), 得到 256×256 转移概率矩阵, 据此填充为 256×256 Markov 图像。
        - **二进制字节流 GLCM 特征(图 3)**: 三步——1) 将字节流按 8 位切分, 由公式(3)转为 [0,255] 无符号十进制整数填充为灰度图像; 2) 直方图均衡化增强对比度, 并将灰度级别**从 256 降至 128** 以加速 GLCM 生成; 3) 取距离值为 1, 在 0°/45°/90°/135° 四个方向各计算一个 128×128 子矩阵并堆叠, 形成 256×256 GLCM 图像。
        - **颜色编码与映射(图 4)**: 三类图像尺寸已统一为 256×256, 无需额外对齐, 分别映射至 R/G/B 三通道生成 GMA 数据集。
    2.  **深度特征抽取模块(算法 1)**: 教师网络为 ResNeXt-50(保留残差连接、用分组卷积替代标准卷积, 提升性能并降低计算成本), 学生网络为 MobileNetV2(深度可分离卷积 + 瓶颈层 + 倒置残差结构)。原文指出 MobileNetV2 相较 ResNeXt **参数量缩减约 86.4%、计算量降低 9.7%**。
        - **解耦知识蒸馏(DKD)**: 总损失(公式 4) DKD = α·TCKD + β·NCKD, 包含目标类知识蒸馏(TCKD)与非目标类知识蒸馏(NCKD)两个独立部分, 通过调整 α、β 在两部分间取得最佳平衡, 引导学生网络既学习教师对正确类别的判断, 也学习其对错误类别的区分能力。
        - **高效多尺度注意力(EMA, 图 6)**: 将输入特征图在通道维度划分为多个子特征, 经三步——1) 并行子网络处理(1×1 分支做宽/高方向一维全局平均池化 + 1×1 卷积 + Sigmoid 生成通道权重; 3×3 分支堆叠 3×3 卷积捕捉局部多尺度); 2) 跨空间学习(用 Softmax 生成两张空间注意力图: 1×1 分支捕捉长程依赖、3×3 分支保留精确空间位置, 聚合后经 Sigmoid 生成空间权重); 3) 特征融合(由空间权重输出融合特征图)。EMA 相较其他注意力更轻量、计算开销低、收敛更快。
        - **空洞空间金字塔池(ASPP)**: 由空洞卷积与空间金字塔池(SPP)组合, 用空洞卷积扩大感受野捕获多尺度上下文, 用 SPP 适应任意尺寸图像输入并输出固定维度向量, 解除 CNN 对输入图像尺寸的限制、降低信息丢失概率。
        - **特征提取流程(算法 1)**: GMA 图像依次经 EMA → 骨干块(ResNeXt_Block / MobileNetV2_Block) → ASPP, 教师与学生分别输出 Feat_T、Feat_S; 计算两者 L2 损失 L=‖Feat_S−Feat_T‖², 用梯度下降优化学生网络。最后将学生输出经全连接层 FC, 再经展开层与激活得到一维深度特征向量 V。
    3.  **恶意软件分类模块**: 将向量 V 输入改进随机森林 IRF。先对每棵树估计关于类别 k 的加权概率 P_{tr}(k|V), 再由公式(5) 计算加权平均 P(k|V)=Σ(P_{tr}(k|V)·CR_{tr})/ΣCR_{tr}(CR_{tr} 为第 tr 棵树的权重), 最后由公式(6) ŷ=argmax_k P(k|V) 选最有可能类别。加权投票相比简单投票更能抑制劣质决策树, 规避过拟合并缓解数据不平衡。
- **训练方式**:
    - GMA 数据集按 **8:2** 划分训练/测试集, 采用 **10 折交叉验证**, 用网格搜索做参数寻优。
    - 深度特征抽取: 批大小 64, 训练 60 个 epoch; 采用**带预热的余弦衰减学习率(Warm-up Cosine Annealing)**, 初始学习率 0.001; Adam 优化器 + 交叉熵损失。
    - DKD 蒸馏系数 α=1.0, β=8.0; IRF 决策树数量 n_estimators=60。
    - 硬件: AMD EPYC 9654 96-Core + NVIDIA RTX 4090; 软件: Ubuntu 22.4、Python 3.10、PyTorch 2.1.0。
- **推理流程**: 恶意软件样本 → 生成 GMA 三通道图像 → 输入含 EMA + ASPP 的轻量学生 MobileNetV2 → 抽取深度特征向量 V → 输入 IRF → 输出家族分类结果。
- **和已有方法的差异**: 1) 数据层面用颜色编码将三种互补特征深度融合为一张 RGB 图, 信息更丰富且规模缩减 2/3; 2) 模型层面用知识蒸馏 + EMA/ASPP 替代大规模端到端 CNN; 3) 分类器层面用加权投票随机森林替代 CNN 末端全连接层, 平衡特征提取能力与分类效率/稳健性。

## 实验

- **数据集**: 微软公开 MMCC 数据集(文献[22]), 使用其训练集部分, 共 **10 868 个样本、9 个家族**, 每样本提供 .byte 与 .asm。家族分布(表 2): Ramnit(蠕虫) 1541、Lollipop(广告) 2478、Kelihos_ver3(后门) 2942、Vundo(木马) 475、Simda(后门) 42、Tracur(下载器) 751、Kelihos_ver1(后门) 398、Obfuscator.ACY(混淆) 1228、Gatak(后门) 1013, 总计 10 868。数据存在明显不平衡。
- **对比方法**:
    - 可视化方案对比(表 3): 单通道 G(字节码 GLCM)/M(汇编 Markov)/A(API 灰度), 三通道 S1(文献[11,25])、S2、S3、GMA。
    - 检测网络对比: 基础 CNN、VGG16、ResNet-50、EfficientNetV2(文献[24])。
    - 分类器对比: KNN、逻辑回归、XGBoost、SVM、IRF。
    - 同类研究对比(表 6): 与同样使用 MMCC 的 6 项工作(文献[17,23,25,26,27,28])比较。
- **评价指标**: 因数据不平衡, 采用加权准确率/召回率/精确率/F1(Accuracy_w、Recall_w、Precision_w、F1_w, 公式 7~10, 权重 w_k=n_k/N)。同时记录参数量、浮点数(FLOPs)与运行时间。
- **主实验结果**:
    - **数据集有效性(图 7)**: 随可视化方案优化各网络准确率总体提升; 单通道中以操作码 Markov 图贡献最高; 三通道优于单通道。GMA 在 MTFKD 上达到 **99.49%** 准确率, 有效性最高。
    - **网络压缩(表 4)**: ResNeXt-50(教师) 参数量 31.65M、FLOPs 1.60G、运行 88.59ms、准确率 98.75%; MobileNetV2(直接训练 / 作学生) 参数量 10.15M、FLOPs 9.66G、运行 47.64ms; 直接训练 97.62%, **作学生网络经蒸馏后达 99.49%(较直接训练 +1.87%, 且超过教师 98.75%)**。对比文献[11] EfficientNetV2(参数量 30.20×10⁶、FLOPs 7.27×10⁹), 本文 MobileNetV2 参数量显著更低。
    - **分类器性能(图 9)**: IRF 与各特征抽取网络结合时均表现出较高准确率, 其加权投票可集成各树性能避免过拟合, 并能并行处理高维特征。
    - **同类对比(表 6)**: MTFKD 在准确率/召回/精确率/F1 上达最优 **(99.49 / 99.49 / 99.50 / 99.50%)**, 运行时间 **47.64ms** 也最具竞争力。对照: Xception CNN[26] 99.12%(500ms)、MalCVS[27] 98.94%(135ms)、EfficientNetB1[23] 99.00%(188.10ms)、FACILE[17] 97.20%(436.14ms)、TriCh-LKRepNet[25] 99.47%(61.00ms)、MalSort[28] 97.85%。仅 EfficientNetB1[23] 与本文采用加权指标。
- **消融实验(表 5, 图 8 混淆矩阵)**: 移去 EMA → 98.85%(参数 6.60M, 37.13ms); 移去 ASPP → 99.03%(7.45M, 40.26ms); 移去最终分类器 → 98.85%(9.78M, 55.45ms); 完整 MTFKD → 99.49%(10.15M, 47.64ms)。各模块缺失均导致性能不同程度下降, 验证 EMA(获取更多有效特征、加速收敛)、ASPP(免裁剪/变形、避免信息丢失冗余)、IRF(提升响应速度)的协同作用。
- **速度/参数量/FLOPs 小结**: 学生 MobileNetV2 参数量 10.15M、运行 47.64ms, 相较教师 ResNeXt-50(31.65M, 88.59ms)与文献[11] EfficientNetV2(30.20M)体现显著轻量化优势。

## 局限

1.  **数据集局限**: 实验仅使用 MMCC 单一公开数据集; 论文结语也明确表示后续将"使用包含更多家族样本的公开数据集进一步验证模型的泛化性"。
2.  **对零日攻击的检测**: 模型依赖已知家族特征学习; 论文结语将"加强对持续性威胁及零日攻击的检测"列为未来工作, 即当前对零日攻击的检测能力 PDF 文本未给出实验证据。
3.  **预处理成本未量化**: 表 4/表 6 报告的运行时间仅为模型推理阶段; 数据预处理(API 聚类、Markov 矩阵、GLCM 计算、生成 GMA 图像)的计算开销 PDF 文本未明确说明。
4.  **FLOPs 表象需注意**: 表 4 中 MobileNetV2 FLOPs(9.66G)反而高于 ResNeXt-50(1.60G), 但参数量、运行时间均显著更低; PDF 文本未对此 FLOPs 反差作解释(待核)。
5.  **知识蒸馏的依赖性**: 学生网络性能上限受教师网络(ResNeXt)选择与训练效果影响, 这一依赖性 PDF 文本未单独讨论(基于框架推断)。

## 个人评论

1.  **多特征融合的数据轻量化思路**: 通过颜色编码将三种不同层次特征(二进制底层纹理 / 汇编指令行为模式 / API 语义序列)融合到一张 RGB 图中, 在丰富信息的同时把数据规模缩减 2/3。这种"异构特征 → 统一尺寸图 → 通道映射"的范式可推广到其他多模态/多特征融合检测任务。
2.  **"知识蒸馏 + 轻量骨干"的模型压缩范式**: 论文给出一个值得注意的现象——学生 MobileNetV2 经 DKD 蒸馏后准确率(99.49%)反超教师 ResNeXt-50(98.75%), 说明蒸馏不只是压缩, 还可能起到正则/知识提纯作用; 这是该方向常见但仍有意思的结论。

# 论文精读

## 1. 论文定位
本文属于网络安全领域的**恶意软件检测**方向, 具体研究"图像可视化 + 深度学习模型轻量化"的恶意软件家族分类。核心问题是: 如何在保持高检测准确率的同时, 大幅降低检测模型的计算复杂度与资源消耗, 以便在资源受限环境(如边缘设备)中部署。论文围绕三个支点展开——多特征 RGB 可视化(GMA)、解耦知识蒸馏(教师 ResNeXt-50 → 学生 MobileNetV2)、改进随机森林分类器(IRF)。适合归入"入侵检测 / 恶意软件分析"主题, 与"深度学习模型压缩""恶意软件可视化"交叉。

## 2. 一句话总结
本文提出融合数据映射(生成三通道 GMA 图像)与解耦知识蒸馏的轻量化恶意软件检测模型 MTFKD, 将复杂教师网络(ResNeXt-50)知识迁移至轻量学生网络(MobileNetV2)并结合 EMA/ASPP 与改进随机森林, 在 MMCC 数据集上达到 99.49% 准确率的同时把参数量降至 10.15M、推理时间降至 47.64ms。

## 3. 背景与问题
- **为什么要做**: 恶意软件变种指数级增长(Kaspersky 报 2024 年日增近 50 万个新样本), 编辑者通过加密、混淆、操作码重排等生成变种, 使传统签名/特征检测失效。深度学习虽有效, 但端到端模型复杂度高、资源需求大, 难以在资源受限环境部署。
- **之前方法的问题**: 1) 多用单一特征灰度图或简单组合多特征图, 忽略恶意代码间特征依赖关系, 难检测变种; 2) 端到端模型复杂度高、性能开销大、部署困难。
- **核心矛盾**: 检测准确性 vs 模型轻量化。

## 4. 核心贡献
1.  **GMA 三通道可视化数据集**: 二进制字节流 GLCM 图、汇编指令 Markov 图、API 调用序列灰度图(各 256×256)经 RGB 颜色编码映射为三通道, 信息更全面且规模比单通道组合缩减 2/3。
2.  **MTFKD 轻量化框架**: 基于解耦知识蒸馏(DKD)将知识由 ResNeXt-50 迁移至 MobileNetV2, 精简模型规模。
3.  **EMA + ASPP 强化特征**: 集成高效多尺度注意力与空洞空间金字塔池, 避免特征损失/冗余、解除输入尺寸限制。
4.  **改进随机森林(IRF)分类器**: 把深度网络作纯特征提取器, 后接基于加权投票的 IRF, 降低计算成本、提升分类速度与稳健性。

## 5. 方法详解
- **整体框架(图 5)**: 深度特征抽取模块(DKD + EMA + ASPP)与分类模块(IRF)两部分; 输入提供 .byte/.asm 的恶意软件样本, 输出 9 类家族标签。
- **GMA 生成**:
    - **API(图 1)**: 词嵌入 + 余弦相似度 + K 均值聚类对 API 分组, 聚类名按字母做 ASCII 编码(范围 32~126 → [0,255])直接映射为像素, 得 API 灰度图。
    - **Markov(图 2)**: 提取操作码/操作数, 合并同功能操作码(如 Mov/Movq/Movd), 缩减至 255 个 + 1 个(剩余约 0.04%)= 256 类, 按公式(1) P_{m,n}=f(m,n)/Σf(m,n) 算一步转移概率, 填充 256×256 Markov 图。
    - **GLCM(图 3)**: 字节流按 8 位切分经公式(3)转 [0,255] 灰度图 → 直方图均衡化 + 灰度级 256 降至 128 → 取距离 1、0°/45°/90°/135° 四方向各 128×128 子矩阵堆叠成 256×256 GLCM 图。
    - **颜色编码(图 4)**: 三图尺寸已统一为 256×256, 直接映射 R/G/B 生成 GMA。
- **深度特征抽取(算法 1)**: 教师 ResNeXt-50(分组卷积)、学生 MobileNetV2(深度可分离卷积 + 倒置残差); MobileNetV2 相较 ResNeXt 参数量减约 86.4%、计算量降 9.7%。DKD 损失(公式 4) = α·TCKD + β·NCKD。EMA(图 6, 三步: 并行子网络 / 跨空间学习 / 特征融合)生成通道与空间注意力。ASPP(空洞卷积 + SPP)适应任意输入尺寸。流程: GMA → EMA → 骨干块 → ASPP → 教师/学生各出特征 → L2 损失 ‖Feat_S−Feat_T‖² 经梯度下降优化学生 → FC + Flatten 得向量 V。
- **分类(IRF)**: 公式(5) 加权平均 P(k|V)=Σ(P_{tr}(k|V)·CR_{tr})/ΣCR_{tr}, 公式(6) ŷ=argmax_k P(k|V); 加权投票抑制劣质树、缓解不平衡。
- **训练**: 8:2 划分 + 10 折交叉验证 + 网格搜索; batch=64, epoch=60, Warm-up Cosine Annealing lr 初值 0.001, Adam + 交叉熵; α=1.0/β=8.0; IRF 树数 60。硬件 RTX 4090, PyTorch 2.1.0。

- **指标**: 加权 Accuracy/Recall/Precision/F1(公式 7~10) + 参数量/FLOPs/运行时间。
- **主结果**:
    - **数据集有效性(图 7)**: 单通道中 Markov 贡献最高; GMA 在 MTFKD 上达 99.49%。
