## 摘要

本文通过部署高空摄像头构建近地面监控网络，并采用Faster R-CNN模型实时识别视频图像中的耕地违法占用行为（如机械作业、场地硬化），结合空间信息融合实现了对违法行为的自动化预警，有效提升了特大城市耕地保护的监管时效性。
## 研究背景与动机

- **论文为什么要做**：中国（特别是上海这样的特大城市）对耕地保护要求严格，需坚守1.8亿亩耕地红线。传统的卫星影像执法存在时效性差、准确性有限的问题，无法满足“发现即执法”的精细化管理需求。
- **之前方法有什么问题**：1) **时效性不足**：卫星影像重访周期长，难以实时发现违法行为。2) **准确性局限**：对上海耕地分散、面积小的特点，大尺度卫星监测的精度和粒度不够。3) **单一监管手段**：传统的远程感监测与地面人工巡查相结合的模式效率不高。
- **作者想解决的核心矛盾**：如何在城市耕地分散、违法行为隐蔽的背景下，实现**高时效、高粒度、自动化**的土地违法行为监测与预警。
## 关键贡献

1.  **提出了系统的违法场景分类与识别目标体系**：将土地违法行为细化为三大类预警场景（启动预警、施工场地预警、破土预警）及13个具体识别目标（如起重机、围墙、废弃物堆积、地面硬化等），为模型训练提供了明确的任务定义。
2.  **构建了面向违法监测的多源样本库与优化流程**：综合利用多年遥感识别成果、航空/卫星/无人机多角度影像以及AI生成图像构建样本库，并针对样本边缘坐标复杂的问题，采用“最大外接矩形”简化和优化样本，提升了样本质量。
3.  **采用了适配小目标识别的深度学习模型与优化策略**：选用Faster R-CNN模型作为检测框架，并针对“破土预警”等场景中目标尺寸差异大的问题，优化设置了多尺度的anchor尺寸 `(32², 64², 128², 256², 512²)`，以兼顾大小目标的识别。
4.  **设计并实现了从识别到预警的闭环监管平台**：将模型识别结果通过视频空间位置与地理坐标的双向转换进行空间定位，结合业务审批数据进行比对分析，实现自动推送疑似违法图斑、现场核查与反馈的完整管理闭环。
## 方法

- **整体框架**：技术路线为“高空摄像头部署 -> 视频实时传输与帧提取 -> Faster R-CNN模型目标识别 -> 空间信息融合与坐标转换 -> 违法行为实时预警 -> 人工核查与反馈”。
- **输入输出**：**输入**为高空摄像头拍摄的实时视频流经帧提取得到的图片。**输出**为检测到的违法目标的**类别（三种场景之一）**、**图像边界框**，并通过坐标转换得到其**地理坐标**。
- **关键模块与连接**：
    1.  **骨干网络 (Backbone)**：采用ResNet50进行图像特征提取，其深层网络结构有助于提取抽象和深层的目标特征，适用于纹理特征不明显的目标。
    2.  **区域提议网络 (RPN)**：在输入的特征图上滑动窗口，为每个位置生成k个不同大小的anchor，通过二分类（前景/背景）和边界框回归，筛选出高质量的候选区域（proposals）。
    3.  **感兴趣区域池化 (RoI Pooling)**：将不同尺寸的候选区域映射为固定大小的特征图，以便后续进行统一的分类和回归。
    4.  **检测头 (Head)**：包含全连接层和softmax分类器用于目标分类，以及回归器用于对边界框进行微调，最终输出每个推荐区域所属的类别和精确位置。
- **数学公式机制**：论文给出了模型评估的核心指标公式（p.250）：
    - 精确率 (Precision)： P = TP / (TP + FP)，衡量预测为正的样本中实际为正的比例。
    - 召回率 (Recall)： R = TP / (TP + FN)，衡量实际为正的样本中被预测为正的比例。
    - 平均精度均值 (mAP)：不同类别平均精度（AP）的均值，AP是精确率-召回率曲线下的面积。
- **训练方式**：在开源框架PyTorch上进行训练。使用ResNet50作为特征提取网络，初始学习率设为`0.001`。epoch数量根据过拟合风险和时间成本权衡设定，anchor尺寸根据目标尺度优化设定。
- **推理流程**：摄像头实时获取视频 -> 定期抽取视频帧为图像 -> 图像输入训练好的Faster R-CNN模型 -> 模型输出检测到的目标框及类别 -> 将目标框在视频图像中的像素坐标，通过预设的转换模型（论文中称“双向转换技术”）转换为地理坐标 -> 地理坐标与审批数据库比对，若无匹配则生成疑似违法警报并推送。
- **与已有方法的差异**：区别于纯卫星遥感的大尺度、长周期监测，本方法利用**近地面视频监控**实现了更高时空分辨率的监测；区别于通用的目标检测应用，本研究针对**土地违法场景**专门定义了三类预警场景及13个目标，并优化了模型和样本，使其更适合识别工程车辆、场地硬化等特定目标。
