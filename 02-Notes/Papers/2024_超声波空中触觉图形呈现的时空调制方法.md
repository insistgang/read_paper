## 研究背景与动机

- **为什么要做**：随着虚拟现实（VR）、增强现实（AR）和混合现实（MR）的发展，触觉交互成为提升沉浸感的关键。超声波空中触觉技术因其非接触、无约束的特点成为主要途径。然而，在呈现多点构成的触觉图形时，现有技术存在不足。
- **之前方法的问题**：传统的调制方法（特别是顺序时空调制）在呈现多点图形时，**在一个调制周期内仅进行单点聚焦**，然后快速顺序切换到下一个点。这种方法的**超声波发射阵列使用率较低**，并且由于在周期内存在信号“空档期”，导致低频噪声较大，聚焦反馈力较弱，影响用户的触觉体验和图形识别。
- **核心矛盾**：**需要在单个调制周期内呈现多个聚焦点（以形成连续图形），同时要兼顾阵列的高效率利用和低噪声输出**。传统顺序切换方法无法很好地平衡这两点。
## 关键贡献

1.  **提出了新型的基于时空调制的超声波多点同步聚焦方法**：该方法将单个调制周期按需聚焦的点数平均分配成时间片，在每个时间片内完成一个点的聚焦，从而在一个周期内实现所有焦点的聚焦。
2.  **提高了超声波发射阵列的利用率**：与传统方法相比，新方法在调制周期的整个时间段内都持续发射信号，避免了资源闲置，提升了聚焦效率。
3.  **显著降低了聚焦噪声**：由于消除了信号“空档期”，减少了低频噪声的叠加，使调制信号的能量更集中，可听噪声更低。
4.  **提升了复杂触觉图形的主观识别率**：实验表明，新方法使得三角形、矩形、圆形等图形的用户识别准确率得到明显提升。
5.  **给出了完整的算法设计与实现框架**：包括从图形焦点选取、延时计算、驱动信号生成到分时聚焦控制的完整流程，并提供了可验证的实验设置与数据分析。
## 方法

- **整体框架**：该方法是一个**信号处理与控制流程**。首先确定待呈现图形所需的多个焦点坐标；其次，计算每个焦点对应的各超声发射器的驱动延时；然后，生成一个调制信号，并将其周期按焦点数量等分；最后，在等分的时间片内，依次将对应焦点的延时数据送入延时控制模块，驱动发射器阵列完成多点聚焦。
- **输入**：待呈现触觉图形的**多个焦点的三维坐标 (x, y, z)**。
- **输出**：驱动324个（18x18）超声波发射器的**脉冲信号序列**。
- **关键模块与连接**：
    1.  **焦点坐标接收模块**：接收上位机发送的焦点坐标。
    2.  **延时计算与存储模块**：为每个焦点计算所有发射器所需的延时（公式1-3），并存储。这是**核心计算部分**。
    3.  **信号发生与分频模块**：产生超声波载波信号（40kHz）和人体可感知的调制信号（如100Hz/200Hz），并将调制周期等分。
    4.  **延时控制与驱动模块**：在调制周期的不同时间片内，加载对应焦点的延时数据，控制驱动信号时序，最终放大信号驱动发射器。
- **数学公式与机制解释**：
    - **公式1** `Smni = sqrt((xm-xi)^2 + (yn-yi)^2 + zi^2)` 计算阵列中第(m,n)个发射器到第i个焦点的距离，用于后续判断发射器是否在有效角度内。
    - **公式2** `Lmax = zi / cos(θ/2)` 根据焦点距离`zi`和发射器衰减角`θ`（实验中为80°），计算最长有效发射距离，用于筛选参与工作的发射器。
    - **公式3** `τmni = (sqrt((na*r)^2 + zi^2) - sqrt((nb*r)^2 + zi^2)) / c` 计算任一发射器相对中心发射器（最近）的驱动延时`τ`。其中`c`为声速，`r`为发射器间距。**核心思想**是让距离远的发射器先发射，距离近的后发射，以保证所有声波同时到达焦点。
- **训练/推理流程**：这是一个**确定性的计算流程**，不存在模型训练。推理（或执行）流程即为上述框架的顺序执行：接收坐标 -> 计算并存储所有焦点的延时表 -> 生成分时驱动信号 -> 驱动阵列。
- **与已有方法的差异**：与**传统顺序时空调制**（如图1所示）相比，传统方法在每个调制周期内只完成一个点的聚焦，点与点之间切换时存在信号低电平期。本方法（如图2所示）将调制周期`T0`等分为`I`个时间片（I为焦点数），在`T1`到`TI`内依次完成`I`个点的聚焦，整个周期内信号持续，无空档，从而**提升了阵列利用率并降低了低频噪声**。
