## 研究背景与动机

- **论文为什么要做**：图像在拍摄、传输和存储过程中常遭遇多种退化（雨雪雾、模糊、噪声、低分辨率、压缩伪影等），不仅降低视觉效果，还严重影响计算机对图像的理解，并削弱依赖高质量输入的下游高层任务（语义分割、目标检测），在自动驾驶、智能医疗等数据敏感场景影响尤甚。随着 OpenAI 的 ChatGPT、SoRA 等现象级应用出现，视觉/语言/多模态大模型在理解、生成、交互方面性能大幅提升，为图像复原增强这类底层视觉任务带来新的解决思路。本文旨在系统总结这些大模型技术如何推动该领域发展。
- **图像复原的数学刻画**：论文给出退化模型 **I = R + B**，其中 I 为输入降质图像、R 为退化信息、B 为干净背景信息。由于 R、B 均不可知，由 I 重建 B 是一个 **1→∞ 的欠定（不适定）问题**。2017 年之前方法大多是"模型 + 优化"的非深度学习方法（如 He 等人 2011 的暗通道先验去雾）；之后进入深度学习时期，用 CNN/RNN/GAN 等端到端学习"降质图像→清晰图像"的直接映射。
- **之前方法的问题**：传统方法依赖数学建模和手工特征，往往只针对单种退化、训练样本少，泛化能力有限，复杂场景下效果不理想。深度学习方法虽有进步，但仍面临任务本身的**不适定性**、真实场景退化分布的复杂性、约束弱与先验不足、与高层任务兼容性差、缺乏自适应和难以交互等挑战。
- **核心矛盾**：**真实世界图像退化的复杂性、多样性与现有复原模型在泛化能力、细节恢复、语义理解、交互性之间的矛盾**。作者通过总结视觉/多模态大模型的最新应用，展示它们如何为解决这一矛盾提供新路径。

1.  **系统整理图像复原增强数据集**：按任务类型（去噪、去雨、去雾、超分、低光、去阴影、去模糊等）汇编常用公共基准，分析其规模、质量、配对情况及低质图像的生成方式（详见原文表 1）。

3.  **总结扩散模型的复原方法**：介绍从生成模型（DDPM、Stable Diffusion、ControlNet）到复原模型（DDRM、DiffIR、Refusion）的迭代去噪范式，强调其在严重退化下恢复细节的能力，同时指出可能生成"不真实"内容的风险。

5.  **介绍多模态大模型的复原应用**：阐述 CLIP、GPT-4V 等如何通过跨模态对齐与语义信息融合，为复原任务（如 DACLIP-UIR）提供文本指导，增强灵活性与上下文理解。
6.  **分析挑战并展望未来方向**：明确指出数据获取困难、计算资源需求高、模型稳定性不足等关键挑战，并展望提高模型对资源约束的适应性、开发更高效的数据获取方法、增强鲁棒性等方向。

## 方法

本文为综述（survey），未提出单一新方法，而是系统总结四大类技术路径在图像复原增强中的应用。论文结构：背景介绍（第 1 节）→ 国内外研究现状（第 2 节，含数据集 2.1、基于 ViT 2.2、基于扩散模型、基于 X-anything、基于多模态大模型）→ 挑战与展望（第 3 节）。

- **基于 ViT 的方法**：核心是用**自注意力机制**建模图像**长距离依赖**，将图像切分为固定大小图块当作序列处理，克服 CNN 全局信息建模的局限。论文将现有工作归为三个方向：(1) 利用 ViT 长距离依赖与大数据预训练优势，在大量退化数据上预训练（如 IPT）；(2) 基于面向高层任务的 ViT 基准模型，探索其在复原领域的应用并提出多任务基准（如 SwinIR）；(3) 针对少数底层任务结合先验改进，涵盖轻量高效（ESRT）、空间—频域求解（Kong 2023）、长距离依赖（Zhu 2023）、注意力设计（Chen 2023b）、多尺度提取（Zhou 2024）等角度。
    - **代表模型**：**IPT**（Chen 2021，多头多尾结构处理多种复原任务，用 ImageNet 生成退化对预训练）；**SwinIR**（Liang 2021，基于 Swin Transformer，由浅层特征提取 / 深层特征提取 / 高质量重建三模块组成，引入 3D 位置嵌入提供相对位置编码与空间信息，结合 CNN 与 Transformer 优势）；**Restormer**（Zamir 2022，多头注意力 + 前馈网络，兼顾适用性与长距离像素交互，适用于高分辨率复原，缓解计算复杂度随分辨率剧增的问题）。
    - **分任务代表工作**（提取文本 2.2 节）：去雨—TDATDN（3D 注意力 + Transformer，减少去雨伪影）、DRSformer（稀疏 Transformer，自适应保留关键注意力分数）、FDSATFormer（频率引导双稀疏自注意力降算量）、ELF（江奎 2024，CNN 局部感知 + 自注意力全局聚合）；去雾—DeHamer（特征调制融合全局上下文与局部表征）、DehazeFormer（改进 Swin Transformer 的归一化层/激活函数/空间聚合）；去模糊—Kong 2023（频域自注意力求解器，逐元素乘积降复杂度）；去噪—LIDFormer（轻量三重多尺度反卷积头转置注意力）；去阴影—Xiao 2024（随机洗牌均匀化阴影分布 + 不依赖位置编码的局部自注意力）；超分—TTSR（纹理 Transformer 转移高分纹理）、ESRT（轻量 CNN 骨干 + 高效 Transformer）、CAET（CNN 与 Transformer 特征融合 + 通道注意力）。
- **基于扩散模型的方法**：核心是**迭代去噪生成**——逐步加噪并学习逆向去噪过程。脉络：Sohl-Dickstein 2015 提出扩散模型 → DDPM（Ho 2020，参数化高斯建模逆向步骤，前/反向更对称简洁）→ Stable Diffusion（Rombach 2022，VAE 映射到潜在空间内扩散，降算量）→ ControlNet（Zhang 2023c，扩散步骤引入控制信号实现精细控制）。复原方向：**DDRM**（Kawar 2022，用预训练 DDPM 解去模糊/超分等线性逆问题）、**DiffIR**（Xia 2023）、**Refusion**（Luo 2023），结合 Stable Diffusion 的适应性修复不同程度退化。优势是细节丰富，风险是可能生成不真实内容、推理速度慢。
- **基于 X-anything 的方法**：核心是利用视觉基础模型的**零样本迁移**与**强先验**。**SAM**（Kirillov 2023，SA-1B 数据集含 1100 万图像、11 亿掩码）实现零样本向新分布/新任务迁移，性能媲美甚至优于全监督。其催生大量 X-anything 模型（SegmentAnything 3D、Inpaint-Anything、Caption-Anything、Grounding DINO、Recognize-Anything、Grounded-SAM、Depth Anything、Matting Anything 等），但多数侧重高层理解/生成任务，缺乏在底层复原上的应用；部分研究（Jin 2023；Xiao 2023；Jiang & Holz 2023）尝试将其零样本预测能力引入复原，尤其适用无标注/弱标注退化场景。
- **基于多模态大模型（LMM）的方法**：核心是**文本—图像跨模态对齐**与**语义指导**。**CLIP**（Radford 2021）采用图像编码器 + 文本编码器双塔架构，通过对比学习使同语义图文特征在高维空间接近，零样本能力强；**GPT-4V** 能从图像提取复杂语义并生成描述。复原应用以 **DACLIP-UIR**（Luo 2024a，degradation-aware CLIP for universal image restoration）为代表，引入视觉—语言模型用文本提示对复原任务（去噪/超分/去模糊等）精细控制，实现多任务高效复原。
- **与已有方法的差异**：相较传统 CNN/GAN，这些大模型方法分别带来**更强的全局建模**（ViT）、**更精细的生成**（扩散模型）、**更强的零样本泛化**（X-anything）和**更智能的语义理解与交互**（多模态大模型）。

## 1. 论文定位
本文是一篇**综述（Survey）论文**，系统总结并分析近年国内外将视觉（大）模型（ViT、扩散模型、SAM 等 X-anything）和多模态大模型（CLIP、GPT-4V）应用于图像复原增强领域的研究进展。它属于计算机视觉**底层视觉**中的**图像复原与增强**方向（去噪、去雨、去雾、去模糊、超分、低光增强、去阴影等），旨在梳理这些大模型如何借助强大的表征、生成、理解与交互能力应对复杂退化问题。适合作为研究"**基于大模型的图像复原技术**"的入门综述与现状参考。发表于《中国图象图形学报》2025, 30(5): 1197-1219。

## 2. 一句话总结
本文系统梳理了视觉 Transformer（ViT）、扩散模型、X-anything 模型（以 SAM 为代表）与多模态大模型（CLIP、GPT-4V）在图像复原增强任务中的应用方法、潜力与挑战，并附带按任务整理的代表性数据集，为利用新兴大模型解决图像退化问题提供了全面的现状分析与未来展望。

## 3. 背景与问题
- **论文为什么要做**：图像在拍摄、传输、存储中常遭遇雨雪雾、模糊、噪声、低分辨率、压缩伪影等退化，降低视觉效果并削弱语义分割、目标检测等下游高层任务的精度，对自动驾驶、智能医疗等数据敏感场景影响重大。随着 ChatGPT、SoRA 等现象级应用出现，视觉/语言/多模态大模型快速发展，其表征、理解、生成、交互能力为图像复原增强这类底层任务带来新思路。本文系统总结这些大模型如何推动该领域发展。
- **图像复原的数学刻画**：退化模型 **I = R + B**（I 输入降质图像、R 退化信息、B 干净背景），R、B 均不可知，由 I 重建 B 是 **1→∞ 的欠定（不适定）问题**。2017 年前以"模型 + 优化"的非深度学习方法为主（如 He 2011 暗通道先验去雾），之后进入深度学习时期，用 CNN/RNN/GAN 端到端学习降质→清晰映射。
- **之前方法的问题**：传统方法依赖数学建模和手工特征，多针对单种退化、样本少、泛化有限。深度学习虽有进步，仍面临不适定性、真实退化分布复杂、约束弱与先验不足、与高层任务兼容性差、缺乏自适应与交互等挑战。
- **核心矛盾**：真实世界退化的复杂性、多样性与现有模型在泛化、细节恢复、语义理解、交互性上的不足之间的矛盾。

## 4. 核心贡献
论文摘要把贡献组织为六个方面：
1.  **数据集整理**：按任务（去噪、去雨、去雾、超分、低光、去阴影、去模糊）汇编公共基准，分析规模、质量、配对与低质图像生成方式（表 1）。
2.  **基于 ViT 的方法**：总结 ViT 长距离依赖与大数据预训练的优势，及 IPT、SwinIR、Restormer 等的应用演进。
3.  **基于扩散模型的方法**：梳理 DDPM→Stable Diffusion→ControlNet 与 DDRM、DiffIR、Refusion 的迭代去噪范式，强调恢复细节的能力与"生成不真实内容"的风险。
4.  **基于 X-anything 的方法**：以 SAM（SA-1B：1100 万图像、11 亿掩码）为代表，分析视觉基础模型的鲁棒零样本预测先验在无/弱标注退化样本上的潜力。
5.  **基于多模态大模型的方法**：CLIP、GPT-4V 通过跨模态对齐与语义融合（如 DACLIP-UIR 用文本提示）指导复原。
6.  **挑战与展望**：数据获取难、计算需求高、稳定性不足；展望对资源约束的适应性、高效数据获取、增强鲁棒性。

## 5. 方法详解
本文为综述，未提出新方法，而是评述四大类路径（结构：背景 1 → 现状 2，含数据集 2.1、ViT 2.2、扩散、X-anything、多模态 → 挑战展望 3）：
1.  **基于 ViT**：用自注意力建模长距离依赖，图块化处理。三个方向：大数据预训练（IPT）、复用高层 ViT 基准并提多任务基准（SwinIR）、结合任务先验改进（轻量 ESRT、空间—频域 Kong、长距离 Zhu、注意力设计、多尺度）。代表模型：**IPT**（多头多尾 + ImageNet 退化对预训练）、**SwinIR**（浅层/深层特征提取 + 高质量重建三模块，3D 位置嵌入，CNN+Transformer）、**Restormer**（多头注意力 + 前馈网络，缓解算量随分辨率剧增，适用高分辨率）。分任务工作：去雨 TDATDN/DRSformer/FDSATFormer/ELF；去雾 DeHamer/DehazeFormer；去模糊 Kong 频域求解器；去噪 LIDFormer；去阴影 Xiao 随机洗牌；超分 TTSR/ESRT/CAET。
2.  **基于扩散模型**：迭代去噪生成。Sohl-Dickstein 2015 → DDPM（Ho 2020，参数化高斯逆向）→ Stable Diffusion（Rombach 2022，潜在空间扩散 + VAE，降算量）→ ControlNet（控制信号精细控制）。复原：DDRM（解线性逆问题）、DiffIR、Refusion。细节丰富但可能不真实、推理慢。
3.  **基于 X-anything**：零样本迁移 + 强先验。SAM（SA-1B 大规模预训练，零样本媲美甚至优于全监督）催生 SegmentAnything 3D、Inpaint/Caption-Anything、Grounding DINO、Depth/Matting Anything 等；多偏高层任务，部分研究（Jin/Xiao/Jiang & Holz 2023）尝试引入底层复原，适合无/弱标注退化场景。
4.  **基于多模态大模型（LMM）**：文本—图像跨模态对齐 + 语义指导。CLIP 双塔（图像/文本编码器 + 对比学习）零样本强；GPT-4V 提取图像复杂语义。复原代表 DACLIP-UIR（degradation-aware CLIP，文本提示精细控制多任务复原）。
- **与已有方法的差异**：相较 CNN/GAN，分别提供更强全局建模（ViT）、更精细生成（扩散）、更强零样本泛化（X-anything）、更智能语义理解与交互（LMM）。
