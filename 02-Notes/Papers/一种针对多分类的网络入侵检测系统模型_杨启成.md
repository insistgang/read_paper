## 摘要

本文提出一种融合自适应卷积、长短期记忆网络和改进自注意力机制的混合深度学习模型CLSA-Net，用于提升多分类网络入侵检测的准确率并降低误报率，并通过模型轻量化实现了在ESP32-S3边缘设备上的高效部署。
## 研究背景与动机

- **为什么要做**：随着物联网发展，网络攻击日趋复杂，对入侵检测系统的性能要求越来越高。同时，许多物联网设备是资源受限的边缘设备，需要轻量化的安全解决方案。
- **之前方法的问题**：
    1.  传统机器学习方法（如SVM、RF）依赖复杂的**人工特征工程**，在处理高维海量数据时面临准确率瓶颈和高误报率。
    2.  现有的深度学习模型（如CNN、LSTM）在**多分类任务**中，尤其是在UNSW-NB15、CICIoT2023等现代数据集上，检测性能显著下降，准确率低且误报率高。
    3.  大多数高性能模型难以在**资源受限的物联网边缘设备**上高效运行和部署。
- **核心矛盾**：如何在**提升多分类入侵检测精度**的同时，实现模型在**低功耗、低算力边缘设备**上的有效部署，达到精度与效率的平衡。
## 关键贡献

1.  **提出了CLSA-Net深度学习模型**：一种分层混合架构，将CNN、LSTM和改进的自注意力机制级联，协同提取网络流量的局部空间特征和长期时序依赖。
2.  **设计了自适应卷积模块**：采用3个级别的CNN-LSTM处理单元，通过**逐步增加卷积核数量（从32到256）** 实现从粗粒度到细粒度特征的逐级提取。
3.  **引入改进的自注意力机制与位置编码**：在LSTM层后引入自注意力机制，并**融合正余弦位置编码**，使模型能动态聚焦于序列中最具信息量的部分，并感知输入事件的顺序。
4.  **实现了模型到边缘设备的部署**：将训练好的模型转换为**TFLite格式**，并成功移植到低成本的**ESP32-S3**嵌入式平台，验证了在资源受限环境中进行实时入侵检测的可行性。
5.  **在多个现代数据集上取得优异性能**：在UNSW-NB15、CICIoT2023等6个公共数据集上进行实验，模型综合检出率和准确率分别达到98.60%和97.42%，优于多种主流方法。
6.  **验证了边缘部署的有效性**：优化后的模型在ESP32-S3上保持了超过80%的准确率，并能实现低功耗下的实时检测。
## 方法

- **整体框架**：CLSA-Net是一个**分层混合深度学习模型**，其结构为“自适应卷积模块 → LSTM层 → 自注意力机制层 → 全连接分类层”。数据流经各模块依次提取空间、时序和全局关键特征。
- **输入输出**：
    - **输入**：经过预处理（独热编码和标准化）的网络流量特征序列。
    - **输出**：通过Softmax函数输出的各个网络攻击类别的概率。
- **关键模块**：
    1.  **自适应卷积模块（CNN）**：使用**一维卷积（1D-CNN）** 提取每个时间步的局部特征。每个卷积块包含`1D-CNN -> BN -> ReLU -> 最大池化`。BN层用于稳定训练，池化层用于降维。采用3个级别，卷积核数量递增（32->...->256）。
    2.  **长短期记忆网络（LSTM）**：接收CNN输出的特征序列，通过其**输入门、遗忘门、输出门**的门控机制，捕捉序列中的**长期时间依赖关系**，对识别时序行为模式的攻击至关重要。
    3.  **改进的自注意力机制与位置编码**：在LSTM层之上。首先，为特征序列叠加**正余弦位置编码**，使模型感知顺序信息。然后，通过**缩放点积注意力机制**计算序列元素间的相关性权重，动态增强重要特征并抑制无关信息。注意力公式为：`Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V`。
    4.  **全连接分类层**：接收注意力加权后的特征，通过带有Dropout的全连接层进行非线性映射，最终由Softmax输出分类结果。
- **模块之间连接**：模块**级联**连接。原始流量数据 → 预处理 → CNN模块提取特征序列 → LSTM模块建模时序 → 叠加位置编码 → 自注意力层加权 → 全连接层分类。
- **数学公式/机制的直观解释**：
    - **CNN**：通过可学习的卷积核扫描数据，提取局部模式（公式1）。
    - **BN**：对批次数据进行标准化，解决内部协变量偏移（公式2,3）。
    - **LSTM**：通过门控机制（公式4-8）选择性地记忆和遗忘信息，维持长期依赖。
    - **自注意力**：通过查询(Q)、键(K)、值(V)矩阵计算注意力权重，实现序列内部信息的动态加权聚合（公式9）。位置编码（公式10,11）为每个位置生成唯一模式，注入顺序信息。
- **训练方式**：使用**RMSprop优化器**，初始学习率0.001。引入**Dropout层**（失活率0.5）防止过拟合。采用**分层10折交叉验证**进行稳健评估。
- **推理流程**：输入流量数据经过与训练时相同的预处理，依次通过训练好的CNN、LSTM、自注意力、全连接层，最终输出分类概率和预测类别。
- **和已有方法的差异**：与单纯的CNN、LSTM或CNN-LSTM混合模型相比，CLSA-Net**增加了改进的自注意力机制与位置编码**，增强了对序列中关键部分和全局关系的建模能力。更重要的是，它**额外考虑了模型的边缘部署**，通过TFLite转换在资源受限设备上实现了实际运行。
## 实验

- **使用的数据集**：**6个**公共数据集：NSL-KDD、UNSW-NB15、CICIDS2017、CICIDS2019、LuFlow、CICIoT2023。其中UNSW-NB15和CICIoT2023更具现代性和复杂性。
- **对比方法**：SVM、AdaBoost、CNN、MLP、LSTM、HAST-IDS、LuNet等。
- **评价指标**：准确率(A)、检测率(R_D)、假阳性率(R_FP)、F1分数。
- **主实验结果**：
    - 在**NSL-KDD**数据集上，平均检测率98.99%，准确率99.03%，假阳性率0.70%。
    - 在**UNSW-NB15**数据集上，平均检测率96.16%，准确率95.22%，假阳性率1.93%。
    - 在**CICIoT2023**（33类攻击）数据集上，平均检测率高达99.84%，准确率98.15%，假阳性率仅0.0067%。
    - 在多个数据集上的性能均优于文中列出的对比方法。
- **消融实验**：在UNSW-NB15上对比了三种变体：
    1.  `CNN-LSTM`：检测率95.073%，准确率83.521%。
    2.  `CNN-LSTM-Self-Attention`：检测率95.862%，准确率94.983%。
    3.  `CNN-LSTM-Encoding-Self-Attention`（即本文CLSA-Net）：检测率96.162%，准确率95.221%。
    结果表明，逐步引入自注意力机制和位置编码能持续提升模型性能。
- **泛化实验**：模型在6个不同规模和类型的公开数据集上均表现出良好性能，验证了其泛化能力。
- **速度/参数量/FLOPs**：论文报告了**训练时间**（CICIoT2023数据集：GPU训练总耗时约81分钟，CPU约243分钟），但**未明确给出模型参数量、FLOPs等具体效率指标**。边缘部署测试显示在ESP32-S3上可进行实时推理。
## 局限

1.  **对少数类攻击检测能力不足**：在UNSW-NB15中，对**Worms、Shellcode、Backdoor**等极端稀有类别（占比不足1%）的检测率很低，常被误分类为Exploits。这在CICIoT2023中也存在类似情况。
2.  **计算复杂度较高**：论文中分析了模型理论时间复杂度较高（包含O(n^2)的自注意力），虽然通过架构优化缩短了训练周期，但在极低功耗设备上的实时性挑战仍存在。
3.  **边缘部署存在精度损失**：模型在ESP32-S3部署后，准确率从97%以上降至**超过80%**，存在显著的性能下降，这可能源于TFLite量化过程中的信息损失。
4.  **数据集与评估的局限性**：实验主要集中在特定数据集上，这些数据集虽多样但仍为模拟数据。论文**未在真实、动态的物联网网络环境**中进行测试。此外，部分现代数据集（如CICIoT2023）的实验结果图表未完全展示。
