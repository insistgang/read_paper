## 研究背景与动机

- **为什么要做**：现有的3D物体检测模型在单一数据集上表现优异，但迁移到新数据集（跨域）时性能显著下降，这限制了其实际应用。传统评估指标（如BEV AP、3D AP）为单域设计，无法全面、合理地衡量模型的跨域性能。
- **之前方法的问题**：1) **过拟合于物体尺寸**：现有模型容易过度适应训练集中物体的平均尺寸，在目标域尺寸不同时表现糟糕。2) **评估指标不合理**：传统指标计算预测框与真值框的2D/3D重叠，鼓励模型预测完整、精确的物体尺寸。但在跨域场景下，预测完整尺寸极其困难，且LiDAR点云本身就不完整，导致这些指标不能公平评价模型的“避障”能力。3) **核心矛盾**：跨域场景下，**预测整个物体的精确尺寸（中心+长宽高）非常困难且不必要，但预测距离自车最近、未被遮挡的表面是可行且关键的**。然而，现有方法和指标均未针对这一关键能力进行优化和评估。
## 关键贡献

1.  提出两个新的跨域3D检测评估指标：**CS-ABS AP**（绝对更近表面AP）和**CS-BEV AP**（更近表面惩罚鸟瞰图AP），用于更全面、合理地评估模型的跨域性能。
2.  设计了一个即插即用的第二阶段优化头——**EdgeHead**，通过修改回归目标，引导模型专注于学习更近表面的偏移量。
3.  发现了**先旋转锚框再计算回归目标**的关键技术细节，确保模型最终预测的最近点能与真值对齐。
4.  通过大量实验证明，仅将EdgeHead添加到现有模型上，不仅能在新指标上大幅提升性能，甚至也能改善原始BEV和3D指标，说明关注更近表面能让模型学习到更鲁棒的特征。
## 方法

本文方法包含两大部分：新的评估指标和EdgeHead优化模块。

**整体框架与输入输出**：
- **评估指标**：输入为模型的预测框和真值框（在鸟瞰图BEV平面上），输出为基于更近表面检测质量的AP值。
- **EdgeHead**：作为一个可选的第二阶段模块，连接在现有3D检测模型（如PV-RCNN）的头部之后。输入是第一阶段的预测框（作为RoI）和主干网络的早期特征（如3D稀疏卷积特征），输出是优化后的预测框。

**关键模块详解**：

1.  **更近表面评估指标**：
    - **动机**：物体靠近自车一侧的表面（最近顶点及其相邻的两条边）是防碰撞的关键，且对应点云更密集。
    - **定义绝对间隙 G_cs**：对预测框和真值框的四个BEV顶点按到自车（原点）的距离排序，并进一步排序，得到最近顶点V1。G_cs = |V1_pred - V1_gt| + Dist(V2_pred, E1,2_gt) + Dist(V3_pred, E1,3_gt)，即最近点距离之和加上第二、第三个顶点到真值对应边的垂距。
    - **CS-ABS AP**：直接使用 G_cs 来惩罚检测置信度，公式为 Γ_CS_ABS = 1 / (1 + α * G_cs)。它直接衡量更近表面检测质量。
    - **CS-BEV AP**：将 CS-ABS 与原有BEV IoU结合，公式为 Γ_CS_BEV = Γ_BEV / (1 + α * G_cs)。它在整体框检测质量和更近表面质量间取得平衡。α默认为1。

2.  **EdgeHead 优化模块**：
    - **特征聚合**：使用**体素RoI池化**，从主干网络的最后两层3D稀疏卷积特征中为每个RoI聚合特征，以利用丰富的空间结构信息。
    - **修改回归损失（核心创新）**：
        - **传统回归损失** L_reg 对边界框的7个参数（中心、尺寸、转角）计算Smooth L1损失。
        - **EdgeHead 的损失 L'_reg** **只回归3个参数**：最近顶点的x, y坐标偏移 (Δx_cv, Δy_cv) 和旋转角 θ。
        - **关键技巧——旋转锚框**：为了将对最近顶点的回归与旋转角θ的回归协调一致，先将锚框按真值框的旋转角 θ_gt 进行旋转，然后计算旋转后锚框最近顶点与真值框最近顶点的偏移量作为回归目标。如图2所示，若不先旋转，即使分别回归了最近点和角度，最终预测框的最近点也可能与真值不吻合；先旋转则能保证最终对齐。
        - **不回归的内容**：不回归z坐标（假设z轴垂直于地面）、不回归物体尺寸(l, w, h)。**这直接避免了过拟合于物体尺寸的问题**。
    - **与已有方法的差异**：传统RoI头（如PV-RCNN的）回归所有7个参数，而EdgeHead通过精简目标，将模型的学习重点转移到更鲁棒、更关键的“更近表面”定位上。它相当于一个轻量的、目标更聚焦的第二阶段修正器。

**训练与推理**：
- **训练**：EdgeHead与原模型一起端到端训练，或单独在原模型训练后进行微调。损失函数使用修改后的 L'_reg 加上原有的分类损失。
- **推理**：在现有模型产生第一阶段预测后，EdgeHead对这些预测框进行优化，输出最终结果。

3.  **简单有效的模块化设计**：EdgeHead是一个典型的“即插即用”模块，设计简洁（只回归3个参数），却能带来多方面提升。这说明精心设计的辅助任务和回归目标有时比复杂的主干网络改动更有效。
4.  **“少即是多”的回归策略**：通过去掉对易导致过拟合的物体尺寸(l, w, h)的回归，模型反而获得了更好的泛化能力。这对其他存在分布偏移问题的回归任务（如目标跟踪）有启发。
