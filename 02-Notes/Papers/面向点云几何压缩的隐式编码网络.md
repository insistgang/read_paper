## 摘要

> **英文原摘要（据 PDF 提取文本整理，已修复空格与连字符断裂）**：
> Point clouds captured by depth sensors or generated by reconstruction algorithms are essential for various 3D vision tasks, including 3D scene understanding, scan registration, and 3D reconstruction. However, a simple scene or object contains massive amounts of unstructured points, leading to challenges in the storage and transmission of these point cloud data. Therefore, developing point cloud geometry compression algorithms is important to effectively handle and process point cloud data. Existing point cloud compression algorithms typically involve converting point clouds into a storage-efficient data structure, such as an octree representation or sparse points with latent features. These intermediate representations are then encoded as a compact bitstream by using either handcrafted or learning-based entropy coders. Although the correlation of spatial points effectively improves compression performance, existing algorithms may not fully exploit these points as representations of the object surface and topology. To deal with these limitations, we proposed a novel point cloud geometry compression framework, including a signed logarithmic distance field (SLDF), an implicit network structure with the multiplicative branches (MINE), and an adaptive marching cubes algorithm (AMC) for surface extraction. Compared with the suboptimal method (INR), our method reduces L1-CD loss by 12.4% and improves NC and F-score by 1.5% and 13.6% on the ABC and Famous datasets, with compression efficiency increasing by an average of 12.9% as model parameters grow. Within the 10 KB range our method achieves D1-PSNR over 55 dB on the 512/1024/2048-resolution MPEG PCC datasets, highlighting a higher effective compression limit than G-PCC.

## 研究背景与动机

- **为什么要做**：随着自动驾驶、VR/AR 等技术发展，高精度高密度扫描使点云体量快速增长，存储与传输面临挑战。现有主流压缩算法（G-PCC、PCGC）通常将点云**量化至一定分辨率的坐标点**（提取文本提到需量化到 256~1024 像素范围的网格点）再压缩，这一过程**不可逆地丢失细节**，且精度**受限于量化分辨率**；同时忽视了点云作为"物体表面连续采样"的连续一致性。直接对连续表面压缩，可使重建点云不受分辨率限制、获得更高保真度。
- **之前方法的问题**：
    1.  **显式表征的局限性**：无论传统方法（八叉树 Octree / 三角网格 Trisoup / V-PCC 投影）还是深度学习方法（如稀疏卷积），大多沿用离散显式表征，必须量化到网格点，导致**量化误差**和**内存随分辨率剧增**的问题。
    2.  **现有隐式表征的不足**：将隐式表征直接用于点云压缩面临困难——① SDF/OF 需要界限清晰的内外表面，**只能作用于水密物体**，无法用于离散（非水密）点云；② UDF 虽支持任意拓扑，但**在表面处梯度消失/不可导**，难以用网络优化学习；近期 UDF 改进方法（结合语义特征、表面概率、渲染损失等）虽缓解了不可微问题，但仍**边界定义模糊、表面精度受限**，且多为"基于学习"路线——需同时编码原始点云与重建网络，**难以直接用于压缩**。
    3.  **网络结构的瓶颈**：拟合隐式表征的网络通常为全连接 MLP，靠增加参数扩大函数空间，**难以在重建精度与压缩效率之间找到平衡**。
- **核心矛盾**：如何设计一种既能**连续表示任意拓扑点云表面**（避免量化）、又能**被神经网络高效学习**（表面可导）、同时**网络参数量小利于模型压缩**的隐式表征及配套网络框架。

## 关键贡献

1.  **提出基于隐式表征的点云几何压缩框架**：将离散点云转换为连续隐式表征进行编码，**既适用于离散点云几何压缩，也支持连续点云表面压缩**，克服了量化分辨率对压缩质量的限制。
2.  **设计符号对数距离场（SLDF）**：在 UDF 基础上引入"表面厚度假设"与对数变换并反转符号。SLDF 在表面外保持 UDF 特性（可表征任意拓扑），在重新定义的"厚度表面"上具备 SDF 特性（零等值面可微），从而克服 UDF 难以被网络优化学习的缺点。
3.  **构造乘性隐式神经编码网络（MINE）**：将乘性分支（Fathony 等 2021）引入 SIREN 网络，通过 Hadamard 积扩大网络函数空间、改善参数分布特性，在有限参数下拟合更复杂的点云表面，提升压缩效率。
4.  **设计自适应 Marching Cubes（AMC）表面提取算法**：针对 SLDF 厚度假设导致的零等值面偏移，在经典 MC 后添加**双层表面融合**步骤，利用偏移表面的对称特性消除厚度误差，高精度重建连续表面。
5.  **在多个公开数据集上验证**：在 ABC、Famous、MPEG PCC、ShapeNet 四个数据集上实验表明，本文算法在点云表面重建精度和压缩效率上均取得提升，消融实验验证了 SLDF 与 MINE 的有效性。

## 方法

- **整体框架**（图2）：含三个核心模块——(1) SLDF 表征变换，(2) MINE 网络编码与模型压缩，(3) AMC 表面提取与点云恢复。流程：先将点云转换为 SLDF 表征，用 MINE 网络将空间点坐标映射到对应 SLDF 值；编码阶段用模型压缩算法把 MINE 参数编码为二进制码流；解码阶段用 AMC 从解压网络中提取连续表面并采样得点云。
- **输入输出**：
    - 编码输入：原始点云坐标集合；编码输出：压缩后的网络参数二进制码流。
    - 解码输入：压缩码流；解码输出：重建的点云表面点集。
- **关键模块详解**：
    1.  **符号对数距离场（SLDF）**：
        - **问题**：OF/SDF 需界限分明的内外表面，无法用于离散点云；UDF 可用于任意拓扑但表面处不可微，无法用基于优化的网络结构。
        - **定义**：将离散点云所在表面视作有一定厚度的表面，在 UDF 基础上引入表面距离偏移，再做对数变换并反转符号。公式（式4）：`SLDF(x) = -[log(||s|| + ε) + δ]`，其中 `s` 为归一化后空间点到最邻近表面点的距离，`δ` 为点云表面厚度（设为 **10⁻³**），`ε` 为极小偏移值（设为 **10⁻⁵**，确保对数在零等值面处有定义）。
        - **直观解释**：对数变换放大表面邻近值的差异、扁平化表面外的函数值，使"重新定义的厚度表面"与实际表面更贴合，且靠近表面处优化梯度更大；符号反转使表面外符号与 UDF 一致（均为正值）。最终 SLDF 在表面外有 UDF 特性（任意拓扑），在零等值面有 SDF 特性（可微）。
    2.  **乘性隐式神经编码网络（MINE）**：
        - **结构**（图4）：SIREN 将输入坐标编码为 `z₀ = sin(wx + φ₀)`，再经一系列带正弦激活的线性层 `zᵢ = sin(Wᵢzᵢ₋₁ + bᵢ)`。MINE 在每个隐藏层输出处添加一个接收原始输入 `x` 的单层分支，通过 Hadamard 积 (⊗) 并入主干：`zᵢ = sin(Wᵢzᵢ₋₁ + bᵢ) ⊗ sin(wᵢx + φᵢ)`；最终经线性全连接层输出 `y = Wₒᵤₜ·zᵢ + bₒᵤₜ`。
        - **理论分析**：用泰勒展开分析隐藏层特征 `zᵢ`（式6、式7）。SIREN 中线性层系数构成隐藏层特征的高阶项系数；乘性分支引入 `wᵢ, φᵢ` 后，使高阶项中同时出现关于输入 `x`（`xᵘ` 项）与前一层特征 `zᵢ₋₁`（`zᵛᵢ₋₁` 项）的系数自由度，从而**理论上扩大网络的模型空间**，可用更少参数拟合更复杂的隐式表征。
        - **模型压缩**：因剪枝（Han 等 2016）与蒸馏（Hinton 等 2015）对精度影响大且耗时，本文沿用 COIN（Dupont 等 2021）策略——**量化 + 算术编码**：用 AI Model Efficiency Toolkit 将权重量化至 **8 位精度**，再用二进制算术编码无损压缩。
    3.  **自适应 Marching Cubes（AMC）算法**（算法1）：
        - **问题**：SLDF 厚度假设使零等值面成为与实际表面等距的对称偏移表面，标准 MC（Lorensen-Cline 1987）/ Sphere Tracing（Hart 1996）仅支持单调一致的等值面，直接提取会有误差（图5）。
        - **表面融合步骤**：① 用两个阈值 `δc`（待优化外层表面，设为 **0**）和 `δf`（更贴合真值的内层表面，设为 **-10⁻³**）经 MC 各提取一个初始表面 `Sc`、`Sf`；② 把 `Sf` 构建成 KD 树，对 `Sc` 上每个点搜索 `Sf` 最近邻，计算搜索方向 `nᵢ` 与距离 `dᵢ`；③ 迭代：沿方向移动 `Sc` 得 `S'c`，截取局部表面（局部表面点数阈值 **2×10³**，每点最近邻点群 **10²**），计算移动前后局部表面点最近邻点群的平均方差 `σ²c`、`σ'²c`，**若 `σ'²c < σ²c` 则接受更新 `Sc = S'c`，否则将搜索步长减半 `d = d/2`**；重复直至收敛（最大迭代 T）。④ 对优化后表面采样得重建点云。
        - **副作用**：表面融合虽降低重建表面与原始表面的位置差距，但**存在表面重叠问题**；因关注点云表面压缩，AMC 采样后仍为有效点，可缓解厚度假设带来的精度下降。
- **训练方式**：用均方误差（MSE）损失优化网络输出 `f(xᵢ; Θ)` 与 SLDF 真值的差异。数据预处理时对点云表面下采样后添加噪声作为伪随机点输入网络，SLDF 真值由"连续表面上点到最邻近表面的垂直距离 / 离散表面上点到最邻近点的距离"经式(4)变换得到。batch=10⁴，学习率初始 10⁻³，用 ReduceLROnPlateau 调度（损失连续 500 epochs 未下降则学习率减半）。
- **推理流程**：解码端加载压缩参数重建 MINE，在三维空间采样网格点算 SLDF 值，用 AMC 提取并优化连续表面，再均匀采样得离散点云。
- **和已有方法的差异**：① 与 UDF 及其改进方法比，SLDF 提升泛化性且**存在表面梯度与可学习的表面临界值**，可将原始点云作为编码对象、解码端无需先验点云即可重建；② 与 SIREN 比，MINE 用乘性分支以更少参数获得更大函数空间；③ 与标准 MC 比，AMC 通过双层表面融合修正 SLDF 厚度偏移。
- **论文类型特化（3D类）**：任务为**点云几何压缩**（含连续表面压缩与量化点云压缩）。**数据表达**：将离散点集转换为连续隐式距离场（SLDF）。**几何约束**：SLDF 零等值面隐式定义表面。**网络结构**：定制 MINE（带乘性分支的正弦激活网络）。**评价指标**：连续表面用 L1-CD、NC、F-score（阈值 0.005），量化点云用 D1-PSNR；压缩效率用实际内存占用（KB）而非 BPP，以充分体现分辨率对内存的影响。

## 实验

- **使用的数据集**（表1）：
    - **连续表面压缩**：ABC（含孔洞的 CAD 工件模型，**96** 个）、Famous（多角度图像重建的连续表面，**10** 个，含 armadillo/dragon/hand/happy/horse/bunny/liberty/tortuga/netsuke/angel）。
    - **量化点云压缩**：MPEG PCC 的 MVUB（512 分辨率，4 个：andrew/david/phil/sarah）、8iVFB（1024 分辨率，4 个：longdress/loot/redandblack/soldier）、Owlii（2048 分辨率，4 个：basketball player/dancer/exercise model — 提取文本列出 3 类）。
    - **三维重建验证**：ShapeNet（8 个类别共 **80** 个模型：airplane/cabinet/chair/display/lamp/sofa/car/vessel）。
- **对比方法**：
    - **连续表面压缩**：NP、BACON、INR、LevelSetUDF（均为基于优化方法；NP/LevelSetUDF 用带 ReLU 的 MLP，BACON 用 MFN，INR 用 SIREN）。
    - **量化点云压缩**：G-PCC（八叉树标准算法）、INR（此处为 UDF + SIREN 组合，因 INR 的 SDF 表征无法直接作用于离散点云表面）。
    - **三维重建**：P2S、NDF、GeoUDF、NP、BACON、INR、LevelSetUDF（P2S 用 SDF，NDF/GeoUDF 用 UDF）。
- **评价指标**：连续表面 L1-CD（越低越好）、NC（越高越好）、F-score（阈值 µ=0.005，越高越好）；量化点云 D1-PSNR（越高越好）；压缩效率用实际内存占用（KB）。
- **实验环境**：Intel i7 CPU + NVIDIA RTX 3090 GPU + Ubuntu 20.04。压缩任务隐藏层用 3层64维/3层128维/3层256维（代表不同压缩效率），重建任务统一 3层256维，LevelSetUDF 受参数影响大故用 8层256维对比。
- **主实验结果**：
    - **连续表面压缩**（图6/7/8）：表面重建性能随隐藏层从 64 增至 256 而提升。与基准 INR 相比——**ABC 数据集**：L1-CD 平均下降 **18.5%**，NC、F-score 平均提升 **1.48%**、**20.3%**；**Famous 数据集**：L1-CD 平均下降 **6.31%**，NC、F-score 平均提升 **1.52%**、**6.88%**（两数据集平均即摘要的 12.4% / 1.5% / 13.6%）。相同隐藏层大小与数量下，压缩后内存开销低于 INR，随隐藏层增大降幅从 **11% 提升至 14.7%**。可视化上本文在 ABC 孔洞结构与 Famous 复杂表面更精确；隐藏层 64（**11.6 KB**）的重建效果优于 INR 隐藏层 128（**46.3 KB**）。"Dragon"模型实现 **1395:1** 压缩比。
    - **量化点云压缩**（图9/10）：相同框架下，与 INR(UDF) 相比 D1-PSNR 平均提升 **15 dB**（表明 SLDF 有效改善 UDF 零等值面不可导对拟合精度的影响）；在 10 KB 内存下，512/1024/2048 分辨率均保持 **55 dB 以上**，有效压缩上限高于 G-PCC。但随内存增大本文逐渐劣于 G-PCC（G-PCC 直接压坐标、趋于无损，而本文拟合的是连续表面、采样点难与原网格点完全重合），故本文更适合**高压缩率（低码率）场景**。误差可视化上本文与 INR 误差更连续一致（无量化误差），且与 INR 相比误差距离降低**一个数量级（0.01 → 0.001）**。
    - **三维重建**（表2，ShapeNet）：与优化算法 NP/LevelSetUDF 相比，基于学习的 GeoUDF 取得更高 NC，但 L1-CD 与 F-score 次于现有优化方法（表2 完整数值在提取缓存未覆盖页）。

1.  **实验数据集局限性**：实验集中在 CAD 模型（ABC）、扫描重建模型（Famous）、MPEG 标准数据集与 ShapeNet。对**极端拓扑、极稀疏或强噪声**的真实世界点云泛化能力未验证（PDF 文本未明确讨论）。
2.  **厚度假设引入系统误差**：SLDF 的厚度参数 `δ=10⁻³` 是超参数，假设本身使零等值面与真实表面存在偏移；AMC 旨在修正但文本明确指出其**存在表面重叠问题**，可能在重建点云中引入冗余/错误点。

## 个人评论

1.  **将隐式表征系统性引入压缩任务**：跳出"量化网格"范式，把三维重建领域的隐式表征（SDF/UDF）迁移到压缩任务，并为压缩**定制**表征（而非直接套用重建表征），提供了点云压缩的新思路。
2.  **SLDF 的"重定义问题"思路**：用"厚度假设 + 对数变换 + 符号反转"把 UDF 在表面不可导这一根本障碍，转化为一个零等值面可微的新场。这种在数学上重新定义问题以适配现有优化工具（梯度下降）的做法很值得学习。
3.  **MINE 的结构创新有理论支撑**：乘性分支以较小代价换取函数空间扩展，泰勒展开（式6/7）明确给出"乘性分支引入 xᵘ 高阶项"的机理，是平衡模型容量与参数量的有效案例，对"小模型拟合复杂信号"类任务有借鉴价值。
4.  **三模块流水线协同**：SLDF 定义可学习的连续场、MINE 高效编码、AMC 精确提取表面，三者环环相扣，是"为最终任务（压缩 + 表面重建）设计完整流水线"的范例。
5.  **关注"有效压缩上限"而非单看率失真曲线**：强调 10 KB 下仍保 55 dB+ 的低码率可用性，对带宽受限的实际部署很有意义；同时论文也诚实指出高码率劣于 G-PCC，结论可信度较高。

# 论文精读

## 1. 论文定位
本文属于计算机视觉（CV）中**三维点云处理**方向，聚焦**点云几何压缩**（含连续表面压缩与量化点云压缩）任务。核心是把三维重建领域的隐式神经表征（SDF/UDF）创新性引入压缩任务，并针对压缩场景对隐式表征（SLDF）、神经网络（MINE）、表面提取（AMC）三处做定制化改进，旨在解决传统量化网格（八叉树）方法中**重建精度受量化分辨率限制**的根本问题。归类于 `D_3D_点云_分类_分割_配准`，技术内核为"点云压缩与隐式表面重建"。发表于《中国图象图形学报》2024 年第 29 卷 12 期。

## 2. 一句话总结
本文提出由符号对数距离场（SLDF）+ 乘性隐式神经编码网络（MINE）+ 自适应 Marching Cubes（AMC）构成的端到端点云几何压缩框架，将离散点云转为连续可微的隐式场并以小参数神经网络过拟合后做模型压缩，从而突破量化网格的分辨率瓶颈，在更高压缩效率下取得更优的表面重建精度与更高的有效压缩上限。

## 3. 背景与问题
- **为什么要做**：自动驾驶、VR/AR 推动点云体量快速增长，存储传输受限。G-PCC/PCGC 等需将点云量化到一定分辨率（提取文本提到 256~1024 像素范围网格点）再压缩，**不可逆丢失细节**且**精度受限于量化分辨率**，并忽视了点云作为"物体表面连续采样"的连续一致性。
- **之前方法的问题**：
    1.  **显式表征**（八叉树/三角网格/V-PCC 投影/稀疏卷积）必须量化到网格点，存在**量化误差**与**内存随分辨率剧增**；连接面的引入还会降低压缩效率。
    2.  **隐式表征直接用于压缩的困难**：SDF/OF 仅适用水密物体（需对非闭合表面做水密化预处理），无法用于离散点云；UDF 支持任意拓扑但**表面处梯度消失/不可导**，且改进方法多为"基于学习"，需同时编码原始点云与重建网络，**难以直接用于压缩**，且边界模糊、表面提取困难。
    3.  **网络瓶颈**：MLP/SIREN 靠增层数或增隐藏层维度扩大函数空间，**难以平衡重建精度与压缩效率**。
- **核心矛盾**：设计一个既能连续表示任意拓扑表面（避免量化）、又能被网络高效学习（表面可微）、还能小参数高效压缩的隐式表征与网络框架。

## 4. 核心贡献
1.  基于隐式表征的点云几何压缩框架，同时适用于离散点云压缩与连续表面压缩。
2.  SLDF 表征：UDF + 厚度假设 + 对数变换 + 符号反转，表面外保 UDF 特性、零等值面具 SDF 可微性。
3.  MINE 网络：SIREN + 乘性分支（Hadamard 积），扩大函数空间、改善参数分布，小参数拟合复杂表面。
4.  AMC 表面提取：经典 MC + 双层（δc/δf）表面融合，消除厚度假设带来的偏移误差。
5.  在 ABC、Famous、MPEG PCC、ShapeNet 四数据集验证，重建精度与压缩效率均提升，并做了 SLDF/MINE 消融。

## 5. 方法详解
- **整体框架**（图2）：点云 → SLDF 表征 → MINE 过拟合（坐标→SLDF 值）→ 量化+算术编码成码流 →（解码）解压网络 → AMC 提取连续表面 → 采样得点云。
- **SLDF**（式4）：`SLDF(x) = -[log(||s|| + ε) + δ]`，`s` 为归一化后点到最邻近表面点距离，`δ=10⁻³`（厚度），`ε=10⁻⁵`（保证对数在零等值面有定义）。对数变换放大表面邻近差异、扁平化外部值，靠近表面优化梯度更大；符号反转使外部符号同 UDF（正值）。结果：表面外 UDF 特性（任意拓扑）+ 零等值面 SDF 特性（可微）。
- **MINE**（图4，式5/6/7）：SIREN 基线 `z₀=sin(wx+φ₀)`、`zᵢ=sin(Wᵢzᵢ₋₁+bᵢ)`；MINE 每层加接收原始输入 x 的分支并以 Hadamard 积并入：`zᵢ=sin(Wᵢzᵢ₋₁+bᵢ)⊗sin(wᵢx+φᵢ)`，输出 `y=Wₒᵤₜzᵢ+bₒᵤₜ`。泰勒展开（式6/7）表明：SIREN 线性层系数构成高阶项系数；乘性分支引入 `wᵢ,φᵢ`，使高阶项中出现 `xᵘ·zᵛᵢ₋₁`（η₁+η₂ 为系数），系数自由度更高，故模型空间更大，可用更少参数拟合更复杂场。
- **模型压缩**：弃用剪枝/蒸馏（精度损失大、耗时），沿用 COIN（Dupont 等 2021）的量化+算术编码——AI Model Efficiency Toolkit 量化至 8 位 + 二进制算术编码无损压缩。
- **AMC**（算法1）：δc=0、δf=-10⁻³ 经 MC 得 Sc、Sf；Sf 建 KD 树；对 Sc 每点求 Sf 最近邻得方向 nᵢ、距离 dᵢ，初始步长 d=Σdᵢ/N；while t<T：移动得 S'c，截取局部表面（点数阈值 2×10³、最近邻点群 10²），算局部最近邻点群平均方差 σ²c、σ'²c，若 σ'²c<σ²c 接受更新否则 d=d/2，t++。利用偏移表面对称性消除厚度误差，但存在表面重叠（采样后仍为有效点）。
- **训练**：MSE 损失拟合 SLDF 真值（连续表面用点到表面垂直距离、离散表面用点到点距离，下采样后加噪作为伪随机输入）；batch=10⁴，lr=10⁻³，ReduceLROnPlateau（连续 500 epochs 不降则学习率减半）。

## 6. 实验与结果

- **对比方法**：连续表面—NP/BACON/INR/LevelSetUDF；量化点云—G-PCC/INR(UDF)；重建—P2S/NDF/GeoUDF/NP/BACON/INR/LevelSetUDF。
- **指标**：L1-CD↓、NC↑、F-score↑（µ=0.005）、D1-PSNR↑；压缩效率用实际内存（KB，非 BPP）。
- **环境**：Intel i7 + RTX 3090 + Ubuntu 20.04；压缩任务隐藏层 3×{64,128,256}，重建任务 3×256（LevelSetUDF 8×256）。
- **主结果**：
    - 连续表面（vs INR）：**ABC** L1-CD↓18.5%、NC↑1.48%、F-score↑20.3%；**Famous** L1-CD↓6.31%、NC↑1.52%、F-score↑6.88%（两集平均 ≈ 摘要 12.4%/1.5%/13.6%）。内存开销低于 INR，降幅随隐藏层增大从 11%→14.7%。隐藏层 64（11.6 KB）优于 INR 隐藏层 128（46.3 KB）；Dragon 模型 1395:1 压缩比。
    - 量化点云（vs INR-UDF）：D1-PSNR 平均↑15 dB；10 KB 下 512/1024/2048 均保 55 dB+，有效压缩上限高于 G-PCC；高内存时逐渐劣于 G-PCC（后者趋无损）。误差距离比 INR 降一个数量级（0.01→0.001）。
