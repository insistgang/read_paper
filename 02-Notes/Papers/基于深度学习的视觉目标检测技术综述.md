## 摘要

**清理后英文原摘要 (据 PDF 提取文本整理, 修复粘连空格与连字符):**

> Visual object detection aims to locate and recognize objects in images, which is one of the classical tasks in the field of computer vision and also the premise and foundation of many computer vision tasks. Visual object detection plays a very important role in the applications of automatic driving and video surveillance, which has attracted extensive attention of researchers in past few decades. In recent years, with the development of the technique of deep learning, visual object detection has also made great progress. This paper focuses on a deep survey on deep learning based visual object detection, including monocular object detection and stereo object detection. First, we summarize the pipeline of deep object detection during the training and inference. The training process is composed of data pre-processing, detection network design, and label assignment and loss function in common. Data pre-processing (e.g., multi-scale training and flip) aims to enhance the diversity of the given training data, which can improve detection performance of the object detector. Detection network usually consists of three key parts like the backbone (e.g., VGG and ResNet), feature fusion module (e.g., feature pyramid network (FPN)), and prediction network (e.g., RoI head). Label assignment aims to assign the true value for each prediction, and loss function can supervise the network training. During inference, we adopt the trained detector to generate the detection bounding-boxes and employ the post-processing step (e.g., non-maximum suppression (NMS)) to combine the bounding-boxes. Second, we illustrate a deep review on monocular object detection, including anchor-based, anchor-free, and end-to-end methods. Third, we introduce stereo object detection. According to the coordinate space of features, existing detectors are divided into two categories: frustum-based and inverse-projection-based approaches. Based on the summary of monocular and stereo object detection, we further compare the progress of domestic and foreign researches, and present some representative universities or companies on visual object detection. Finally, we present some development tendencies in visual object detection, including efficient end-to-end object detection, self-supervised object detection, long-tailed object detection, few-shot and zero-shot object detection, large-scale stereo object detection dataset, and weakly-supervised stereo object detection.
>

## 研究背景与动机

*   **为什么要做:** 视觉目标检测是计算机视觉的经典任务, 旨在定位图像中物体的位置并识别其类别, 是许多计算机视觉任务及应用的基础与前提, 在自动驾驶、视频监控等领域有重要价值。引言指出, 据谷歌学术统计, 研究人员近 10 年来在目标检测方面发表论文 15000 余篇; 国内外科技巨头 (谷歌、脸书、华为、百度) 与初创公司 (商汤、旷视) 均投入大量资源, 该技术也被视为新一代人工智能的重要共性关键技术。
*   **之前方法的问题:** 早期目标检测多采用"手工设计特征 + 浅层分类器"路线 (如 SVM、AdaBoost), 经典特征描述子包括 Haar 特征 (Viola & Jones, 2004)、方向梯度直方图 HOG (Dalal & Triggs, 2005) 等, 特征设计繁琐且性能受限。2012 年以来深度学习飞速发展, 并行算力迭代、大规模数据库与评测标准 (如 ImageNet) 相继公开, 涌现 R-CNN、SSD、YOLO、DETR 等大量工作, 但缺乏一个涵盖单目与双目、从训练到测试、从基础流程到前沿方法的完整技术图谱。作者也指出, 当前目标检测性能仍无法达到人类视觉水平, 存在巨大改进空间。
*   **作者想解决的核心矛盾:** 如何系统地总结和分析深度学习时代视觉目标检测技术 (含国内外研究现状与未来趋势), 并按视觉传感器数量分为单目与双目两大类加以梳理。相比单目, 双目相机能提供 3 维信息, 在自动驾驶等领域能更好满足应用需求。

## 方法

**1. 整体框架:** 先介绍通用流程 (训练 / 测试), 再分别详述单目与双目检测, 最后对比国内外进展并展望趋势。

**2. 基本流程 (第 1 章, 图 1):**
*   **训练阶段:**
    *   **输入:** 含标注 (物体位置及类别) 的训练图像。
    *   **数据预处理:** 增强数据多样性以提升检测能力。基础手段含翻转、缩放、均值归一化、色调变化等; 高级策略包括区域擦除 (CutOut, Random erasing, HaS, GridMask)、图像混合 (MixUp, 将不同图像与标签做差值表示)、实例粘贴 (CutMix, 将其他图像粘贴到擦除子区域以避免信息损失)、多图拼接 (Mosaic, Montage, DST 动态尺度训练) 以提升尺度变化鲁棒性; Chen 等 (2021e) 进一步提出自动搜索的尺度增强策略。
    *   **检测网络 (三部分):**
        1.  **基础骨干:** 通常采用图像分类深度卷积网络, 如 AlexNet、VGGNet、ResNet、DenseNet; 近期引入 Transformer 骨干 ViT、Swin、PVT。通常用 ImageNet 预训练权重作为骨干初始权重。
        2.  **特征融合:** 对骨干特征融合用于后续分类回归, 常见方式为特征金字塔结构 (Lin 等, 2017a); 也有基于 Transformer 编解码的融合方式。
        3.  **预测网络:** 执行分类与回归。两阶段方法常用全连接, 单阶段常用全卷积。Guo 等 (2020b) 用神经网络搜索同时搜索骨干、特征融合与预测网络三部分。检测器通常还需锚点框、角点、查询特征等初始化。
    *   **标签分配与损失计算:** 标签分配准则含交并比 (IoU) 准则 (常用于锚点框法)、距离准则 (常用于无锚点框法, 按点到物体中心距离分配)、似然估计准则、二分匹配 (后两者基于分类回归联合损失做最优分配)。分类损失含交叉熵、聚焦损失 Focal Loss (Lin 等, 2017b); 回归损失含 L1、平滑 L1、IoU、GIoU (Rezatofighi 等, 2019)、CIoU (Zheng 等, 2020b)。利用反向传播更新权重。
*   **测试阶段:** 输入待检测图像 → 训练好的检测网络生成分类与回归结果 → 后处理去除冗余框。最常用为非极大值抑制 NMS (保留每个物体分类得分最高的框); 改进版包括 Soft-NMS (Bodla 等, 2017, 通过降低高 IoU 框的得分抑制冗余, 解决近邻物体漏检)、IoU-Net (Jiang 等, 2018, 预测框与真实框 IoU 并据此做 NMS)、定位方差加权 (He 等, 2018)、上下文重打分 (Pato 等, 2020)。
*   **开源平台 (原文亦提及):** 国外 FaceBook AI 研究院发布 Detectron / maskrcnn-benchmark / Detectron2; 国内商汤与图森发布 mmdetection / SimpleDet; 底层框架含 Caffe2、PyTorch、MXNet, 以及国内的 PaddlePaddle、MindSpore、Jittor。

**3. 单目视觉目标检测 (第 2 章, 图 2 给出发展历程):** 分为三类。
*   **基于锚点框的方法:** 为空间每个位置设定多个矩形框以覆盖图中物体。又分:
    *   **两阶段方法:** 先提取 k 个类别不具体的候选窗口, 再分类回归。代表为 R-CNN 系列: R-CNN (Girshick 等, 2014, 用选择性搜索生成约 2000 个候选框 + CNN 提特征 + SVM 分类, 但逐框提特征导致速度慢) → SPPNet (He 等, 2015, 特征共享 + 空间金字塔池化得固定长度特征) → Fast R-CNN (Girshick, 2015, RoI 池化 + 全连接, 可联合训练) → Faster R-CNN (Ren 等, 2015, 候选窗口生成与分类回归统一到一个网络)。后续改进: PSRoI 池化 (Dai 等, 2016)、CoupleNet (Zhu 等, 2017, 融合 RoI 与 PSRoI 特征)、可变形 RoI 池化 (Dai 等, 2017)、RoIAlign (He 等, 2017, 解决量化误差)、级联结构 Cascade R-CNN (Cai & Vasconcelos, 2018); 应对尺度变化还有图像金字塔法 (SNIP, Singh & Davis, 2018) 与特征金字塔法 (FPN, Lin 等, 2017a, 计算量更小, 更受关注)。
    *   **单阶段方法:** 直接对锚点框分类回归, 速度更快。代表为 YOLO 系列: YOLO (Redmon 等, 2016, 将图像分成 N×N 子区域预测物体概率/类别/位置偏移) → YOLOv2 (引入批归一化、高分辨率输入、全卷积) → YOLOv3 (Darknet-53 骨干、多尺度预测) → YOLOv4 (Bochkovskiy 等, 2020) → YOLOv5; 以及 SSD (Liu 等, 2016)。
*   **无锚点框的方法:** 无需手工预设锚框, 更鲁棒。分为基于关键点 (预测物体多个关键点定位, 代表 CornerNet) 与基于中心点 (预测物体中心点及到上下左右边界的距离, 代表 FCOS、CenterNet)。*(据原文后续页, 提取缓存仅覆盖到 2.1 节, 此部分细节据摘要与原笔记整理, 待核)*
*   **端到端预测的方法:** 无需后处理, 直接为每个物体预测一个检测框, 代表为 DETR (Carion 等, 2020), 用 Transformer 模块做集合预测。*(据原文后续页 / Fig.5 "Architecture of end-to-end object detection" 标题线索, 提取缓存未覆盖正文, 待核)*

**4. 双目视觉目标检测 (第 3 章):** 按特征坐标空间分两类。*(以下据 PDF 提取的英文摘要整理, 正文在提取缓存未覆盖的页, 待核)*
*   **基于截锥的方法:** 直接在图像截锥空间 (2D 图像 + 深度) 预测 3D 物体。通过拼接成对单目特征构建立体特征 (如 Stereo R-CNN、Stereo CenterNet), 或用 plane-sweeping 构建代价体 (如 IDA-3D、YOLO Stereo 3D)。
*   **基于逆投影的方法:** 将像素或截锥特征显式投影到 3D 笛卡尔空间, 三种方式: ① 将所有像素投影为伪点云 (Pseudo-LiDAR, 结合视差估计与基于 LiDAR 的 3D 检测); ② 将代价体特征投影为 3D 特征体并压成鸟瞰图 BEV 检测 (DSGN, 深度立体几何网络); ③ 将每个候选区域像素投影为实例级点云 (Disp R-CNN, 借助 Mask R-CNN 实例分割)。

**5. 与已有方法的差异:** 本文价值不在提出新方法, 而在提供清晰的结构化分类体系 (单目三分法 + 双目两分法), 将从 R-CNN 到 DETR、从单目到双目的繁杂研究串联成完整知识框架。

## 3. 背景与问题
*   **为什么要做:** 视觉目标检测是计算机视觉经典任务, 在自动驾驶、视频监控等领域价值重大; 近 10 年相关论文逾 15000 篇, 学界工业界投入巨大, 已成新一代人工智能共性关键技术, 亟需系统梳理。
*   **之前方法的问题:** 早期"手工特征 (Haar、HOG) + 浅层分类器 (SVM、AdaBoost)"路线特征设计繁琐、性能受限; 2012 年后深度学习方法 (R-CNN、SSD、YOLO、DETR 等) 井喷, 但缺乏涵盖单目与双目、从训练到测试、从基础到前沿的完整图谱; 且当前性能仍未达人类视觉水平。
*   **核心矛盾:** 如何全面系统地梳理深度学习时代的目标检测技术, 按单目/双目两类对比国内外进展与不同技术路线优劣, 并指明未来方向。

## 5. 方法详解
本文为综述, "方法"是对现有研究的分类与梳理 (详见上文"## 方法"小节)。要点:

**(a) 基本流程 (第 1 章, 图 1):** 训练 = 数据预处理 + 检测网络 + 标签分配/损失计算; 测试 = 检测网络 + 后处理。数据增强含基础操作 (翻转/缩放/归一化/色调) 与高级策略 (CutOut/Random erasing/HaS/GridMask 擦除、MixUp 混合、CutMix 粘贴、Mosaic/Montage/DST 拼接、自动尺度增强)。检测网络三件套 = 骨干 (AlexNet/VGG/ResNet/DenseNet, 及 ViT/Swin/PVT, ImageNet 预训练) + 特征融合 (FPN / Transformer 编解码) + 预测网络 (两阶段全连接、单阶段全卷积)。标签分配准则 = IoU / 距离 / 似然估计 / 二分匹配; 分类损失 = 交叉熵、Focal Loss; 回归损失 = L1、Smooth L1、IoU、GIoU、CIoU。后处理 = NMS 及 Soft-NMS / IoU-Net / 定位方差加权 / 上下文重打分等改进。
