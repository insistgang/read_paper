## 研究背景与动机

- **为什么要做**：单棵树（individual tree）制图是监测树种分布、病害扩散模式与森林砍伐（deforestation）的系统性工具。传统生态调查依赖小样地（small plot-level）数据，耗时耗力且规模有限。机载 LiDAR 提供地表几何结构，高光谱成像在一组窄波段内记录反射辐射、刻画辐射特性，二者结合可在大尺度上实现单棵树种的精细制图。多传感器方法此前已成功用于稀树草原（savanna）树种制图、入侵物种监测、以及光谱性质与叶片化学的关联分析。
- **之前方法的两大技术瓶颈（原文 INTRODUCTION）**：
    1.  **共对准困难**：LiDAR 的瞄准（boresight）处理系统和空间分辨率比高光谱传感器更精确，导致两类数据之间存在错位（mismatches），必须借助地面控制点（ground control points）做显式校正。
    2.  **单棵树勾勒困难**：现有勾勒算法（移动窗口 moving windows [5]、分水岭 watershed [6]）依赖对 LiDAR 首次回波（first returns）的插值。插值伪影（interpolation induced artefacts）的不确定性会导致漏掉林下木或小树（dropping sub-canopy or small trees），并使森林参数推算不准。基于点云的方法（递归图割 recursive graphcut [7]、自适应聚类 adaptive clustering [8]）虽已提出，但因计算复杂度高、可及性（accessibility）差，在森林分析中应用仍受限。
- **核心矛盾**：如何实现**异源、异分辨率传感器数据的精确共对准**，并在此基础上建立一种**不依赖插值、可直接在点云上操作**的单棵树分割方法，以克服上述瓶颈。

## 关键贡献

1.  采用 **NGF-Curv 配准方法**（参考作者自己的工作 [9]），以 LiDAR 强度图像为基准，将高光谱图像配准到分辨率更高的 LiDAR 上，确保二者共对准。
2.  提出一种**结合先验知识的修改版归一化图割（normalised graphcut）算法**（先验机制参考 [10]），直接在 LiDAR 点云上分割单棵树冠，避免插值相关问题，可由点云直接导出更准确的森林参数（树冠体积、树高）。
3.  建立一条**从多传感器原始数据到生态产品（树种图、叶片化学）的通用工作流（generic work flow）**，集成配准、分割与光谱分析三大环节（图 1）。
4.  在单棵树尺度上结合 **SVM 分类**与**光谱指数（PRI）**，演示了估计叶片化学性质（光合效率）并将其与环境变量（海拔梯度）关联的能力。

## 方法

**整体框架（图 1）**：数据获取 → 高光谱数据预处理（用 ATCOR-4 做大气与 BRDF 校正） → LiDAR 与高光谱图像配准 → 树木勾勒（可仅用 LiDAR，或结合高光谱反射率） → 对单棵树冠做光谱分析（SVM 物种分类、光谱指数提取生物物理性质）。
- **输入**：原始机载 LiDAR 点云、高光谱图像。
- **输出**：单棵树种分布图、叶片化学性质（如 PRI）随环境梯度的分布。

**关键模块与连接**：
1.  **配准模块（2.2 节）**：采用 NGF-Curv 方法。设 R 为 LiDAR 强度图像、T 为由高光谱图像得到的灰度图像，均建模为定义在有限二维网格上的函数，把网格点 x 映射到强度值 R(x)、T(x)。目标是求最优变换 u，把高光谱图像配准到分辨率更精确的 LiDAR 上。变分形式 = **相似性项 D + 正则化项 S**（带正则化参数）。相似性项 D 采用 **NGF 距离度量（normalised gradient field）**，基于归一化图像梯度，含边缘参数（>0，刻画图像噪声水平），对光照差异较鲁棒；正则化项 S 采用**曲率（curvature）**，对 u 施加光滑性约束。
    *   直观解释：寻找一个平滑的变换场，使配准后高光谱图像的梯度模式与 LiDAR 强度图像的梯度模式尽量一致。
2.  **树木分割模块（2.3 节）**：核心是**受先验知识约束的修改版归一化图割**。在 LiDAR 点云上建图 G=(顶点集, 边集)，边权 w(i,j) 为非负相似度，**由 LiDAR 点间欧氏距离、强度值，以及（可选的）高光谱反射率共同决定**。设 W 为 N×N 对称相似度矩阵、D 为度对角矩阵、X 为 N×C 的指示矩阵（C 为簇数）。标准归一化割最小化 tr(XᵀD^{-1/2}(D−W)D^{-1/2}X)，约束 XᵀD^{1/2}1=0、XᵀX=I。本文的修改：把**树冠表面局部极大值点及其邻域**构成的**先验矩阵 S** 作为附加约束引入，在最小化割能量的同时**最大化分割结果与先验的相关性**（相关项 diag(XᵀS)=diag(I)），从而倾向于把局部高点识别为树冠中心。
    *   与已有方法差异：不同于基于插值的栅格法（移动窗口、分水岭），本法直接在点云上操作，规避插值伪影；相对标准图割，它显式注入地理空间先验（树冠高点）。
3.  **单棵树制图与光谱分析模块（2.4 节）**：在 **ENVI 5.0（EXELIS，美国）** 中用 **SVM 分类器**与内置植被分析函数做物种识别。由于 Q. canariensis 与 Q. suber 在高光谱数据中清晰可辨，仅**手动选取两类的少量样本**用于训练。为抑制光照影响，先在 LiDAR 三维表面上做**光线追踪（ray tracing）模拟**——以数据采集时刻的太阳方位角与高度角为输入——筛出**光照度 >70% 的受光（sunlit）像素**，再对这些像素施加 SVM 与植被指数计算。

## 实验

## 5. 方法详解
**整体框架（图 1）**：数据获取 → 高光谱预处理（ATCOR-4 大气 + BRDF 校正） → LiDAR/高光谱配准 → 树木勾勒（仅 LiDAR 或结合高光谱） → 单棵树冠光谱分析（SVM + 光谱指数）。

**关键模块**：
1.  **配准（2.2）**：R = LiDAR 强度图，T = 高光谱灰度图，均为二维网格上的函数。求最优变换 u 把 T 配准到分辨率更精确的 LiDAR R 上。变分目标 = 相似性项 D + 正则化项 S（带正则化参数）。D 用 **NGF 距离度量**（基于归一化梯度场，含刻画噪声的边缘参数，对光照鲁棒）；S 用**曲率**，对 u 施加光滑性。直观上：找平滑变换场，使配准后高光谱梯度模式与 LiDAR 强度梯度模式尽量一致。
2.  **树木分割（2.3）**：在 LiDAR 点云上建图 G=(顶点, 边)，边权由**点间欧氏距离、LiDAR 强度、（可选）高光谱反射率**共同决定（对称矩阵 W，度矩阵 D，指示矩阵 X∈N×C）。标准归一化割：min tr(XᵀD^{-1/2}(D−W)D^{-1/2}X)，s.t. XᵀD^{1/2}1=0、XᵀX=I。**本文修改**：把树冠表面局部极大值及邻域构成的**先验矩阵 S** 作为附加约束（相关项 diag(XᵀS)=diag(I)），在最小化割能量的同时最大化与先验的相关性，使局部高点更易被判为树冠中心。
3.  **单棵树制图与光谱分析（2.4）**：在 ENVI 5.0 中用 SVM + 内置植被分析；两种栎在高光谱中清晰可辨，**仅手动选少量样本训练**。为抑制光照影响，先在 LiDAR 三维表面做**光线追踪**（输入采集时刻太阳方位角与高度角），筛出**光照度 >70% 的受光像素**，再对其施加 SVM 与植被指数计算。
