## 研究背景与动机

- **为什么要做**：单棵树木制图对于监测树种分布、病害扩散和森林砍伐至关重要。传统生态调查方法耗时耗力且数据规模小。机载LiDAR和高光谱成像能提供大规模森林的详细几何和光谱信息，为精准制图提供了可能。
- **之前方法的问题**：
    1.  **数据对准困难**：LiDAR与高光谱传感器的空间分辨率和处理系统不同，导致数据之间存在错位，需要地面控制点进行手动或显式校正，技术难度大。
    2.  **树木分割不准确**：现有的树木勾勒算法（如移动窗口、分水岭）依赖于对LiDAR首次回波的插值，插值产生的伪影会导致遗漏林下或小树木，并导致森林参数（如树高、体积）估算不准确。基于点云的方法（如递归图割、自适应聚类）虽然被提出，但因计算复杂和可及性低，在森林分析中应用受限。
- **核心矛盾**：如何实现**异源、异分辨率传感器数据的精确共对准**，并在此基础上发展一种**高效、准确且不依赖插值的单棵树分割方法**，以克服现有技术瓶颈。
## 关键贡献

1.  提出采用**NGF-Curv配准方法**，以LiDAR强度图像为基准，将高光谱图像与之精确对准，解决了异源数据共对准的技术难题。
2.  提出了一种**结合先验知识（局部极大值）的修改版归一化图割（Normalized Graphcut）算法**，直接在LiDAR点云上进行单棵树分割，避免了插值问题，能更准确地提取树木的几何结构。
3.  建立了一个**从原始多传感器数据到最终生态产品（树种图、叶片化学信息）的通用处理工作流程**，集成了配准、分割与光谱分析。
4.  在单棵树级别上，结合SVM分类与光谱指数（如PRI）分析，展示了利用该流程**估计叶片化学性质（如光合效率）并研究其与环境因子（如海拔）关系的能力**。
## 方法

**整体框架**：处理流程如图1所示，依次为：数据获取 → 高光谱数据预处理（大气和BRDF校正） → LiDAR与高光谱图像配准 → 基于LiDAR点云的树木分割（可选结合高光谱信息） → 对分割出的单棵树冠进行光谱分析（物种分类、化学性质提取）。
- **输入**：原始机载LiDAR点云数据、高光谱图像数据。
- **输出**：单棵树种分布图、叶片化学性质（如PRI指数）空间分布图。

**关键模块与连接**：
1.  **配准模块**：采用NGF-Curv方法。将LiDAR强度图(R)和高光谱灰度图(T)视为函数。目标是找到一个最优变换u，将高光谱图像配准到LiDAR图像上。优化目标是最小化一个能量函数，该函数由**相似性项D**和**正则化项S**组成。相似性项采用NGF距离度量，基于图像梯度（归一化梯度流），对光照变化具有一定鲁棒性。正则化项采用曲率，以确保变换场u的光滑性。
    *   公式直观解释：寻找一个平滑的变换场，使得变换后的高光谱图像的梯度模式与LiDAR强度图像的梯度模式尽可能一致。
2.  **树木分割模块**：输入是配准后的LiDAR点云（可能融合高光谱反射率信息）。核心是**修改的归一化图割**。首先构建一个图，顶点是LiDAR点，边权重由点间的欧氏距离、强度以及（可选的）高光谱反射率值决定。标准归一化图割旨在最小化切割代价，本文修改后**加入了先验约束**：将树冠局部表面极大值点及其邻域作为先验矩阵S，在优化目标中增加一项，要求分割结果X与先验矩阵S的相关性最大化（通过系数κ控制）。这使得算法更倾向于将局部高点识别为潜在的树冠中心。
    *   与已有方法的差异：与基于插值的栅格方法（如移动窗口、分水岭）不同，此方法直接在点云上操作，避免了插值伪影。与标准图割相比，它融入了明确的地理空间先验知识（树冠高点），引导分割更合理。
3.  **光谱分析模块**：对分割出的每个树冠多边形区域，在高光谱图像上提取其光谱信息。使用**SVM分类器**（在ENVI 5.0中实现）进行物种识别，训练样本为手动选取的少量样本。为减少光照影响，在分析前，利用LiDAR三维表面和太阳位置信息，通过**光线追踪模拟**，筛选出光照条件较好（如光照度>70%）的像素参与分类和指数计算。计算光谱指数（如PRI）以评估叶片化学性质。
