## 摘要

本文提出了一种改进的一阶全卷积目标检测网络（FCOS），通过引入滑动顶点结构和倾斜度因子，实现了在遥感影像上高效、高精度的无锚框倾斜目标检测。
## 研究背景与动机

- **论文为什么要做**：主流基于锚框的目标检测方法需要精心设计锚框参数，泛化能力受限。更重要的是，传统方法使用平行于图像坐标轴的水平矩形框（正框）来定位物体。在遥感影像中，地物目标往往具有任意的朝向，使用正框会导致检测框内包含大量背景和其他目标的干扰信息，特别是在目标密集排列时，这严重影响了检测精度。
- **之前方法有什么问题**：
    1.  **基于锚框的方法**（如Faster R-CNN, YOLOv3, SSD）：锚框设置是超参数，需要针对不同数据集调整；匹配机制不平衡；计算和内存开销大。
    2.  **现有倾斜框检测方法**：部分方法仍依赖锚框；一些基于滑动顶点的方法存在将目标框预测为任意四边形的问题，且训练过程耗时。
- **作者想解决的核心矛盾**：如何设计一种**无锚框**的检测框架，既能避免锚框带来的超参数和样本不平衡问题，又能有效、稳定地生成与目标朝向一致的**倾斜边界框**，以适应遥感影像的特点。
## 关键贡献

1.  **将无锚框检测器FCOS扩展到倾斜目标检测领域**：在FCOS的基础架构上进行改进，使其能够输出倾斜框。
2.  **提出一种改进的斜框表示与回归方法**：通过在水平框（正框）的两条邻边上预测滑动顶点比率（α1，α2）来生成斜框顶点，并引入斜框与正框的面积比（倾斜因子k）来处理极端形状（如接近水平）的目标，解决了传统滑动顶点方法可能产生任意四边形和对小角度倾斜敏感的问题。
3.  **改进多尺度特征融合模块**：在原始FCOS特征金字塔的基础上，对相邻层级的特征图在通道维度进行拼接后，增加了1×1卷积和批量归一化操作，以提升融合效果和网络收敛速度。
4.  **在大规模遥感斜框检测基准DOTA上进行验证**：实验证明所提方法在精度和速度上均优于基础正框FCOS和经典的水平框检测器YOLOv3，并且精度优于专门的斜框检测器R3Det。
## 方法

- **整体框架**：网络由三部分组成：骨干网络（特征提取）、特征金字塔网络（多尺度特征融合）和检测头（分类与回归）。整体流程为：输入遥感影像 -> 骨干网络提取多层级特征 -> 特征金字塔融合不同尺度特征 -> 检测头在每个特征图位置预测类别、中心度及斜框参数。
- **输入输出**：
    - **输入**：高分辨率遥感影像。
    - **输出**：对于图像上的每个候选位置，输出包括：目标类别概率、中心度分数、以及用于描述一个斜框的7维参数向量`(l, t, r, b, α1, α2, k)`。
- **关键模块**：
    1.  **骨干网络**：使用ResNet（如ResNet50）作为特征提取器，提取多层次的特征图（C3， C4， C5）。
    2.  **多尺度特征融合（改进的FPN）**：
        - 对C3， C4， C5分别进行1x1卷积降维。
        - 通过自上而下的路径和横向连接生成P3， P4， P5。
        - 对P5使用步长为2的卷积生成P6， P7。
        - **关键改进**：对于相邻的特征图（如C3‘和P4’），在通道维度上进行**拼接**，随后接1x1卷积和批量归一化，以生成最终的融合特征图（如P3）。这种操作旨在更平滑地融合相邻尺度特征。
    3.  **检测头**：
        - **分支1（类别与中心度）**：预测每个位置所属的目标类别，以及一个中心度分数`ct`。中心度用于抑制远离目标中心的低质量预测框，其计算基于点到框四边距离的比值。
        - **分支2（框回归）**：回归7维参数`(l, t, r, b, α1, α2, k)`。
            - `(l, t, r, b)`：特征图上点到目标正框左、上、右、下边界的距离。
            - `(α1, α2)`：斜框在正框上边和右边的滑动偏移比率，定义为`α1 = s1/w`， `α2 = s2/h`，其中`s1, s2`是偏移量，`w, h`是正框的宽高。**假设遥感目标是平行四边形**，因此仅需预测两个邻边的偏移。
            - `k`：倾斜因子，定义为斜框面积`|O|`与正框面积`|B|`的比值`k = |O|/|B|`。`k`趋近于1表示目标接近水平，趋近于0表示目标狭长且倾斜。
- **模块之间连接**：骨干网络的输出特征图送入改进的FPN进行融合。融合后的多尺度特征图P3-P7分别送入两个共享参数的检测头分支。每个检测头位置并行输出类别/中心度和斜框参数。
- **数学公式与机制直观解释**：
    - 框表示：给定一个点`(x0, y0)`，通过`(l, t, r, b)`确定其正框`(xmin, ymin, xmax, ymax)`。然后，根据`(α1, α2)`计算正框上边和右边的滑动偏移`s1 = α1 * w`, `s2 = α2 * h`，进而确定斜框的两个顶点`p1, p2`。基于平行四边形假设和对称性，可推导出斜框的另外两个顶点`p3, p4`。
    - 倾斜因子`k`的作用：在推理时，可以根据`k`的大小选择输出正框还是斜框。当`k`接近1时（目标近乎水平），直接使用正框可能误差更小，从而避免对微小倾斜的过拟合和误差。
- **训练方式**：损失函数`L`由三部分构成：`L = L1 + L2 + L3`。
    - `L1`：类别损失（采用焦点损失）与中心度损失（二元交叉熵）之和。
    - `L2`：正框四边距离`(l, t, r, b)`的回归损失，采用IoU损失。
    - `L3`：斜框参数`(α1, α2, k)`的回归损失，采用Smooth L1损失。
- **推理流程**：
    1.  特征图上每个点计算类别分数`c`和中心度`ct`，最终置信度为`c * ct`。
    2.  根据`(l, t, r, b)`和映射坐标`(x0, y0)`计算正框。
    3.  根据`(α1, α2)`和正框计算斜框顶点。
    4.  结合`(k)`值，可以选择最终输出正框或斜框。
    5.  对所有预测框进行非极大值抑制（NMS）得到最终结果。
- **和已有方法的差异**：
    - 与**FCOS（正框）** 相比：增加了预测斜框参数的分支，将水平检测扩展到旋转检测。
    - 与**滑动顶点（Gliding Vertex）方法** 相比：不直接预测角度或四个顶点偏移，而是通过预测`(α1, α2, k)`并引入平行四边形假设，简化了表示，降低了回归难度，避免了任意四边形问题。
    - 与**基于锚框的斜框检测器（如R3Det）** 相比：完全摒弃了锚框，属于无锚框检测，减少了超参数和正负样本不平衡问题。
## 实验

- **使用的数据集**：DOTA（Dataset for Object Detection in Aerial Images），论文中提到这是“当前最大、最复杂的斜框遥感目标检测数据集”。
- **对比方法**：
    - 基线：原始的**FCOS**（水平框）。
    - 水平框检测器：**YOLOv3**。
    - 倾斜框检测器：**R3Det**（Refined Rotation RetinaNet）。
- **评价指标**：平均精度均值（mAP）， 以及速度指标FPS（frames per second）。
- **主实验结果**：
    - 在DOTA数据集上，使用**ResNet50**作为骨干网络，本文方法（Improved FCOS）的**mAP达到74.84%**。

    - 与YOLOv3相比，**FPS效率提升了38.82%**（表明在达到更优精度的同时，速度也有优势）。

        - 通过自上而下的路径和横向连接生成P3， P4， P5。
        - 对P5使用步长为2的卷积生成P6， P7。
        - **关键改进**：对于相邻的特征图（如C3‘和P4’），在通道维度上进行**拼接**，随后接1x1卷积和批量归一化，以生成最终的融合特征图（如P3）。这种操作旨在更平滑地融合相邻尺度特征。
    3.  **检测头**：
        - **分支1（类别与中心度）**：预测每个位置所属的目标类别，以及一个中心度分数`ct`。中心度用于抑制远离目标中心的低质量预测框，其计算基于点到框四边距离的比值。
        - **分支2（框回归）**：回归7维参数`(l, t, r, b, α1, α2, k)`。
            - `(l, t, r, b)`：特征图上点到目标正框左、上、右、下边界的距离。
            - `(α1, α2)`：斜框在正框上边和右边的滑动偏移比率，定义为`α1 = s1/w`， `α2 = s2/h`，其中`s1, s2`是偏移量，`w, h`是正框的宽高。**假设遥感目标是平行四边形**，因此仅需预测两个邻边的偏移。
            - `k`：倾斜因子，定义为斜框面积`|O|`与正框面积`|B|`的比值`k = |O|/|B|`。`k`趋近于1表示目标接近水平，趋近于0表示目标狭长且倾斜。
- **模块之间连接**：骨干网络的输出特征图送入改进的FPN进行融合。融合后的多尺度特征图P3-P7分别送入两个共享参数的检测头分支。每个检测头位置并行输出类别/中心度和斜框参数。
- **数学公式与机制直观解释**：
    - 框表示：给定一个点`(x0, y0)`，通过`(l, t, r, b)`确定其正框`(xmin, ymin, xmax, ymax)`。然后，根据`(α1, α2)`计算正框上边和右边的滑动偏移`s1 = α1 * w`, `s2 = α2 * h`，进而确定斜框的两个顶点`p1, p2`。基于平行四边形假设和对称性，可推导出斜框的另外两个顶点`p3, p4`。
    - 倾斜因子`k`的作用：在推理时，可以根据`k`的大小选择输出正框还是斜框。当`k`接近1时（目标近乎水平），直接使用正框可能误差更小，从而避免对微小倾斜的过拟合和误差。
- **训练方式**：损失函数`L`由三部分构成：`L = L1 + L2 + L3`。
    - `L1`：类别损失（采用焦点损失）与中心度损失（二元交叉熵）之和。
    - `L2`：正框四边距离`(l, t, r, b)`的回归损失，采用IoU损失。
    - `L3`：斜框参数`(α1, α2, k)`的回归损失，采用Smooth L1损失。
- **推理流程**：
    1.  特征图上每个点计算类别分数`c`和中心度`ct`，最终置信度为`c * ct`。
    2.  根据`(l, t, r, b)`和映射坐标`(x0, y0)`计算正框。
    3.  根据`(α1, α2)`和正框计算斜框顶点。
    4.  结合`(k)`值，可以选择最终输出正框或斜框。
    5.  对所有预测框进行非极大值抑制（NMS）得到最终结果。
- **和已有方法的差异**：
    - 与**FCOS（正框）** 相比：增加了预测斜框参数的分支，将水平检测扩展到旋转检测。
    - 与**滑动顶点（Gliding Vertex）方法** 相比：不直接预测角度或四个顶点偏移，而是通过预测`(α1, α2, k)`并引入平行四边形假设，简化了表示，降低了回归难度，避免了任意四边形问题。
    - 与**基于锚框的斜框检测器（如R3Det）** 相比：完全摒弃了锚框，属于无锚框检测，减少了超参数和正负样本不平衡问题。
