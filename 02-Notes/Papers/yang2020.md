## 摘要

**英文原摘要（据 PDF 提取文本整理，修复空格与连字符断裂）**：

> Image denoising is about removing measurement noise from input image for better signal-to-noise ratio. In recent years, there has been great progress on the development of data-driven approaches for image denoising, which introduce various techniques and paradigms from machine learning in the design of image denoisers. This paper aims at investigating the application of ensemble learning in image denoising, which combines a set of simple base denoisers to form a more effective image denoiser. Based on different types of image priors, two types of base denoisers in the form of transform-shrinkage are proposed for constructing the ensemble. Then, with an effective re-sampling scheme, several ensemble-learning-based image denoisers are constructed using different sequential combinations of multiple proposed base denoisers. The experiments showed that sequential ensemble learning can effectively boost the performance of image denoising.

## 研究背景与动机

- **为什么要做**：图像去噪是底层视觉的基础问题，噪声模型为 `g = f + n`（`f` 干净图像，`n` 测量噪声）。尽管传感器在进步，许多场景（低成本相机、弱光、高 ISO）的信噪比仍不理想；且去噪常作为其他图像恢复方法的一个基础模块，其重要性随网络摄像头与手机的普及而增长。
- **方法论视角**：作者把"干净自然图像集中在高维线性空间中的一个非线性低维流形上"作为出发点；图像先验本质是对该流形几何的刻画，去噪器即把含噪图像投影回该低维流形。由于图像内容变化大、流形几何复杂，单个简单先验/去噪器（弱模型）难以充分刻画——类比于线性分类器无法表示高曲率决策边界。
- **之前方法的问题**：
    - 手工设计先验（如局部强度变化的稀疏性 / hyper-Laplacian 先验、局部图像块的复现性）简单且具一定普适性，但面对实际图像内容的巨大变化仍有较大提升空间。
    - 已有迭代去噪方法（如迭代小波阈值）**可被解释为一种顺序集成**——每次迭代即一个简单去噪器（小波阈值）。Fig.1 用迭代小波收缩在 σ=15、Fig.8 的 12 张自然图像上验证：PSNR 随集成规模（迭代次数）增大而上升，佐证集成能提升去噪。但这类迭代方法**未针对集成学习优化**：每次迭代的简单去噪器大体相同，违背集成学习赖以制胜的"多样性"（diversity）原则；同时也无法施加集成学习中强大的"重采样"（resampling）技术。
- **核心矛盾**：需要专门设计一类"为利用集成学习而优化"的去噪器，使其既能体现多样性、又能配合重采样，从而突破现有迭代方法的局限。

## 关键贡献

1.  **首次引入**：本文是**第一篇**将集成学习范式引入图像去噪问题的工作（"the first one that introduces ensemble learning to solve the problem of image denoising"）。
2.  **提出框架**：提出一个**顺序集成去噪框架**，结构类似级联分类器（cascade classifier）；最终集成去噪器 `E` 由 `L` 个基底去噪器级联而成，每个基底去噪器同时接收前一级输出与原始含噪图像作为输入。
3.  **设计基底去噪器**：基于不同图像先验，提出**两种**形式为变换-收缩的基底去噪器（"two types of base denoisers"）；其收缩函数创新地用 **Gabor 原子的线性组合** 来表示（区别于既有工作 [27][51] 用高斯函数表示收缩算子），以利用 Gabor 在局部时频分析上的能力，对图像细节做更精细的处理。
4.  **重采样方案**：开发了一种有效的重采样（re-sampling）方案用于性能提升（具体实现细节落在提取缓存未覆盖的 III.B 之后，待核）。
5.  **灵活性与可解释性**：相比变分模型驱动的可训练迭代法，本框架可融合对应不同先验的不同优化模型；相比神经网络方法，更易融入领域知识先验、在训练数据不足时更具吸引力，还能集成 BM3D 这类强去噪器，且因每个基底去噪器可解释而整体可解释性更好。
6.  **实验验证**：在若干常用测试集上做了全面实验，结果表明所提集成去噪器取得了扎实（solid）的性能。

## 方法

- **整体框架（Fig.2）**：类似级联分类器的顺序结构。集成去噪器 `E: R^N → R^N` 由 `L` 个基底去噪器 `{B_l}_{l=1}^L` 级联组成：`E(f) = B_L(B_{L-1}(···(B_1(f))))`。
- **噪声模型**：`g = f + n`，其中 `n ~ N(0, σ²I)` 为加性高斯白噪声（AWGN）。给定 `g` 估计 `f`。
- **基底去噪器接口**：每个 `B_l: R^N × R^N → R^N` 接收两个输入——前一级输出 `f^{(l-1)}` 与原始含噪观测 `g`，输出对 `f` 的新估计 `f^{(l)}`，即 `B_l: (f^{(l-1)}, g) → f^{(l)}`。第一个基底去噪器的 `f^{(0)}` 直接设为 `g`。
- **为何每级都喂入原图 g**：每个 `B_l` 的目标是在前一级估计 `f^{(l-1)}` 基础上，同时**抑制残余噪声**并**恢复 `f^{(l-1)}` 中丢失的图像信息**；把原始观测 `g` 送入 `B_l` 正是为它提供恢复这些丢失信息的信息源。
- **变换-收缩基底**（论文采用的简单弱去噪器）：给定含噪输入 `y ∈ R^N`，先经变换 `W` 得 `c = Wy`，再施加收缩算子 `Ψ(c; β)`，最后用算子 `W^+` 变换回图像：
    - `y* = W^+ Ψ(Wy; β)`（式 2），`β` 为收缩算子参数向量。
    - 论文指出许多经典去噪器都属此类：Wiener 估计用 DFT 作 `W`、其逆作 `W^+`、衰减函数（参数由信噪比决定）作收缩；小波收缩用离散小波变换作 `W`，收缩算子为硬阈值或软阈值（硬阈值把小系数置零；软阈值把小系数置零并衰减大系数）。
- **逐元素 Gabor 收缩算子（核心创新）**：收缩算子逐元素作用 `Ψ(y; β)[i] = h(y[i]; β)`，衰减函数 `h(·; β)` 用一组 Gabor 原子线性组合表示（式 4）：
    - `h(z; β) = Σ_{p=1}^P Σ_{q=1}^Q β¹_{p,q} d¹_{p,q}(z) + Σ_{p=1}^P Σ_{q=1}^Q β²_{p,q} d²_{p,q}(z)`
    - 其中（式 5）`d¹_{p,q}(z) = exp(−(z−μ_p)²/(2ρ²)) cos(ω_q x)`，`d²_{p,q}(z) = exp(−(z−μ_p)²/(2ρ²)) sin(ω_q x)`，即以高斯为窗的余弦/正弦 Gabor 原子（提取文本指数项符号略有 OCR 偏差，标准 Gabor 应为负指数，已据上下文标注）。
    - 参数化设置：网格点 `{μ_p}` 在区间 **[−310, 310]** 上等间距、步长 **10**。理由：像素值范围 [0,255]，归一化高通滤波输出范围 [−255,255]，但集成中间结果可能超出该范围，故用更大的 [−310,310] 使绝大多数取值落入区间内。因相邻网格间距为 10，高斯标准差 `ρ` 也设为 10，使原子具备足够的多项式再现能力又不过度冗余。`β` 随机初始化、从训练数据学习。
- **训练方式**：**顺序训练**。每个 `B_l` 基于前一级的去噪结果与真值干净图像进行训练，优化目标是最小化估计 `f^{(l)}` 对真值 `f` 的逼近误差。
- **推理流程**：含噪图 `g` → `B_1` 得 `f^{(1)}` →（`f^{(1)}`, `g`）入 `B_2` 得 `f^{(2)}` → … → 经全部 `L` 级，输出 `f^{(L)}` 作为去噪结果。
- **与已有方法的差异**：
    - 对比变分模型驱动的可训练迭代法（如可训练 MRF/扩散 [27][29]）：本框架可整合对应不同先验的不同优化模型，灵活性更高；且专为集成设计，基底可具多样性并能用重采样。
    - 对比神经网络方法（CNN/自编码器/MLP [22]–[26]）：本框架更易融入领域知识先验、在训练数据不足时更有优势，可集成 BM3D 等强去噪器，且每个基底可解释、整体可解释性更好。

1.  **计算成本**：顺序集成需依次运行多个基底去噪器，推理开销可能高于单次前向的网络；提取文本可见部分未讨论速度。

# 论文精读

## 1. 论文定位
计算机视觉 / 图像处理中的"图像去噪"方向（IEEE TIP 2020）。从含噪图像 `g = f + n` 恢复干净图像 `f`，属低层视觉。本文不是又一个网络结构，而是把"集成学习"这一机器学习范式系统性地引入去噪：用一串简单的"变换-收缩"弱去噪器顺序级联成强去噪器。归在"图像处理-去噪"主题（`T_图像处理_去噪`）准确。

## 2. 一句话总结
本文首次把集成学习引入图像去噪，提出顺序集成框架：将多个基于不同先验、形式为"变换-收缩"（收缩函数用 Gabor 原子线性组合表示）的简单基底去噪器级联，每级同时吃前一级输出与原始含噪图，再配合重采样，从而把弱去噪器组合成性能更强的去噪器。

## 3. 背景与问题
- **为什么要做**：去噪是众多图像恢复任务的基础模块，弱光 / 高 ISO / 低成本相机下信噪比仍差，需求随手机普及增长。
- **理论视角**：干净自然图像集中在高维空间的非线性低维流形上；图像先验即刻画该流形几何，去噪 = 把含噪图投影回流形。流形几何复杂 → 单一简单先验（弱去噪器）不够，正如线性分类器表达不了高曲率决策边界。
- **之前方法的缺口**：手工先验（稀疏 / 块复现）普适但提升空间大；迭代小波收缩其实就是一种顺序集成（Fig.1：σ=15、12 图，PSNR 随迭代/集成规模上升），但每次迭代去噪器几乎相同——缺"多样性"，也用不了"重采样"。
- **核心矛盾**：要设计一类"专为集成学习优化"的去噪器，使其兼具多样性并能配合重采样。

## 4. 核心贡献
1. **首篇**把集成学习引入图像去噪。
2. **顺序集成框架**（类级联分类器）：`E(f) = B_L(···(B_1(f)))`，每级吃前级输出 + 原始含噪图。
3. **两种**变换-收缩基底去噪器，收缩函数用 **Gabor 原子线性组合**表示（区别于既有工作用高斯）。
4. **有效重采样方案**（细节在提取缓存截断之后，待核）。
5. 相对网络/可训练迭代法：更易融领域先验、可集成 BM3D、可解释、小数据更有利。
6. 在若干常用测试集上取得 solid 性能（定量数值不在缓存内）。

## 5. 方法详解
- **框架（Fig.2）**：`L` 个基底去噪器顺序级联，`E: R^N→R^N`，`E(f)=B_L(B_{L-1}(···(B_1(f))))`。
- **噪声模型**：`g=f+n`，`n~N(0,σ²I)`，AWGN。
- **每级接口**：`B_l:(f^{(l-1)}, g)→f^{(l)}`；`f^{(0)}=g`。每级目标是在前级估计上同时抑残余噪声、恢复前级丢失的图像信息——把原图 `g` 喂进来正是提供"找回丢失信息"的信息源。
- **变换-收缩**：`y*=W^+ Ψ(Wy; β)`（式2）。`Ψ` 逐元素：`Ψ(y;β)[i]=h(y[i];β)`。经典案例：Wiener（DFT + 信噪比定参数衰减）、小波收缩（DWT + 硬/软阈值）都属此类。
- **Gabor 收缩（创新）**：`h(z;β)=ΣΣ β¹_{p,q} d¹_{p,q}(z)+ΣΣ β²_{p,q} d²_{p,q}(z)`（式4），原子为以高斯为窗的余弦/正弦 Gabor（式5）。网格 `μ` 在 [−310,310] 步长 10（像素 [0,255]、归一化高通输出 [−255,255]、中间结果可能溢出故放宽到 ±310），`ρ=10`（= 网格间距，兼顾再现能力与冗余）。`β` 随机初始化、从数据学。动机：Gabor 的局部时频分析能力 → 对图像细节更精细。
- **训练**：顺序训练，每级用前级去噪结果 + 真值，最小化 `f^{(l)}` 对 `f` 的逼近误差。
- **推理**：`g→B_1→f^{(1)}→(f^{(1)},g)→B_2→…→f^{(L)}`。
