## 研究背景与动机

- **为什么做**：在科学建模中，选择最佳模型至关重要。贝叶斯模型比较通过计算模型证据（边缘似然）提供了一种原则性的方法，但该积分在高维（如计算成像中的O(10^6)维度）下计算极具挑战性。
- **之前方法的问题**：传统的嵌套采样等高精度方法无法扩展到计算成像等高维问题场景。
- **核心矛盾**：如何在高维问题中高效、可靠地计算模型证据，以实现贝叶斯模型选择，尤其是当模型的先验可能是复杂的、数据驱动的时候。
## 关键贡献

1.  **系统回顾了近端嵌套采样框架**：以教学性的方式回顾了该框架的数学基础（凸分析、近端演算），旨在为物理学家等研究者提供更易理解的入门指南。
2.  **首次在经验贝叶斯设置下扩展近端嵌套采样以支持数据驱动先验**：通过Tweedie公式，将经过训练的深度去噪神经网络（如DnCNN）作为正则化先验的得分函数，集成到近端嵌套采样框架中。
3.  **展示了框架在射电干涉成像问题中的应用**：在一个具体的射电干涉成像重建实验中，演示了如何利用该框架在手写先验（小波稀疏性）和数据驱动先验（深度神经网络）之间进行贝叶斯模型选择。
4.  **提供了计算特定近端算子的显式方案**：针对图像重建中常见的高斯负似然和小波稀疏先验，给出了近端算子的闭式解或可高效计算的鞍点问题求解方法。
## 方法

本文的方法核心是**近端嵌套采样框架**及其扩展。

- **整体框架**：在标准嵌套采样（通过迭代收缩似然约束来估计模型证据）中，关键步骤是从先验分布中采样，同时满足硬似然约束L(x) > L*。在高维下，该约束采样极具挑战。本框架通过将似然约束转化为一个**凸集约束**，并利用**近端MCMC**采样来解决此问题。
- **输入输出**：输入是观测数据y、测量模型Φ、噪声模型、先验π(x)和似然L(x)。输出是贝叶斯模型证据Z的估计值，以及一系列带权重的后验样本（死点），可用于计算后验均值等估计量。
- **关键模块与连接**：
    1.  **约束采样问题表述**：将目标分布定义为约束先验π_{L*}(x) ∝ π(x) * 𝟙_{L(x)>L*}。对数形式为 -log π_{L*}(x) = -log π(x) + χ_{B_τ}(x)，其中χ_{B_τ}是定义似然约束集B_τ的特征函数。
    2.  **Langevin MCMC**：使用基于梯度的朗之万MCMC进行高维采样。标准更新式为 x^{(k+1)} = x^{(k)} + (δ/2)∇log π(x^{(k)}) + √δ w^{(k+1)}。
    3.  **近端演算引入**：特征函数χ_{B_τ}不可微。为此，对χ_{B_τ}应用**Moreau-Yosida正则化**，得到光滑近似，并最终得到核心更新方程（公式9）：
        `x^{(k+1)} = x^{(k)} + (δ/2)∇logπ(x^{(k)}) - (δ/2λ)[x^{(k)} - prox_{χ_{B_τ}}(x^{(k)})] + √δ w^{(k+1)}`
        其中`prox_{χ_{B_τ}}`是约束集的近端算子（即投影算子）。直观上，当采样点x^{(k)}在约束集B_τ内时，第三项为0；若在约束集外，该项会将采样点推向其在约束集上的投影。
    4.  **Metropolis-Hastings校正**：为确保收敛到正确的目标分布，需加入MH校正步骤以消除正则化和离散化带来的偏差。
    5.  **扩展至数据驱动先验**：对于隐式由训练数据定义的先验q(x)，其正则化版本p_ε(x)的得分可通过**Tweedie公式**与一个训练好的深度去噪器D_ε关联：∇log p_ε(x) = (1/ε)(D_ε(x) - x)。将其代入公式9，得到新的更新方程（公式15）：
        `x^{(k+1)} = x^{(k)} - (αδ/2ε)[x^{(k)} - D_ε(x^{(k)})] - (δ/2λ)[x^{(k)} - prox_{χ_{B_τ}}(x^{(k)})] + √δ w^{(k+1)}`
        这样，深度神经网络去噪器就被集成进来。
- **与已有方法差异**：与传统嵌套采样不同，本方法通过凸分析和近端算子解决了高维约束采样问题。与Galilean和受约束哈密顿嵌套采样有相似性，但本方法更直接地利用了凸集投影。与Plug-and-Play (PnP)方法都利用去噪器，但本方法将其嵌套在贝叶斯模型选择框架内。
- **推理流程**：在标准嵌套采样流程中，使用上述更新方程从受约束的先验中采样“活跃点”。随着似然阈值迭代提高，活跃点逐渐收缩，累积的“死点”及其似然值用于计算模型证据。
