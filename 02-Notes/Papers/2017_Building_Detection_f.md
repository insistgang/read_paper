## 研究背景与动机

## 方法

**整体框架**：系统是一个多阶段的流水线（pipeline）。主要分为：**1) 数据收集与标注** -> **2) 候选区域生成** -> **3) 弱监督建筑分类** -> **4) 半监督建筑分割** -> **5) 系统性误差调试**。

**输入输出**：
- **输入**：全球高分辨率卫星图像（总计约**500TB**）。
- **最终输出**：全球范围内的建筑分布图/人口密度图（如图3的热力图）。
- **中间输出**：64x64像素的图像块（masks）及其建筑存在概率或像素级分割结果。

**关键模块与连接**：
1.  **候选区域生成（Bounding Box Proposals）**：采用朴素的直边检测方法从原始卫星图中提取可能的建筑区域，生成大量64x64的候选块。这一步将需要处理的数据量减少了**50%**。随后，用一个**弱建筑分类器**对重叠（IoU > 0.3）的候选块进行去重，保留中心区域建筑概率最高的块。
2.  **弱监督建筑分类模型**：基于修改的**SegNet** [4]架构。这是一个编码器-解码器网络，利用最大池化层的索引进行非线性上采样。它使用**弱标签**（即只知道整个64x64块是否包含建筑，而不知道精确位置）进行训练。网络输出每个像素的建筑概率，然后通过**全局平均池化**得到整个块的建筑存在概率。该模型速度快，适合处理海量数据。
3.  **半监督建筑分割模型**：为了获得更精细的建筑轮廓，但避免昂贵的像素级标注，采用基于**反馈神经网络** [6] 的弱监督分割方法。它利用大量弱标签数据进行训练。在推理时，先使用上述**分类模型**过滤掉明显的负样本区域，再对剩余区域应用分割模型。两者结合（如图1）能有效抑制误报并生成更精确的结果。
4.  **系统性误差处理模块**：
    - **发现**：通过构建KMZ文件并叠加Google Earth进行**可视化手动排查**，定位误报/漏报集中区域。同时，与外部数据集进行**定量比对**以发现系统误差。
    - **修复**：1) 针对**数据质量问题**（如噪声），训练一个浅层的**端到端神经网络去噪模型**，模仿卫星图像中的常见噪声类型，并作为分类网络的前置预处理模块（图2）。2) 利用地理元信息检测云遮挡。3) 通过**主动学习**，在模型“不确定”（概率接近阈值）的样本上进行采样标注，用于迭代训练，减少系统误差。

**训练方式**：
- **分类模型**：采用**弱监督**学习，使用图像块级别的标签进行训练。
- **分割模型**：采用**半监督**学习，结合少量的昂贵像素级标签和大量的廉价块级标签。
- **模型泛化策略**：首先训练一个在某个国家（如坦桑尼亚）表现良好的模型，发现直接应用于新国家效果差。但随着标注数据国家的增多，用多国数据训练的**全球模型**在原始国家（坦桑尼亚）上的表现甚至超过了**国家专属模型**。为了进一步提升特定国家的性能，会对全球模型进行**微调（Fine-tuning）**，使用该国的数据子集重新训练，精度和召回率提升可达**20-40%**，但可能在某些国家引入系统性误报。

**推理流程**：
1.  对原始卫星图像进行边缘检测，生成候选块。
2.  用弱分类器过滤重叠块。
3.  将候选块输入弱监督分类模型，得到建筑存在概率。概率高于阈值的块被视为阳性。
4.  （可选）对阳性区域应用半监督分割模型，获得精细的建筑掩码。
5.  对结果进行后处理（包括去噪网络）。

**与已有方法的差异**：
- 相比依赖**手工特征**的工作，本方法使用深度学习，更具泛化潜力。
- 相比仅在**小范围验证**的工作，本方法强调**全球部署**的可行性与挑战，并设计了相应的数据、模型和调试策略。
- 相比完全监督的分割方法（如FCN [5]），本方法探索了**弱监督和半监督**路径，以应对像素级标注成本过高的问题。

3.  **半监督建筑分割模型**：为了获得更精细的建筑轮廓，但避免昂贵的像素级标注，采用基于**反馈神经网络** [6] 的弱监督分割方法。它利用大量弱标签数据进行训练。在推理时，先使用上述**分类模型**过滤掉明显的负样本区域，再对剩余区域应用分割模型。两者结合（如图1）能有效抑制误报并生成更精确的结果。
4.  **系统性误差处理模块**：
    - **发现**：通过构建KMZ文件并叠加Google Earth进行**可视化手动排查**，定位误报/漏报集中区域。同时，与外部数据集进行**定量比对**以发现系统误差。
    - **修复**：1) 针对**数据质量问题**（如噪声），训练一个浅层的**端到端神经网络去噪模型**，模仿卫星图像中的常见噪声类型，并作为分类网络的前置预处理模块（图2）。2) 利用地理元信息检测云遮挡。3) 通过**主动学习**，在模型“不确定”（概率接近阈值）的样本上进行采样标注，用于迭代训练，减少系统误差。

**训练方式**：
- **分类模型**：采用**弱监督**学习，使用图像块级别的标签进行训练。
- **分割模型**：采用**半监督**学习，结合少量的昂贵像素级标签和大量的廉价块级标签。
- **模型泛化策略**：首先训练一个在某个国家（如坦桑尼亚）表现良好的模型，发现直接应用于新国家效果差。但随着标注数据国家的增多，用多国数据训练的**全球模型**在原始国家（坦桑尼亚）上的表现甚至超过了**国家专属模型**。为了进一步提升特定国家的性能，会对全球模型进行**微调（Fine-tuning）**，使用该国的数据子集重新训练，精度和召回率提升可达**20-40%**，但可能在某些国家引入系统性误报。

**推理流程**：
1.  对原始卫星图像进行边缘检测，生成候选块。
2.  用弱分类器过滤重叠块。
3.  将候选块输入弱监督分类模型，得到建筑存在概率。概率高于阈值的块被视为阳性。
4.  （可选）对阳性区域应用半监督分割模型，获得精细的建筑掩码。
5.  对结果进行后处理（包括去噪网络）。

**与已有方法的差异**：
- 相比依赖**手工特征**的工作，本方法使用深度学习，更具泛化潜力。
- 相比仅在**小范围验证**的工作，本方法强调**全球部署**的可行性与挑战，并设计了相应的数据、模型和调试策略。
- 相比完全监督的分割方法（如FCN [5]），本方法探索了**弱监督和半监督**路径，以应对像素级标注成本过高的问题。
