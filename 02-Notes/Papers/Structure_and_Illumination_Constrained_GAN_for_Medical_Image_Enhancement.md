## 研究背景与动机

- **为什么要做：** 医学影像质量（如光照不均、对比度低、模糊或噪声）直接影响自动化疾病筛查、分析与诊断的准确性。例如，有研究显示约12%的眼底图像因质量不足而无法判读 (p.3955)。因此，发展自动、可靠的医学图像增强技术作为临床应用的前置步骤至关重要。
- **之前方法的问题：**
    1. **传统方法**（如直方图均衡化、Retinex）：通常对参数敏感，缺乏自适应性，且容易过度平滑或放大噪声，难以保留精细细节。
    2. **全监督深度学习方法**：需要严格对齐的低/高质量图像对进行训练，但在临床场景中难以获得此类配对数据。
    3. **现有无监督方法（如CycleGAN）**：虽然无需配对数据，但主要关注全局外观和域间循环一致性，缺乏对**结构**和**光照**这两个医学图像关键特征的约束，因此在捕捉局部细节方面效果不佳。
- **核心矛盾：** 如何在**无需配对训练数据**的约束下，同时提升医学图像的**光照均匀性**并**保留关键的结构细节**。

## 方法

### 整体框架
StillGAN是一个无监督的双向GAN框架，其核心思想是将低质量（LQ）和高质量（HQ）医学图像视为两个不同的域，并学习两者之间的双向映射。框架如图2所示，包含两个生成器-判别器对：(1) `G_LQ->HQ` / `D_HQ`，负责将LQ图像转换为HQ图像，并判断是否像真实HQ图像；(2) `G_HQ->LQ` / `D_LQ`，负责反向转换和判断。框架在标准的对抗损失和循环一致性损失基础上，加入了光照正则化`L_ill`和结构损失`L_st`这两个新约束项。

### 输入输出
- **输入**：训练时是一批未配对的低质量医学图像`a`（来自LQ域）和高质量医学图像`b`（来自HQ域）。
- **输出**：增强后的医学图像`~b = G_LQ->HQ(a)`。

### 关键模块与连接
1.  **生成器结构**：两个生成器`G_LQ->HQ`和`G_HQ->LQ`采用**编码器-解码器架构**（类似ResU-Net），包含8个编码层和对称的8个解码层，并带有跳跃连接。每个编码/解码层由**残差块**（两个3x3卷积层）构成。解码时使用双线性插值进行上采样 (p.3957, 图3)。
2.  **判别器结构**：两个判别器`D_LQ`和`D_HQ`采用**PatchGAN**架构，包含5个卷积层，不判断整张图像真伪，而是判断图像中**70x70大小的局部块**是否真实。这使得判别器更轻量，并能引导生成器产生局部真实的细节 (p.3957)。
3.  **新增损失项机制**：
    - **光照正则化 `L_ill`**：直观解释是惩罚生成图像`~b`中的光照不均匀。其计算步骤为（p.3958）：
        a. 计算图像全局平均亮度。
        b. 将图像分割成`n x m`个局部块，计算每个块的平均亮度，得到光照矩阵`D`。
        c. 用`D`的每个元素减去全局平均亮度，得到光照差异矩阵`E`。
        d. 将`E`通过双线性插值缩放回原图尺寸，得到光照分布矩阵`R`。
        e. 计算`R`中所有元素的平均绝对值。该值越小，说明光照越均匀。最终损失是期望图像在此值上的平均。
    - **结构损失 `L_st`**：为保留结构细节，此损失利用一个预训练的ResNet（如ResNet-50）作为特征提取器。它分别提取低质量原图`a`和其增强图`~b`的特征图，并计算两者之间的**余弦相似度**。损失函数旨在最小化这两者特征之间的差异，从而在增强过程中保持关键结构信息 (p.3959)。

### 训练方式
总目标函数为：`L = L_transfer + λ1 * L_ill + λ2 * L_st`。
- `L_transfer` 是基础转移损失，包括：对抗损失`L_adv`、循环一致性损失`L_cyc`和身份映射损失`L_idt` (公式4，p.3958)。
- `L_cyc`确保图像经过`a -> ~b -> ^a ≈ a`和`b -> ~a -> ^b ≈ b`的循环后能还原，保证了域间映射的合理性 (公式2)。
- `L_idt`鼓励生成器在接收到属于其目标域的真实图像时保持不变，即`G_HQ->LQ(a) ≈ a`和`G_LQ->HQ(b) ≈ b`，有助于保留颜色等低层信息 (公式3)。
- `λ1`和`λ2`是控制新损失项权重的超参数。

### 推理流程
训练完成后，仅使用`G_LQ->HQ`生成器。输入一张低质量医学图像，直接输出增强后的高质量图像。

### 和已有方法的差异
与CycleGAN相比，StillGAN的核心差异在于在基础的双向GAN框架上，**显式地加入了光照正则化和结构损失这两个先验约束**。CycleGAN仅依赖对抗损失和循环一致性，容易在医学图像上丢失细节或产生不真实的光照；而StillGAN通过`L_ill`主动引导生成光照均匀的图像，通过`L_st`约束结构不丢失，从而更好地满足医学图像对光照和结构的高要求。

        d. 将`E`通过双线性插值缩放回原图尺寸，得到光照分布矩阵`R`。
        e. 计算`R`中所有元素的平均绝对值。该值越小，说明光照越均匀。最终损失是期望图像在此值上的平均。
    - **结构损失 `L_st`**：为保留结构细节，此损失利用一个预训练的ResNet（如ResNet-50）作为特征提取器。它分别提取低质量原图`a`和其增强图`~b`的特征图，并计算两者之间的**余弦相似度**。损失函数旨在最小化这两者特征之间的差异，从而在增强过程中保持关键结构信息 (p.3959)。

### 训练方式
总目标函数为：`L = L_transfer + λ1 * L_ill + λ2 * L_st`。
- `L_transfer` 是基础转移损失，包括：对抗损失`L_adv`、循环一致性损失`L_cyc`和身份映射损失`L_idt` (公式4，p.3958)。
- `L_cyc`确保图像经过`a -> ~b -> ^a ≈ a`和`b -> ~a -> ^b ≈ b`的循环后能还原，保证了域间映射的合理性 (公式2)。
- `L_idt`鼓励生成器在接收到属于其目标域的真实图像时保持不变，即`G_HQ->LQ(a) ≈ a`和`G_LQ->HQ(b) ≈ b`，有助于保留颜色等低层信息 (公式3)。
- `λ1`和`λ2`是控制新损失项权重的超参数。

### 推理流程
训练完成后，仅使用`G_LQ->HQ`生成器。输入一张低质量医学图像，直接输出增强后的高质量图像。

### 和已有方法的差异
与CycleGAN相比，StillGAN的核心差异在于在基础的双向GAN框架上，**显式地加入了光照正则化和结构损失这两个先验约束**。CycleGAN仅依赖对抗损失和循环一致性，容易在医学图像上丢失细节或产生不真实的光照；而StillGAN通过`L_ill`主动引导生成光照均匀的图像，通过`L_st`约束结构不丢失，从而更好地满足医学图像对光照和结构的高要求。
