## 摘要

清理后英文原摘要（据 PDF 提取文本整理，修复空格与连字符断裂）：

> We introduce and solve the problem of Byzantine fault tolerant distributed quickest change detection in both continuous and discrete time setups. In this problem, multiple sensors sequentially observe random signals from the environment and send their observations to a control center that will determine whether there is a change in the statistical behavior of the observations. We assume that the signals are independent and identically distributed across sensors. An unknown subset of sensors are compromised and will send arbitrarily modified and even artificially generated signals to the control center. It is shown that the performance of the so-called CUSUM statistic, which is optimal when all sensors are honest, will be significantly degraded in the presence of even a single dishonest sensor. In particular, instead of logarithmically, the detection delay grows linearly with the average run length (ARL) to false alarm. To mitigate such a performance degradation, we propose a fully distributed low complexity detection scheme. We show that the proposed scheme can recover the log scaling. We also propose a centralized group-wise scheme that can further reduce the detection delay.

中文翻译：

> 本文提出并求解了连续时间与离散时间两种设定下的“拜占庭容错分布式快速变化检测”问题。该问题中，多个传感器顺序观测来自环境的随机信号，并将观测发送给一个控制中心，由其判断观测的统计特性是否发生了变化。我们假设各传感器的信号是跨传感器独立同分布的。一个未知的传感器子集被攻陷，会向控制中心发送任意篡改、甚至人工伪造的信号。本文表明，在所有传感器都诚实时最优的 CUSUM 统计量，只要存在哪怕一个不诚实的传感器，其性能就会严重退化：检测延迟相对虚警平均运行长度（ARL）从对数增长退化为线性增长。为缓解这一退化，我们提出一个完全分布式、低复杂度的检测方案，并证明它能恢复对数缩放；此外还提出一个集中式的“分组”方案，可进一步降低检测延迟。

## 研究背景与动机

- **为什么要做**：无线传感器网络被广泛部署用于异常活动检测，应用场景包括质量控制、安全监控、无线通信、化学/生物攻击检测等（引言列举）。分布式快速变化检测（quickest change detection）是其核心任务：在未知时刻 τ 观测的概率密度发生改变，目标是在虚警约束下以最小延迟检出。已有的分布式快速检测工作几乎都**假设传感器始终上报真实观测**。
- **之前方法的问题**：在攻击检测等场景，传感器可能被攻陷而上报篡改甚至人工伪造的数据（拜占庭故障——组件以任意方式失效，而非简单停止工作）。当所有节点诚实时，Lorden 准则下 CUSUM（Page 累积和）是最优的；但本文证明：**只要一个传感器被攻陷**，攻击者用一个简单攻击（让该传感器报告带有强正漂移的虚假布朗运动 `ξ̄(1)_t = Nt + W(1)_t`，见式 (3.6)）就能使 CUSUM 的检测延迟相对 ARL 从对数增长退化为线性增长（命题 3.1）。
- **核心矛盾**：在**传感器子集不可信、攻击策略任意且不作任何假设**的强敌手模型下，如何设计仍能保持高效（延迟与 ARL 对数关系）的快速变化检测方案，并在检测延迟与抗攻击鲁棒性之间取得平衡。
## 关键贡献

1.  **理论揭示攻击危害**：用一个简单攻击策略 (3.6) 证明，即使只有单个拜占庭传感器，也能使传统最优 CUSUM 的检测延迟相对 ARL 从对数缩放退化为线性缩放（命题 3.1，连续时间）。
2.  **提出完全分布式鲁棒方案（“第二警报”策略）**：每个传感器对自己的信号本地运行 CUSUM，一旦本地统计量越过阈值 h 就向融合中心发送 1 比特报警；融合中心**忽略第一个报警，收到第二个传感器报警时才发出最终警报**。低复杂度、低通信开销（Remark 3.4）。
3.  **证明分布式方案恢复对数缩放**：借助序统计工具，给出对任意攻击策略都成立的检测延迟上界与 ARL 下界，并证明延迟相对 ARL 对数增长，即恢复了对数缩放（定理 3.2 连续时间；定理 4.1 离散时间，据原文后续页 p.14，提取缓存未覆盖完整，待核）。
4.  **提出集中式分组优化方案**：将 N 个传感器均匀分为 **3 组**，每组对组内融合信号运行一个组级 CUSUM；融合中心在**至少两组报警**后发出最终警报。该方案保持对数缩放，同时把预对数因子从 `4/µ²` 降到 `12/(µ²N)`，即斜率随 N 增大而减小（定理 3.7；离散时间对应定理 4.2，据原文后续页，待核）。
5.  **鲁棒性与扩展说明**：上界对任意（可随时间任意变化的）攻击策略都成立（Remark 3.3）；方案可推广到各传感器漂移/波动率不同的情形（Remark 3.5）；可推广到被攻陷传感器多于 1 个或数目未知的情形——只要已知上界 `N_max < N/2`，融合中心用 `N_max+1` 警报策略即可（Remark 3.6）；并论证了为何分组取 3 组而非 2 组（Remark 3.9）。
## 方法

**整体框架与问题建模（第 2 节）**：
- **系统**：`N ≥ 3` 个传感器连到一个融合中心；假设其中一个传感器可能被攻陷（方案可改造以处理多个）。被攻陷传感器索引 `n_c` 未知。
- **输入**：传感器 n 观测 `ξ(n)_t`，上报值 `ξ̄(n)_t`。诚实时 `ξ̄(n)_t = ξ(n)_t`；被攻陷时 `ξ̄(n_c)_t` 由攻击策略 s 任意生成（可利用其观测到的 `ξ(n_c)_t`），**对攻击策略不作任何假设**。
- **输出/目标**：设计停止规则 T（融合中心报警时刻），求解
  - `inf_T d(T)  s.t.  ARL(T) ≥ γ`（式 2.1）。
  - 检测延迟用修正 Lorden 指标 `d(T) = sup_{τ,n_c,s} esssup E_{τ,n_c,s}[(T−τ)^+ | F_τ]`（对变化时刻、被攻陷传感器、攻击策略取最坏情形）。
  - 虚警 ARL `ARL(T) = inf_{n_c,s} E_{∞,n_c,s}[T]`。
- **两种信号模型**：
    - **连续时间布朗运动模型**：`ξ(n)_t = µ(t−τ)^+ + W(n)_t`，τ 为未知变化时刻，µ 为变化后信号强度（漂移），`{W(n)_t}` 为独立标准布朗运动。
    - **离散时间模型**：时间取整数，变化前后观测分别服从 pdf `f0`（t≤τ）和 `f1`（t>τ）。

**关键模块详解**：
1.  **传统 CUSUM（基准，不抗攻击；第 3.1 节）**：
    - 统计量 `y_t = u_t − m_t`，其中 `u_t = Σ_n µ·ξ̄(n)_t − (1/2)Nµ²t`，`m_t = inf_{0≤s≤t} u_s`。
    - 停止规则 `T_ν = inf{t ≥ 0 : y_t ≥ ν}`（式 3.2）。无攻击时由式 (3.3) 选阈值 ν 使 `ARL(T_ν) = 2(e^ν − ν − 1)/(Nµ²) = γ`，此时延迟 `d(T_ν) = 2(e^{−ν}+ν−1)/(Nµ²)`（式 3.4），当 γ↑∞ 时 `d ≈ (2/Nµ²)[log(ARL) + log(Nµ²/2) − 1 + o(1)]`，**对数缩放**（式 3.5）。
    - 攻击下退化（命题 3.1）：攻击者令 `n_c=1` 并按 (3.6) 生成 `ξ̄(1)_t = Nt + W(1)_t`。证明利用 Itô 公式与辅助函数 `f(y)=y+e^{−y}−1`，得到
      `ARL(T_ν) ≤ (e^{−ν}+ν−1)/(Nµ²/2)`，`d(T_ν) ≥ (e^{−ν}+ν−1)/((3N/2−1)µ²)`（式 3.7）。两者都随 `(e^{−ν}+ν−1)` 同阶，故 d 与 ARL **线性**相关。

2.  **“第二警报”完全分布式方案（第 3.2 节）**：
    - **流程**：融合中心对每个信号独立跑 CUSUM `T(n)_h = inf{t≥0 : y(n)_t ≥ h}`，其中 `y(n)_t = µξ̄(n)_t − (1/2)µ²t − inf_{s≤t}(µξ̄(n)_s − (1/2)µ²s)`。`T(n)_h` 即传感器 n 的报警时刻。融合中心忽略第一个报警，收到第二个传感器报警时立即报警。
    - **关键机制**：最终报警时刻 `T_h ≜ T_{(2),N}`，即 N 个 i.i.d. 随机变量 `{T(n)_h}` 的**第二序统计量**。
    - **鲁棒性来源（定理 3.2 证明）**：攻击者只控制 1 个传感器。① ARL 下界——攻击者想缩短 ARL，最优做法是让被控传感器尽快报警，于是虚警须等 `N−1` 个诚实传感器中第一个误报，故 `ARL(T_h) ≥ E_{∞,N,s}{T_{(1),N−1}} = ∫ [P_∞(T(1)_h ≥ t)]^{N−1} dt`，借助 [10] 给出的首穿越分布闭式 (3.9)(3.10) 算得 `= (2/((N−1)µ²))[e^h + “lower exponents”]`（式 3.11），随 h 指数增长。② 延迟上界——攻击者想拉长延迟，最优做法是不报警，于是须等两个诚实传感器报警，`d(T_h) ≤ E_{0,N,s}{T_{(2),N−1}} ≤ 4(e^{−h}+h−1)/µ²`。两式相除得
      `d(T_h) ≤ (4/µ²)[log(ARL(T_h)) + log((N−1)µ²/2) − 1 + o(1)]`（定理 3.2），**恢复对数缩放**。
    - **与已有方法差异**：不依赖数据融合或集中假设检验，而用分布式独立检测 + 简单计数逻辑，把单个拜占庭传感器的影响限制为“最多让一个本地检测失效”，靠多数诚实传感器保证性能。

3.  **“分组”集中式方案（第 3.3 节）**：
    - **流程**：把 N 个传感器均匀分为 3 组 `G1,G2,G3`（各 N/3 个）。每组对组内融合信号跑组级 CUSUM `T^{Gi}_h = inf{t : y^{Gi}_t ≥ h}`，其中 `u^{Gi}_t = Σ_{n∈Gi} µξ̄(n)_t − (1/2)(N/3)µ²t`。融合中心在**至少两组报警**后报警，即 `T^G_h ≜ T^G_{(2),3}`（三组报警时间的第二序统计量）。
    - **数学直观**：组级 CUSUM 的 `u^{Gi}_t` 变化前漂移 −µ²N/6、变化后 +µ²N/6、标准差 `µ√(N/3)`；组内传感器多，组级检测比单传感器更快。沿定理 3.2 思路得 `ARL(T^G_h) ≥ (3/(µ²N))[e^h + “lower exponents”]`、`d(T^G_h) ≤ 2E_{0,N,s}{T^{G1}_h} = (2/(µ²N/6))(e^{−h}+h−1)`，合得
      `d(T^G_h) ≤ (12/(µ²N))[log(ARL(T^G_h)) + log(Nµ²/3) − 1 + o(1)]`（定理 3.7）。预对数因子 `12/(µ²N)` 优于分布式方案的 `4/µ²`。
    - **为何 3 组而非 2 组（Remark 3.9）**：若只分 2 组并用第二警报，攻击者可在其所在组注入足够小的负漂移使该组迟迟不报警，从而把延迟拉到任意大；若改用普通 CUSUM，则攻击者用足够大正漂移可把 ARL 压得很短。3 组是抵御这两类攻击的最小划分。
    - **代价（Remark 3.8）**：融合中心需组内全部传感器信号，**不是**完全分布式。

**对比分析**：ARL 约束 γ 很大时，两种新方案延迟均与 `log(γ)` 成正比，而攻击下的传统 CUSUM 与 `γ` 成正比。分组方案延迟上界比分布式方案小一个 `O(1/N)` 因子，代价是集中式实现。
## 局限

1.  **敌手模型假设**：核心分析假设**只有一个**传感器被攻陷；推广到多个时须已知上界 `N_max < N/2`（Remark 3.6）。当 `N_max ≥ N/2` 时方案失效（攻击者让被控传感器全部沉默即可使其永不报警），实际中攻击数目可能未知。
2.  **方案性质权衡**：
    - **“第二警报”分布式方案**：鲁棒且完全分布式，但预对数因子 `4/µ²` 大于已知攻击者身份时的 `2/((N−1)µ²)`，即延迟随 ARL 增长更快。
    - **“分组”方案**：预对数因子 `12/(µ²N)` 更小，但需融合中心集中处理组内全部信号，**不是**完全分布式，增加融合中心计算与通信负担（Remark 3.8）。
3.  **信号模型假设**：假设传感器信号跨传感器、跨时间均独立同分布。实际应用常存在时空相关性。Remark 3.5 仅把模型放宽到各传感器漂移/波动率不同，未放宽独立性。
4.  **理论与实践差距**：结论均为渐近 / 不等式上下界；数值算例的具体参数与读数在提取缓存中未覆盖，与启发式抗攻击方法（如中值、截断均值融合）的系统对比未见于已覆盖文本。
5.  **计算/实现开销**：每个传感器须持续运行 CUSUM 并维护本地状态，分组方案融合中心须对每组实时计算；这些开销论文未量化讨论。
## 个人评论

1.  **问题洞察的深刻性**：清晰揭示了分布式检测中“**单个恶意节点足以彻底破坏经典最优算法的理论保证**”——把 CUSUM 的对数缩放打成线性缩放。这比一般异常检测讨论更具理论冲击力，提示对抗环境下不能直接套用诚实假设下的最优性。
2.  **方法设计的优雅**：“第二警报”策略只用本地 CUSUM + 1 比特通信 + 计数，却在最坏情形恢复对数性能。其核心哲学是用**结构性冗余（多数诚实）**与**简单决策（计数而非融合）**抵御强敌手，对设计其他分布式鲁棒算法有借鉴意义。
3.  **严谨的分析范式**：将问题建模为“连续/离散时间下的鲁棒最优停止”，用 Itô 公式、首次穿越时间闭式 (3.9)(3.10) 与序统计把“鲁棒性”转化为对序统计量期望的上下界估计，是一套可复用的分析工具链。
4.  **分布式 vs 集中式的清晰权衡**：同时给出弱保证低开销的分布式方案与强保证高计算的分组方案，并把差异落到预对数因子（`4/µ²` vs `12/(µ²N)`），为系统设计提供了直观的性能-开销取舍；Remark 3.9 对“为何 3 组”的论证尤其体现了对攻击面的细致考量。

本文属于**统计信号处理 / 分布式序贯检测 / 系统安全**的交叉领域，具体解决**分布式传感器网络在拜占庭（Byzantine）攻击下的最优快速变化检测（Quickest Change Detection）问题**。传统分布式快速检测都假设传感器始终如实上报，本文则聚焦于未知子集传感器被敌手控制、可发送任意篡改或人工伪造数据的强敌手场景。论文是纯理论/概率工作（arXiv math.PR），与自然语言处理无关；在本库 taxonomy 中没有匹配的具体 CV 主题，归入 `T_通用_NLP_其他` 这一“通用/其他”兜底主题最贴切。

## 2. 一句话总结
本文证明拜占庭攻击会把传统最优 CUSUM 的检测延迟从相对 ARL 的对数缩放退化为线性缩放，并提出两种恢复对数缩放的鲁棒方案——完全分布式的“第二警报”策略（预对数因子 4/µ²）与集中式“分组”策略（预对数因子 12/(µ²N)，更小但需集中处理）。

## 3. 背景与问题
- **为什么要做**：无线传感器网络广泛用于质量控制、安全、无线通信、化生攻击检测等异常检测场景，分布式快速变化检测是核心任务。已有工作几乎都假设传感器如实上报；但在攻击检测等场景，传感器可能被攻陷而上报任意数据（拜占庭故障）。
- **之前方法的问题**：所有节点诚实时 Lorden 准则下 CUSUM 最优；本文证明**只要一个传感器被攻陷**，攻击者用简单攻击 (3.6)（让被控传感器报告带强正漂移的虚假布朗运动）就能使 CUSUM 检测延迟相对 ARL 从对数增长退化为线性增长（命题 3.1）。
- **核心矛盾**：在传感器子集不可信、攻击策略任意且不作任何假设的强敌手模型下，如何设计仍保持对数缩放的高效检测，并平衡检测延迟与抗攻击鲁棒性。

## 4. 核心贡献
1.  **揭示攻击危害**：用简单攻击 (3.6) 证明单个拜占庭传感器即可让 CUSUM 延迟相对 ARL 由对数缩放退化为线性缩放（命题 3.1，连续时间）。
2.  **完全分布式“第二警报”方案**：各传感器本地跑 CUSUM，越阈值即发 1 比特报警；融合中心忽略首报、收到第二个传感器报警才报警。低复杂度、低通信（Remark 3.4）。
3.  **证明分布式方案恢复对数缩放**：用序统计给出对任意攻击都成立的延迟上界与 ARL 下界，证明 `d = O(log ARL)`（定理 3.2 连续；定理 4.1 离散，据原文后续页，待核）。
4.  **集中式“分组”方案**：均分 3 组、组级 CUSUM、至少两组报警；保持对数缩放并把预对数因子从 4/µ² 降到 12/(µ²N)（定理 3.7；离散对应 4.2，据原文后续页，待核）。
5.  **鲁棒性与扩展**：界对任意时变攻击成立（Remark 3.3）；可推广到各传感器参数不同（3.5）、多/未知数目被攻陷且 `N_max<N/2`（3.6，用 `N_max+1` 警报）；论证为何分组取 3 而非 2（3.9）。

## 5. 方法详解
**问题建模（第 2 节）**：
- 系统 `N ≥ 3` 个传感器 + 融合中心；被攻陷传感器索引 `n_c` 未知；诚实时 `ξ̄(n)_t = ξ(n)_t`，被攻陷时 `ξ̄(n_c)_t` 由任意攻击策略 s 生成（不作假设）。
- 优化目标 `inf_T d(T)  s.t. ARL(T) ≥ γ`（式 2.1）；延迟用修正 Lorden 指标 `d(T)=sup_{τ,n_c,s} esssup E[(T−τ)^+|F_τ]`，ARL `=inf_{n_c,s} E_{∞,n_c,s}[T]`。
- 两模型：连续时间布朗运动 `ξ(n)_t = µ(t−τ)^+ + W(n)_t`；离散时间 pdf `f0`(t≤τ)/`f1`(t>τ)。

**模块 1 — 传统 CUSUM（基准，第 3.1 节）**：
- `y_t = u_t − m_t`，`u_t = Σ_n µξ̄(n)_t − (1/2)Nµ²t`，`m_t = inf_{0≤s≤t} u_s`；停止规则 `T_ν = inf{t : y_t ≥ ν}`（3.2）。
- 无攻击：`ARL(T_ν)=2(e^ν−ν−1)/(Nµ²)=γ`（3.3），`d(T_ν)=2(e^{−ν}+ν−1)/(Nµ²)`（3.4），`d ≈ (2/Nµ²)[log ARL + log(Nµ²/2) − 1 + o(1)]`（3.5），对数缩放。
- 攻击 (3.6) 下（命题 3.1，Itô + `f(y)=y+e^{−y}−1`）：`ARL(T_ν) ≤ (e^{−ν}+ν−1)/(Nµ²/2)`，`d(T_ν) ≥ (e^{−ν}+ν−1)/((3N/2−1)µ²)`（3.7），d 与 ARL 线性。

**模块 2 — “第二警报”分布式方案（第 3.2 节）**：
- 本地 CUSUM `T(n)_h = inf{t : y(n)_t ≥ h}`，`y(n)_t = µξ̄(n)_t − (1/2)µ²t − inf_{s≤t}(µξ̄(n)_s − (1/2)µ²s)`。
- 最终报警 `T_h ≜ T_{(2),N}`（N 个 i.i.d. `{T(n)_h}` 的第二序统计量）。
- 定理 3.2 证明双向最坏情形：攻击者想缩短 ARL → 让被控传感器尽快报警 → `ARL ≥ E{T_{(1),N−1}} = ∫[P_∞(T(1)_h≥t)]^{N−1}dt = (2/((N−1)µ²))[e^h+“lower exponents”]`（3.11，用首穿越闭式 3.9/3.10）；攻击者想拉长延迟 → 不报警 → `d ≤ E{T_{(2),N−1}} ≤ 4(e^{−h}+h−1)/µ²`。合得 `d(T_h) ≤ (4/µ²)[log ARL + log((N−1)µ²/2) − 1 + o(1)]`，恢复对数缩放。

**模块 3 — “分组”集中式方案（第 3.3 节）**：
- 均分 3 组 `G1,G2,G3`（各 N/3），组级 CUSUM `T^{Gi}_h`，`u^{Gi}_t = Σ_{n∈Gi}µξ̄(n)_t − (1/2)(N/3)µ²t`；至少两组报警，`T^G_h ≜ T^G_{(2),3}`。
- `u^{Gi}_t` 变化前漂移 −µ²N/6、变化后 +µ²N/6、标准差 µ√(N/3)；沿定理 3.2 思路得 `ARL ≥ (3/(µ²N))[e^h+…]`、`d ≤ (2/(µ²N/6))(e^{−h}+h−1)`，合得 `d(T^G_h) ≤ (12/(µ²N))[log ARL + log(Nµ²/3) − 1 + o(1)]`（定理 3.7），预对数因子优于分布式方案。
- Remark 3.9：分 2 组会被攻击者用小负漂移（第二警报方案下延迟任意大）或大正漂移（CUSUM 下 ARL 任意短）攻破，故取 3 组；Remark 3.8：分组方案为集中式。

## 7. 这篇论文真正有价值的地方
1.  **单恶意节点摧毁最优性**：揭示分布式检测中单个拜占庭节点足以把 CUSUM 的对数缩放打成线性缩放，是对鲁棒性的根本性认识。
2.  **极简而有效的设计**：第二警报只用本地 CUSUM + 1 比特 + 计数，却在最坏情形恢复对数性能；体现“结构性冗余 + 简单决策”的鲁棒设计哲学。
3.  **可复用的分析范式**：把鲁棒性需求转化为对序统计量期望的上下界估计，配合 Itô 公式与首穿越时间闭式，是对抗环境下统计检测的工具链。
4.  **清晰的性能-开销权衡**：分布式（4/µ²，低开销弱保证）与分组（12/(µ²N)，强保证高计算）两方案对照，并落到预对数因子，给系统设计直接指南。

## 8. 局限与问题
1.  **敌手数目假设**：核心分析设单个被攻陷；多个须已知 `N_max < N/2`（Remark 3.6），`N_max ≥ N/2` 时失效，实际攻击数目可能未知。
2.  **方案权衡**：第二警报方案因子 4/µ² 大于已知身份时 2/((N−1)µ²)，延迟增长更快；分组方案因子更小但为集中式，增加融合中心负担（Remark 3.8）。
3.  **信号模型**：假设跨传感器、跨时间 i.i.d.；Remark 3.5 仅放宽到各传感器漂移/波动率不同，未放宽独立性，实际常有时空相关。
4.  **理论与实践差距**：结论为渐近/不等式界；数值算例参数与读数提取缓存未覆盖，与中值/截断均值等启发式抗攻击融合的系统对比未见于已覆盖文本。
5.  **实现开销**：各传感器持续跑 CUSUM 维护状态、分组方案融合中心实时组级计算，开销未量化。
