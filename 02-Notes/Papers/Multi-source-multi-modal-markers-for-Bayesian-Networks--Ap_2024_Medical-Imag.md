## 摘要

本研究提出一种新的贝叶斯网络结构学习算法MPC-HC，并用它整合极早产儿脑部的多模态MRI数据与认知测试数据，以学习变量间的依赖网络，从而发现影响认知结局的脑影像生物标志物并量化其相互影响。
## 研究背景与动机

- **为什么要做**：早产（尤其是极早产）导致的脑发育异常与认知障碍是一个复杂表型，涉及多种脑结构/功能的改变和多个认知域的缺陷。现有研究多局限于单一影像模态或单一认知指标，或使用回归等方法，无法有效揭示这些异构变量之间的复杂、多向依赖关系，也无法充分建模不确定性。
- **之前方法的问题**：
    1.  常用的贝叶斯网络结构学习算法（如PC、HC、MMHC）存在局限：HC易陷入局部最优；PC和MMHC依赖的统计检验受多重假设检验和弱依赖关系的影响，可能导致结构错误。
    2.  既往神经影像研究多使用单一数据源，忽略了整合多模态数据（如结构、功能、认知）的巨大潜力。
    3.  许多研究只关注预测或关联发现，未充分利用贝叶斯网络在**建模不确定性、稳定性评估、敏感性分析**等方面的能力。
- **核心矛盾**：如何从高维、多源、异质的早产儿生物医学数据中，学习一个**稳健、可解释**的变量依赖网络结构，以全面刻画早产表型，并量化不同变量（特别是脑影像标志物）如何相互影响并共同决定认知结局。
## 关键贡献

1.  **提出了新的结构学习算法MPC-HC**：该算法是一种混合方法，先使用基于约束的方法（类似PC算法）学习网络骨架（无向图），再结合基于评分的方法（类似HC算法）和对I-等价类的搜索来定向边。其关键创新在于在定向阶段搜索所有可能的不道德（immoralities）配置，并在更大的等价类假设空间上进行评分优化，旨在找到全局最优结构。
2.  **全面的算法验证**：通过基准测试验证了MPC-HC在**重建真实网络结构**方面优于PC、HC和MMHC算法。
3.  **展示了贝叶斯网络在多模态标志物分析中的完整应用范式**：不仅用于关联发现和预测，还具体演示了如何利用学到的网络进行**变量预测、不确定性评估（通过bootstrapping）和敏感性分析**，以量化变量间的相互影响。
4.  **应用于极早产儿表型刻画**：首次应用此方法整合极早产青年的多模态脑影像（结构、功能连接密度、功能激活）和多项认知指标，发现结果与文献一致，证明了方法的有效性和实用性。
## 方法

- **整体框架**：方法核心是**MPC-HC贝叶斯网络结构学习算法**，其流程分为两个主要阶段：**骨架识别**和**边定向**。整个流程的目标是从包含多个连续或离散变量（如脑区体积、连接密度、认知分数）的数据集中，学习一个有向无环图（DAG），节点代表变量，边代表直接的统计依赖关系。
- **输入输出**：
    - **输入**：一个多变量数据集，本研究中包含10个变量：4个认知分数（VCI, PRI, VWM, VSM）、3个脑区功能激活指标（PRF, DGM, MTR）、3个白质连接密度指标（PMN, PDN, DMN）。
    - **输出**：一个贝叶斯网络结构（DAG），以及对应的条件概率表参数。
- **关键模块与连接**：
    1.  **骨架识别模块（约束部分）**：采用类似PC算法的策略。从一个全连接的无向图开始，通过逐步进行条件独立性检验（使用卡方检验，显著性水平α=0.01）来移除边。具体地，如果两个变量在给定某个条件集U下独立，则移除它们之间的边。条件集U的大小从0开始逐步增加，直到骨架稳定。
    2.  **边定向与结构优化模块（评分部分）**：这是MPC-HC与传统混合算法（如MMHC）的核心区别。它不是简单地用评分函数（如BIC）对骨架的定向进行局部搜索，而是：
        - 首先，枚举骨架中所有可能的**不道德（V-结构，形如X→Z←Y）**配置。每一种配置定义了一个部分有向无环图（PDAG），其中涉及不道德的边方向被固定。
        - 然后，对每一种PDAG，使用评分函数（BIC）引导的搜索（类似HC算法，但受约束）来定向剩余的边。合法的操作包括：定向未定向的边、删除非固定边、反转非固定边。搜索目标是找到在当前不道德配置下能最大化BIC分数的DAG。
        - 最后，在所有可能的不道德配置产生的最优DAG中，选择BIC分数最高的那个作为最终输出。
- **数学公式与机制的直观解释**：
    - **参数学习**：使用贝叶斯方法，假设多项式分布的先验是狄利克雷分布，后验也是狄利克雷分布，从而可以方便地计算给定数据的参数估计和新样本的预测概率（公式1-3）。
    - **结构评分**：使用BIC分数（公式5），它在模型的似然度（数据拟合程度）和模型复杂度（独立参数数量）之间进行权衡，防止过拟合。
    - **I-等价类**：核心理论。具有相同骨架和相同不道德集合的DAG是I-等价的，它们具有相同的BIC分数。因此，学习的最终目标是恢复真实网络所属的I-等价类中的一个DAG，而非追求唯一的真实图。MPC-HC通过搜索不道德配置来主动探索不同的等价类代表。
- **训练方式**：对于基准网络验证，使用从已知网络生成的数据。对于真实早产儿数据，使用收集的138名受试者的标准化数据集进行结构学习。通过**Bootstrap（重采样）** 评估结构的置信度和稳定性：多次从变量的概率密度函数中采样，分别学习网络，最终选择拟合最好的网络进行后续分析。
- **推理流程**：学习到网络结构和参数后，可以进行：
    1.  **预测**：给定部分变量观测值，推理其他变量的后验概率。
    2.  **敏感性分析**：改变一个变量的状态，观察其对其他变量概率分布的影响。
- **与已有方法的差异**：
    - 与 **PC** 相比：MPC-HC增加了评分导向的边定向和等价类搜索，减少了因统计检验误差累积导致的结构错误。
    - 与 **HC** 相比：MPC-HC使用基于约束的骨架学习作为起点，并搜索等价类，而非在完全图上从头进行局部搜索，有助于跳出局部最优。
    - 与 **MMHC** 相比：MPC-HC在定向阶段不局限于MMPC找到的骨架，而是在骨架基础上通过枚举不道德配置来探索更广泛的假设空间，旨在获得全局更优的结构。
- **论文类型特化（医学类）**：
    - **任务类型**：**多模态生物标志物发现与变量关系建模**。这不是传统的图像分割或分类任务，而是利用贝叶斯网络作为“玻璃盒”模型，揭示不同医学变量间的依赖关系。
    - **图像模态**：结构MRI（用于提取脑区体积/密度）、静息态fMRI（用于提取功能连接密度）、任务态fMRI（用于提取激活水平）。结合了神经心理学认知测试数据。
    - **数据集**：来自EPICure项目的纵向队列数据，包含85名极早产青年和53名足月对照青年，匹配了社会经济背景。
    - **流程**：数据预处理（脑区分割、连接计算、标准化）→ 多变量数据整合 → MPC-HC结构学习 → 网络参数学习 → 预测/敏感性分析。
    - **临床意义**：有助于理解早产如何通过影响特定的脑网络连接和功能，最终导致认知缺陷，为寻找早期干预靶点提供理论依据。

## 局限

3.  **连续变量的处理**：提供的变量描述（如连接密度、认知分数）可能是连续或有序分类的。论文使用了离散BN（多项式分布），需要对连续变量进行离散化，这可能会损失信息或引入偏差。文本中未详细说明离散化策略。

## 5. 方法详解
- **整体框架**：方法核心是**MPC-HC贝叶斯网络结构学习算法**，其流程分为两个主要阶段：**骨架识别**和**边定向**。整个流程的目标是从包含多个连续或离散变量（如脑区体积、连接密度、认知分数）的数据集中，学习一个有向无环图（DAG），节点代表变量，边代表直接的统计依赖关系。
- **输入输出**：
    - **输入**：一个多变量数据集，本研究中包含10个变量：4个认知分数（VCI, PRI, VWM, VSM）、3个脑区功能激活指标（PRF, DGM, MTR）、3个白质连接密度指标（PMN, PDN, DMN）。
    - **输出**：一个贝叶斯网络结构（DAG），以及对应的条件概率表参数。
- **关键模块与连接**：
    1.  **骨架识别模块（约束部分）**：采用类似PC算法的策略。从一个全连接的无向图开始，通过逐步进行条件独立性检验（使用卡方检验，显著性水平α=0.01）来移除边。具体地，如果两个变量在给定某个条件集U下独立，则移除它们之间的边。条件集U的大小从0开始逐步增加，直到骨架稳定。
    2.  **边定向与结构优化模块（评分部分）**：这是MPC-HC与传统混合算法（如MMHC）的核心区别。它不是简单地用评分函数（如BIC）对骨架的定向进行局部搜索，而是：
        - 首先，枚举骨架中所有可能的**不道德（V-结构，形如X→Z←Y）**配置。每一种配置定义了一个部分有向无环图（PDAG），其中涉及不道德的边方向被固定。
        - 然后，对每一种PDAG，使用评分函数（BIC）引导的搜索（类似HC算法，但受约束）来定向剩余的边。合法的操作包括：定向未定向的边、删除非固定边、反转非固定边。搜索目标是找到在当前不道德配置下能最大化BIC分数的DAG。
        - 最后，在所有可能的不道德配置产生的最优DAG中，选择BIC分数最高的那个作为最终输出。
- **数学公式与机制的直观解释**：

    - **I-等价类**：核心理论。具有相同骨架和相同不道德集合的DAG是I-等价的，它们具有相同的BIC分数。因此，学习的最终目标是恢复真实网络所属的I-等价类中的一个DAG，而非追求唯一的真实图。MPC-HC通过搜索不道德配置来主动探索不同的等价类代表。
- **训练方式**：对于基准网络验证，使用从已知网络生成的数据。对于真实早产儿数据，使用收集的138名受试者的标准化数据集进行结构学习。通过**Bootstrap（重采样）** 评估结构的置信度和稳定性：多次从变量的概率密度函数中采样，分别学习网络，最终选择拟合最好的网络进行后续分析。
- **推理流程**：学习到网络结构和参数后，可以进行：
    1.  **预测**：给定部分变量观测值，推理其他变量的后验概率。
    2.  **敏感性分析**：改变一个变量的状态，观察其对其他变量概率分布的影响。
- **与已有方法的差异**：
    - 与 **PC** 相比：MPC-HC增加了评分导向的边定向和等价类搜索，减少了因统计检验误差累积导致的结构错误。
    - 与 **HC** 相比：MPC-HC使用基于约束的骨架学习作为起点，并搜索等价类，而非在完全图上从头进行局部搜索，有助于跳出局部最优。
