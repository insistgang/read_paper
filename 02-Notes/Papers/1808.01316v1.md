## 摘要

**英文原文 (清理后)**：
Recent works on adaptive sparse and on low-rank signal modeling have demonstrated their usefulness in various image/video processing applications. Patch-based methods exploit local patch sparsity, whereas other works apply low-rankness of grouped patches to exploit image non-local structures. However, using either approach alone usually limits performance in image reconstruction or recovery applications. In this work, we propose a simultaneous sparsity and low-rank model, dubbed STROLLR, to better represent natural images. In order to fully utilize both the local and non-local image properties, we develop an image restoration framework using a transform learning scheme with joint low-rank regularization. The approach owes some of its computational efficiency and good performance to the use of transform learning for adaptive sparse representation rather than the popular synthesis dictionary learning algorithms, which involve approximation of NP-hard sparse coding and expensive learning steps. We demonstrate the proposed framework in various applications to image denoising, inpainting, and compressed sensing based magnetic resonance imaging. Results show promising performance compared to state-of-the-art competing methods.

**中文翻译**：
近期关于自适应稀疏建模和低秩信号建模的工作，已在各类图像/视频处理应用中证明了其价值。基于图像块的方法利用局部块稀疏性，而另一些工作则利用分组块的低秩性来挖掘图像的非局部结构。然而，单独使用任一方法通常会限制图像重建或恢复任务的性能。本文提出一种同时施加稀疏性与低秩性的模型，命名为 STROLLR，以更好地表示自然图像。为充分利用图像的局部与非局部特性，我们用变换学习方案配合联合低秩正则化，构建了一个图像恢复框架。该方法在计算效率与性能上的优势，部分源于采用变换学习来做自适应稀疏表示，而非流行的合成字典学习算法（后者涉及 NP-hard 稀疏编码的近似求解和昂贵的学习步骤）。我们在图像去噪、修复、以及基于压缩感知的磁共振成像（CS MRI）等多种应用中验证了该框架，结果表明其性能相比于当前先进方法颇具竞争力。

**关键词 (Index Terms)**：Sparse representation, Image denoising, Image inpainting, Image Reconstruction, Block matching, Collaborative filtering, Machine learning.

## 研究背景与动机

- **为什么要做**：图像重建即从一组测量中重建图像。即便相机传感器已大幅进步，低光条件下数字图像仍受严重噪声污染；在现代计算成像中，为降低系统复杂度、采集时间或辐射剂量，常需从不完整/受损的测量中重建高质量图像。这类问题统一写成 `y = Ax + e`（`A` 为传感算子、`e` 为加性噪声），涵盖去噪、去模糊、修复、超分、压缩感知（CS）等。对这类（尤其是病态的）逆问题，有效的正则项是成功的关键。
- **之前方法的问题**：主流方法大多只利用稀疏性**或**非局部结构其中一种。一类基于**稀疏性**（固定变换如 DCT/小波，或数据驱动的字典/变换学习）利用图像块的局部结构；另一类基于**非局部自相似性 / 低秩性**（块匹配分组后做协同滤波或低秩近似）。论文明确指出：据作者所知，此前**还没有任何 2D 图像恢复算法同时联合使用变换学习与低秩近似**。
- **核心矛盾**：如何设计统一模型，同时、高效地利用图像的**局部稀疏性**与**非局部低秩性**这两种互补先验。论文还强调一个效率选择——不用核范数等替代项，而是**直接最小化数据矩阵的秩**，以得到更高效的算法。

## 关键贡献

1.  **提出 STROLLR 模型（Sparsifying TRansfOrm Learning and Low-Rank）**：一个灵活模型，将图像块的自适应变换稀疏性与由块匹配（BM）构成的数据矩阵的低秩性结合，从而同时利用稀疏性和非局部自相似性。
2.  **统一的图像恢复框架**：基于 STROLLR 学习的变分公式（P2），在同一框架内求解多种逆问题，包括图像去噪、修复、CS MRI 等。
3.  **高效的块坐标下降算法**：将求解分解为四步——(i) 低秩近似、(ii) 稀疏编码、(iii) 变换更新、(iv) 图像重建，每一步都有简单且精确的解（SVD + 硬阈值）。在一组测试数据集上评估，相比包括近期深度神经网络方法在内的领先方法展示了有竞争力的性能。
4.  **相对会议版 [9] 的两点扩展**：① 会议版只能处理 patch-wise 传感算子 `A`（去噪、修复），本文推广到 image-wise `A`（如 CS MRI）；② 会议版在 2D 图像块上学习变换，本文（类似 [25] 的扩展）在高度相关的块组（3D 堆叠）上学习 **3D 稀疏变换**，提升恢复性能。
5.  **实验**：在多个标准数据集上做了详尽评估，并与相关竞争方法对比（注：提取缓存截断于第 12 页，定量数值表见原文 Section VI，缓存未覆盖）。

## 方法

**整体框架**：用经典变分公式建模图像恢复——
(P1) `x̂ = argmin_x { ν_F · ‖Ax − y‖₂² + R_strollr(x) }`，
其中 `ν_F · ‖Ax − y‖₂²` 是图像保真项（`y` 为传感算子 `A` 下的测量，`ν_F` 为其权重），`A` 的结构随任务不同（去噪时 `A` 简化，CS MRI 时为欠采样傅里叶算子）；`R_strollr(x)` 是同时施加变换域稀疏与组低秩的正则项。

**STROLLR 正则项（式 1）**：`R_strollr(x) = ν_LR · R_LR(x) + ν_S · R_S(x)`，是非局部组低秩惩罚与稀疏惩罚的加权和，`ν_LR`、`ν_S` 为对应权重。

**低秩项 R_LR（式 2）**：`R_LR(x) = min_{D_i} Σ_i { ‖V_i x − D_i‖_F² + θ² · rank(D_i) }`。其中 `V_i : x ↦ V_i x ∈ C^{n×M}` 是块匹配（BM）算子——以 `R_i x` 为参考块（`R_i` 提取第 i 个 n 像素重叠块），去均值后，在欧氏距离意义下选出最接近参考块的 `M` 个块 `{u_j}_i`，按距离升序填入 `V_i x` 的各列；低秩近似后再加回均值。为避免对大图全局搜索/排序的昂贵代价，实际只在以参考块为中心、`√Q × √Q` 像素的方形搜索窗内评估候选块（假设邻域块空间相似度更高）。注意此处直接用 `rank(·)` 惩罚而非核范数。

**稀疏项 R_S（式 3→式 4→式 5）**：
- 2D 版本（式 3）：`R_S^{2D}(x;W) = min_{α_i} Σ_i { ‖W R_i x − α_i‖₂² + λ² · ‖α_i‖₀ }`，`‖·‖₀` 计非零元素个数。
- 3D 扩展（式 4）：不取 `u_i = R_i x`，而取 `u_i = C_i x ∈ C^{nl}`。算子 `C_i` 先取 BM 矩阵 `V_i x`（首列为 `R_i x`）的前 `l` 列子矩阵，再按列字典序向量化；于是 `R_S(x;W) = min_{α_i} Σ_i { ‖W C_i x − α_i‖₂² + λ² · ‖α_i‖₀ }`。
- 变换学习（式 5）：`R_S(x) = min_W R_S(x;W)  s.t.  W^H W = I_{nl}`。本文把变换限定为**方形且酉**（`m = nl`，`W^H W = I`）。该问题有闭式解，仅需对一个 `nl × nl` 矩阵做 SVD，故学习与恢复都高效。

**联合问题（P2）**：把 (P1) 与 (1)(2)(4)(5) 合并并把最小化提到外层：
`min_{x,W,{α_i},{D_i}} ν_F‖Ax−y‖₂² + ν_S Σ_i{‖W C_i x − α_i‖₂² + λ²‖α_i‖₀} + ν_LR Σ_i{‖V_i x − D_i‖_F² + θ² rank(D_i)}  s.t.  W^H W = I_{nl}`。

**算法 A1（块坐标下降，Fig. 2）**：输入测量 `y`，初始化 `Ŵ_0 = W_0`（如 2D DCT）与 `x̂_0`；对 `t = 1…T` 重复四步：
1. **低秩近似**（对所有 i）：用 BM 形成 `V_i x̂_{t−1}`；对其做完整 SVD `Γ diag(γ) Λ^H = V_i x̂_{t−1}`；更新 `D̂_i = Γ diag(H_θ(γ)) Λ^H`（对奇异值硬阈值）。每轮所用块的索引被更新并保存，供重建步使用。
2. **稀疏编码**：`α̂_i = H_λ(Ŵ_{t−1} R_i x̂_{t−1})`（变换后做硬阈值；3D 版相应用 `C_i`）。
3. **变换更新**：对 `Σ_i (R_i x̂_{t−1}) α̂_i^H` 做完整 SVD 得 `S Σ G^H`，更新 `Ŵ_t = G S^H`（求最优酉变换的闭式解）。
4. **图像重建**：固定上面各量，对具体 `A` 求解关于 `x` 的二次问题（式 9），得 `x̂_t`。

**输入输出**：输入降质/不完整测量 `y` 与传感算子 `A`；输出恢复图像 `x̂_T`。
**训练与推理**：此处“学习”指算法内部对单张待处理图像迭代地学变换 `W`、解稀疏码/低秩近似，是**内部（internal）、无监督**的，不需外部干净训练集；推理即跑 A1 至收敛。
**与已有方法差异**：与 BM3D（协同滤波/低秩为主）、K-SVD（合成字典稀疏为主）不同，STROLLR 在模型层面**显式且联合**地施加稀疏与低秩；与 Yin et al. 的“卷积 framelet”（用行/列空间分别捕局部/非局部，但局部是线性表示、非稀疏）也不同——本文局部用稀疏、非局部用低秩，二者同时施加。

## 局限

1.  **计算成本**：算法虽设计高效，但仍是迭代过程（每轮对每个块做 BM + SVD），对大尺寸图像计算量可能偏大，实时性受限。论文也承认全局块匹配/排序对大图昂贵，故用搜索窗 `√Q × √Q` 近似。
2.  **仅限内部方法**：论文明确把研究范围限定在 internal（仅用噪声图自身）方法，并把与 external/监督方法的结合“留作未来工作”；因此在有大量同分布干净训练数据时，外部/DNN 方法可能更优。
3.  **超参数较多**：含 `ν_LR, ν_S, λ, θ` 等权重/阈值，以及块大小 `n`、匹配块数 `M`、搜索窗 `Q`、3D 列数 `l` 等；其设置与普适推荐值在提取缓存中未充分讨论（待核于实验页）。
4.  **假设依赖**：方法依赖图像具备丰富的自相似块结构与可稀疏的局部结构；对纹理单一或结构特殊的图像，互补先验的收益可能下降。
5.  **复现复杂度**：完整块匹配（搜索窗管理、块索引的更新与存储）和 3D 块操作有一定实现复杂度。

## 个人评论

1.  **互补先验的优雅统一**：把“局部稀疏（变换学习）”与“非局部低秩（块匹配分组）”这两种互补先验统一进一个可优化正则项，是本文最有借鉴价值之处——对设计其他视觉任务的正则器有启发。
2.  **“每步皆可精确求解”的设计哲学**：整个优化被拆成低秩近似、稀疏编码、变换更新、图像重建四个子问题，每个都有 SVD/硬阈值的闭式或精确解。这种把难问题分解为一串可解子问题的思路清晰、易实现、理论上干净。
3.  **变换学习 vs 字典学习**：用酉变换学习取代合成字典学习，把 NP-hard 的稀疏编码换成一次硬阈值，是效率上的关键决策，值得在做稀疏建模时优先考虑。
4.  **无监督内部建模的适用面**：仅靠单张输入图像自适应学模型、不需外部训练集，对遥感、生物医学成像、科学发现等难以获得可靠训练集的领域尤为有用；框架仅通过更换数据保真项里的 `A` 即可适配去噪/修复/CS MRI，通用性强。

## 5. 方法详解
- **变分框架 (P1)**：`x̂ = argmin_x ν_F‖Ax−y‖₂² + R_strollr(x)`，`A` 随任务变化。
- **正则项 (式1)**：`R_strollr = ν_LR R_LR + ν_S R_S`。
- **低秩项 (式2)**：`R_LR = min_{D_i} Σ_i ‖V_i x − D_i‖_F² + θ² rank(D_i)`；`V_i` 为块匹配算子，以去均值参考块为中心、在 `√Q×√Q` 搜索窗内按欧氏距离选 `M` 个相似块按升序成列；用 SVD + 奇异值硬阈值得低秩近似。
- **稀疏项 (式3/4/5)**：2D 版 `min_{α_i} Σ_i ‖W R_i x − α_i‖₂² + λ²‖α_i‖₀`；3D 版把 `R_i x` 换成 `C_i x`（取 BM 矩阵前 `l` 列向量化）；变换 `W` 限定方形酉矩阵（`W^H W=I`），可由一次 `nl×nl` 矩阵 SVD 闭式求解。
- **联合问题 (P2)**：把保真项、稀疏项、低秩项合并联合最小化，约束 `W^H W=I`。
- **算法 A1（块坐标下降，Fig. 2）**：初始化 `W_0`=2D DCT；每轮 ① 对各块 BM→SVD→奇异值硬阈值得 `D̂_i`；② `α̂_i = H_λ(W R_i x)`；③ 用 `Σ_i (R_i x) α̂_i^H` 的 SVD 闭式更新酉变换 `Ŵ_t=G S^H`；④ 固定其余量、对具体 `A` 解二次问题（式9）更新图像。
- **性质**：internal + 无监督，仅用单张输入图；效率来自“精确稀疏编码（硬阈值）”与“小矩阵 SVD”，避开合成字典学习的 NP-hard 近似。

## 8. 局限与问题
1. 迭代 + 逐块 BM/SVD，对大图计算量偏大，实时性受限（故用搜索窗近似全局匹配）。
2. 范围限于 internal 方法，未结合 external/监督方法（留作未来工作）；数据充足时 DNN 可能更优。
3. 超参较多（`ν_LR, ν_S, λ, θ`、块大小、匹配数 `M`、窗口 `Q`、3D 列数 `l`），普适设置在缓存覆盖范围内未充分讨论（待核）。
4. 依赖图像具备自相似 + 可稀疏结构，纹理单一/结构特殊图像收益可能下降。
5. 完整块匹配（索引更新存储）与 3D 块操作实现复杂度较高。
