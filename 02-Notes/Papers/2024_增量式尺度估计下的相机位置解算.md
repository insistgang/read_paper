## 研究背景与动机

- **为什么要做**：全局式SfM通过运动平均一次性恢复所有相机位姿，效率高于增量式SfM，但其核心步骤之一的**平移平均**面临三大难题：1）从本质矩阵分解得到的相对平移仅有方向信息，存在**尺度歧义性**；2）相对平移估计对特征误匹配敏感，**易受异常值影响**；3）位置解算的约束比旋转解算更严格，仅限于**平行刚性分量**内的相机可被唯一解算。
- **之前方法的问题**：传统的基于鲁棒优化（如BATA、LUD）或输入增强（如1DSfM、CReTA）的方法虽有一定效果，但流程复杂或对输入质量依赖高。一种基于尺度分离的方法（L1SE-L1TA）通过先解算基线长度来消除尺度歧义，但鲁棒性仍有提升空间。另一种增量式平移平均方法（ITA）具有良好的鲁棒性，但其求解依赖相机三元组，在相机共线运动时可能退化。
- **核心矛盾**：如何在**消除平移平均的尺度歧义性**的同时，**提升求解过程的鲁棒性**，并且保持解算流程的**简洁与高效**，且不因相机运动形式（如共线运动）而受限。
## 关键贡献

1.  **提出ISE-L1TA框架**：首次将**增量式参数估计思想**与**尺度分离策略**同时引入平移平均流程，设计了增量式尺度求解器（ISE）来解算局部和全局绝对尺度，有效滤除尺度异常值。
2.  **设计归一化完全平方差函数**：提出了一种用于计算尺度误差的距离函数 `dR+(xi, xj) = (xi - xj)^2 / (xi * xj)`，该函数能够**有效消除尺度缩放效应**对误差计算的影响，提升了尺度估计的稳定性。
3.  **提出基线精度评测方法**：设计了一种**基于中值标量对齐**的相对基线长度评测方案，用于评估不同尺度解算方法的准确性。
## 方法

- **整体框架**：如图1所示，方法输入为成对的SIFT特征匹配点，输出为相机的绝对位置。流程分为四个主要阶段：相对运动估计、两视图重建、增量式尺度估计、L1优化位置解算。
- **输入输出**：输入是图像间的SIFT特征匹配点。输出是所有相机在世界坐标系下的绝对位置 `ci`。
- **关键模块与连接**：
    1.  **相对运动估计**：通过估计并分解本质矩阵，获得每对相机间的相对旋转 `Rj` 和单位化相对平移 `tij`。
    2.  **两视图重建与深度比计算**：对存在共视点的相机三元组 `(i, j, k)` 进行两视图三角化，得到特征点在相机 `i` 坐标系下的深度 `dij_m` 和 `dik_m`。通过计算中值深度比 `d^i_jk = med({dij_m / dik_m})` 来估计局部相对深度。
    3.  **增量式尺度估计（ISE）**：这是核心模块。它将式（1）和式（3）所描述的局部与全局尺度求解问题统一为 `c = a/b` 的形式，并设计了通用的增量求解器。
        - **尺度分离**：根据深度比 `d^i_jk` 和局部尺度 `s^i_ij`、`s^i_ik` 的关系 `s^i_ik / s^i_ij = d^i_jk`（式1），以及全局相对尺度 `s_ij = s^j_ji / s^i_ij`（式2）与全局绝对尺度 `s_i, s_j` 的关系 `s_i / s_j = s_ij`（式3），将问题分解。
        - **增量求解**：该模块包含三个关键步骤：**a) 初始三元组选择**：在尺度解算图中选择累计匹配点最多的前1000个三元组，通过局部优化为每个三元组求解初始尺度，并选择加权支持度最高的作为初始种子。**b) 基于加权支持集的下一最优视图（NBV）选择**：已求解顶点 `Ve_s` 中的每个顶点为未求解顶点 `vu_s` 预计算一个尺度值，根据该预计算值与其他已解算邻居的一致性（选择奖励 `R^i_j`）选择下一个加入 `Ve_s` 的顶点 `vj*`。**c) 加权局部/全局优化和重优化**：每添加一个NBV，进行一次局部优化；当已解算顶点增长超过30%时，触发全局优化和重优化。优化过程使用`Ceres`求解器最小化`dR+`定义的误差。
        - **异常值滤除**：在优化过程中，只有当尺度误差 `dR+(x^P_ij, fs(x^P_i, x^P_j)) < th^P_s` 时，该约束才被当作内点加入求解。这实现了在估计尺度的同时滤除异常值。
    4.  **尺度已知的绝对位置解算**：利用计算得到的相对基线长度 `bij = 1/2 (s_i * s^i_ij + s_j * s^j_ji)`（式4）和对齐到全局坐标系的相对平移 `cij = -R^T_j tij`，构建线性超定方程组 `Ac * xc = bc`（式19），并通过**L1范数优化**求解绝对位置 `ci`。
- **与已有方法的差异**：
    - 相较于**L1SE-L1TA**：本文引入了增量式估计，能在估计尺度时主动滤除异常值，提升了鲁棒性。
    - 相较于**ITA**：本文通过尺度分离先解算基线长度，摆脱了对相机三元组的依赖，避免了在共线运动下的性能退化。
    - 本文的**尺度距离函数** `dR+` 相比直接差值或比值差值，具有尺度不变性，实验也验证了其优越性。

## 局限
