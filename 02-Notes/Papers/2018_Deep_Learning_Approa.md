## 研究背景与动机

- **为什么要做**：建筑物检测在城市规划、非法建筑监控、通信基站选址等应用中至关重要。现有方法如现场测绘耗时耗力，而自动化的深度学习方法存在提升精度的空间。
- **之前方法的问题**：论文提及，尽管已有深度学习方法用于遥感对象检测（如参考文献[2], [3], [9]），但在准确恢复建筑物轮廓、处理小目标以及利用多光谱信息方面仍有改进余地。此外，直接应用经典网络（如U-Net）可能无法最优地处理卫星图像特性。
- **核心矛盾**：如何在复杂的大气条件、低分辨率及多光谱特性下，**准确、自动化地从卫星图像中检测出建筑物轮廓**，特别是对于大小不一、形状各异的建筑。
## 关键贡献

1.  **提出了一种集成建模（Ensemble Modelling）策略**用于建筑物轮廓检测，结合了三个子模型：v1（使用选定多光谱波段）、v2（将原始图像切片以保留细节）、v3（融合OpenStreetMap建筑和道路图层作为额外输入）。
2.  **采用2-Sigma百分位归一化**进行数据预处理，以减少各波段噪声。
3.  **应用二值距离变换（BDT）** 来改进建筑物轮廓的标签标注过程，以更好地处理小建筑。
4.  **修改了U-Net网络**：在每一层的激活函数前添加**批归一化（Batch Normalization）** 层，并将优化器从SGD更换为**ADAM**以提高训练稳定性和最终精度。
## 方法

- **整体框架**：如图1所示，流程分为四个阶段：**预处理、图像准备、模型训练、建筑轮廓预测**。
- **输入与输出**：
    - **输入**：SpaceNet数据集提供的8波段多光谱图像（MUL-PanSharpen）及RGB-PanSharpen图像。
    - **输出**：与输入图像对应、以Well-Known Text (WKT) 格式表示的建筑物轮廓多边形坐标。
- **关键模块与连接**：
    1.  **预处理**：对整个数据集计算各波段的均值和标准差，将像素值裁剪在±2σ（对应2.28%和97.72%百分位数）范围内，然后进行最大-最小归一化。
    2.  **图像准备与集成模型**：
        - **模型v1**：输入为原始650x650图像中选取的5个特定波段（Coastal, Yellow, Red, Red Edge, Near-IR1）与RGB共8个通道。标签通过在原始分辨率下绘制建筑多边形并应用**BDT**生成（正/负距离），最后缩放至256x256。
        - **模型v2**：为减少缩放信息损失，将原始650x650图像**切分为9个256x256的子图**作为输入，使用全部多光谱波段。
        - **模型v3**：在模型v2的基础上，**额外融合来自OpenStreetMap的建筑和道路图层**作为输入通道，旨在锐化标签并减少误检。
    3.  **网络结构（修改的U-Net）**：采用U-Net作为基础分割网络。关键修改是在网络每一层的卷积输出与激活函数（如ReLU）之间插入**批归一化层**。优化器从SGD改为**ADAM**。
    4.  **预测与后处理**：将三个模型对同一原始图像的预测结果（v2和v3需要将子图拼接回原始尺寸）进行**平均**，得到最终预测。对预测出的多边形进行合并，并过滤掉面积小于阈值`minArea`的过小区域。
- **数学公式与机制解释**：
    - **归一化公式**：见公式(1)，对每个通道独立进行最大-最小归一化。
    - **损失/精度度量**：训练中使用**Jaccard指数（交并比）** 评估模型，见公式(2)。最终评估使用**IoU**（公式(3)）判定检测是否为真阳性（≥0.5），并用**F1分数**（公式(4)）综合评估精确率和召回率。

- **与已有方法的差异**：本文不采用目标检测框架（如R-CNN），而是直接进行语义分割。其特色在于**集成多源信息（多波段、图像切片、OSM辅助数据）** 以及**针对卫星图像和建筑物特性的U-Net改进与数据预处理流程**。
