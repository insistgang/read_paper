## 摘要

**英文原摘要（据 PDF 提取文本整理，已修复断词与空格）：**

> In recent years, the highly dynamic and covert nature of network attacks has posed significant threats to Internet security and stability. This paper developed a network anomaly traffic detection method based on bidirectional temporal sliding window Transformer to address the insufficient accuracy of local temporal modeling and poor minority class recognition in multi-classification tasks of existing network intrusion detection methods. The method transformed network traffic data into three-dimensional sequential data that highlighted temporal relationships. It introduced learnable embedding encoding and contextual position encoding to enhance the representation capability of sequential features. These improvements enhanced the accuracy and stability of anomaly traffic detection. Validation was performed on UNSW-NB15 and CIC-IDS-2017 public datasets. Experimental results showed that the proposed method achieved 99.79% and 99.77% detection accuracy in binary classification tasks and 98.48% and 99.76% in multi-classification tasks, outperforming other advanced deep learning models. Therefore, the proposed method enhances the accuracy of network anomaly traffic detection and the recognition capability for minority class attacks. It provides a new technical approach for network security protection.

## 研究背景与动机

- **为什么要做**：互联网业务日益复杂多样，流量类型增多，其中隐藏着高度变异、隐蔽的网络威胁（渗透、僵尸网络、模糊测试攻击、远程控制等），且常以高级持续性威胁（APT）为技术背景，通过复合攻击与动态变形手段威胁网络安全。传统入侵检测以特征匹配（仅能识别已知攻击）与异常检测（依赖正常行为建模，误报率偏高）为主，面对未知威胁与复杂攻击模式时明显不足。
- **之前方法的问题**：
    1.  **机器学习方法**（决策树、朴素贝叶斯、SVM、随机森林、ECO-ELM 等）：虽提升了检测效率并能识别部分未知攻击，但对复杂攻击模式建模能力有限，难以捕捉高维非线性特征，高度依赖特征工程、自动化程度低，对新型/变异攻击泛化能力弱。
    2.  **深度学习方法**（RNN、分层 CNN-RNN、HCRNN、CNN-LSTM 等）：在时序建模上优于机器学习（如 CNN-LSTM 在 UNSW-NB15 上二分类 97.1%、多分类 98.43%），但仍有共性局限：
        - 时序特征建模多采用**单向滑动窗口或独立流量特征输入**，仅基于单向历史数据，无法同时捕获流量在时间维度上的双向动态演变规律。
        - 研究多以**二分类**（正常/异常）为主，多分类场景常采用攻击类别合并策略，粗粒度分类导致低频攻击特征易被主导类别淹没，难以实现细粒度分类；模型对数据不平衡敏感。
        - 对流间上下文的建模能力仍有待提升。
    3.  **基于 Transformer 的方法**（如基于 BERT 改进的 NIDS[10]、IDS-INT[11]、RTIDS[12]）已为该领域提供新视角，但在局部时序建模上仍以单向历史建模为主，面对 APT 时常出现漏检率偏高、类别混淆等问题。
- **核心矛盾**：如何设计一种能同时充分利用流量双向时序上下文信息、并在多类别（特别是少数类攻击）场景下提升检测精度与稳定性的入侵检测模型。

## 关键贡献

1.  **三维数据序列生成方法**：提出基于双向时间滑动窗口的三维数据序列生成方法，突出相邻流量分组之间的局部时间序列关系，以提升模型检测精度。

3.  **新的网络入侵检测模型**：设计了基于双向时间滑动窗口的 **Encoder-only Transformer** 架构，通过优化改进的 Transformer 利用三维数据序列深入挖掘流量在时间窗口内的序列特征，增强模型识别异常的能力。
4.  **公开数据集验证**：在 UNSW-NB15、CIC-IDS-2017 上验证，二分类检测准确率分别为 99.79%、99.77%；多分类准确率分别达 98.48%、99.76%，效果显著。

## 方法

- **整体框架（图1）**：a) 数据预处理（数据清洗、字符编码、数据归一化、数据类平衡）→ b) 基于时间的双向滑动窗口处理，生成三维序列数据 → c) 划分训练/验证/测试集 → d) 嵌入操作后输入带上下文位置编码的 Encoder 训练，最后经全连接层与 softmax 完成二分类和多分类。
- **输入输出**：输入为经预处理（清洗、编码、归一化、类别平衡）的网络流量特征序列；输出为二分类（正常/异常）或多分类（具体攻击类型）标签。
- **关键模块**：
    1.  **双向滑动窗口（1.1，图2）**：传统前向滑动窗口仅利用当前时刻之前的历史流量，难以建模具有前后依赖特征的攻击（如 APT）。本文以当前中心窗口为基准，分别向前、向后滑动指定步长 `r`，构建包含左窗口、中心窗口、右窗口的局部时序上下文结构。设窗口大小 `windows_size=w`、完整数据流长度 `S`，则存在 `m = S − w + 1` 个互不重叠的中心窗口（式1）；以这 m 个窗口为中心双向滑动步长 `r` 获取左右窗口，首尾组超出序列处用 0 填充以保持窗口长度，形成 N 组三维数据窗口 `Nm = {NmL, NmC, NmR}`（式2、3）。实验确定 **`w=16, r=1`** 为较优组合（见 2.4.3）。
    2.  **可学习动态嵌入 CLS_TOKEN（1.2，图3）**：在输入序列开头添加可学习参数 CLS_TOKEN，作为整个序列的代表。与固定嵌入不同，它在端到端训练中通过反向传播不断更新，特征表达能力自适应不同类型流量序列，用于聚合整个序列的全局代表性特征，提升对复杂攻击模式的识别。
    3.  **Encoder-only Transformer（1.3，图4–5）**：针对网络流量高维、固定特征长度、非线性分布以及 RNN 的梯度消失/并行效率低问题，采用仅含编码器的结构。流量先经 embedding 层转为数值向量，再送入含 CoPE 的 Encoder；Encoder 通过层归一化（LayerNorm）将每个张量特征维度归一化到均值为 0、方差为 1，保证训练稳定与收敛。核心为多头自注意力（Multi-head Self-Attention）：输入经三个线性变换得到 h 组 Q/K/V 并行送入注意力汇聚模块，输出拼接后再经线性投影产生最终输出。
    4.  **基于上下文位置编码（CoPE）的自注意力机制（1.4，图6）**：核心创新。传统正弦/余弦位置编码无法按输入内容动态调整位置权重，而攻击行为时序特征往往动态变化。CoPE 工作流程为：
        - **门值计算（式4）**：`g_ij = σ(q_i · k_j)`，当前 token 查询向量 q 与先前 token 键向量 k 点积后经 sigmoid 激活得到门值 g，决定哪些 token 对当前位置信息有显著影响。
        - **累积求和（式5）**：`p_ij = Σ_{k=j..i} g_ik`，对门值累积求和量化每个 token 相对于当前 token 的位置关系。
        - **位置插值（式6）**：位置值 p 可为非整数，对最接近整数值的嵌入向量做（双线性）插值得到位置嵌入 e(p)。
        - **注意力计算（式7）**：`a_ij = Softmax(q_i · (k_j + e(p_ij)))`，将位置嵌入注入注意力分数后经 softmax 归一化，得到上下文感知的增强型注意力权重。
        - **包含 CoPE 的自注意力模块（1.4.2）**采用三阶段流程：线性变换生成 Q/K/V 并计算 Q·K 点积得未归一化基础注意力分数 sim → 将 Q 与 sim 输入 CoPE 单元，通过门控生成累积位置坐标并对可学习位置嵌入表双线性插值，输出连续可微的位置编码偏差 → 将偏差注入原始注意力分数，softmax 归一化后与 V 相乘，生成上下文感知的增强注意力权重。
- **和已有方法的差异**：与固定正弦/余弦位置编码的传统 Transformer 不同，CoPE 可按输入内容动态调整位置信息权重；与单向滑动窗口相比，双向窗口能同步利用前后上下文，更全面捕捉攻击行为的时序演变规律。

1.  **场景依赖**：方法效果高度依赖数据集本身的时间序列特性；对时间相关性不强或高度无序的攻击流量，双向时序窗口优势可能无法充分发挥。（论文未直接论述，据方法原理推断）
2.  **计算成本未充分讨论**：论文测试了推理性能，但未详细讨论训练阶段计算开销；双向滑动窗口与 CoPE 机制可能增加训练复杂度。（推断）
3.  **数据集局限**：仅在 UNSW-NB15、CIC-IDS-2017 两个公开数据集验证，与真实、动态变化的网络环境仍有差距，更复杂/噪声更大场景下的泛化能力有待验证。

# 论文精读

## 1. 论文定位
本文属于网络安全领域的入侵检测（NIDS）方向，发表于《计算机应用研究》（第43卷第1期，网络首发 2025-09-19）。它解决基于深度学习的入侵检测方法两个共性问题：（1）局部时序建模多采用单向滑动窗口或独立流量输入，无法同时捕获流量在时间维度上的双向动态演变；（2）多分类场景常合并攻击类别，导致低频/少数类攻击被主导类别淹没、细粒度分类困难。适合归于 `T_安全_入侵检测` 主题，子领域为 "用 Transformer 处理网络流量时序数据做异常检测"。

## 2. 一句话总结
提出一种基于双向时间滑动窗口 + 上下文位置编码（CoPE）的 Encoder-only Transformer 入侵检测模型：把流量重构为含前后上下文的三维时序序列，并用 CoPE 增强位置语义感知，在 UNSW-NB15、CIC-IDS-2017 上提升对复杂、隐蔽攻击（尤其多分类少数类）的检测精度与稳定性。

## 3. 背景与问题
- **为什么要做**：网络业务复杂化、流量多样化，威胁高度变异且隐蔽（渗透、僵尸网络、模糊测试、远控等，常以 APT 为背景）。传统特征匹配仅识别已知攻击，异常检测误报率高，面对未知/复杂攻击不足。
- **之前方法的问题**：
    1.  **机器学习**（决策树、朴素贝叶斯、SVM、随机森林、ECO-ELM）：依赖特征工程、自动化低，难捕捉高维非线性特征，对变异攻击泛化弱。
    2.  **深度学习**（RNN、CNN-RNN、HCRNN、CNN-LSTM，后者 UNSW-NB15 二分类 97.1%/多分类 98.43%）：时序建模多为单向滑动窗口，仅用历史数据；多分类常合并类别、对低频攻击识别弱；对数据不平衡敏感；流间上下文建模待提升。
    3.  **Transformer 类**（BERT-NIDS[10]、IDS-INT[11]、RTIDS[12]）：提供新视角但仍以单向历史建模为主，面对 APT 易漏检、类别混淆。
- **核心矛盾**：如何同时利用双向时序上下文、并在多类别（尤其少数类）下提升检测精度与稳定性。

## 4. 核心贡献
1.  **三维数据序列生成**：基于双向时间滑动窗口，将预处理后的流量转为突出相邻流量分组局部时序关系的三维序列，提升检测精度。
2.  **引入 CoPE**：上下文位置编码融合位置与上下文信息，相较正弦/余弦编码更高效灵活，帮助模型理解序列结构与语义。
3.  **Encoder-only Transformer 模型**：基于双向滑动窗口的仅编码器架构，利用三维序列与 CoPE 自注意力挖掘时间窗口内序列特征。
4.  **公开数据集验证**：UNSW-NB15、CIC-IDS-2017 上二分类 99.79%/99.77%、多分类 98.48%/99.76%，显著优于先进深度学习模型。

## 5. 方法详解
- **整体框架（图1）**：预处理（清洗/字符编码/归一化/类平衡）→ 双向滑动窗口生成三维序列 → 70/20/10 划分 → 嵌入（含 CLS_TOKEN）→ 含 CoPE 的 Encoder-only Transformer → 全连接层 + softmax 做二/多分类。
- **双向滑动窗口（1.1）**：以中心窗口为基准向前/后滑步长 r，构建左/中/右窗口；`m = S − w + 1` 个互不重叠中心窗口（式1），双向滑动得 N 组三维窗口 `Nm={NmL,NmC,NmR}`（式2、3），首尾超界处 0 填充。实验定 **w=16, r=1**。
- **CLS_TOKEN（1.2）**：序列首部可学习参数，端到端反向传播更新，自适应聚合序列全局代表性特征，增强复杂攻击模式识别。
- **Encoder-only Transformer（1.3）**：替代存在梯度消失/并行低效的 RNN；embedding→含 CoPE 的 Encoder，LayerNorm 将特征维归一化到均值0方差1 保稳定；多头自注意力 h 组 Q/K/V 并行汇聚后拼接投影。
- **CoPE 自注意力（1.4）**：
    - 门值 `g_ij = σ(q_i·k_j)`（式4）——决定哪些 token 影响当前位置。
    - 累积求和 `p_ij = Σ_{k=j..i} g_ik`（式5）——量化相对位置（可非整数）。
    - 插值 `e(p_ij)`（式6）——对最近整数嵌入做双线性插值。
    - 注意力 `a_ij = Softmax(q_i·(k_j + e(p_ij)))`（式7）——位置偏差注入后归一化。
    - 模块三阶段（1.4.2）：Q·K 得 sim → CoPE 单元生成累积位置坐标并插值出可微位置偏差 → 注入 sim、softmax 后乘 V 得增强注意力。
- **差异**：CoPE 按内容动态调权（vs 固定正弦/余弦）；双向窗口同步用前后上下文（vs 单向窗口）。
