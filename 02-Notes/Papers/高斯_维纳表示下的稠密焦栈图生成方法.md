## 研究背景与动机

- **为什么做**：焦栈图像在计算摄影、显微成像、沉浸式媒体等领域有重要应用，例如用于合成全景深图像和恢复场景三维结构。然而，这些应用通常需要稠密的焦栈序列作为基础。直接通过相机拍摄稠密焦栈对硬件（如快速对焦、高分辨率）和拍摄环境（物体运动、手动操作）要求很高，而通过光场重聚焦获取则面临设备昂贵、分辨率低等问题。
- **之前方法的问题**：
    1.  **直接拍摄法**：对相机性能和拍摄专业性要求高，受环境干扰大。
    2.  **光场重聚焦法**：依赖光场相机或相机阵列，设备成本高、体积大，且受限于传感器，重聚焦后的图像分辨率较低。
    3.  **基于深度图或卷积核估计的方法**：例如基于深度图的方法在纹理少的区域效果不佳且计算慢；基于卷积核的方法（如广义高斯核、基于空间坐标的方法）在处理局部区域复杂变化或噪声较高时效果受限，且部分方法未充分利用序列间的相关性。
- **核心矛盾**：**应用对稠密焦栈图像的高需求**与**现有获取方式在成本、质量、效率上的限制**之间的矛盾。作者旨在找到一种计算生成的方法，直接从稀疏焦栈“插值”出稠密的中间图像，绕过硬件限制。
## 关键贡献

1.  **提出了一个基于高斯-维纳表示的双向预测模型框架**：该框架将焦栈图像的清晰度变化抽象为高斯卷积（模拟散焦）和维纳反卷积（模拟聚焦）过程。
2.  **设计了双向拟合模块**：通过将相邻焦距的图像块组成“块对”，并让它们轮流作为参考块和当前块，利用高斯-维纳表示进行拟合，从而找到描述两者之间清晰度变化的最佳参数（模式与高斯标准差σ）。
3.  **设计了预测生成模块**：基于双向拟合模块输出的最佳参数，通过对σ取半的方式推导出用于生成中间焦距图像块的预测参数。
4.  **引入了基于块的处理策略**：对图像进行分块并组合成块对，使得算法能够针对图像不同区域的特性进行自适应预测，提升了方法的灵活性和准确性。
5.  **通过双向预测充分利用邻近信息**：正向和反向两个方向的拟合增加了可利用的信息量，有助于找到更优的拟合参数，从而生成更接近真值的图像。
6.  **在11个稀疏焦栈数据集上验证了方法的有效性**：实验结果表明，所提方法在客观指标（PSNR, SSIM）和主观视觉质量上均显著优于对比方法。
## 方法

- **整体框架**：如图1所示，框架主要包含三部分：1）**图像分块与块对划分**；2）**双向预测模型**（核心）；3）**新焦栈图的拼接**。整体思路是“分而治之”，将整张图的预测问题转化为对每个局部图像块对的预测问题。
- **输入与输出**：
    - **输入**：一组稀疏的焦栈图像序列，按焦距编号（如0, 2, 4, ..., 20）。
    - **输出**：新生成的、位于中间焦距（如1, 3, 5, ..., 19）的焦栈图像，它们与输入图像共同组成稠密的焦栈序列。
- **关键模块详解**：
    1.  **图像分块和块对划分**：
        - 对每张输入图像按固定大小（实验确定为64×64）分块。若尺寸不能整除，则进行边缘镜像填充。
        - 将**相邻焦距**编号（如0和2）的两幅图像中**空间位置相同**（相同x, y坐标）的两个块组合成一个“块对”。块对是进行双向预测的最小单元。
    2.  **双向预测模型**：这是方法的核心，建立在**高斯-维纳表示**之上。
        - **高斯-维纳表示基础**：该表示用**高斯卷积**模拟图像块的“散焦”（变模糊）过程，用**维纳反卷积**模拟图像块的“聚焦”（变清晰）过程。其物理依据是光学系统的点扩散函数(PSF)可用高斯函数近似。
        - **双向拟合模块**：
            - 对每个块对，进行两次“单向拟合”。在一次单向拟合中，一个块被指定为**参考块(R)**，另一个为**当前块(I)**。
            - 分别用三种模式尝试将R变换为I：
                - **复制模式**：直接复制R，代价函数为 $J_1(σ)= \frac{1}{M \times N} \| I - C(R, σ) \|_2^2$。
                - **高斯模式**（当R更清晰时）：对R进行高斯卷积，搜索最佳σ，代价为 $J_2(σ)= \min_{σ∈[l_1, l_2]} \frac{1}{M \times N} \| I - G(R, σ) \|_2^2$。
                - **维纳模式**（当R更模糊时）：对R进行维纳反卷积，搜索最佳σ，代价为 $J_3(σ)= \min_{σ∈[l_1, l_2]} \frac{1}{M \times N} \| I - W(R, σ) \|_2^2$。
            - 选择三种模式中代价最小的那个，得到本次单向拟合的最佳参数（模式m, σ）。
            - 进行第二次单向拟合，互换R和I的角色。
            - 最后，从两次单向拟合的结果中，选择**代价更小**的那次作为**最佳双向拟合参数** `opt(b, m, σ)`。其中b是该次拟合的参考块。
        - **预测生成模块**：
            - 输入：最佳双向拟合参数 `(m, σ)` 及其对应的参考块 `b`。
            - 目标：预测一个位于R和I中间焦距的新图像块。
            - **关键预测公式**：`m_pred = m`, `σ_pred = σ / 2`。即使用与拟合相同的模式，但将高斯卷积或维纳反卷积的标准差参数减半。直观理解是，如果σ是描述从R到I整个变化过程的参数，那么σ/2描述的则是从R到“中间状态”的半程变化。
            - 根据 `m_pred` 的绝对值决定使用复制、高斯卷积还是维纳反卷积操作，将 `σ_pred` 作用于参考块 `b`，生成新的预测块。
    3.  **拼接新焦栈图**：将所有预测生成的新块，按照它们的焦距编号和空间坐标(x, y)进行拼接，形成新的焦栈图像。最终，将新生成的图像与原始稀疏图像按焦距顺序排列，得到稠密焦栈序列。
- **训练方式**：本文方法基于参数优化和公式推导，**未涉及神经网络的训练过程**。其“学习”体现在对每个块对进行迭代搜索以找到最佳拟合参数σ。
- **推理流程**：推理即执行上述整体框架流程：输入稀疏焦栈序列 -> 分块、组块对 -> 对每个块对执行双向拟合 -> 根据拟合参数执行预测 -> 拼接所有新块 -> 输出稠密序列。
- **与已有方法的差异**：
    1.  **与广义高斯核方法(Liu等,2021)**：后者主要使用单参数高斯模型，未引入维纳反卷积来处理聚焦（清晰化）过程，因此在需要恢复清晰的场景下表现较差。
    2.  **与空间坐标方法(Fu等,2023)**：后者基于三维空间坐标变化建模，在简化为单方向后，可能无法精确捕捉局部区域的复杂变化，容易产生伪影和块效应。
    3.  **核心差异**：本文方法同时引入了**高斯卷积和维纳反卷积**两种互补的操作，并采用**双向拟合**策略，更全面地建模了图像块在焦距域上的变化，从而提升了预测的准确性和鲁棒性。
## 实验

- **数据集**：使用Wu等人(2020)的11组焦栈图像数据集。每个序列包含21幅图像，分辨率为512×512至1024×768不等。实验时，抽取偶数编号(0,2,...,20)图像作为稀疏输入，抽取奇数编号(1,3,...,19)图像作为真值(Ground Truth)。
- **对比方法**：
    1.  **广义高斯核方法** (Liu等, 2021)
    2.  **空间坐标方法** (Fu等, 2023)
- **评价指标**：
    1.  **峰值信噪比 (PSNR)**：值越高越好。
    2.  **结构相似性 (SSIM)**：值越接近1越好。
- **主实验结果**：
    - **定量结果**：本文方法在所有11个序列上平均PSNR达到**40.861 dB**，平均SSIM达到**0.976**。
    - **对比提升**：相较于“广义高斯”和“空间坐标”两种对比方法，PSNR分别提升了**6.503 dB**和**6.467 dB**；SSIM分别提升了**0.057**和**0.092**。在单个序列上，PSNR和SSIM的最少提升分别为**3.474 dB**和**0.012**。
    - **定性结果**：如图8所示，对比方法中，广义高斯结果存在模糊，空间坐标结果存在明显伪影和块效应。本文方法的结果在视觉上更接近真值，细节保留更好。
- **消融实验**：
    1.  **双向拟合 vs 单向拟合**：实验结果（图9）表明，完整的双向拟合（本文方法）在所有序列上的PSNR和SSIM均优于仅使用正向或反向单向拟合的变体，验证了双向预测的必要性。统计显示，正向预测和反向预测的使用比例约为57.5% vs 42.5%，说明两者都很重要。
    2.  **最小损失策略验证**：在序列I01上的实验（图6）证明，选择拟合代价最小的模式进行预测生成，能够得到PSNR和SSIM最高的结果。
- **泛化/延伸实验**：
    1.  **焦距间隔测试**：在I01, I05, I11序列上，测试了不同输入焦距间隔（从2到20）对生成质量的影响。结果（图10）显示，随着间隔增大，PSNR和SSIM总体下降。当间隔超过12时，PSNR低于36 dB。建议间隔在12或以内可获得较好效果。
    2.  **光场重聚焦数据测试**：额外在3组由光场重聚焦得到的焦栈序列上进行了实验，生成结果与真值（光场重聚焦结果）的PSNR均在37 dB以上，SSIM均在0.9以上，显示了方法在不同来源数据上的适用性。

    3.  **基于深度图或卷积核估计的方法**：例如基于深度图的方法在纹理少的区域效果不佳且计算慢；基于卷积核的方法（如广义高斯核、基于空间坐标的方法）在处理局部区域复杂变化或噪声较高时效果受限，且部分方法未充分利用序列间的相关性。
- **核心矛盾**：**应用对稠密焦栈图像的高需求**与**现有获取方式在成本、质量、效率上的限制**之间的矛盾。作者旨在找到一种计算生成的方法，直接从稀疏焦栈“插值”出稠密的中间图像，绕过硬件限制。

## 4. 核心贡献
1.  **提出了一个基于高斯-维纳表示的双向预测模型框架**：该框架将焦栈图像的清晰度变化抽象为高斯卷积（模拟散焦）和维纳反卷积（模拟聚焦）过程。
2.  **设计了双向拟合模块**：通过将相邻焦距的图像块组成“块对”，并让它们轮流作为参考块和当前块，利用高斯-维纳表示进行拟合，从而找到描述两者之间清晰度变化的最佳参数（模式与高斯标准差σ）。
3.  **设计了预测生成模块**：基于双向拟合模块输出的最佳参数，通过对σ取半的方式推导出用于生成中间焦距图像块的预测参数。
4.  **引入了基于块的处理策略**：对图像进行分块并组合成块对，使得算法能够针对图像不同区域的特性进行自适应预测，提升了方法的灵活性和准确性。
5.  **通过双向预测充分利用邻近信息**：正向和反向两个方向的拟合增加了可利用的信息量，有助于找到更优的拟合参数，从而生成更接近真值的图像。
6.  **在11个稀疏焦栈数据集上验证了方法的有效性**：实验结果表明，所提方法在客观指标（PSNR, SSIM）和主观视觉质量上均显著优于对比方法。

## 5. 方法详解
- **整体框架**：如图1所示，框架主要包含三部分：1）**图像分块与块对划分**；2）**双向预测模型**（核心）；3）**新焦栈图的拼接**。整体思路是“分而治之”，将整张图的预测问题转化为对每个局部图像块对的预测问题。
- **输入与输出**：
    - **输入**：一组稀疏的焦栈图像序列，按焦距编号（如0, 2, 4, ..., 20）。
    - **输出**：新生成的、位于中间焦距（如1, 3, 5, ..., 19）的焦栈图像，它们与输入图像共同组成稠密的焦栈序列。
- **关键模块详解**：
    1.  **图像分块和块对划分**：
        - 对每张输入图像按固定大小（实验确定为64×64）分块。若尺寸不能整除，则进行边缘镜像填充。
        - 将**相邻焦距**编号（如0和2）的两幅图像中**空间位置相同**（相同x, y坐标）的两个块组合成一个“块对”。块对是进行双向预测的最小单元。
    2.  **双向预测模型**：这是方法的核心，建立在**高斯-维纳表示**之上。
        - **高斯-维纳表示基础**：该表示用**高斯卷积**模拟图像块的“散焦”（变模糊）过程，用**维纳反卷积**模拟图像块的“聚焦”（变清晰）过程。其物理依据是光学系统的点扩散函数(PSF)可用高斯函数近似。
        - **双向拟合模块**：
            - 对每个块对，进行两次“单向拟合”。在一次单向拟合中，一个块被指定为**参考块(R)**，另一个为**当前块(I)**。
            - 分别用三种模式尝试将R变换为I：
                - **复制模式**：直接复制R，代价函数为 $J_1(σ)= \frac{1}{M \times N} \| I - C(R, σ) \|_2^2$。
                - **高斯模式**（当R更清晰时）：对R进行高斯卷积，搜索最佳σ，代价为 $J_2(σ)= \min_{σ∈[l_1, l_2]} \frac{1}{M \times N} \| I - G(R, σ) \|_2^2$。
                - **维纳模式**（当R更模糊时）：对R进行维纳反卷积，搜索最佳σ，代价为 $J_3(σ)= \min_{σ∈[l_1, l_2]} \frac{1}{M \times N} \| I - W(R, σ) \|_2^2$。
            - 选择三种模式中代价最小的那个，得到本次单向拟合的最佳参数（模式m, σ）。
            - 进行第二次单向拟合，互换R和I的角色。
            - 最后，从两次单向拟合的结果中，选择**代价更小**的那次作为**最佳双向拟合参数** `opt(b, m, σ)`。其中b是该次拟合的参考块。
        - **预测生成模块**：
            - 输入：最佳双向拟合参数 `(m, σ)` 及其对应的参考块 `b`。
            - 目标：预测一个位于R和I中间焦距的新图像块。
            - **关键预测公式**：`m_pred = m`, `σ_pred = σ / 2`。即使用与拟合相同的模式，但将高斯卷积或维纳反卷积的标准差参数减半。直观理解是，如果σ是描述从R到I整个变化过程的参数，那么σ/2描述的则是从R到“中间状态”的半程变化。
            - 根据 `m_pred` 的绝对值决定使用复制、高斯卷积还是维纳反卷积操作，将 `σ_pred` 作用于参考块 `b`，生成新的预测块。
    3.  **拼接新焦栈图**：将所有预测生成的新块，按照它们的焦距编号和空间坐标(x, y)进行拼接，形成新的焦栈图像。最终，将新生成的图像与原始稀疏图像按焦距顺序排列，得到稠密焦栈序列。
- **训练方式**：本文方法基于参数优化和公式推导，**未涉及神经网络的训练过程**。其“学习”体现在对每个块对进行迭代搜索以找到最佳拟合参数σ。
- **推理流程**：推理即执行上述整体框架流程：输入稀疏焦栈序列 -> 分块、组块对 -> 对每个块对执行双向拟合 -> 根据拟合参数执行预测 -> 拼接所有新块 -> 输出稠密序列。
- **与已有方法的差异**：
    1.  **与广义高斯核方法(Liu等,2021)**：后者主要使用单参数高斯模型，未引入维纳反卷积来处理聚焦（清晰化）过程，因此在需要恢复清晰的场景下表现较差。
    2.  **与空间坐标方法(Fu等,2023)**：后者基于三维空间坐标变化建模，在简化为单方向后，可能无法精确捕捉局部区域的复杂变化，容易产生伪影和块效应。
    3.  **核心差异**：本文方法同时引入了**高斯卷积和维纳反卷积**两种互补的操作，并采用**双向拟合**策略，更全面地建模了图像块在焦距域上的变化，从而提升了预测的准确性和鲁棒性。
