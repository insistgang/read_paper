## 摘要

**英文原摘要（据 PDF 提取文本整理，已修复断词与杂入字符）**：

> Change Detection (CD) is a vital monitoring method in Earth observation, especially pertinent for land-use analysis, city management, and disaster damage assessment. However, in the era of constellation interconnection and air-sky collaboration, the changes in the Regions Of Interest (ROI) cause many false detections due to geometric perspective rotation and temporal style difference. In response to these challenges, we introduce CDNeXt, this framework elucidates a robust and efficient method for combining Siamese networks based on the pre-trained backbone with the innovative Temporospatial Interactive Attention Module (TIAM) for remote sensing imagery. The CDNeXt can be categorized into four primary components: Encoder, Interactor, Decoder, and Detector. Notably, the Interactor, powered by TIAM, queries and rebuilds spatial perspective dependencies and temporal style correlations from binary temporal features extracted by the Encoder to enlarge the difference of ROI change. Culminating the process, the Detector integrates the hierarchical features generated by the Decoder, subsequently producing a binary change mask. We have achieved new State-Of-The-Art (SOTA) performance in change detection, with our method surpassing existing techniques on four benchmark datasets: an F1 score of 82.63% on SYSU-CD, 87.14% on LEVIR-CD+, 66.71% on S2Looking, and 71.11% on BANDON. To further validate the effectiveness of the TIAM, we compared it to other attention modules in both interactive and non-interactive modes.

## 研究背景与动机

- **为什么要做**：变化检测的本质是对相邻双时相遥感影像分割并比较其纹理与语义相似性——相似即“未变化”，不相似即“变化”（p.1）。传统基于光谱像素比较和面向对象分析的方法对传感器、观测目标、视角有严苛要求，需要大量预处理（几何校正、辐射校正、空间对齐、云阴影去除）（p.1）。深度学习兴起后，以预训练分类网络作为骨干、嵌入孪生网络结构成为 CD 主流策略（p.1）。
- **核心难点**：在“星座互联与天地协同”时代，同一区域影像间存在**立体视角旋转**和**时相风格差异**两类干扰。视角旋转使同一建筑屋顶与立面区域产生空间错位与语义差异（图1第一行）；时相风格差异源于不同时间的光照、天气、季节变化，会产生与真实变化无关的“伪变化”（pseudo-changes），如沙尘暴中部分可见的建筑被算法误检（图1最后一行）。即使直方图分布在视角/光照变化下仍相似，天气与季节也会导致 RGB 分布完全不同（p.2）。
- **之前方法的问题**：主流方法通过构造特定数据集模拟风格/视角、改进 CD 框架、改进特征注意力机制来增强变化表达；但**现有注意力机制在对双时相拼接特征建模时，常忽略当前时相内特征固有的自相似性（intra-temporal self-similarity）对视角与风格问题的影响**（p.2）。早期特征交互方法也忽略了时空维度的整合（p.2-3）。
- **核心矛盾**：如何在单一计算过程中，同时抑制空间视角旋转和时相风格差异带来的干扰，并放大真实变化特征。

## 关键贡献

1.  **提出 CDNeXt 框架**：一个面向遥感影像、为 TIAM 量身定制的新型变化检测范式，采用 Encoder / Interactor / Decoder / Detector 四层架构，使预训练骨干网络与创新的 TIAM 协同工作（p.2-3，贡献条 1）。
2.  **提出时空间交互注意力模块（TIAM）**：一种易于嵌入的注意力机制，在**单一计算过程**中同时应对几何视角旋转与时相风格差异——查询并重建“空间视角依赖”与“时相风格相关性”（p.3，贡献条 2）。
3.  **在四个公开数据集上取得 SOTA**：SYSU-CD、LEVIR-CD+、S2Looking、BANDON，F1 分别为 82.63% / 87.14% / 66.71% / 71.11%，**超越九篇不同论文的方法**，在鲁棒性和误检抑制上表现优越；代码已开源（p.2 摘要 / p.3 贡献条 3）。框架强调无需特殊训练技巧或超参数微调，可端到端输出（p.2）。

## 方法

**整体框架**：CDNeXt 是端到端孪生网络，输入为同一地区配对双时相影像 {T_A, T_B} ∈ R^{C×H×W}，输出二值变化掩码 Mask，即 Mask = CDNeXt(T_A, T_B)（式1，p.3）。框架由四个模块串接（图2）：

1.  **编码器（Encoder）**：基于预训练 **ConvNeXt (CNX)**、权重共享的孪生层次化结构，自顶向下下采样提取四级特征 {F_1, F_2, F_3, F_4}（式2，p.3-4）。每级含一个下采样层与多个 CNX 基础块：下采样倍率 n ∈ {4, 2, 2, 2}，下采样为 LN(Conv^{(n,n)})（式8）；CNX 块为 `Conv(GELU(Conv(LN(Conv^{(7)}(F))))) ⊕ F`，即 7×7 Conv → LN → 1×1 Conv → GELU → 1×1 Conv 加残差，两个 1×1 Conv 先把通道扩 4 倍再恢复（式9）；每个 stage 内 CNX 块迭代次数 M ∈ {3, 3, 9, 3}（式10）。激活函数用 GELU（p.4）。
2.  **交互器（Interactor）= TIAM**：对同层级双时相特征对 F_A^l 与 F_B^l 处理，查询并重建“空间视角依赖”与“时相风格差异”，输出 {F̂_A^l, F̂_B^l}（式3，p.3-4）。
    - **理论基础**：在两个时相特征间构建 **Gram 矩阵**，查询时间与空间的注意力分数——分别对应空间视角依赖 S2 与时相风格相关性 S1（p.4）。
    - **Q/K/V 构造**（式11）：先把特征从 R^{C×H×W} 重塑为 R^{C×HW}，再经 Batch Norm 与 1×1 卷积（此顺序避免骨干网络梯度爆炸）：V_i = Conv1(BN(F_t))，Q_i = Conv1_i(BN_i(F_t))，K_i = Q_i^T；其中 V_1、V_2 共享参数，Q_1、Q_2 不共享，(i,t) ∈ {(1,A),(2,B)}。
    - **注意力分数**（式12，嵌入高斯函数）：S_i = Softmax(Q_i ⊗ K_j^T)，(i,j) ∈ {(1,2),(2,1)}。**S1 = 当前时相每个通道与另一时相每个通道的相似度（时相风格相关性）**；**S2 = 当前时相每个空间位置与另一时相每个空间位置的相似度（空间视角依赖）**（p.4-5）。
    - **加权重建**（式13）：Z1 = S1^T ⊗ V_k ⊗ S2，Z2 = S1 ⊗ V_k ⊗ S2^T（依不同 Z_k，{S1,S2} 之一作转置）。
    - **残差恢复**（式14）：F̂_t = BN(Conv1(Z_k)) ⊕ F_t，(k,t) ∈ {(1,A),(2,B)}，与输入做逐元素残差和以利于训练。
    - **与主流注意力的对比**（式15-18）：作者把传统注意力抽象为三类——SAM(自注意力)=Q⊗K^T⊗V；DAM(双重注意力)=Q⊗K^T⊗V + Q^T⊗K⊗V；CAM(交叉注意力)=Q_i⊗K_j^T⊗V_i。**TIAM = (Q_i⊗K_j^T) ⊗ V_i ⊗ (Q_i^T⊗K_j)**，即**同时用跨时相相关项 (Q_i⊗K_j^T) 与其转置项 (Q_i^T⊗K_j) 从两侧夹乘 V_i**，是专为 CD 视角/风格问题设计的新型注意力（p.5）。
3.  **解码器（Decoder）= FSR 块**：接收交互器输出 {F̂_A^l, F̂_B^l}，与上一级解码器输出 F_D^{l+1} 的插值特征拼接（式4），经特征压缩残差块（Feature Squeeze Residual, FSR）压缩特征维度、提取变化残差，并与交互器建立跳跃连接以增强梯度传播（p.5）。FSR 由 FSRSqueeze 与 FSRResidual 构成，二者均基于 FSRBase = GELU(BN(Conv))（式19-20）：FSRSqueeze 用 1×1 Conv 压缩通道（式21）；FSRResidual 依次用 3×3 与 1×1 Conv 并加残差（式22）。
4.  **检测器（Detector）**：把解码器各级特征 {F̃_1,…,F̃_4} 插值到输入尺寸后做两次 FSR（式23 / 式19），最后 1×1 Conv 接 Softmax（在每个空间位置）输出二值变化掩码 Mask（式24，p.5）。

**直观解释**：真实变化应在不同视角下保持语义不变（由 S2 空间视角依赖建模，减少误检）；而背景与未变化区域在不同时相间的风格距离应被刻画并抑制（由 S1 时相风格相关性建模，减少不变特征/背景造成的差异）（p.4）。

**训练方式**：用交叉熵（Cross-Entropy, CE）损失对每个像素的预测 ŷ_n 与标签 y_n 优化，θ* = argmin_θ CE(CDNeXt(T_A,T_B,θ), Label)（式6-7，p.4）。

**注意力类特化**：
- **作用维度**：同时作用于**空间维度**（S2 建模空间位置间视角依赖）与**通道维度**（S1 建模通道间风格相关性）。
- **可插入性**：TIAM 被设计为可嵌入“任何需要表达两个特征间相似性的视觉任务”（p.4）。
- **计算特点**：核心由矩阵乘法（Gram 矩阵、Softmax 注意力）构成，结构清晰；作者在交互/非交互两种模式下与其他注意力对比验证其有效性（具体数值见提取截断后的实验节，本缓存未覆盖）。

## 3. 背景与问题

- **之前方法的问题**：现有方法靠构造数据集、改框架、改注意力来增强变化表达，但**对双时相拼接特征建模时，普遍忽略当前时相内特征的自相似性（intra-temporal self-similarity）对视角/风格的影响**；早期特征交互也忽略时空维度整合（p.2-3）。
- **核心矛盾**：如何在单次计算中同时抑制视角旋转与时相风格干扰、放大真实变化。

## 4. 核心贡献
1.  **CDNeXt 框架**：面向遥感、为 TIAM 定制的四层架构（Encoder/Interactor/Decoder/Detector），让预训练骨干与 TIAM 协同，端到端无需特殊训练技巧（p.2，贡献条1）。
2.  **TIAM 模块**：易嵌入的注意力，在单一计算过程中查询并重建空间视角依赖与时相风格相关性，应对几何旋转与风格差异（p.3，贡献条2）。
3.  **四数据集 SOTA**：SYSU-CD 82.63%、LEVIR-CD+ 87.14%、S2Looking 66.71%、BANDON 71.11%（F1），超越九篇论文方法，误检显著减少，代码开源（p.2-3，贡献条3）。

## 5. 方法详解
**整体框架**（图2，式1-5）：输入配对影像 {T_A,T_B} ∈ R^{C×H×W}，Mask = CDNeXt(T_A,T_B)。四模块：
- **Encoder**（式2，3.2节）：权重共享孪生 **ConvNeXt** 骨干，提四级特征 {F_1..F_4}。下采样倍率 n∈{4,2,2,2}，式8 为 LN(Conv^{(n,n)})；CNX 块（式9）= 7×7 Conv→LN→1×1 Conv→GELU→1×1 Conv ⊕ 残差，两个 1×1 Conv 先扩 4 倍通道再恢复；各 stage 迭代 M∈{3,3,9,3} 次（式10）；激活用 GELU。
- **Interactor = TIAM**（3.3节，式11-14）：对同层 F_A^l、F_B^l 输出 {F̂_A^l,F̂_B^l}。Gram 矩阵查询时空注意力分数。Q/K/V（式11）：重塑 R^{C×H×W}→R^{C×HW} 后 BN+1×1 Conv，V_i=Conv1(BN(F_t))，Q_i=Conv1_i(BN_i(F_t))，K_i=Q_i^T；V_1/V_2 共享参数、Q_1/Q_2 不共享。注意力（式12，嵌入高斯）：S_i=Softmax(Q_i⊗K_j^T)；**S1=通道间相似度=时相风格相关性，S2=空间位置间相似度=空间视角依赖**。重建（式13）：Z1=S1^T⊗V_k⊗S2，Z2=S1⊗V_k⊗S2^T。残差恢复（式14）：F̂_t=BN(Conv1(Z_k))⊕F_t。
- **Decoder = FSR 块**（式4、19-22）：拼接交互器输出与上级解码插值特征，FSRSqueeze（1×1 Conv 压通道）+ FSRResidual（3×3 后 1×1 Conv 加残差），基元 FSRBase=GELU(BN(Conv))，并与交互器跳跃连接增强梯度。
- **Detector**（式23-24）：各级 {F̃_1..F̃_4} 插值到输入尺寸做两次 FSR，最后 1×1 Conv + Softmax（每空间位置）输出二值 Mask。

**TIAM vs 主流注意力**（式15-18）：SAM=Q⊗K^T⊗V；DAM=Q⊗K^T⊗V+Q^T⊗K⊗V；CAM=Q_i⊗K_j^T⊗V_i；**TIAM=(Q_i⊗K_j^T)⊗V_i⊗(Q_i^T⊗K_j)**——用跨时相项与其转置项**双侧夹乘** V_i，是专为 CD 视角/风格设计的新算子。

**直观解释**：真实变化跨视角语义不变（S2 建模）；背景/未变化区域跨时相风格距离应被刻画并抑制（S1 建模），从而放大变化、压制伪变化（p.4）。

**训练**：逐像素交叉熵损失（式6-7）。
