> Deep convolutional neural networks perform better on images containing spatially invariant noise (synthetic noise); however, their performance is limited on real-noisy photographs and requires multiple stage network modeling. ## 研究背景与动机

- **为什么做**：图像去噪是底层视觉的关键任务。其重要性体现在三方面：(1) 图像采集时噪声不可避免地降低视觉质量，去噪是众多 CV 与图像分析应用的关键步骤；(2) 从贝叶斯视角看，去噪是评估图像先验和优化方法的独特试验场；(3) 许多图像复原任务可通过变量分裂（variable splitting）的展开式推断拆解为一系列去噪子任务，这进一步拓宽了去噪的适用范围。
- **之前方法的问题**：
    1. 基于模型的方法（NSS 非局部自相似、稀疏、梯度法、MRF、外部先验）计算昂贵、耗时，无法直接抑制空间变化噪声，也难以刻画复杂图像纹理；外部去噪先验还是类别特定（class-specific）的。
    2. 基于学习的判别式 CNN（DnCNN、IrCNN 等）虽提升了性能，但被裁剪/定制到特定噪声水平；它们盲预测噪声残差，不考虑图像的底层结构与纹理。
    3. 处理真实噪声通常是**两步流程**（先噪声估计、再非盲去噪），如 NC、FFDNet（需手动选高噪声水平）、CBDNet（两个子网 + 多重损失 + 手动干预）。现有单盲模型在真实照片上的效果不令人满意。
    4. 传统做法把权重层连续级联，单纯加深网络并不能提升性能，还可能引发梯度消失。
- **核心矛盾**：一个实用的去噪算法应当高效、灵活，用**单一模型**同时处理空间变化与空间不变噪声（噪声标准差已知或未知）。当前 SOTA 远未同时达成这些目标。

## 关键贡献

1.  **首个单阶段真实去噪模型**：现有真实图像去噪方法都采用两阶段模型；本文提出首个仅用单阶段就达到 SOTA 的模型 (RIDNet)。
2.  **首次引入特征注意力**：据作者所知，这是第一个在去噪中引入特征注意力（feature attention）的模型，自适应地重新校准通道特征的重要性。
3.  **模块化、可加深网络**：多数模型把权重层连续相连，加深不利于性能且易梯度消失；本文提出模块化网络（残差上的残差），增加模块数量可提升性能。
4.  **全面实验**：在三个合成数据集和四个真实噪声数据集上，与 19 种 SOTA 算法做定量与定性对比，证明优越性。

## 方法

- **整体框架**：网络由三个主模块组成——特征提取、特征学习（残差上的残差模块 Mfl）、图像重建。见 Figure 2。
- **输入输出**：输入含噪图像 `x`，输出去噪图像 `ŷ`。通过把输入图像经长跳跃连接加回网络输出，让网络学习的是**噪声残差**而非去噪图像；论文指出因噪声的稀疏表示，学习残差比学习原图收敛更快。
- **关键模块**：
    1.  **特征提取模块 (Me)**：单个卷积层，从 `x` 提取初始特征 `f0 = Me(x)`（公式 1）。
    2.  **特征学习模块 (Mfl)**：`fr = Mfl(f0)`（公式 2），由级联的**增强注意力模块 (EAM, Enhancement Attention Module)** 组成，是网络核心。每个 EAM 包含 D 个块后接特征注意力。EAM 内部按"覆盖全感受野 → 学习特征 → 压缩特征 → 特征注意力增强"四步组织：
        - **Merge-and-run 单元**（EAM 第一部分，覆盖全感受野）：输入特征分两支，分别经**不同扩张率的扩张卷积**，再拼接并经另一卷积。网络深度小，但靠 EAM 初始两支的核扩张获得宽感受野。
        - **残差块 (RB)**：两个卷积，用于学习特征。
        - **增强残差块 (ERB)**：三个卷积层，最后一层用 1×1 核"压扁"特征以压缩、加速。
        - **特征注意力模块 (FA)**：对最后卷积层输出做通道维度重新校准（见下）。
        - EAM 末端：特征注意力单元的输出加回 EAM 的输入（**短跳跃连接 SSC**）。
    3.  **重建模块 (Mr)**：单个卷积层，将特征映射回与输入通道数一致的图像。
- **残差上的残差与多重跳跃连接（信息流）**：
    - 第 m 个 EAM：`fm = EAM_m(fm-1)`，且每个 EAM 输出加回其输入 `fm = fm + fm-1`（公式 5，局部连接 LC / 短跳跃）。
    - 论文观察到仅级联残差模块不能取得更好性能；于是把特征提取器的输入加到堆叠模块的最终输出：`fg = f0 + Mfl(W_w,b)`（公式 6）——此即**长跳跃连接 (LSC)**，缓解组间信息流动。
    - `fg` 送入重建层；再用**另一条长跳跃连接**把输入图像加到网络输出：`ŷ = Mr(fg) + x`，使网络学习噪声残差。
    - 动机来自图像超分中的 EDSR（堆叠残差块 + LSC）与 ResNet（千层残差网络），以及参考 [66] 的残差上残差思路；作者指出此前深网络尚未在去噪中被研究。
- **特征注意力机制 (FA)**（公式 7–9，Figure 3）：
    - **动机**：以往去噪方法对各通道特征"一视同仁"，不合理。图像可分为低频区（平滑/平坦）与高频区（线、边缘、纹理）；卷积只用局部信息、无法利用全局上下文。
    - **全局平均池化**（公式 7）：把最后卷积层 c 个 h×w 特征图压成 1×1×c 的描述子 `gp`，表征整图统计。
    - **自门控（self-gating）机制**（公式 8）：参考 [34]（SE 风格），用 `rc = σ(HU(δ(HD(gp))))`，其中 HD 为通道降采样（缩减比因子 16，使中间只有 4 个特征图）、HU 为通道升采样；δ 为 **soft-shrinkage**（软阈值）激活、σ 为 **sigmoid** 激活。
    - **逐通道缩放**（公式 9）：`f̂c = rc · fc`，把注意力权重逐通道乘回原特征图。
- **实现细节 (3.3)**：
    - **4 个 EAM 模块**。卷积核默认 3×3（用零填充保持尺寸），唯 ERB 最后一层与特征注意力单元用 1×1。
    - 通道数固定 64；特征注意力下采样按因子 16 缩减，故中间仅 4 个特征图。
    - 最终卷积层依输入输出 3 或 1 个特征图（彩色/灰度）。
    - 运行时间：处理一张 512×512 图像约 **0.2 秒**。
- **训练 (4.1)**：
    - **损失**：只用 L1 损失，`L(W) = (1/N) Σ ||RIDNet(xi) − yi||₁`（公式 4），区别于 CBDNet 等的多重损失。
    - **优化器**：Adam，默认参数。
    - **学习率**：初始 1e-4，1e5 次迭代后减半。
    - **批/patch**：每批取 32 个 patch，输入尺寸 80×80。
    - **数据增强**：随机旋转 90°/180°/270° 与水平翻转。
    - **框架/硬件**：PyTorch，单张 Nvidia Tesla V100 GPU。
- **与已有方法差异**：端到端单阶段（vs CBDNet 两子网 + 手动干预）；首次用特征注意力利用通道依赖；用残差上的残差 + 多类型跳跃连接（LSC/SSC/LC）使深网络在去噪中可行。

## 实验

- **数据集**：
    - **训练（合成噪声）**：BSD500、DIV2K、MIT-Adobe FiveK，共约 4k 图。
    - **训练（真实噪声）**：SSID、Poly、RENOIR 的 512×512 裁剪 patch。
    - **测试（合成）**：Set12（12 张经典图）、BSD68（灰度/彩色 68 图），加性白高斯噪声 σ=15, 25, 50。
    - **测试（真实）**：RNI15（15 张，无干净图，仅定性）、Nam（11 个静态场景，每场景由 500 张同景噪声图取均值得无噪图；裁 512×512 并随机选 110 patch 测试）、DND（原 50 对，裁成 1000 个 512×512 patch，结果仅可经在线系统获取 PSNR/SSIM）、SSID（Smartphone Image Denoising Dataset；公开 320 训练 + 1280 验证对，用验证集测试）。
- **对比方法（19 种）**：传统方法 CBM3D、WNNM、EPLL、CSF；CNN 方法 MLP、TNRD、DnCNN、IrCNN、CNLNet、FFDNet、CBDNet、DenoiseNet 等。
- **评价指标**：主用 PSNR；DND/SSID 部分经在线系统得 SSIM。
- **主实验结果**：
    - **灰度合成 (BSD68, Table 2)**：σ=15/25/50 时 RIDNet PSNR = **31.81 / 29.34 / 26.40 dB**，三档均最优（如 σ=25：DnCNN 29.23、FFDNet 29.23；σ=50：FFDNet 26.29）。
    - **Set12 (12 张经典图, Table 3)**：σ=15/25/50 时 RIDNet = **32.91 / 30.60 / 27.43 dB**，均为最优（如 σ=50：DnCNN 27.18、FFDNet 27.32）。
    - **彩色合成 (CBSD68, Table 4)**：论文称 RIDNet 在 CBSD68 上一致超过所有对比方法，并给出最佳感知质量（Figure 4，σ=50 的可视化中 RIDNet 32.84 dB 高于 DnCNN 32.33、IRCNN 32.21、BM3D 31.68）。（具体 Table 4 完整数字位于原文后续，提取缓存在 4.3.3 后截断，**待核**。）
    - **真实噪声 (4.3.4 起)**：论文在四个真实数据集上声称取得 SOTA 定量与定性结果，但 **4.3.4 "Real-World noise" 节及之后被提取缓存截断**，四个真实数据集的具体 PSNR/SSIM 表格未覆盖，**待核**。
- **消融实验 (Table 1, BSD68, 2×10⁵ 次迭代)**：
    - **跳跃连接 + 特征注意力**：表中 PSNR 从 28.45 到 28.96 dB 渐升；同时启用 LSC + SSC + LC + FA 时最高 **28.96 dB**；缺任一连接性能下降。无跳跃连接时单纯加深网络无益。
    - **特征注意力**：开启 FA（最高 28.96 dB）相对不开 FA（28.45 dB）约提升 0.5 dB，支撑 FA 有效性的论点。
- **效率信息**：512×512 图像约 0.2 秒（见实现细节）。

## 个人评论

1.  **工程化、可扩展的模块设计**：EAM 以"残差上的残差"为骨架，可通过堆叠模块稳定提升性能，为其它底层视觉网络（超分、去模糊）提供了可复用的结构范式。
2.  **注意力机制向低层视觉的迁移**：把图像分类中成熟的 SE 式通道注意力（自门控）首次引入去噪，并以消融（+0.5 dB）证实有效；值得注意的是其门控用了 soft-shrinkage（软阈值）而非常见的 ReLU，与"抑制小幅噪声值"的去噪先验天然契合，这是相对 SE 的一个去噪定制化细节。
3.  **单阶段范式的价值**：相对 CBDNet 等两阶段 + 多损失 + 手动干预，RIDNet 用单阶段、单 L1 损失、端到端就超过两阶段方法，简化了真实去噪流程，体现了"把先验设计内化进网络结构"的思路。
4.  **可改进处**：仅用 L1 损失、固定 4 个 EAM 与缩减因子 16 都是经验设定；若补充参数量/FLOPs 与更系统的模块数 vs 性能曲线，论文对"加模块即提性能"的论点会更有说服力。

# 论文精读

## 1. 论文定位
本文属于计算机视觉的**底层视觉**任务，方向是**真实图像去噪 / 图像复原**（标题即 "Real Image Denoising with Feature Attention"）。它解决一个实际问题：如何用一个高效的**单阶段**深度模型处理真实照片中复杂、未知的噪声（含空间变化与空间不变噪声），而无需两阶段（噪声估计 + 非盲去噪）建模或手动干预。核心主题是"真实/盲去噪"与"特征注意力"。归类应放在"图像复原（超分/去噪/去雨去雾）"主题下。

## 2. 一句话总结
RIDNet 是一个端到端、单阶段的盲真实图像去噪网络，用"残差上的残差"模块化结构（4 个 EAM）缓解低频信息流动，并首次在去噪中引入"特征注意力"利用通道依赖，在三个合成数据集与四个真实噪声数据集、对 19 种 SOTA 的对比中取得最优。

## 3. 背景与问题
- **为什么做**：去噪是底层视觉关键任务——采集噪声不可避免、是评估图像先验的贝叶斯试验场、且许多复原任务可经变量分裂展开为去噪子任务。
- **之前方法的问题**：(1) 基于模型方法（NSS/稀疏/MRF/外部先验）昂贵、无法直接抑制空间变化噪声、外部先验类别特定；(2) 判别式 CNN（DnCNN/IrCNN）被裁剪到特定噪声水平、盲预测噪声而忽略图像结构纹理；(3) 真实去噪多为两步流程（NC、FFDNet 需手选高噪声、CBDNet 两子网 + 多损失 + 手动干预），单盲模型在真实照片上不理想；(4) 连续级联权重层单纯加深不利且易梯度消失。
- **核心矛盾**：用单一、高效、灵活的模型同时处理空间变化/不变、已知/未知噪声标准差——当前 SOTA 未能同时满足。

## 4. 核心贡献
1.  **首个单阶段真实去噪模型**（vs 现有两阶段）。
2.  **首次在去噪中引入特征注意力**，自适应重校准通道特征重要性。
3.  **模块化网络**：残差上的残差使深网络可行，增加模块数可提性能（缓解了"加深无益 + 梯度消失"）。
4.  **三合成 + 四真实数据集、对 19 种 SOTA** 的定量定性验证。

## 5. 方法详解
- **三模块框架**：特征提取 Me（1 个卷积，`f0=Me(x)`）→ 特征学习 Mfl（4 个级联 EAM，`fr=Mfl(f0)`）→ 重建 Mr（1 个卷积）。
- **EAM 内部（四步）**：① Merge-and-run 单元——输入分两支经不同扩张率的扩张卷积，拼接后再卷积（小深度获宽感受野）；② 残差块 RB（2 卷积）学习特征；③ 增强残差块 ERB（3 卷积，末层 1×1）压缩加速；④ 特征注意力 FA 重校准；末端用短跳跃 SSC 把 FA 输出加回 EAM 输入。
- **残差上的残差 + 多跳跃连接**：每个 EAM 输出加回其输入（公式 5，LC/SSC）；把 f0 加到堆叠模块最终输出 `fg=f0+Mfl(·)`（公式 6，LSC）；再把输入图像加到网络输出 `ŷ=Mr(fg)+x`，使网络学噪声残差（因噪声稀疏表示而收敛更快）。动机源自 EDSR/ResNet/[66]。
- **特征注意力 (公式 7–9, SE 风格)**：全局平均池化把 c 个 h×w 图压成 1×1×c 描述子 gp（公式 7）；自门控 `rc=σ(HU(δ(HD(gp))))`（公式 8），HD/HU 为通道降/升采样（缩减因子 16）、δ=soft-shrinkage、σ=sigmoid；逐通道缩放 `f̂c=rc·fc`（公式 9）。
- **实现**：4 EAM；核默认 3×3（ERB 末层与 FA 单元用 1×1）；通道 64，FA 下采样按因子 16（中间 4 个图）；末层输出 3 或 1 通道；0.2 秒/512×512。
- **训练**：仅 L1 损失（公式 4）；Adam 默认参数；学习率 1e-4，1e5 迭代后减半；每批 32 个 80×80 patch；增强用旋转 90/180/270° + 水平翻转；PyTorch + Tesla V100。

## 7. 这篇论文真正有价值的地方
1.  **可堆叠的模块化骨架（EAM/残差上的残差）**：把"加深有效"从经验变为结构性保障，对其它底层视觉网络有迁移价值。
