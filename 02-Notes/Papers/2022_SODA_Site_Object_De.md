## 研究背景与动机

- **为什么要做**: 建筑行业的自动化监控与安全管理亟需深度学习技术，但该领域缺乏大规模、开源的专用数据集，限制了依赖数据的深度学习算法的发展和实际应用。(p.1, p.2)
- **之前方法的问题**:
    1.  通用图像数据集（如ImageNet, COCO）缺乏建筑工地特有的类别。(p.4)
    2.  现有的建筑行业数据集（如MOCS, ACID, CHV）普遍规模较小、类别较少，且主要集中在工人和部分机械上，缺乏对建筑材料和场地布局等要素的覆盖。(p.2, p.5)
    3.  建筑工地图像获取困难（因安全原因不公开）、在线资源有限且重复、拍摄视角单一易导致模型过拟合、标注难度和成本高。(p.2)
- **核心矛盾**: 建筑工地对智能化、自动化监控的迫切需求与可用的大规模、高质量、多要素数据集极度匮乏之间的矛盾。

## 关键贡献

1.  **构建了首个大规模建筑工地目标检测数据集 SODA**：该数据集包含19，846张图像和286，201个标注对象，覆盖15个具体类别。(p.1, p.12)
2.  **首次实现四要素全面覆盖**：SODA是首个同时检测建筑工地中**工人、材料、机械和布局**四大关键要素的开源数据集。(p.20)
3.  **提供了系统化的数据集构建方法论**：详细记录了从类别选择、多源数据采集（无人机、手持相机、监控）、严格的数据清洗到标准化标注的完整流程及经验。(p.6-12)
4.  **建立了检测性能基准**：在YOLO v3和YOLO v4两个经典单阶段检测器上进行了实验，获得了基准性能数据，验证了数据集的可行性和挑战性。(p.15-19)

## 方法

- **论文类型与整体框架**: 本文的核心是**数据集构建**，而非提出新的检测模型。其整体框架遵循一个标准的数据集构建流程：类别定义 -> 数据采集 -> 数据清洗 -> 人工标注。(p.6, Fig. 2)

    - **输出**: 符合VOC格式的XML标注文件，包含图像信息及每个目标的边界框（BBox）和类别标签。(p.11, p.12)
- **关键模块**:
    1.  **类别选择与定义**：将建筑工地要素系统化为工人、材料、机器、布局四大类，并细分为15个具体检测类别（如工人、安全帽、钢筋、挖掘机、基坑等）。(p.6, Table 1, Table 2)
    2.  **数据采集与清洗**：
        - 从多个建筑工地采集了超过20，000张原始图像。(p.8, p.9)
        - 数据清洗旨在去除重复、模糊、不含目标的图像，并对人脸、公司LOGO等隐私信息进行模糊处理。此过程花费约300小时，占总构建时间的25%。(p.9, p.10)
    3.  **人工标注**：
        - 由35名经培训的土木工程专业学生使用LabelImg工具进行标注。(p.11, p.12)
