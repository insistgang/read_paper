## 研究背景与动机

- **为什么要做**：特征融合（如InceptionNet中的拼接、ResNet中的相加、FPN中的跨层连接）是现代CNN的基石，但通常使用简单固定的加法或拼接操作，无法根据输入内容自适应地调整融合策略。
- **之前方法的问题**：现有的基于注意力的方法（如SKNet、ResNeSt）存在三个主要缺点：1) **场景局限**：仅适用于同一层内的特征选择，无法统一处理跨层的短连接和长连接融合。2) **初始集成粗糙**：在生成注意力权重前，需要对输入特征进行一次初始融合（如直接相加），这个粗糙的初始集成本身会成为性能瓶颈。3) **上下文聚合尺度单一**：依赖于全局平均池化来生成通道注意力权重，这偏向于强调大物体，可能忽略图像中重要的小物体细节。
- **核心矛盾**：如何设计一个**统一、通用**的融合机制，使其能够同时处理不同场景（同层、短跳连、长跳连）下的特征融合，并解决特征间**语义不一致和尺度不一致**的问题。
## 关键贡献

1.  **提出了统一的注意力特征融合（AFF）框架**：将多种特征融合场景（同层融合、短跳连、长跳连）统一为一个通过多尺度通道注意力（MS-CAM）生成动态权重的软选择过程。
2.  **设计了多尺度通道注意力模块（MS-CAM）**：首次在通道注意力中引入多尺度概念，通过结合全局上下文（全局平均池化）和局部上下文（逐点卷积）来生成注意力权重，以更好地处理不同尺度的物体。
3.  **提出了迭代注意力特征融合（iAFF）**：通过迭代地应用AFF模块来优化特征融合前的“初始集成”过程，缓解初始集成粗糙的问题。
4.  **实验验证了通用性和有效性**：在InceptionNet、ResNet和FPN三种典型架构上集成AFF/iAFF，在CIFAR-100、ImageNet和StopSign数据集上取得了优于原始网络和其它融合策略的性能。
## 方法

- **整体框架**：AFF的核心是将两个输入特征图X和Y通过一个注意力模块M进行自适应融合。输出融合特征Z。MS-CAM是生成注意力权重M的关键模块。
- **输入输出**：
    - **输入**：两个具有相同空间尺寸和通道数的特征图X, Y ∈ ℝ^{C×H×W}。论文默认Y具有更大的感受野。
    - **输出**：融合后的特征图Z ∈ ℝ^{C×H×W}。
- **关键模块：多尺度通道注意力（MS-CAM）**
    - **动机**：传统的全局通道注意力（如SENet）将每个H×W的特征图压缩为一个标量，偏向全局信息，不利于小物体。
    - **机制**：MS-CAM的核心思想是通过改变空间池化大小，实现在不同尺度上聚合通道上下文信息。
        1.  **全局上下文分支**：对输入特征X进行全局平均池化（GAP），得到C维向量g(X)，代表全局信息。
        2.  **局部上下文分支**：使用**逐点卷积（PWConv）** 和一个瓶颈结构来提取每个空间位置上的通道上下文L(X)，保持与原特征图相同的尺寸C×H×W，从而保留局部细节。
        3.  **融合**：将全局上下文g(X)与局部上下文L(X)进行广播相加，再通过Sigmoid函数，生成最终的多尺度通道注意力权重M(X) ∈ ℝ^{C×H×W}。
    - **数学表达**：
        - 全局上下文：`g(X) = GAP(X)`
        - 局部上下文：`L(X) = BN(PWConv2(ReLU(BN(PWConv1(X)))))`
        - 注意力权重：`M(X) = σ(L(X) ⊕ g(X))`，其中⊕是广播加法。
- **注意力特征融合（AFF）的数学机制**：
    - 公式：`Z = M(X⊎Y) ⊗ X + (1 - M(X⊎Y)) ⊗ Y`
    - 其中`⊎`表示初始特征集成操作（论文实验中默认使用相加`+`）。`M`是由MS-CAM生成的注意力权重，其值在0到1之间。这等效于对特征X和Y进行**动态的软选择或加权平均**，权重由两个特征共同决定。
- **迭代注意力特征融合（iAFF）**：针对AFF中初始集成`X⊎Y`可能粗糙的问题，iAFF提出用**另一个AFF模块**来替代简单的初始集成。即：`X⊎Y = M'(X+Y) ⊗ X + (1-M'(X+Y)) ⊗ Y`，其中`M'`是另一个MS-CAM。这形成了一个两阶段的迭代精炼过程。
- **模块连接与网络集成**：
    - AFF/iAFF模块设计为即插即用，用于**替换**现有网络中的简单特征融合操作。
    - **同层融合（InceptionNet）**：替换不同卷积核输出的拼接操作，得到AFF-Inception模块（图3a）。
    - **短跳连（ResNet）**：替换ResBlock中残差块与恒等映射的相加操作，得到AFF-ResBlock（图3b）。
    - **长跳连（FPN）**：替换FPN中自顶向下路径的相加操作，得到AFF-FPN（图3c）。
- **与已有方法的差异**：
    - **统一性**：不同于SKNet（仅同层）或GAU（仅长跳连），AFF是一个统一框架。
    - **上下文感知级别**：AFF是**完全上下文感知**的，同时使用X和Y来生成融合权重。
    - **权重类型**：AFF进行的是**软选择**，权重和为1；而SENet等是特征精炼/调制。
    - **注意力尺度**：MS-CAM首次在**通道注意力**内引入**多尺度**（全局+局部）上下文聚合，而以往的多尺度注意力多针对空间维度。

- **与已有方法的差异**：
    - **统一性**：不同于SKNet（仅同层）或GAU（仅长跳连），AFF是一个统一框架。
    - **上下文感知级别**：AFF是**完全上下文感知**的，同时使用X和Y来生成融合权重。
    - **权重类型**：AFF进行的是**软选择**，权重和为1；而SENet等是特征精炼/调制。
    - **注意力尺度**：MS-CAM首次在**通道注意力**内引入**多尺度**（全局+局部）上下文聚合，而以往的多尺度注意力多针对空间维度。
