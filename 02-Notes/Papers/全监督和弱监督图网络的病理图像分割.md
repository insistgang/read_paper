## 摘要

> **英文原文 (据 PDF 提取文本整理, 修复断词与空格)**:
> **Objective** Computer-assisted techniques and histopathology image processing technologies have significantly facilitated pathological diagnoses. Among them, histopathology image segmentation is an integral component of histopathology image processing, which generally refers to the separation of target regions (e.g., tumor cells, glands, and cancer nests) from the background, and is further used for downstream tasks (e.g., cancer grading and survival prediction). In recent years, the rapid development of deep learning has resulted in significant breakthroughs in histopathology image segmentation. Segmentation networks such as FCN and U-Net have demonstrated strong capabilities in accurately delineating edges. However, most existing deep learning methods rely on a fully supervised learning mode, which depends on numerous accurately annotated digital histopathology images. Manual annotation, conducted by medical professionals, is time-consuming and introduces a high likelihood of missed diagnoses and false detections; consequently there is a scarcity of precisely annotated histopathology images. Moreover, histopathology images are highly complex, making it extremely challenging to distinguish targets from the background (inter-class homogeneity), while significant variations among pathological objects within the same tissue dataset exhibit intra-class heterogeneity. Differences between patients and nonlinear relationships between image features impose high requirements on the robustness and generalization of segmentation algorithms. Therefore, this study proposes a graph-based framework for histopathology image segmentation. **Method** The framework consists of two modes — fully supervised graph network (FSGNet) and weakly supervised graph network (WSGNet) — aiming to adapt to datasets with different levels of annotation and precision requirements. FSGNet is used when samples have pixel-level labels and high accuracy is required; WSGNet is used when samples only have sparse point labels, using superpixel-level inference. The framework uses graph convolutional networks (GCN) to represent the irregular morphology of histopathological tissues and introduces graph Laplacian regularization to learn similar features from neighboring nodes, enhancing generalization. WSGNet uses simple linear iterative clustering (SLIC) for superpixel segmentation, transforming weakly supervised semantic segmentation into a binary classification problem for superpixels. **Result** Tests were conducted on two public datasets (GlaS, with test set split into Parts A and B; CRAG) and one private dataset (LUSC). Both modes outperformed comparison algorithms in overall accuracy (OA) and Dice index (DI). FSGNet improved most on GlaS Part B (+1.61% OA, +2.26% DI); WSGNet improved most on CRAG (+2.63% OA, +2.54% DI). **Conclusion** Both modes demonstrate excellent, robust and generalizable performance, achieving more complete segmentation with fewer missed and false detections.

## 研究背景与动机

- **为什么做**: 病理图像分割是计算机辅助诊断的关键技术, 但其发展面临两大核心矛盾。1) **数据标注矛盾**: 构建高精度分割模型需要大量像素级精准标注, 而细粒度标注需要经验丰富的病理学家、费时费力且易漏检误检, 导致具有精准标注的数据集极少。2) **图像复杂性矛盾**: 病理图像具有三种特性 —— 目标与背景难辨别(类间同质性)、同组织数据集内病理对象差异大(类内异质性)、患者间差异与图像特征间的非线性关系(使多数算法需重新训练才能适配新数据集), 对算法鲁棒性和泛化性要求极高。
- **之前方法的问题**:
    - 全监督方法(如 FCN, U-Net)在精细刻画边缘上很强, 但严重依赖大量像素级标签, 难以满足实际需求。
    - 现有深度学习方法大多基于规则网格的卷积操作, 难以有效表征病理组织不规则、复杂的形态结构。论文具体指出 Chen 等(2021, 即对比方法 WESUP)引入了局部监督信息缓解前背景区分度低、类内异质性强的问题, 但"没有很好地捕捉图像特征之间的非线性关系", 仍存在较多漏检误检区域和噪声。
- **切入思路**: 受图学习(Kipf 和 Welling 2017; Lu 等 2019; Anklin 等 2021)启发, 用图网络挖掘数据间的非线性潜在特征。论文将其用于病理图像中腺体等局部组织识别, 提出兼具全监督与弱监督两种模式的图网络分割框架。
- **核心矛盾**: 如何在**标注数据有限**(甚至仅有稀疏点标注)的条件下, 设计出能**有效捕捉病理组织不规则形态**并具备**强泛化能力**的分割模型。

## 关键贡献

论文自述三点贡献(对应原文第 0 节末尾):

1.  **灵活的双模式框架**: 可根据不同数据集的人工标注量和精度需求, 灵活切换为全监督图网络(FSGNet)模式或弱监督图网络(WSGNet)模式。
2.  **弱监督转化为超像素分类**: 将弱监督语义分割转化为超像素分类问题, 在少量点注释下有效处理病理图像, "期望将病理学家从繁重的注释工作中解放出来"。
3.  **用 GCN 处理不规则形态**: 利用图卷积网络(GCN)处理组织病理学图像中的不规则形态, 能准确分割不同组织。实验证明该框架可从多种染色方式数据集成功分割不同组织, 精度优于多种经典与先进方法; 弱监督模式不仅超过其他弱监督算法, 还能超过部分全监督算法。

(笔记补充: 图拉普拉斯正则化是上述贡献 3 的关键机制, 见方法节; 多数据集/高光谱泛化验证见实验节。)

## 方法

- **整体框架(图 1)**: 含两种模式。**FSGNet** 适用于有像素级标签且要求高精度的场景, 结构为"主干网络(编码—解码器) + GCN"。**WSGNet** 将语义分割转化为超像素二分类问题, 适用于仅有稀疏点标签的场景, 结构为"超像素分割 → 弱监督主干提特征 → 层级化特征 → GCN(拉普拉斯正则化) + 分类器"。两种模式均用 GCN 处理任意结构数据并施加图拉普拉斯正则化以提升鲁棒性、泛化性、降低过拟合。
- **输入输出**:
    - **FSGNet**: 输入病理图像 `X ∈ R^{W×H×3}`, 经 UNeXt 输出像素特征 `F = [f_1,…,f_I]^T ∈ R^{I×C}` (I=WH 为像素总数, 论文中 C=1), 最终输出像素级二值分割掩码。
    - **WSGNet**: 输入病理图像 `X` 与对应稀疏点标签, 输出每个超像素的类别(目标或背景), 进而得到分割图。
- **关键模块与连接**:
    1.  **主干网络**:
        - **FSGNet**: 使用**从头训练**的 **UNeXt**(Valanarasu 和 Patel, 2022; 基于卷积 MLP 的编码器—解码器分割网络)作为主干 `Ψ0`。编码器前 3 块为卷积块、后 2 块为 Tok-MLP, 每块下采样 1/2; 解码器对称(2 个 Tok-MLP + 3 个卷积块), 每块上采样 2 倍; 卷积块含卷积层 + BN + ReLU, 用边缘填充 0 保持尺寸。相比 U-Net 参数更少、复杂度更低。
        - **WSGNet**: 使用在 ImageNet 上**预训练的 VGG-16** 作为主干 `Ψ1`, 改进: 去掉最后的 1×1 全连接层、改进后续池化层、加入双线性插值使各卷积层特征图输出到与输入同尺寸(可接受任意大小输入)。输出多尺度卷积特征图 `{F_l^{conv}}_{l=1}^{L_conv}`。
    2.  **图卷积网络(GCN, 图 4)**:
        - **图构建**: 采用**一跳(one-hop)邻域图** `G={V, E}`, 每个顶点与其最近 1 个相邻节点相连, 连接关系由邻接矩阵 A 定义(1 表示有边, 0 表示无边)。FSGNet 以主干编码器最终输出像素特征 `{f_i}_{i=1}^{I}` 为顶点; WSGNet 以超像素层级化特征 `{h_m}` 为顶点。
        - **GCN 操作**: 逐层聚合一跳邻域信息, 第 l+1 层输出 `Z^{l+1} = σ(Â Z^l θ^l)` (式 1), 其中 σ 为非线性函数(如 ReLU), θ^l 为第 l 层可训练权重, `Â` 是 A 的对称归一化(Kipf 和 Welling, 2017)。
    3.  **图拉普拉斯正则化**: 正则化项 `ℓ_tr = tr(y_g^T A_g y_g)` (式 5), 其中 `y_g` 是 GCN 输出, `A_g` 是图邻接矩阵。促使网络学习相邻节点的相似特征(Smola 和 Kondor, 2003), 有效聚集相似节点, 提升泛化能力。
    4.  **点标签生成超像素标签(仅 WSGNet, 图 6)**: 用 **SLIC**(Achanta 等, 2012)将图像 `X` 过分割成超像素 `{S_m}_{m=1}^{M}`(M 为超像素数), 通过**众数投票**(以出现次数最高的标签作为该超像素标签)将点标签 `{y_k^P}` 的语义扩散到整个超像素区域, 生成超像素标签 `{y_m}`; 不含任何点标签的超像素记为空。
    5.  **层级化特征(仅 WSGNet)**: 将 VGG-16 各卷积层特征图双线性上采样到统一尺寸并串联得到 `f_h`, 把超像素轮廓叠加在 `f_h` 上、对每个超像素内像素深层特征求平均得 `f_m`; 再用 MLP `Ψ2` 非线性降维得层级化特征 `h_m`(维度远小于 `f_h`)。`h_m` 一路输入 GCN, 一路输入分类器 `Ψ3` 预测类别 `ŷ_m = Ψ3(h_m)`。采用多尺度训练与推理(对目标随机缩放)以获得对尺寸差异的鲁棒性。
- **机制直观解释**:
    - **GCN**: 在图上做"信息传递与聚合", 每个节点新特征是自身与邻居特征的加权聚合再经非线性变换, 从而捕获局部结构与上下文; 拓扑图善于表达高维流形特征和非线性关系, 适合表征形态不规则的病理组织。
    - **图拉普拉斯正则化**: 类似在图上施加平滑约束, 使紧密相连(相似)的节点在特征空间表示也相近, 提升对噪声和变化的鲁棒性。
- **训练方式**:
    - **FSGNet**: 主干损失 `ℓ_d = 0.5·BCE(ŷ_i, y_i) + Dice(ŷ_i, y_i)` (式 2; BCE 为二分类损失, Dice 衡量真实区域与预测区域的重叠), 总损失 `ℓ = ℓ_d + λ ℓ_tr` (式 6), `λ=0.3`, 用 SGD 优化。
    - **WSGNet**: 超像素分类损失 `ℓ_0 = Σ_m ς_m·g(y_m, ŷ_m)` (式 7; g(·) 为交叉熵, `ς_m` 为处理类别不平衡的类别权重), 总损失 `ℓ_w = ℓ_0 + λ ℓ_tr` (式 8), 同样用 SGD 优化。
- **和已有方法的差异**: 与 FCN、U-Net 等基于规则网格卷积的方法相比, 核心差异是引入 **GCN** 处理不规则结构 + **图拉普拉斯正则化**, 并提供灵活的**双模式框架**; 弱监督模式将分割转化为超像素分类, 大幅降低标注要求。论文亦将自身与 Graph-FCN(Lu 等 2019, 首次把 GCN 用于语义分割)、FGNet(Zhang 等 2021, 动态超像素连接 FCN 与 GCN)等图网络分割工作做了关联区分。

## 实验

- **使用的数据集(4 个)**:
    1.  **GlaS**(腺体分割挑战公开数据集, Sirinukunwattana 等 2017): 165 幅 H&E 染色图像, 来自 16 幅 T3/T4 期结直肠腺癌全切片, 训练:测试 = 85:80, BMP 格式, 多数尺寸 775×522; 测试集按组织学等级与视野分层为 A 部分(60 幅)和 B 部分(20 幅)。
    2.  **CRAG**(结直肠腺癌公开数据集, Graham 等 2019): 213 幅 20 倍 H&E 染色图像, 多数 1512×1516, 训练:测试 = 173:40, PNG 格式, 具完备实例级标签。
    3.  **LUSC**(私有肺鳞状细胞癌数据集, 中国上海组织病理诊断中心 Histo 提供): 110 幅免疫组化染色 PD-L1 图像, 训练:测试 = 70:40, PNG, 40 倍物镜扫描, 每幅 1000×1000。
    4.  **MDC**(多维胆管癌公开高光谱数据集, Sun 等 2022): 538 个场景, 二值 MHSI 分割任务, 波长 550–1000 nm, 每场景 60 个光谱带, 单波段图像调整为 256×320, 以患者为中心划分训练:验证 = 3:1, 格式 hdr/img; 用于验证在高光谱图像上的泛化性。
- **对比方法**:
    - **全监督(对比 FSGNet)**: FCN-8(2015), U-Net(2015), UNeXt(2022), YAMU(2022)。
    - **弱监督(对比 WSGNet)**: MICRANet(2022), WESUP(Chen 等 2021), CDWS(2017), SizeLoss(2019)。
    - **泛化性验证(MDC)**: Dual-Stream-MHSI(Yun 等 2023)。
- **实验设置**: 所有算法用 PyTorch 实现, 运行于 64 GB 内存、NVIDIA GeForce RTX 3090 的机器。数据增强含模糊、颜色抖动、翻转。弱监督点标签由"模仿病理专家做法"从像素级标签随机采样生成, **点标签比例 0.001%**, 各数据集点标签量约: GlaS ~20 点/样本、CRAG ~35 点/样本、LUSC ~25 点/样本、MDC ~64 点/样本。多尺度缩放因子: GlaS [0.35,0.47]、CRAG [0.2,0.3]、LUSC [0.4,0.6]、MDC [0.4,0.6]。SLIC: 每超像素面积约 300 像素、紧凑度 40(对比方法 WESUP 设为约 50 像素)。SGD: 动量 0.9、权重衰减 0.001、批大小 1、初始学习率 0.001, 每 10 个轮次评估一次, 若整体损失不降则学习率减半, 直到损失停止下降或学习率降至 0.00001。
- **评价指标**: 整体像素级分类精度(OA)和 Dice 指数(DI), 以百分比记录, 取每模型运行 3 次的平均值, 得分越高越好。

# 论文精读

## 1. 论文定位
这篇论文属于**医学图像分割**方向, 具体是**数字病理图像分割**(发表于《中国图象图形学报》2024, 29(03):0697-0712)。它解决的核心问题是: 数字病理图像精准像素级标注稀缺且成本高, 同时病理图像本身具有类间同质性、类内异质性、背景复杂与特征非线性等挑战, 导致现有分割算法泛化性与鲁棒性不足。论文通过结合图卷积网络(GCN) + 灵活的全/弱监督双模式来应对。因此本文最适合放在 **"A1_医学图像_分割"** 主题下。

## 2. 一句话总结
本文提出一个基于 GCN 的病理图像分割框架, 含全监督(FSGNet, UNeXt+GCN)与弱监督(WSGNet, VGG-16 + 超像素层级特征 + GCN + 分类器)两种模式, 用图拉普拉斯正则化学习病理组织不规则形态, 在 GlaS/CRAG/LUSC 上 OA、DI 全面领先, 且仅用 0.001% 点标签的弱监督模式精度反超全监督 FCN-8。

## 3. 背景与问题
- **为什么做**: 病理图像分割是计算机辅助诊断关键技术, 面临两大矛盾。1) **标注矛盾**: 高精度分割需大量像素级标注, 而细粒度标注需病理专家、耗时且易漏检误检, 精准标注数据极少。2) **复杂性矛盾**: 类间同质性(目标背景难辨)、类内异质性(同组织内对象差异大)、患者间差异与特征非线性关系, 使多数算法需重训才能适配新数据集。
- **之前方法的问题**: 全监督方法(FCN、U-Net)依赖大量像素级标签; 基于规则网格卷积的方法难表征不规则形态。论文点名 Chen 等(2021, WESUP)虽引入局部监督缓解类内异质性, 但未很好捕捉特征间非线性关系, 仍有较多漏检误检与噪声。
- **核心矛盾**: 如何在标注有限(甚至仅稀疏点标注)下, 既捕捉不规则形态又强泛化。

## 4. 核心贡献
1.  **灵活双模式框架**: 按标注量与精度需求切换 FSGNet / WSGNet。
2.  **弱监督→超像素分类**: 把弱监督语义分割转化为超像素二分类, 少量点注释即可训练, 解放标注人力。
3.  **GCN 处理不规则形态**: 用 GCN 学习病理组织不规则、非线性结构; 实验证明可跨多种染色方式分割不同组织, 弱监督模式既超其他弱监督算法、又超部分全监督算法。
4.  (机制层) **图拉普拉斯正则化** `ℓ_tr = tr(y_g^T A_g y_g)` 促使相邻节点特征相似, 提升泛化与鲁棒、降过拟合, 是上述效果的关键支撑。

## 5. 方法详解
- **整体框架(图 1)**: **FSGNet** = "主干(编码—解码器 UNeXt) + GCN", 用于像素级标签 + 高精度场景; **WSGNet** = "SLIC 超像素 → VGG-16 提多尺度特征 → 层级化特征 h_m → GCN + 分类器 Ψ3", 把语义分割转为超像素二分类, 用于仅有稀疏点标签场景。两者均用 GCN + 图拉普拉斯正则化。
- **输入输出**: FSGNet 输入 `X ∈ R^{W×H×3}`, UNeXt 输出 `F ∈ R^{I×C}`(I=WH, C=1), 出像素级二值掩码; WSGNet 输入图像 + 稀疏点标签, 出每个超像素类别→分割图。
- **关键模块**:
    1.  **主干**: FSGNet 用**从头训练**的 UNeXt(卷积 MLP, 编码器 3 卷积块 + 2 Tok-MLP, 解码器对称, 含 BN/ReLU, 边缘补 0); WSGNet 用 **ImageNet 预训练 VGG-16**(去 1×1 全连接、改池化层、加双线性插值使各层特征图同尺寸、可接受任意尺寸输入), 输出 `{F_l^{conv}}`。
    2.  **GCN(式 1)**: 一跳邻域图(每点连最近 1 邻居), `Z^{l+1}=σ(Â Z^l θ^l)`, `Â` 为对称归一化邻接矩阵; FSGNet 以像素特征 `{f_i}` 为顶点, WSGNet 以超像素层级特征 `{h_m}` 为顶点。
    3.  **图拉普拉斯正则化(式 5)**: `ℓ_tr = tr(y_g^T A_g y_g)`, 聚集相似节点。
    4.  **超像素标签(仅 WSGNet)**: SLIC 过分割成 `{S_m}`, 众数投票把点标签语义扩散为超像素标签 `{y_m}`, 无点标签的超像素记空。
    5.  **层级化特征(仅 WSGNet)**: VGG-16 各层特征双线性上采样 + 串联→`f_h`, 超像素内均值→`f_m`, MLP `Ψ2` 降维→`h_m`; 多尺度训练/推理增强尺寸鲁棒性。
- **机制直观解释**: GCN = 图上信息传递与聚合, 捕局部结构与上下文, 适合不规则形态; 图拉普拉斯正则化 = 图上平滑约束, 相似节点表示相近, 增鲁棒。
- **训练**: FSGNet `ℓ_d = 0.5·BCE + Dice`(式 2), 总损失 `ℓ = ℓ_d + λ ℓ_tr`(式 6), λ=0.3, SGD; WSGNet `ℓ_0 = Σ ς_m·g(y_m, ŷ_m)`(式 7, g 为交叉熵, ς_m 处理类别不平衡), 总损失 `ℓ_w = ℓ_0 + λ ℓ_tr`(式 8), SGD。
- **与已有方法差异**: 引入 GCN + 图拉普拉斯正则化处理不规则结构, 提供双模式框架, 弱监督转超像素分类大幅降标注; 与 Graph-FCN、FGNet、WSNTG、BASGCN 等图网络分割工作有承接与区分。

## 6. 实验与结果
- **数据集(4)**: GlaS(165 幅 H&E, 训:测 85:80, 多数 775×522, 测试集 A 60 幅/B 20 幅); CRAG(213 幅 20× H&E, 多数 1512×1516, 173:40, 实例级标签); LUSC(私有, 110 幅 IHC PD-L1, 70:40, 40× 扫描, 1000×1000); MDC(高光谱, 538 场景, 550–1000 nm, 60 波段, 256×320, 训:验 3:1, 泛化验证)。
- **对比**: 全监督 FCN-8/U-Net/UNeXt/YAMU; 弱监督 MICRANet/WESUP/CDWS/SizeLoss; 泛化 Dual-Stream-MHSI。
- **设置**: PyTorch, RTX 3090 + 64GB; 数据增强(模糊/色抖/翻转); 点标签比例 0.001%(GlaS~20、CRAG~35、LUSC~25、MDC~64 点/样本); 多尺度因子 GlaS[0.35,0.47]/CRAG[0.2,0.3]/LUSC[0.4,0.6]/MDC[0.4,0.6]; SLIC 超像素~300 像素/紧凑度 40; SGD 动量 0.9/权重衰减 0.001/批 1/初始 lr 0.001, 每 10 轮评估、损失不降则 lr 减半至 0.00001。指标 OA、DI(3 次均值, %)。
- **主结果(表 1)**: FSGNet 在 GlaS A 88.15/89.64、GlaS B 91.58/91.23、CRAG 93.74/92.58、LUSC 92.84/93.20, 全面最优, 加 GCN 后均高于 UNeXt; GlaS B 提升最明显(+1.61/+2.26)。WSGNet 在 GlaS A 84.27/86.15、GlaS B 84.91/83.60、CRAG 85.50/80.17、LUSC 88.45/87.89, 为弱监督最优, CRAG 提升最明显(对 WESUP +2.63/+2.54), 且精度超过全监督 FCN-8。
- **定性(图 7/8)**: FSGNet 分割更完整、中心漏检更少; WSGNet 比 WESUP 等漏检误检噪声更少; UMAP 显示训练后同类超像素聚拢。
- **消融**: ① 损失(表 2): 去 BCE 或 Dice 均降, 完整最优; ② 主干 + GCN(表 4, 提取缓存未覆盖数值, 待核): 换 U-Net/ResNet18 主干性能大降, 冻结 GCN 后 OA/DI 降(尤其 DI), 证 GCN 关键; 全监督在 GlaS A 数据简单时去 GCN 反略好。③ 效率(表 3): FSGNet GlaS A 训练 7.88/测试 7.42 秒, WSGNet 44.62/18.94 秒, 远快于 ResNet18+GCN 变体。
- **泛化(表 5/图 9, 据原文 p.13 待核)**: MDC 上 FSGNet DI 超 Dual-Stream-MHSI 约 2.8%; 论文归因后者依赖 CP 张量分解挖低秩特征, 语义分割不如图学习。
