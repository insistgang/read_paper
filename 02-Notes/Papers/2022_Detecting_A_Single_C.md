## 研究背景与动机

- **为什么要做**：本书整体焦点是检测「多个」变点，但作者主张先吃透「单变点」这一更简单的子问题——它的直觉与结论是理解二元分割、动态规划等多变点方法的基石（p.1）。
- **之前方法的问题**：论文不是对比已有方法的实证研究，而是理论综述。它指出实践中「如何选阈值」是核心难点：基于 Gumbel 渐近分布的阈值过于保守（收敛慢，阈值约为真实值两倍），基于 Bonferroni 校正的 `2 log n` 阈值则因忽略 `LR_τ` 之间的强相关而偏松（保守性来自 Slepian 引理）。
- **核心矛盾**：在变点位置 `τ` 未知的情况下，既要用 `max_τ LR_τ` 这一非标准统计量正确检验「是否有变化」（标准似然比正则条件在此不成立，零分布即使渐近也不是卡方），又要准确定位变点、并对变化幅度 `Δ` 做出（尽量）无偏的估计。

## 关键贡献

1.  **建立似然比检验框架并证明其与 CUSUM 统计量等价**：固定 `τ` 时 `LR_τ = C_τ² / σ²`，未知 `τ` 时取 `LR = max_τ LR_τ` 作为检验统计量，等价于取 `max_τ C_τ`（p.2）。
2.  **刻画零假设下的渐近分布**：固定 `τ` 时 `LR_τ ~ χ²₁`，但 `max_τ LR_τ` 因 `LR_τ` 间的相关而不再是卡方；其极值收敛到 Gumbel 分布（Yao & Davis 1986 定理 2.1），给出阈值随 `n` 增长的速率为 `2 log log n`，并配套规范化常数 `a_n = (2 log log n)^{1/2}`、`b_n`（公式(2)，p.3）。
3.  **系统对比三种阈值来源**：Gumbel 渐近分布、Bonferroni 的 `2 log n` 上界、蒙特卡洛模拟的经验分位数，指出渐近阈值高度保守、Bonferroni 偏松，推荐用蒙特卡洛（且蒙特卡洛易推广到更复杂的变点场景）（p.3-4, p.6）。
4.  **完整分析功效、位置精度与幅度偏差**：
    - 功效由非中心参数 `ν` 主导，`ν` 关于 `n` 线性、关于 `Δ` 二次（故检测幅度减半的变化约需四倍数据），并依赖位置 `q_0`（公式(3)(4)，p.5、p.7）。
    - 位置估计误差在原始时间尺度上：固定 `Δ`、`q_0` 而增大 `n` 时为 `O_p(1)`；增大 `Δ` 时为 `O_p(1/Δ)`——即定位精度主要由变化幅度决定，而非样本量（p.8-10）。
    - 朴素幅度估计 `ˆΔ` 存在「赢家诅咒」式正偏，来自两层选择效应（数据集层面 + 数据集内位置层面）（p.10-11）。

## 方法

- **整体框架**：对长度 `n` 的序列，遍历每个候选变点 `τ` 计算似然比 `LR_τ`（或等价 CUSUM `C_τ`），取最大值 `LR = max_τ LR_τ`；若超过阈值 `c` 则判定存在变点，并以 `ˆτ = argmax_τ LR_τ` 估计位置。
- **输入输出**：
    - 输入：长度 `n` 的一维序列 `X_1, ..., X_n`（已知方差 `σ²`）。
    - 输出：是否存在变点（布尔）、变点位置估计 `ˆτ`、变化幅度估计 `ˆΔ = ¯X_{(ˆτ+1):n} − ¯X_{1:ˆτ}`。
- **关键模块**：
    1.  **CUSUM 统计量**：`C_τ = √[τ(n−τ)/n] · |¯X_{1:τ} − ¯X_{(τ+1):n}|`（p.2）。直观上它比较变点前后样本均值之差并重缩放，使无变化时 `C_τ` 是一个方差为 1 的正态随机变量的绝对值。
    2.  **似然比统计量**：由「有变点」与「无变点」两个模型的最大似然之比推导，化简后 `LR_τ = C_τ² / σ²`（p.2）。无变化时 `LR_τ ~ χ²₁`。
- **模块连接**：先在「信号 + 高斯噪声」模型下定义 `LR_τ`，再揭示其与 CUSUM 的代数等价；检验统计量是所有位置上 `LR_τ` 的最大值，因而问题转化为对一族相关高斯变量取极值的分布刻画。
- **数学公式直观解释**：
    - 公式(1)：`X_i = f_i + ε_i`，信号加独立同分布零均值高斯噪声（方差 `σ²`）。
    - 公式(2)：`max_τ C_τ/σ` 经 `a_n`、`b_n` 规范化后收敛到 Gumbel 分布，给出阈值增速 `~ 2 log log n`。
    - 公式(3)：非中心参数 `ν = (1/q_0 + 1/(1−q_0)) · nΔ²`（`q_0 = τ_0/n`），决定真实变点处 `LR_{τ0} ~ χ²₁(ν)` 的分布。
    - 公式(4)：基于 Laurent & Massart (2000) 的 `χ²₁(ν)` 尾界，给出功效下界 `Pr(χ²₁(ν) > k) ≥ 1 − exp(−(1+ν−k)²/(4+8ν))`，再由 `max LR_τ ≥ LR_{τ0}` 推得检验功效下界。
    - 公式(5)：用布朗桥 `W⁰(t)` 定义连续时间过程 `˜W⁰(t)`，使 `{C_1,...,C_{n−1}}` 与 `{|˜W⁰(i/n)|}` 同分布，从而精确刻画有变点时 CUSUM 的随机行为及定位精度。
- **训练方式**：非机器学习方法，无「训练」过程；它是基于模型假设的频率派假设检验，阈值通过蒙特卡洛在零假设下模拟得到。
- **推理流程**：
    1. 一次扫描计算累积和 `S_t = Σ_{i≤t} X_i`。
    2. 借助累积和，对所有 `τ`（或在最小段长约束下 `k ≤ τ ≤ n−k`）以 `O(1)` 计算每个 `LR_τ`，全程 `O(n)` 时间与 `O(n)` 空间（p.4，文中给出 R 代码片段）。
    3. 取 `max_τ LR_τ` 及对应 `ˆτ`。
    4. 将 `max_τ LR_τ` 与蒙特卡洛阈值比较，决定是否拒绝零假设。
    5. 若拒绝则输出 `ˆτ` 与 `ˆΔ`。
- **和已有方法的差异**：本文不提出新算法，而是把经典似然比 / CUSUM 单变点检验的零分布、阈值、功效、定位精度、幅度偏差等性质做了一次系统、严谨的理论梳理，目标是为后续多变点章节打基础。

## 实验

- **使用的数据集**：**全部为模拟数据**，主要是独立同分布的标准高斯噪声（已知方差）；变化幅度 `Δ`、样本量 `n`、相对位置 `q_0` 为主要可调变量。正文 p.1-12 未使用任何真实世界数据集（补读段落提到第 1.5 节讨论 AR(1)、重尾噪声等模型误差，仍为模拟）。
- **对比方法**：本质是三种阈值来源的对比——Gumbel 渐近分布、Bonferroni 的 `2 log n` 上界、蒙特卡洛经验分位数。
- **评价指标**：
    1.  阈值大小（给定 `n` 与误报率，如 5%/1%/0.1% 分位）。
    2.  检验功效（给定 `Δ`、`q_0` 下检测到变点的概率下界）。
    3.  位置估计精度（`ˆτ` 的分布 / 直方图）。
    4.  幅度估计偏差（`ˆΔ` 的分布及对真实 `Δ` 的系统偏离）。
- **主实验结果**：
    - 阈值比较（图1(a)，`n=10000` 量级）：蒙特卡洛真实阈值随 `n` 增长「非常缓慢」，明显慢于 `2 log n`；Gumbel 渐近阈值高度保守，约为真实值两倍。图1(b)：无变化时若误检，估计位置的分布严重偏向序列首尾（中间位置 `LR_τ` 相关更强）。
    - 最小段长（图2(a)）：以数据比例形式施加最小段长约束 `max_{k≤τ≤n−k} LR_τ`，可显著降低所需阈值（误报率 0.01，给出 `n=100/1000` 曲线）。
    - 检测功效（图2(b)，`n=1000`、`q_0=0.5`、误报率 0.01）：变化幅度 `Δ` 从约 0.2（难检）增到约 0.4（易检），功效下界快速从近 0 升到近 1。
    - 位置精度（图3，`q_0=0.4`；`n=100,Δ=1` / `n=400,Δ=1` / `n=100,Δ=2`）：在重缩放时间下增大 `n` 使 CUSUM 均值更尖锐（功效更高）但围绕均值的波动不变；在原始时间尺度上 `n` 对定位精度影响不明显，而增大 `Δ`（保持 `nΔ²` 相同的两行曲线几乎一致）则显著提升定位精度。
    - 幅度偏差（图4，各 10000 次实现，`q_0=0.5`）：(i) `n=100,Δ=0.5`（功效约 50%）高估 `Δ` 约 **62%**；(ii) `n=400,Δ=0.5`（功效 >97%）高估 **7.4%**；(iii) `n=100,Δ=1`（功效 >97%）高估 **5.7%**。对比表明低功效（数据集选择效应）是偏差主因，而非定位不确定性。
- **消融实验**：即上述「最小段长」分析（图2(a)），约束越强、所需阈值越低、检测能力越高。
- **泛化实验**：第 1.3 节考察「数据中存在多个变点时用单变点检验会怎样」（图5，三变点模拟数据）。结论是 `LR_τ` 期望值的所有局部极大（含全局极大）都落在真实变点处，故单变点检验仍有功效、`ˆτ` 仍靠近某个真实变点；但对比「全数据」与「仅前两段数据」可见，第一个变点的信号在全数据上被后续变化稀释、有所减弱。
- **效率信息**：通过预存累积和，所有 `τ` 的 `LR_τ` 在 `O(n)` 时间、`O(n)` 空间内算完（朴素逐点重算为 `O(n²)`）（p.4）。

## 局限

1.  **模型假设强**：核心结论建立在「独立同分布高斯噪声、方差已知」之上。补读段落（第 1.4 节「Unknown Variance」、第 1.5 节「Impact of Model Error」）指出，方差未知、AR(1) 自相关、重尾噪声等会显著抬高误报率、损失功效与精度——PDF 文本对这些扩展的定量细节仅部分给出。
2.  **单变点定位**：方法面向单变点。第 1.3 节虽说明其在多变点数据上仍有功效，但直接用单变点检验处理多变点会丢失信号（图5），并非多变点检测的完整解。
3.  **结论依赖模拟**：正文 p.1-12 的全部数值结论来自模拟数据，缺少真实数据验证，模拟设定未必覆盖现实复杂性。
4.  **渐近理论保守**：作者自陈 Gumbel 渐近阈值收敛慢、保守（约真实值两倍），实用价值有限，故转向蒙特卡洛。
5.  **阈值计算成本**：单次扫描虽为 `O(n)`，但用蒙特卡洛确定阈值需对每个 `n` 反复模拟大量（如图4 中 10000 次量级）零假设序列；对极大 `n` 与极低误报率要求，这一步可能成为主要计算开销。

## 个人评论

本文（书籍章节）最大的价值在于**系统性与深入性**：它不是方法的表面介绍，而像一份针对经典单变点检测的「理论说明书 + 分析报告」。
- **对研究者**：清晰示范了如何从「信号+噪声」模型出发，推导统计量、刻画零分布（含为何不是卡方）、分析功效与相合性、讨论收敛速度，并横向比较多种理论近似的优劣——是统计方法学写作的优秀范本。
- **对应用者**：点明了实践中的几个「坑」：① Gumbel 渐近阈值太保守，蒙特卡洛才是实用选择；② 幅度估计 `ˆΔ` 天然正偏（赢家诅咒），需校正或谨慎解释；③ 变点定位精度主要取决于变化幅度 `Δ` 而非数据量 `n`；④ 引入领域知识（最小段长）能明显提升性能。
- **对算法设计者**：阐明了 CUSUM / 似然比的良好性质——多变点存在时其期望的局部极大仍落在真实变点上，这为把它作为二元分割等多变点算法的核心构件提供了理论依据（并指出该性质对其他检验统计量未必成立，见 Venkatraman 1993）。

# 论文精读

## 1. 论文定位
这是一本《变点检测与数据分割》(Change-Point Detection and Data Segmentation, Fearnhead & Fryzlewicz, 2022) 专著的章节预印本（arXiv:2210.07066v1，stat.ME），主题是**时间序列 / 统计信号处理中的变点检测**，与计算机视觉无关。本章聚焦最基础的子问题：在一维序列中**检测是否存在单个均值变点、并估计其位置与幅度**。它是后续「多变点检测与数据分割」章节的理论基石。归类上应放在「时间序列分析 / 统计方法学」之下（本库 taxonomy 取 `T_通用_NLP_其他`）。

## 2. 一句话总结
本章用「信号+高斯噪声」模型，把经典的均值单变点似然比检验（等价于 CUSUM 统计量）从零分布、阈值选取（Gumbel 渐近 / Bonferroni `2 log n` / 蒙特卡洛）、检验功效、位置估计精度到「检测后幅度估计的偏差」做了一次系统而严谨的理论梳理，并讨论了它在多变点数据上的表现。

## 3. 背景与问题
- **为什么要做**：本书整体关注多变点，但单变点更简单，其直觉有助于理解多变点方法（p.1）。
- **之前方法的问题**：阈值选取是实践难点——Gumbel 渐近阈值过于保守（收敛慢、约为真实值两倍），Bonferroni 的 `2 log n` 因忽略 `LR_τ` 间强相关而偏松（保守性源自 Slepian 引理）。
- **核心矛盾**：变点位置 `τ` 未知 → 检验统计量是相关高斯变量族的极值 `max_τ LR_τ`，标准似然比正则条件失效，零分布即使渐近也非卡方；既要正确检验，又要准确定位并尽量无偏地估计变化幅度。

## 4. 核心贡献
1.  建立似然比检验框架并证明 `LR_τ = C_τ²/σ²`、`max_τ LR_τ` 与 `max_τ C_τ` 等价（p.2）。
2.  刻画零分布：固定 `τ` 时 `LR_τ ~ χ²₁`；`max_τ` 后经 `a_n=(2 log log n)^{1/2}`、`b_n` 规范化收敛到 Gumbel，阈值增速 `~ 2 log log n`（公式(2)，p.3）。
3.  系统对比三种阈值（Gumbel / Bonferroni `2 log n` / 蒙特卡洛），推荐蒙特卡洛（精确且易推广）（p.3-6）。
4.  完整分析功效（`ν` 关于 `n` 线性、关于 `Δ` 二次）、位置精度（原始时间尺度上对 `n` 为 `O_p(1)`、对 `Δ` 为 `O_p(1/Δ)`）与幅度偏差（赢家诅咒式正偏，含两层选择效应）（p.5-11）。

## 5. 方法详解
- **整体框架**：遍历候选 `τ` 取 `LR = max_τ LR_τ` 与阈值 `c` 比较；超阈则判有变点，`ˆτ = argmax_τ LR_τ`，`ˆΔ = ¯X_{(ˆτ+1):n} − ¯X_{1:ˆτ}`。
- **输入输出**：输入长度 `n` 的一维序列（已知 `σ²`）；输出「是否有变点 + `ˆτ` + `ˆΔ`」。
- **关键模块**：
    1.  **CUSUM**：`C_τ = √[τ(n−τ)/n] · |¯X_{1:τ} − ¯X_{(τ+1):n}|`，无变化时是方差 1 的正态绝对值（p.2）。
    2.  **似然比**：由「有/无变点」两模型的最大似然比化简得 `LR_τ = C_τ²/σ²`，无变化时 `~ χ²₁`（p.2）。
- **数学公式直观解释**：
    - (1) `X_i = f_i + ε_i`，IID 零均值高斯噪声。
    - (2) `max_τ C_τ/σ` 规范化后收敛 Gumbel，阈值增速 `2 log log n`。
    - (3) `ν = (1/q_0 + 1/(1−q_0))·nΔ²`，决定真实变点处 `LR_{τ0} ~ χ²₁(ν)`。
    - (4) 功效下界 `Pr(χ²₁(ν)>k) ≥ 1 − exp(−(1+ν−k)²/(4+8ν))`（Laurent & Massart 2000 尾界），再由 `max LR_τ ≥ LR_{τ0}` 得检验功效下界。
    - (5) 布朗桥 `W⁰` 构造 `˜W⁰(t)`，使 `{C_τ}` 与 `{|˜W⁰(i/n)|}` 同分布，刻画有变点时的定位行为。
- **训练方式**：无训练，是基于模型假设的假设检验；阈值由蒙特卡洛在零假设下模拟。
- **推理流程**：算累积和 → 借累积和对所有 `τ`（或 `k≤τ≤n−k`）`O(1)` 算 `LR_τ`，全程 `O(n)`（p.4 含 R 代码）→ 取 `max` 与 `ˆτ` → 与蒙特卡洛阈值比较 → 输出 `ˆτ`、`ˆΔ`。
- **和已有方法的差异**：不提新算法，而是对经典似然比/CUSUM 单变点检验做系统理论分析，为后续多变点章节铺垫。

## 6. 实验与结果
- **数据集**：全部为模拟数据（IID 标准高斯，已知方差）；变量为 `Δ`、`n`、`q_0`。正文 p.1-12 无真实数据集。
- **对比/指标**：三种阈值来源（Gumbel / `2 log n` / 蒙特卡洛）对比；指标为阈值大小、检验功效、位置精度、幅度偏差。
- **主结果**：
    - 阈值（图1(a)）：蒙特卡洛真实阈值随 `n` 增长极慢、远慢于 `2 log n`；Gumbel 阈值约为真实值两倍。图1(b)：无变化误检时，`ˆτ` 严重偏向序列首尾。
    - 最小段长（图2(a)）：施加最小段长约束显著降低所需阈值（误报率 0.01）。
    - 功效（图2(b)，`n=1000`、`q_0=0.5`）：`Δ` 从约 0.2 增到约 0.4，功效下界从近 0 升到近 1。
    - 位置精度（图3，`q_0=0.4`，三组 `(n,Δ)`）：重缩放时间下增大 `n` 使 CUSUM 均值更尖、波动不变；原始时间尺度上 `n` 对定位影响不明显，增大 `Δ` 才显著提升定位（`nΔ²` 相同的两行曲线几乎重合）。
    - 幅度偏差（图4，各 10000 次，`q_0=0.5`）：`n=100,Δ=0.5` 高估 **62%**；`n=400,Δ=0.5` 高估 **7.4%**；`n=100,Δ=1` 高估 **5.7%**——低功效（数据集选择）是偏差主因。
- **泛化（1.3 节，图5）**：多变点数据上，`LR_τ` 期望的局部/全局极大都落在真实变点处，单变点检验仍有功效；但全数据分析会稀释第一个变点的信号。
- **效率**：预存累积和后所有 `LR_τ` 为 `O(n)` 时间/空间（朴素为 `O(n²)`）（p.4）。
