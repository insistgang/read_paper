## 摘要

> **英文原摘要 (清理后)**: Collision detection and collision processing are challenging problems and active research fields in computer graphics and virtual reality. The collision detection algorithm is a technical difficulty and the most important link in the entire simulation process. The quality of collision detection algorithms directly affects the authenticity of simulation situations. For collision detection between fabric and complex rigid body models, the softness and non-fixity of fabric pose great challenges to collision detection. When numerous particles that make up the fabric move, collisions inevitably occur. If collisions cannot be detected in a timely manner and the collision location cannot be repaired, penetration and distortion occur, considerably affecting subsequent simulations. To solve the problem of low detection rate and poor simulation authenticity when collision detection occurs between flexible fabric and complex rigid body models, this study proposes a hybrid hierarchical bounding box method, a fast oriented bounding box (OBB) method, and a spatial grid (space mesh) method. A three-layer hybrid hierarchical bounding box tree is built for the fabric: the top layer uses a spherical bounding box, the middle layer a spherical-AABB hybrid structure, and the bottom layer an AABB bounding box. The complex rigid body is first simplified by triangle folding (with quadratic error metrics), then a fast OBB is constructed on the simplified model. Finally a spatial grid is built between the colliding models for precise detection and collision response. Experiments show that, in the same scenarios, the bounding-box construction speed is shortened by 10%–18%, OBB tightness on the model is improved by 8%–15%, the rejection rate of irrelevant collision pairs is improved by 8%–13%, and the overall collision-detection time is reduced by 6%–13%, while the authenticity of the simulation is preserved.

## 研究背景与动机

- **为什么要做**: 碰撞检测是计算机图形学和虚拟现实中的研究热点, 也是整个模拟过程中的技术难点和性能消耗点。布料形状不固定、运动时容易形变, 属于典型柔性体, 其与复杂刚体模型 (精细建模的兔子、马、人体等) 的碰撞检测对系统的真实性与实时性要求都很高。布料移动时大量粒子随之移动, 必然发生碰撞, 若不能及时检测处理, 会发生穿透甚至失真, 影响后续模拟。
- **现有流程范式**: 现有方法一般将检测分为**粗略检测阶段** (以较少系统开销快速剔除不相交碰撞对) 和**精确检测阶段** (对已获取的碰撞对做更精确检测与响应)。粗略阶段算法主要分为**空间网格法** (划分小单元格, 多用于固定空间较多的场景) 和**包围盒法** (更适合可变形柔性体) 两类。
- **之前方法的问题** (引言综述):
    1.  **单一包围盒方法** (椭球、最小体积 OBB、无厚度圆形包围盒等): 优化单一包围盒有助效率, 但面对复杂模型容易**剔除率低、对模型贴合性差**。
    2.  **混合/层次包围盒方法**: 能结合简单包围盒快速构建与复杂包围盒高效剔除的优势, 但因**结构复杂**, 某些场景下**系统开销大、检测速度慢**。
    3.  **硬件加速路线** (Kim 2019、Mei 2022、Sung 2023 等基于 GPU 的并行方法): 性能好但**对硬件性能要求很高**。
    4.  复杂刚体模型本身**点面数量庞大**, 直接构建包围盒和检测会**效率低、开销大**, 且越复杂越易在模拟中穿透失真。
- **核心矛盾**: 布料与复杂刚体的碰撞检测需同时满足**高实时性** (快速剔除无关碰撞对) 和**高真实性** (精确检测并防穿透), 传统方法难以两者兼顾。本文针对**不同模型采用不同特点的包围盒**来破局。
## 关键贡献

1.  **针对柔性布料的混合结构层次包围盒树 (三层)**: 顶层**球形包围盒** (球心固定、以布料展开最大长度为直径, 移动/形变时不需旋转, 只需适时更新球半径), 中间层**球形-AABB 混合结构**作过渡缓冲, 底层**AABB 包围盒** (更新快、构造与相交测试简单)。该结构兼顾构建更新速度与剔除效率, 适合可变形体。
2.  **对复杂刚体先简化再构 OBB**: 采用基于**二次误差度量 (QEM) + 三角形折叠**的网格简化算法 (Zhou 等, 2020 / 思想源自 Garland & Heckbert, 1997), 在不丢失模型主要特征前提下大幅减少点面数, 用简化模型代替原模型**快速构建 OBB 包围盒**, 降低系统开销。
3.  **改进 OBB 中心点计算 (三角形面积加权法)**: 解决因三角形面片大小不一、密度不均导致 OBB 中心和方向朝稠密方向偏移、检测不准的问题; 中心点按面积加权, 方向由顶点协方差矩阵的特征向量决定, 在更准的同时更省时。
4.  **空间网格法用于精确检测与碰撞响应**: 在包围盒检出的碰撞区域连接两物体表面顶点构网格 (二维三角形、三维四面体), 通过检测网格**面积/体积是否为 0** 判定碰撞, 碰撞时施加约束迫使面积/体积取可接受范围内的最小正值, 从而**防止穿透**。
5.  **层次包围盒树遍历路径优化**: 基于时空相关性 (相近时间段内, 父节点未碰撞则其子节点短期内也不碰撞), 若父节点未碰撞则跳过整个子树, 相比传统单级下降规则 (节点间交集测试累计达 2^(2k−1)−1 次) 大幅减少遍历节点数、降低系统开销。
## 方法

- **整体框架** (图 1 流程, 见正文步骤 1)-3)):
    1.  **布料**: 构建球形-AABB 混合层次包围盒树进行快速初步剔除。
    2.  **刚体**: 先用三角形折叠简化模型, 再对简化模型快速构建 OBB 包围盒代替原模型检测。
    3.  **空间网格**: 在包围盒检出碰撞的模型间构建空间网格, 进行进一步精确碰撞检测和碰撞响应。
- **输入输出**: 输入是布料模型 (粒子系统/网格) 和复杂刚体模型 (三角形网格); 输出是碰撞检测结果 (是否碰撞、碰撞位置) 与碰撞响应 (防穿透的顶点约束)。
- **关键模块与连接**:
    1.  **混合结构层次包围盒树 (BVTT, bounding volume test tree)**:
        - 自顶向下构建。**顶层**固定球心球形包围盒, 以布料展开最大长度为直径, 布料移动时球随之移动 (图 2)。球形/AABB 相交检测简单: 设 R1、R2 为两球心, La、Lb 为 AABB 中心, 若 R1+R2 < L 且 La+Lb < L 则未相交, 否则相交 (图 3)。
        - **中间层**为球形-AABB 混合结构, 先用球形快速排除再用 AABB 进一步剔除, 起顶层与底层的过渡缓冲作用。
        - **自适应增层规则**: 对根节点先构球形包围盒检测; **若根节点球形包围盒剔除率 < 30% 且待检测物体在根节点包围盒内的空间体积占比不足 50%, 则再增加一层球形包围盒**进一步剔除 (否则直接进入中间层)。论文称这是对朱元峰等 (2008) 复合层次包围盒方法的调整。
        - **底层叶子节点**为 AABB 包围盒, 检测到碰撞则对底层图元做相交检测并响应。
        - 检测步骤循环: 1) 根节点球形检测 → 2) 剔除率达阈值则跳到 4), 否则 3) 再加一层球形 → 4) 中间层构球形-AABB、叶子节点构 AABB 并向下遍历 → 5) 叶子节点碰撞则做底层基元检测与响应 → 6) 下一时间步重复。
    2.  **刚体模型简化与 OBB 构建**:
        - **简化 (QEM 三角形折叠)**: 由三角形 3 顶点算平面通式 p=[a,b,c,d]^T (式 1-2, 归一化 a²+b²+c²=1), 用对称矩阵 Mp=pp^T 表示三角形 (式 3); 三角面片 T 的误差矩阵 Qt=Σ Mp (式 4, P_t 是与 T 的 3 顶点相关的面集合); 折叠后新点 v_t 的折叠误差 ε(T)=v_t^T·Qt·v_t (式 5); 对各坐标求偏导置 0 得线性方程组 (式 6-7) 求 v_t, 无解时从三角形中心、各边中点和 3 顶点中取误差最小者作为 v_t。**一次折叠减少 6 条边和 4 个面片** (图 5)。优先折叠误差最小的面以保留特征; 兔子模型即便简化 95% 特征仍存在 (图 6)。
        - **OBB 构建 (面积加权 + 协方差)**: 三角形 i 中心 O_i=(x_i+y_i+z_i)/3 (式 8), 面积 S_i (式 9), 总面积 H=Σ S_i (式 10), **OBB 中心 O=Σ(S_i·O_i)/H** (式 11, 面积加权避免密度不均影响); 顶点期望 u (式 12)、协方差矩阵 C_jk (式 13), **OBB 方向取协方差矩阵的特征向量**, 长度为顶点集在 3 方向上的投影。先将简化模型在坐标轴投影、分块、取离中心最远的顶点集来构包围盒。
    3.  **空间网格法与碰撞响应**:
        - 基本思想: 确定应变张量的最小负特征值, 并在相应特征向量方向上施加约束力; 当网格面积/体积为 0 时检测到碰撞, 此时加约束迫使其取可接受范围内最小正值, 保证两物体间始终存在不影响模拟效果的空间网格, 避免穿透。统一约束式 (式 14): **C2D = |(b−a)×(c−a)| ≥ 0**, **C3D = det[a−o, b−o, c−o] ≥ 0** (o、a、b、c 为构成网格的顶点粒子)。
        - **二维**: 将两物体间顶点依次连接构成大小不等的三角形网格 (图 8)。当三角网格 3 顶点中有 2 个在同一物体上且与该物体共边时, 称其为该物体的空间网格。碰撞时该网格面积被压缩为 0、3 顶点共线; 用式 (15) `(x2−x1)(y3−y1)−(x3−x1)(y2−y1) ≥ 0` 判定并响应, 迫使面积不为 0。物体移动过大、三角形转角过大致网格与物体重叠时, **断开穿过检测物体的边并重新连接顶点构成新网格** (图 8c/d)。
        - **三维**: 空间网格变为四面体, 由一个三角面的 3 顶点 + 另一物体的 1 个顶点组成 (图 9)。设顶点 o、a、b、c, 向量 a/b/c 如式 (16), 判断式 (17) 的 3×3 行列式是否为 0, 为 0 则碰撞并使体积 > 0 响应防穿透。图 10 给出二维顶点-边碰撞、三维顶点-面碰撞的压缩示意。
- **数学公式直观解释**:
    - **QEM 误差矩阵 (4×4 对称)**: 编码三角形所在平面的几何信息, 顶点误差矩阵累加 ≈ 该顶点到相邻各平面距离平方和, 用作折叠代价度量。
    - **协方差矩阵**: 描述顶点分布离散程度, 其特征向量给出数据分布主方向, 即 OBB 的最佳朝向; 面积加权中心则纠正密度不均偏移。
    - **空间网格约束**: 本质是几何约束 (面积/体积 ≥ 0 且不坍缩), 保证网格元素不退化, 物理上对应"两物体间不可压穿"的防穿透层。
- **与已有方法的差异**: 不像传统单一包围盒或固定混合包围盒一刀切, 本文**对布料和刚体按各自特性采用不同包围盒策略** (布料用混合层次包围盒, 刚体用简化+OBB), 并引入**空间网格**作为最后的精确几何约束层, 形成"异构包围盒快速粗筛 + 空间网格精确约束"的两阶段流程; 遍历又用时空相关性剪枝。
## 实验

- **实验环境**: Windows 系统, Visual Studio 2019, C++ + OpenGL 搭建模拟仿真系统; 硬件 3.00 GHz Intel Core i7-9700 CPU, 显卡 NVIDIA GeForce RTX 2070 Super。
- **数据集/场景**: 自定义模拟场景 (图 11) 三个: (a) 布料悬挂 (fabric drapes); (b) 布料随风摆动 (sways with the wind); (c) 布料与小球交互 (interacts with the ball)。刚体模型用兔子、马、人体三种不同复杂度模型。
- **对比方法**: AABB、Sphere (球形)、AABB-OBB、AABB-圆形包围盒法 (靳雁霞等, 2020)、简化模型 OBB 法 (靳雁霞等, 2023)、Sphere-OBB-MACO 法 (Xu 和 Sun, 2023)、并行 AABB 坐标链法 (Qu, 2021); 紧密性对比另加最小体积 OBB 法 (Qin 等, 2018); 耗时/剔除率对比另加融合 OpenNN 检测法 (靳雁霞等, 2022)。
- **评价指标**: 模拟耗时 (ms)、OBB 构建耗时 (s)、包围盒紧密性 (模型体积/包围盒体积之比, 越接近 1 越紧密)、碰撞检测耗时 (ms)、碰撞对剔除率 (%)。
- **主实验结果**:
    - **模拟耗时 (表 1)**: 三场景本文方法均最优。场景 (a) 31.89ms、(b) 35.65ms、(c) **41.24ms**; 场景 (c) AABB 为 62.12ms, 本文缩短约 33.6%, 也优于 AABB-OBB(52.87)、简化模型 OBB(43.98)、Sphere-OBB-MACO(44.32)、AABB 坐标链法(42.73)。更新+检测拆分 (图 12) 显示本文只有更新耗时略高于结构最简单的球形包围盒法, 总耗时低于其他方法。
    - **OBB 构建耗时 (表 2)**: 本文最快。兔子 1.52s、马 1.44s、人体 **4.93s**; 对比传统 OBB 法兔子 3.32 / 马 3.39 / 人体 9.65s, 最小体积 OBB 法人体 7.58s, 简化模型 OBB 人体 5.68s。马模型简化 95% 时仅 1080 个三角面、654 个顶点 (图 13), 构造加快且未丢精度。
    - **紧密性 (图 14)**: 本文 OBB 紧密性优于传统 OBB 法和简化模型 OBB 法, 略低于最小体积 OBB 法 (但结合本文场景可忽略)。
    - **碰撞检测耗时 (表 3, 模型均简化 80%)**: 本文兔子 40.21 / 马 41.12 / 人体 **69.89ms**; 对 AABB-OBB (兔 59.68 / 马 59.96 / 人体 101.35ms) 缩减约 31%~32%, 相较其他国内外文献方法缩减约 3%~10%; 模型越复杂优势越明显 (图 17)。
    - **剔除率 (表 4)**: 本文兔子 **51.47%** / 马 52.66% / 人体 **56.62%**; 对 AABB-OBB (兔 43.45 / 马 44.12 / 人体 43.96%) 提升约 8~13 个百分点 (正文称比传统方法提升 8%~15%)。注: 本文剔除率与两种融合神经网络方法 (融合 OpenNN、简化模型 OBB 行) 基本持平甚至略低 (如兔子 OpenNN 51.16、简化模型 OBB 52.28; 人体 OpenNN 55.96、简化模型 OBB 56.74), 但**在剔除率持平的前提下本文速率更快**; 并行 AABB 坐标链法因用单一 AABB 剔除率不高。
    - **真实性 (图 15、16)**: 兔子/马/人体简化后构 OBB 并结合空间网格法, 交互碰撞真实且未穿透失真; 而仅用简化模型 OBB 法 (无空间网格) 会出现不同程度穿透 (图 16 对比)。
- **消融实验**: PDF 文本未明确设置独立消融表, 但真实性对比 (图 16: 简化模型 OBB vs 本文+空间网格) 可视为对"空间网格"模块的有效性验证。
- **泛化实验**: PDF 文本未明确以"泛化"命名, 但实验跨兔子、马、人体三种不同复杂度模型与三种场景, 表明方法在不同复杂模型下均有效, 且模型越复杂优势越明显。
- **效率信息总结** (摘要口径): 包围盒构建速度缩短 **10%~18%**, OBB 紧密性提升 **8%~15%**, 包围盒剔除率提升 **8%~13%**, 整体碰撞检测耗时缩短 **6%~13%**。
## 局限

1.  **实验场景有限**: 论文结论自陈"实验中刚体与布料交互的场景数量有限", 仅悬挂、随风、与球三种相对简单场景, 多人穿戴、密集堆叠等复杂场景未验证。
2.  **碰撞响应在大量模型下开销大**: 结论明确指出"对于大量模型在同一场景下进行碰撞检测时的碰撞响应性能消耗较大", 空间网格需动态构建维护, 可能成为新瓶颈。
3.  **假设依赖简化无损特征**: 方法假定刚体表面可简化且不影响主要碰撞特征, 对需要极高表面精度的场景 (如精密装配) 简化可能不适用。
4.  **未利用硬件加速**: 引言综述了 GPU 并行方法, 但本文方法本身未用 GPU, 结论也将"基于 GPU 的硬件加速"列为未来工作, 限制了超大规模场景的实时性。
5.  **自适应规则复现细节有限**: 给出了核心公式, 但混合层次包围盒树何时增球形层 (除 30%/50% 阈值外)、中间层混合占比如何随场景自适应调整, 描述不够细, 增加精确复现难度。
6.  **未来方向**: 论文提出尝试用深度神经网络预测布料粒子碰撞后位置以减少响应耗时, 并增加不同场景数据集、结合 GPU 加速。
## 个人评论

1.  **"分而治之"的异构对象策略**: 对柔性体 (布料) 和刚体 (复杂模型) 走完全不同的优化路径 (混合层次包围盒 vs 简化+OBB), 这种按对象特性差异化处理的思路对异质物体交互问题很有启发, 也比"一种包围盒打天下"更贴合工程现实。
2.  **"粗筛 + 几何约束"的分层框架**: 先用层次包围盒大规模快速剔除, 再用更密集但更精确的空间网格做最终判定与约束, 速度与精度分层平衡, 是经典而稳健的工程范式。
3.  **空间网格防穿透机制简洁**: 用面积/体积 ≥ 0 这类几何约束施加碰撞响应, 绕开了复杂的物理力求解, 简洁易实现易集成; 把"防穿透"等价为"网格不坍缩"是个漂亮的几何直觉。
4.  **诚实的对比**: 表 4 中本文剔除率与两种融合神经网络方法几乎持平甚至略低, 论文没有回避, 而是强调"剔除率持平但速率更快", 这种诚实的定位比夸大单一指标更可信。
5.  **可挑剔之处**: 创新点更多是已有技术 (QEM 简化、面积加权 OBB、时空相关剪枝、空间网格约束) 的工程化组合而非全新理论; 提升幅度 (6%~18% 量级) 属稳健改进而非数量级突破; 且全部为自定义场景、无公开 benchmark, 横向可比性有限。

# 论文精读

## 1. 论文定位
这篇论文属于**计算机图形学与虚拟现实**领域, 核心方向是**碰撞检测 (collision detection)**, 具体聚焦**柔性体布料与复杂刚体模型之间的交互模拟**。它要解决该场景下碰撞检测**速率低**和**模拟真实性差**的核心矛盾。中图分类号 TP391, 发表于《中国图象图形学报》2024 年 29(10):3144-3156。在本知识库的 CV 主题体系中没有精准对应类目, 因此归入 `T_通用_NLP_其他` (非 CV 专题的通用/跨学科桶); 若按图形学语境, 它属于"物理模拟 / 实时图形学 / VR 交互技术"。

## 2. 一句话总结
本文针对布料与复杂刚体交互, 为不同对象定制粗检测策略 (布料用球形-AABB 三层混合层次包围盒, 刚体用 QEM 三角形折叠简化模型 + 面积加权 OBB), 再用空间网格 (二维三角形/三维四面体, 约束面积体积 ≥0) 做精确检测与防穿透响应, 在缩短整体耗时 6%~13%、提升剔除率 8%~13% 的同时保证模拟真实性。

## 3. 背景与问题
- **为什么要做**: 碰撞检测是图形学/VR 的研究热点和模拟流程中的性能消耗点。布料形状不固定、运动易形变, 是典型柔性体, 与精细建模刚体 (兔子、马、人体) 交互时对真实性和实时性要求都很高; 大量粒子运动必然碰撞, 不及时检测处理就会穿透失真。
- **现有范式**: 检测分粗略阶段 (少开销快速剔除不相交碰撞对) 和精确阶段 (对碰撞对精确检测响应)。粗略阶段分空间网格法 (划分单元格, 多用于固定空间) 和包围盒法 (更适合可变形柔性体) 两类。
- **之前方法的问题**:
    1.  **单一包围盒** (椭球、最小体积 OBB、无厚度圆形等): 面对复杂模型**剔除率低、贴合性差**。
    2.  **混合/层次包围盒**: 能结合简单盒快速构建 + 复杂盒高效剔除, 但**结构复杂**, 部分场景**系统开销大、检测慢**。
    3.  **GPU 硬件加速路线** (Kim 2019、Mei 2022、Sung 2023): 性能好但**对硬件要求高**。
    4.  复杂刚体**点面数庞大**, 直接构盒与检测**效率低、开销大、易穿透**。
- **核心矛盾**: 需同时满足高实时性 (快速剔除) 与高真实性 (精确防穿透), 传统方法难两全。

## 4. 核心贡献
1.  **布料的三层混合层次包围盒树**: 顶层球形 (球心固定、布料展开最大长度为直径, 形变时无需旋转只更新球半径), 中间层球形-AABB 混合 (过渡缓冲), 底层 AABB (更新快、相交测试简单), 兼顾构建更新速度与剔除效率。
2.  **刚体先简化再构 OBB**: 基于 QEM + 三角形折叠 (Zhou 2020 / Garland-Heckbert 1997) 简化模型, 保留主要特征同时大幅减点面, 用简化模型快速构 OBB, 降开销。
3.  **面积加权改进 OBB 中心/方向**: 解决三角面片密度不均使 OBB 中心方向偏移的问题, 中心按面积加权 (式 11)、方向取顶点协方差矩阵特征向量, 更准且更省时。
4.  **空间网格法做精确检测与响应**: 碰撞区域连顶点构网格 (2D 三角形 / 3D 四面体), 由面积/体积是否为 0 判碰撞, 碰撞时约束面积体积取最小正值防穿透 (式 14-17)。
5.  **遍历路径优化**: 基于时空相关性, 父节点未碰撞则跳过整子树, 相比传统单级下降 (交集测试累计 2^(2k−1)−1 次) 大幅减节点、降开销。

## 5. 方法详解
- **整体框架**: 三阶段——布料构混合层次包围盒树初筛; 刚体简化后快速构 OBB; 在碰撞模型间构空间网格做精确检测与响应 (图 1)。
- **输入输出**: 输入布料模型 (粒子/网格) + 复杂刚体 (三角网格); 输出碰撞结果 (是否碰、位置) 与响应 (防穿透顶点约束)。
- **模块 1: 混合结构层次包围盒树 (BVTT)**:
    - 顶层固定球心球形包围盒 (布料展开最大长度为直径, 图 2); 球形/AABB 相交检测式: R1+R2 < L 且 La+Lb < L 则未相交 (图 3)。
    - 中间层球形-AABB 混合, 先球形排除再 AABB 剔除, 作过渡缓冲。
    - **自适应增层**: 根节点球形剔除率 < 30% 且待检测物体空间体积占比 < 50% 时, 再加一层球形 (源自对朱元峰等 2008 方法的调整)。
    - 底层 AABB 叶子节点, 碰撞则做底层图元检测与响应。检测步骤循环 6 步 (根球形→剔除率达阈值则直接构中间层否则加球形→中间层球形-AABB+叶子 AABB 向下遍历→叶子碰撞做基元检测响应→下一时间步重复)。
- **模块 2: 简化 + OBB**:
    - **QEM 三角形折叠**: 平面通式 p=[a,b,c,d]^T (式 1-2, 归一化 a²+b²+c²=1) → Mp=pp^T (式 3) → 面片误差矩阵 Qt=ΣMp (式 4) → 折叠误差 ε(T)=v_t^T Qt v_t (式 5) → 偏导置 0 解线性方程组求 v_t (式 6-7), 无解时取中心/边中点/顶点中误差最小者。**一次折叠减 6 边 4 面**, 优先折叠误差最小面以保特征; 兔子简化 95% 特征仍存 (图 6)。
    - **面积加权 OBB**: O_i=(x_i+y_i+z_i)/3 (式 8)、S_i (式 9)、H=ΣS_i (式 10)、**中心 O=Σ(S_i·O_i)/H** (式 11); 顶点期望 u (式 12)、协方差 C_jk (式 13), 方向取协方差特征向量, 长度为顶点集 3 方向投影。
- **模块 3: 空间网格法**:
    - 思想: 确定应变张量最小负特征值, 在对应特征向量方向施加约束力; 面积/体积为 0 时判碰, 约束迫使其取可接受最小正值, 保证存在不影响模拟的网格层防穿透。统一约束式 14: C2D=|(b−a)×(c−a)|≥0, C3D=det[a−o,b−o,c−o]≥0。
    - **2D**: 顶点依次连成三角网格 (图 8); 3 顶点中 2 个在同物体且共边则属该物体的网格; 碰撞时面积压为 0、三点共线, 用式 15 判定响应迫使面积≠0; 网格与物体重叠时断边重连构新网格 (图 8c/d)。
    - **3D**: 四面体 (三角面 3 顶点 + 另一物体 1 顶点, 图 9), 向量 a/b/c (式 16), 判式 17 的 3×3 行列式是否为 0, 为 0 则碰并使体积 > 0 防穿透。图 10 给二维顶点-边、三维顶点-面碰撞压缩示意。
- **与已有方法差异**: 不一刀切用同一包围盒, 而是布料/刚体异构策略 + 空间网格精确约束层 + 时空相关遍历剪枝, 构成"异构粗筛 + 几何约束精检"两阶段流程。
