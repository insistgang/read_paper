## 摘要

**英文原摘要（据 PDF 提取文本整理，修复了断词与空格）**：

> Tensor train decomposition is a powerful tool to tackle high-dimensional large-scale tensor data and is not suffering from the curse of dimensionality. It is based on the low-rank approximation of auxiliary unfolding matrices. To accelerate the calculation of the auxiliary unfolding matrices, some randomized algorithms have been proposed; however, they are not suitable for noisy data. The randomized block Krylov method is capable of dealing with heavy-tailed noisy data in low-rank approximation of matrices. In this paper, we propose a randomized algorithm for low-rank tensor train approximation of large-scale tensors based on randomized block Krylov subspace iteration and provide theoretical guarantees. Extensive numerical experiments on synthetic and real-world tensor data demonstrate the great performance of the proposed algorithm.

## 研究背景与动机

- **为什么做**：在机器学习、压缩感知、数据挖掘等应用中，许多大规模数据集天然以张量形式表示并呈现低秩结构。低秩张量近似的主要模型有 CP、Tucker、t-product、TT、TR 等。CP 因最优 CP 秩难求而不可靠；Tucker 比 CP 稳定但受“维度灾难”影响；相比之下 TT 分解不受维度灾难影响、更可靠，因而本文专注 TT（§1, p.2）。
- **之前方法的瓶颈**：TT 分解依赖对大型辅助展开矩阵做截断 SVD，计算代价随阶数指数增长。Huber 等[15]提出基于随机 SVD 的 TT-rSVD，比经典确定性 TT-SVD[21]快得多。但在 TT 中直接用随机投影近似展开矩阵会导致**尾能量（tail energy）过大**，且每步误差逐层累积，最终误差大于 TT-SVD（§1, p.3）。
- **关键观察**：幂迭代（power iteration）可通过减小尾能量提升随机方法精度，但简单同步幂迭代只保留 Krylov 子空间中最高阶项，受限于奇异值间隙过小的问题。Musco 等[20]提出的随机块 Krylov 子空间迭代（rBKI）实验表现更好，**不依赖奇异值间隙**，且对奇异值快速衰减时可达到接近截断 SVD 的精度；Qiu 等[23]已将块 Krylov 迭代用于 Tucker 分解并在含噪数据上验证有效（§1, p.2-3）。
- **核心矛盾**：如何在**保持随机化方法计算效率优势**的同时，**降低尾能量、提升 TT 近似精度**，特别是**增强对（重尾）含噪数据的鲁棒性**。

## 关键贡献

1.  **提出 TT-rBKI 算法**：将矩阵低秩近似中的随机块 Krylov 子空间迭代（rBKI）扩展到 TT 分解（Algorithm 3）。对比 TT-rBKI 的 Step 6 与 TT-rSVD（Algorithm 2）的 Step 4 可见：TT-rSVD 直接用高斯随机矩阵 sketch 展开矩阵 A，而 TT-rBKI 利用 Krylov 子空间构造一个更大的、**数据相关的随机投影矩阵 U**，使 sketch Y 包含数据更多主成分（§3, p.6）。
2.  **给出概率误差界**：证明 TT-rBKI 的误差上界（Theorem 4）：`∥A − P₂,…,N(A)∥ ≤ √(N−1)·η(r,p,q)·min ∥A−B∥`，其中误差因子 `η = [1 + √(r/(p−1)) + e√s/p]^{1/(2q+1)}`，`s = r+p`。由于 `1/(2q+1)` 指数随幂迭代参数 q 增大而把 η 压向 1，TT-rBKI 误差因子优于 TT-rSVD 的 `η = 1 + t√(12r/p) + ut·e√s/(p+1)`（Theorem 2）。证明思路是利用正交投影的逐层递推（Eq. 11-14）并套用 Theorem 3（Halko Corollary 10.10）的块 Krylov 误差界（§3, p.6-8）。
3.  **验证对含噪数据的鲁棒性**：用 MATLAB `awgn` 加高斯白噪声（噪声数据通常重尾），在合成五阶幂函数张量及灰度/彩色视频上表明，TT-rBKI 在所有随机化方法中重建质量最佳；噪声越大（SNR 越小），与 TT-rSVD/TT-rSI 的差距越明显（§4.2, p.15-18）。
4.  **引入 TT-rSI 作对照**：另给出一个仅用基本子空间幂迭代的简化版本 TT-rSI（Algorithm 4），它只用 Krylov 子空间最高阶信息，复杂度更低但抗噪能力弱于 TT-rBKI，从而清晰对比块 Krylov 迭代相较简单幂迭代的优势（§3, p.8）。

## 方法

- **整体框架**：TT-rBKI 是 TT 分解的随机化变体。逐层（n=1,…,N−1）计算 TT 核心时，不直接对当前辅助展开矩阵 A 做随机投影，而是先用 `A⊤A` 的多次幂构造 Krylov 子空间，取其正交基作为投影矩阵 U，再用 U 投影 A（§3, p.6-7）。
- **输入输出**（Algorithm 3）：
    - 输入：张量 `A ∈ R^{I₁×…×I_N}`，目标 TT 秩 `r = [r₁,…,r_{N−1}]`，幂迭代参数 `q`，过采样参数 `p`，`r₀=1`。
    - 输出：TT 格式核心张量 `Q₁, Q₂, …, Q_N`。
- **关键步骤**（逐字对应 Algorithm 3）：
    1.  **重塑**：`A = reshape(A, [r_{n−1}I_n, I_{n+1}…I_N])`。
    2.  **生成随机高斯矩阵** `Ω ∈ R^{(I_{n+1}…I_N)×(r_n+p)}`。
    3.  **构建 Krylov 空间** `K = [A⊤AΩ, (A⊤A)²Ω, …, (A⊤A)^q Ω]`——用 A⊤A 的逐次幂扩充初始随机方向，捕捉 A 更丰富的低秩结构。
    4.  **正交基** `[U, ∼] = qr(K, 0)`，`U ∈ R^{(I_{n+1}…I_N)×q(r_n+p)}`（经济型 QR）。
    5.  **数据相关投影** `Y = AU ∈ R^{r_{n−1}I_n × q(r_n+p)}`；`[Q, ∼] = qr(Y, 0)`，取前 `r_n` 列 `Q = Q(:,1:r_n)`。
    6.  **形成核心** `Q_n = reshape(Q, [r_{n−1}, I_n, r_n])`；并用 `A = A ×₁ Q⊤` 把张量压缩到更低维进入下一层。
    7.  **最后核心** `r_N=1`，`Q_N = reshape(A, [r_{N−1}, I_N, r_N])`。
- **与 TT-rSVD 的本质差异**：TT-rSVD（Algorithm 2 Step 4）用 `Y = AΩ`，Ω 纯随机；TT-rBKI（Algorithm 3 Step 6）用 `Y = AU`，U 来自与 A 相关的 Krylov 子空间。故 U 的列方向与 A 主成分对齐更好，Y 保留更多主信息，**减少尾能量、提升精度与稳定性**（§3, p.6）。
- **与 TT-rSI 的差异**（Algorithm 4）：TT-rSI 先 `Y = AΩ`，再做 q 轮交替幂迭代（`Ŷ_j = A⊤Q_{j−1}` → QR → `Y_j = AQ̂_j` → QR），只利用 Krylov 子空间中最高阶幂的信息；TT-rBKI 利用整个块 Krylov 空间。故 TT-rBKI 抗噪更强但复杂度略高（§3, p.8）。
- **推理流程**：给定新张量直接按上述循环即可得 TT 近似，无需训练。

- **对比方法**：TT-SVD（确定性基准）、TT-rSVD、TT-rSI、TT-rBKI（本文）。
- **评价指标**：相对误差 `ε_err = ∥A − Â∥_F / ∥A∥_F`；峰值信噪比 `ρ_psnr = 10·log₁₀(I₁I₂I₃∥Â∥²_∞ / ∥A−Â∥²_F)`；CPU 时间（p.9-10）。
- **数据集**：
    - 合成：500×500×500 指数衰减谱张量（T=50, D=1，§4.1.1，p.10-11）；五阶幂函数张量 45×45×45×45×45（N=5, h=5，§4.1.2，p.11）。
    - 真实：灰度视频 `hall-quif` 144×176×150；高光谱数据 1096×715×102；彩色视频 480×848×3×147（第 3、4 维互换使帧数落到第三维）（§4.1.3，p.12）。
- **无噪声结果**：
    - 指数衰减谱张量：TT-SVD 与 TT-rBKI 相对误差几乎相同，但 TT-rBKI 用时少得多；rank 在 30–50 区间时 TT-rSVD 精度略逊于 TT-rBKI（p.11）。
    - 幂函数张量：TT-SVD、TT-rSI、TT-rBKI 相对误差相近且明显优于 TT-rSVD；TT-rSVD 最快但精度最低（p.11-12）。
    - 灰度视频单帧（rank=10，p.13 Fig.4）：TT-SVD CPU 0.28 / PSNR 27.8149；TT-rSVD CPU 0.04 / PSNR 23.5923；TT-rSI CPU 0.10 / PSNR 27.5927；TT-rBKI CPU 0.13 / PSNR 27.7933——TT-rBKI 精度逼近 TT-SVD 而用时约其一半。
    - 彩色视频单帧（p.14 Fig.7）：TT-SVD CPU 30.72 / PSNR 33.6230；TT-rSVD CPU 2.45 / PSNR 28.4304；TT-rSI CPU 5.68 / PSNR 33.4038；TT-rBKI CPU 8.92 / PSNR 33.6205——TT-rBKI PSNR 几乎追平 TT-SVD，用时约其 1/3.4。
- **含噪声结果**（重尾噪声，§4.2，p.15-19）：
    - 噪声灰度视频单帧（5dB, rank=13，p.17 Fig.10）：含噪帧 PSNR 7.6099；TT-SVD CPU 0.29 / PSNR 22.9434；TT-rSVD CPU 0.03 / PSNR 15.4260；TT-rSI CPU 0.07 / PSNR 20.4777；TT-rBKI CPU 0.10 / PSNR 22.0651。
    - 噪声彩色视频单帧（2dB，p.18 Fig.13）：含噪帧 PSNR 11.6637；TT-SVD CPU 34.68 / PSNR 32.3626；TT-rSVD CPU 2.81 / PSNR 22.2809；TT-rSI CPU 6.59 / PSNR 30.8213；TT-rBKI CPU 10.19 / PSNR 32.1218——TT-rBKI 质量最接近 TT-SVD，用时约其 1/3（10.19 vs 34.68）。论文在 p.16 概括随机方法整体上 TT-rBKI 仅需 TT-SVD 约 1/5 CPU 时间。
- **泛化实验**：分别固定 rank 改变噪声水平（SNR）、固定噪声水平改变 rank，结论一致——噪声越大 TT-rBKI 优势越明显（Fig.8-9, Fig.11-12, Fig.14-15）。
- **计算复杂度**（Table 2，p.9）：TT-SVD `O(I^{N+1} + Σ r²I^{N−i})`；TT-rSVD `O(NsI_N)`；TT-rSI `O(I_N s q + Σ r I^{N−i} s q)`；TT-rBKI `O(I_N s²q² + Σ r I^{N−i} s²q²)`，`s = r+p`。三种随机化算法中 TT-rBKI 理论复杂度略高，但换来最佳近似质量。

## 个人评论

这篇论文最值得学习的点在于 **“把成熟的矩阵随机化数值线性代数工具（块 Krylov 迭代）创新性地适配进张量分解框架，并把鲁棒性作为一等公民”**。它的方法骨架朴素——只是把 TT-rSVD 中那个纯随机投影 Ω 换成由 `A⊤A` 多次幂张成、再 QR 正交化的数据相关投影 U——但正是这一替换同时解决了精度（更小尾能量）与抗噪（不依赖奇异值间隙）两个问题，且配有干净的逐层正交投影误差递推证明。研究思路上它提示：张量计算的瓶颈往往落在内层的矩阵 SVD，与其重造轮子，不如从数值线性代数工具箱（Nyström、结构化随机投影、Lanczos 等）里找更强的替代件。实验设计上它提醒——评估随机化张量方法时**必须纳入含噪（尤其重尾噪声）场景**，因为无噪声下 TT-rSI 与 TT-rBKI 几乎打平，差距只有在噪声下才显现。一个可深究的开放问题是：`q`、`p` 的自适应选取，以及把同样思路移植到 TR/Tucker（[23] 已做 Tucker）后的统一框架。

# 论文精读

## 1. 论文定位
本文属于**数值线性代数**与**随机化算法**的交叉领域（arXiv math.NA, MSC 68W20/15A18/15A69），聚焦**大规模高维张量数据的张量列车（Tensor Train, TT）分解的快速、鲁棒近似算法**。它要解决的核心矛盾是：经典确定性 TT-SVD 因逐层截断 SVD 而计算代价随阶数指数增长，而现有随机化 TT-rSVD 在含噪（尤其重尾）数据上精度不足、尾能量累积。论文把矩阵低秩近似里的随机块 Krylov 子空间迭代（rBKI，Musco-Musco[20]）移植进 TT，得到 TT-rBKI。适合放在“随机化张量计算 / 高维数据降维与近似”主题下。

## 2. 一句话总结
本文提出基于**随机块 Krylov 子空间迭代**的张量列车近似算法 **TT-rBKI**：用 `A⊤A` 多次幂张成、再 QR 正交化的**数据相关投影矩阵 U** 取代 TT-rSVD 中的纯随机投影 Ω，从而以远低于 TT-SVD 的计算量达到接近 TT-SVD 的精度，并对含重尾噪声的数据显著更鲁棒，且给出概率误差界。

## 3. 背景与问题
- **为什么做**：机器学习/压缩感知/数据挖掘中的大规模数据多为低秩张量。TT 分解不受维度灾难影响、比 CP/Tucker 更可靠，但核心是对大型辅助展开矩阵做截断 SVD，代价 `O(I^{N+1}+…)` 指数级（§2.2, Algorithm 1）。
- **之前方法的问题**：TT-rSVD[15] 用随机投影加速，但随机矩阵尺寸决定误差、且逐层累积，造成过大尾能量、丢失原始信息（§2.3, p.5）；简单同步幂迭代只保留 Krylov 子空间最高阶项，受限于过小的奇异值间隙；含噪时随机投影易被噪声主导。
- **核心矛盾**：在保住随机化效率的同时降低尾能量、提升精度，并继承 rBKI 在矩阵层面处理重尾噪声的能力。

## 4. 核心贡献
1.  **TT-rBKI 算法**（Algorithm 3）：用 Krylov 子空间 `[A⊤AΩ,(A⊤A)²Ω,…,(A⊤A)^qΩ]` 构造数据相关投影 U，使 sketch `Y=AU` 含更多主成分（§3, p.6）。
2.  **概率误差界**（Theorem 4）：`∥A−P₂,…,N(A)∥ ≤ √(N−1)·η·min∥A−B∥`，`η = [1+√(r/(p−1))+e√s/p]^{1/(2q+1)}`，`s=r+p, p≥4`，置信度 `(1−5t^{−p}−2e^{−u²/2})^{N−1}`；逐层正交投影递推（Eq.11-14）+ Theorem 3。
3.  **抗噪验证**：合成+真实数据、`awgn` 加噪，TT-rBKI 在所有随机化方法中重建质量最佳，噪声越大优势越明显（§4.2）。
4.  **TT-rSI 对照**（Algorithm 4）：仅用最高阶幂迭代、复杂度更低但抗噪弱，凸显完整块 Krylov 的价值（§3, p.8）。

## 5. 方法详解
- **整体**：逐层 n=1..N−1，对辅助展开矩阵 A 不直接随机投影，而是 Krylov 子空间正交基 U 投影。
- **输入**：张量 A，TT 秩 `r=[r₁,…,r_{N−1}]`，幂迭代参数 q，过采样 p，r₀=1；**输出**：核心 `Q₁,…,Q_N`。
- **逐行（Algorithm 3）**：
    1. `A=reshape(A,[r_{n−1}I_n, I_{n+1}…I_N])`；
    2. 高斯随机 `Ω∈R^{(I_{n+1}…I_N)×(r_n+p)}`；
    3. `K=[A⊤AΩ,(A⊤A)²Ω,…,(A⊤A)^qΩ]`；
    4. `[U,∼]=qr(K,0)`，`U∈R^{(I_{n+1}…I_N)×q(r_n+p)}`；
    5. `Y=AU∈R^{r_{n−1}I_n×q(r_n+p)}`，`[Q,∼]=qr(Y,0)`，`Q=Q(:,1:r_n)`；
    6. `Q_n=reshape(Q,[r_{n−1},I_n,r_n])`，`A=A×₁Q⊤`；
    7. 末核心 `Q_N=reshape(A,[r_{N−1},I_N,r_N])`，`r_N=1`。
- **机制直觉**：TT-rSVD 用 `Y=AΩ`（纯随机），TT-rBKI 用 `Y=AU`（U 与 A 相关），U 列向量更贴 A 主成分方向 ⇒ 保留更多主信息、尾能量更小、对含噪更稳（§3, p.6）。
- **vs TT-SVD**：用随机/Krylov 投影替换昂贵精确 SVD，大幅提速；**vs TT-rSVD**：Krylov 投影替换纯随机投影，精度更高；**vs TT-rSI**：用整段块 Krylov 而非仅最高阶幂，抗噪更强但复杂度略高（Table 2）。
- **推理**：直接套循环即可，无需训练。

## 6. 实验与结果
- **环境**：MATLAB + Tensor Toolbox + TT-Toolbox，AMD 5800H + 16GB。
- **指标**：`ε_err=∥A−Â∥_F/∥A∥_F`、`ρ_psnr`、CPU 时间。
- **数据**：合成 500³ 指数衰减谱张量、五阶 45⁵ 幂函数张量；真实灰度视频 `hall-quif` 144×176×150、高光谱 1096×715×102、彩色视频 480×848×3×147。

## 7. 这篇论文真正有价值的地方
价值不在“又一个新算法”，而在示范了一条可迁移的研究路径：**张量分解的瓶颈通常坐落在内层矩阵 SVD，把数值线性代数里成熟、有误差保证的工具（此处块 Krylov 迭代）精准换进去，往往能同时改善精度与鲁棒性**。关键替换只有一处——纯随机投影 Ω → 数据相关投影 U——却同时压低尾能量并获得不依赖奇异值间隙的抗噪能力，且配有干净的逐层正交投影误差递推证明。它也立了一个实验规范：评估随机化张量方法**必须含噪（尤其重尾）测试**，因为无噪声下 TT-rSI 与 TT-rBKI 几乎打平，差异只在噪声下显现。后续可探索 Nyström/结构化随机投影在张量场景的应用，以及 q、p 自适应。
