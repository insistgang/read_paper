## 摘要

**英文原摘要（据 PDF 提取文本整理，已修复空格/连字符断裂）**：

> Transformer and its variants have been widely used for medical image segmentation. However, the large number of parameter and computational load of these models make them unsuitable for mobile health applications. To address this issue, we propose a more efficient approach, the Efficient Group Enhanced UNet (EGE-UNet). We incorporate a Group multi-axis Hadamard Product Attention module (GHPA) and a Group Aggregation Bridge module (GAB) in a lightweight manner. The GHPA groups input features and performs Hadamard Product Attention mechanism (HPA) on different axes to extract pathological information from diverse perspectives. The GAB effectively fuses multi-scale information by grouping low-level features, high-level features, and a mask generated by the decoder at each stage. Comprehensive experiments on the ISIC2017 and ISIC2018 datasets demonstrate that EGE-UNet outperforms existing state-of-the-art methods. In short, compared to the TransFuse, our model achieves superior segmentation performance while reducing parameter and computation costs by 494x and 160x, respectively. Moreover, to our best knowledge, this is the first model with a parameter count limited to just 50KB. Our code is available at https://github.com/JCruan519/EGE-UNet.

## 研究背景与动机

- **为什么要做**：恶性黑色素瘤是全球增长最快的癌症之一（据美国癌症协会估计，2020 年约 100,350 例新发、超 6,500 例死亡），自动皮肤病变分割系统能帮助医生快速定位病灶、推进后续治疗。同时，移动医疗（mobile health）场景对能在资源受限设备上运行的轻量级模型有迫切需求。
- **之前方法的问题**：为提升分割精度，近期研究倾向于引入参数量/计算量更大的模块，尤其是基于 Vision Transformer（ViT）的自注意力机制——如 Swin-UNet、TransUNet（串行融合 CNN 与 ViT）、TransFuse（双路结构分别用 CNN/ViT 捕获局部与全局信息）、UTNetV2、TransBTS。这些方法**忽视了真实医疗环境中的计算资源约束**。另一方面，已有轻量模型 UNeXt（UNet+MLP）和 MALUNet（减少通道数 + 多注意力模块）虽大幅压缩参数，但**分割性能仍落后于 TransFuse 等大模型**。
- **核心矛盾**：如何在**极大降低参数量与计算量**的同时，**达到甚至超越**大模型的分割性能，从而服务于真实可用的移动医疗。
## 关键贡献

> 论文原文自述贡献为"threefold"（三点）：(1) 提出 GHPA 与 GAB 两个模块；(2) 提出极致轻量的 EGE-UNet；(3) 大量实验证明在显著更低资源下达到 SOTA。以下按技术粒度展开为 5 条。

1.  提出 **Hadamard 乘积注意力机制（HPA）**：用一个可学习权重与输入做哈达玛（逐元素）乘积，将自注意力的**二次复杂度降为线性复杂度**。
2.  在 HPA 基础上提出**分组多轴 Hadamard 乘积注意力模块（GHPA）**：沿通道维将输入等分为四组，前三组分别在高-宽（H-W）、通道-高（C-H）、通道-宽（C-W）轴上执行 HPA，从多视角高效提取信息。
3.  提出**分组聚合桥接模块（GAB）**，替代 UNet 的简单跳跃连接。它基于分组聚合融合不同尺寸的低层与高层特征，并引入解码器生成的**掩码（mask）信息**辅助融合，配合不同膨胀率卷积捕获多尺度信息。
4.  基于 GHPA 与 GAB 构建 **EGE-UNet**：参数量仅约 **50KB（0.053M）** 的极致轻量 U 型网络，专为皮肤病变分割设计。
5.  在 ISIC2017、ISIC2018 上全面实验：相比 TransFuse，**参数量与计算量分别减少 494 倍、160 倍**，性能反而更优，达到新的 SOTA；并称其为**首个将参数压到约 50KB 的轻量模型**。
## 方法

**整体框架**：EGE-UNet 基于对称编码器-解码器的 U 型架构（图 2）。编码器分 **6 个阶段**，通道数依次为 {8, 16, 24, 32, 48, 64}。前三阶段使用 kernel size = 3 的普通卷积，后三阶段使用 **GHPA** 提取多视角表示；解码器对称设置。与 UNet 的简单跳跃连接不同，EGE-UNet 在每个编码器-解码器阶段之间插入 **GAB**。模型采用**深度监督**生成不同尺度的掩码预测，这些掩码既用于损失计算，也作为 GAB 的输入之一。

**关键模块：GHPA（分组多轴 Hadamard 乘积注意力）**
- **动机**：MHSA 把输入分多头、各头分别算自注意力，可从多视角整合不同知识、提升性能，但二次复杂度使模型急剧增大。GHPA 用线性复杂度的 HPA 替代之。
- **HPA（基础单元）**：给定输入 `x` 和一个**随机初始化的可学习张量 `p`**，先用双线性插值把 `p` 缩放到与 `x` 同尺寸；再对 `p` 施加深度可分离卷积（DW），最后令处理后的 `p` 与 `x` 做**哈达玛乘积**得到输出。无需计算注意力矩阵。
- **GHPA（分组实现，见算法 1）**：沿通道维**等分为四组**。第一组在 H-W 轴、第二组在 C-H 轴、第三组在 C-W 轴上分别执行 HPA；**第四组仅对特征图施加 DW**。最后将四组沿通道拼接，再过一个 DW 整合不同视角信息。**所有 DW 的 kernel size 均为 3。**
- **作用维度**：兼顾空间（H, W）与通道（C），是一种混合维度的轻量级注意力。

**关键模块：GAB（分组聚合桥接，见图 3）**
- **输入**：低层特征、高层特征、以及深度监督生成的**掩码**三者。
- **流程**：
    1.  对高层特征施加 DW + 双线性插值，使其尺寸与低层特征对齐。
    2.  将高、低层特征**各沿通道分为四组**，把低层的一组与高层的一组拼接，得到四组融合特征。
    3.  对每组融合特征再拼接上**掩码**。
    4.  对四组分别施加 kernel size = 3、**膨胀率分别为 {1, 2, 5, 7}** 的膨胀卷积，提取不同尺度信息。
    5.  四组沿通道拼接，最后过一个 **kernel size = 1 的普通卷积**实现不同尺度特征间的交互。

**损失函数与训练**：
- 因不同 GAB 需要不同尺度的掩码，采用**深度监督**在各阶段分别计算损失：
  - 单阶段损失 `l_i = Bce(y, ŷ) + Dice(y, ŷ)`（二元交叉熵 + Dice）；
  - 总损失 `L = Σ_{i=0}^{5} λ_i · l_i`，权重 **λ_i 默认从 i=0 到 i=5 取 {1, 0.5, 0.4, 0.3, 0.2, 0.1}**。
- 深度监督仅训练时使用；推理时输入图像经编码器-解码器输出分割概率图。

**与已有方法的差异**：
- 相比 TransFuse 等基于 ViT 的方法：用线性复杂度的 GHPA 替代二次复杂度的自注意力，大幅降低计算成本。
- 相比 UNeXt、MALUNet：GHPA 通过多轴分组提供更丰富的多视角特征提取；GAB 通过分组融合 + 掩码引导 + 多尺度膨胀卷积实现更有效的多尺度聚合，从而在更小参数下取得更高性能（基线即取自 MALUNet）。
## 实验

- **数据集**：ISIC2017（2150 张皮肤镜图像）与 ISIC2018（2694 张），与先前研究一致按 **7:3** 随机划分训练/测试集。
- **实现细节**：PyTorch；单卡 NVIDIA RTX A6000；图像归一化并 resize 到 **256×256**；数据增强含水平翻转、垂直翻转、随机旋转；优化器 **AdamW**（初始学习率 0.001），调度器 **CosineAnnealingLR**（最大迭代 50、最小学习率 1e-5）；**batch size = 8，训练 300 个 epoch**。
- **评价指标**：mIoU、DSC（Dice 相似系数）；每个数据集**重复 5 次**报告均值与标准差。
- **对比方法**：UNet、UNet++、Att-UNet、UTNetV2、SANet、TransFuse、MobileViTv2、MobileNetv3、UNeXt-S、MALUNet 等。
- **主实验结果（Table 1）**：
    - **ISIC2017**：EGE-UNet **mIoU 79.81±0.10%，DSC 88.77±0.06%**；参数量 **0.053M**，GFLOPs **0.072**。相比 TransFuse（26.16M，mIoU 79.21%）性能更优，且参数量、计算量分别减少 **494 倍、160 倍**；相比 UNeXt-S（0.32M，mIoU 78.26%）**mIoU 提升 1.55%、DSC 提升 0.97%**，参数/计算仅为其 17%/72%；相比 MALUNet（0.177M，mIoU 78.78%）**mIoU 提升 1.03%、DSC 提升 0.64%**，参数/计算降至其 30%/85%。
    - **ISIC2018**：EGE-UNet **mIoU 80.94±0.11%，DSC 89.46±0.07%**，超越包括 TransFuse（mIoU 80.63%）在内的所有对比方法。
- **消融实验（Table 2，均在 ISIC2017）**：基线取自 MALUNet（6 阶段对称 U 型，通道 {8,16,24,32,48,64}，各阶段普通 3×3 卷积），基线 mIoU 76.30%、参数 0.107M、GFLOPs 0.076。
    - **(a) 宏观消融**：用 GHPA 替换基线后三层普通卷积 → mIoU 78.82%，参数降至 **0.034M**、GFLOPs 降至 0.058；用 GAB 替换跳跃连接 → mIoU 78.78%（参数 0.126M）。两模块均带来提升。
    - **(b) GHPA 微观消融**：去掉"多轴分组"改为单分支 → mIoU 降至 79.13%；不对可学习张量做 DW（仅随机初始化）→ mIoU 79.03%。两项关键设计去除后性能均下降。
    - **(c) GAB 微观消融**：去掉**掩码信息** → mIoU 降至 **78.97%（跌破 79%）**，验证掩码对引导特征融合的关键作用；把膨胀卷积换成普通卷积 → mIoU 降至 79.11%。
- **效率结论**：EGE-UNet 是**首个将参数压到约 50KB（0.053M）**且保持优异分割性能的轻量模型，GFLOPs 0.072 为对比方法中最低。
## 局限

1.  **任务与数据集局限**：仅在皮肤病变分割上验证（ISIC2017/2018 两个数据集），未证明对器官/肿瘤等其他医学分割任务或其他视觉任务的泛化能力。作者在结论中明确将"扩展到其他任务"列为未来工作。
2.  **缺实际部署验证**：论文聚焦参数/计算量的理论下降，**未给出移动设备上的真实推理速度、延迟、能耗等部署指标**；作者也承认未来才计划在真实环境部署。
3.  **极致轻量与复杂任务的平衡**：约 50KB 的模型容量可能限制其在更复杂、更大数据量或更精细分割任务上的表现，本文未予检验。
4.  **消融完备性**：仅对 GHPA、GAB 两模块做了消融，对阶段数、通道数设定、损失权重 λ_i 取值依据等设计选择缺乏系统消融与理论解释。
5.  **可复现风险**：虽已开源，但分组策略、膨胀率 {1,2,5,7} 等超参可能需随任务调整，直接迁移到新任务存在性能波动风险（提取文本未对此明确，属阅读推断）。

## 5. 方法详解
**整体框架**：对称编码器-解码器 U 型网络（图 2），编码器 6 阶段、通道 {8,16,24,32,48,64}；前三阶段普通 3×3 卷积，后三阶段用 GHPA；解码器对称。每个编码器-解码器阶段间用 GAB 取代简单跳跃连接。深度监督生成多尺度掩码预测，既算损失又作为 GAB 输入。

**GHPA**：
- 动机——MHSA 多头可多视角整合知识但二次复杂度大；用线性复杂度 HPA 替代。
- HPA——输入 `x` 与随机初始化可学习张量 `p`：先双线性插值把 `p` 调到 `x` 尺寸，再对 `p` 做 DW，最后 `x ⊙ p` 得输出，免算注意力矩阵。
- GHPA（算法 1）——沿通道四等分；第 1/2/3 组分别在 H-W / C-H / C-W 轴执行 HPA，第 4 组仅 DW；四组通道拼接后再过一个 DW 整合。所有 DW kernel=3。

**GAB（图 3）**：三输入（低层特征、高层特征、掩码）。①高层特征经 DW + 双线性插值对齐低层尺寸；②高/低层各沿通道四等分，对应组拼接成四组融合特征；③每组再拼接掩码；④四组分别用 kernel=3、膨胀率 {1,2,5,7} 的膨胀卷积取多尺度；⑤四组拼接后过 1×1 普通卷积做尺度间交互。

**损失与训练**：深度监督，单阶段 `l_i = Bce + Dice`，总损失 `L = Σ_{i=0}^{5} λ_i l_i`，λ_i 默认 {1, 0.5, 0.4, 0.3, 0.2, 0.1}（i=0→5）。

**与已有方法差异**：相对 ViT 类用线性 HPA 替二次自注意力；相对 UNeXt/MALUNet 以多轴分组 + 掩码引导融合换取更小参数下的更高性能（基线源自 MALUNet）。

## 6. 实验与结果
- **数据集/划分**：ISIC2017（2150）、ISIC2018（2694），7:3 划分。
- **实现**：PyTorch，RTX A6000 单卡，256×256，水平/垂直翻转 + 随机旋转增强；AdamW（lr 0.001）+ CosineAnnealingLR（T_max 50，min lr 1e-5）；batch 8，300 epoch。
- **指标**：mIoU、DSC，重复 5 次报告均值±标准差。
- **主结果（Table 1）**：
    - ISIC2017：EGE-UNet mIoU 79.81±0.10%、DSC 88.77±0.06%，参数 0.053M、GFLOPs 0.072；TransFuse 26.16M/11.50/79.21%/88.40%（→ 参数·计算 494×/160×，性能反超）；较 UNeXt-S mIoU +1.55%、DSC +0.97%；较 MALUNet mIoU +1.03%、DSC +0.64%。
    - ISIC2018：EGE-UNet mIoU 80.94±0.11%、DSC 89.46±0.07%，超过 TransFuse（80.63%/89.27%）等全部对比方法。
- **消融（Table 2，ISIC2017）**：基线（取自 MALUNet）mIoU 76.30%、0.107M、0.076 GFLOPs。
    - (a) +GHPA→78.82%/0.034M；+GAB→78.78%/0.126M。
    - (b) 去多轴分组→79.13%；不对张量做 DW→79.03%。
    - (c) 去掩码→78.97%（破 79%）；膨胀卷积换普通卷积→79.11%。
- **效率**：首个约 50KB（0.053M）且性能优异的轻量模型，GFLOPs 0.072 最低。
