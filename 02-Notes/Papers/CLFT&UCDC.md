## 研究背景与动机

- **为什么要做**：红外小目标检测在海上监视、预警系统、精确制导和灾难救援中有广泛应用。然而，红外小目标存在三大挑战：1）成像距离远导致目标在图像中占比极小；2）红外辐射能量衰减使目标易淹没于背景杂波和传感器噪声；3）目标稀疏导致前景与背景严重不平衡（p.1）。
- **之前方法的问题**：1）**传统方法**（如滤波法、局部对比度法、低秩稀疏矩阵恢复法）严重依赖先验知识且对超参数敏感，在复杂背景和噪声下表现不佳。2）**深度学习方法**（如基于CNN的ACM、ISNet）受限于卷积操作的局部感受野，缺乏全局信息感知能力，易将噪声误检为目标，且多次下采样后容易导致小目标丢失（p.1）。3）**纯Transformer方法**因缺乏卷积归纳偏置，对特征不明显的红外小目标效果也不理想（p.1）。
- **核心矛盾**：**局部特征提取能力**（CNN的优势）与**全局信息感知能力**（Transformer的优势）之间的矛盾，以及**网络深度**（需要提取高级语义）与**小目标保持**（避免在下采样中丢失）之间的矛盾。
## 关键贡献

1.  **设计了CLFT模块**：一种基于Transformer结构的卷积线性融合Transformer模块。它通过创新的双线性注意力模块（BAM）计算注意力矩阵，并将其与卷积/膨胀卷积提取的局部特征进行融合，从而在特征提取阶段有效增强目标特征并抑制噪声（p.2）。
2.  **设计了UCDC模块**：一种U型卷积-膨胀卷积模块，部署在网络较深层。它利用深层特征分辨率小的特点，通过“先用大感受野滤波去噪，再用小感受野精细提取”的U型结构，对深层特征进行更精细的处理（p.2, p.4）。
3.  **提出了ABC模型整体架构**：一个编码器-解码器结构，编码器由卷积模块和CLFT模块交替构成，解码器由卷积模块和UCDC模块构成，并辅以跳跃连接，实现了对红外小目标的高精度分割（p.3）。
4.  **在多个公开数据集上达到SOTA**：在NUAA、IRSTD1k、SIRSTAUG和NUDT四个数据集上，所有评估指标（IoU, nIoU, F1）均超越了现有方法（p.4, p.5）。
## 方法

- **整体框架**：ABC是一个类似U-Net的编码器-解码器结构（p.3, Fig.2）。**编码器**由一个卷积模块和三个CLFT模块组成；**解码器**由一个UCDC模块和三个卷积模块组成。编码器和解码器之间通过跳跃连接进行跨层特征融合。网络最后有一个点卷积层作为分割头输出结果。
- **输入输出**：输入为红外图像特征图 `I ∈ R^(H×W×C)`，输出为像素级的分割结果。
- **关键模块1：CLFT模块**（p.3-4）
    - **目的**：结合CNN的局部特征和Transformer的全局特征，增强目标、抑制噪声。
    - **结构**：主要包含**双线性注意力模块（BAM）**、**卷积层**、**膨胀卷积层**和**前馈层**。
    - **BAM的工作机制**（计算注意力矩阵）：
        1.  输入特征 `I` 经过两个**点卷积**层，分别得到 `I1` 和 `I2`，它们被重塑为 `q ∈ R^(HW×1)` 和 `k ∈ R^(HW×1)`。
        2.  `q` 和 `k` 经过**全连接层**后变为 `q ∈ R^(H×1)` 和 `k ∈ R^(1×H)`。
        3.  对 `q` 和 `k` 进行矩阵乘法，得到注意力矩阵 `attention ∈ R^(H×H)`，再经过点卷积和Softmax操作，得到最终的 `attention ∈ R^(H×H×C)`。公式为：`q = FC(reshape(PW(I)))`, `k = FC(reshape(PW(I)))`, `attention = softmax(PW(q ⊗ k))` (p.3)。
    - **局部特征提取**：输入 `I` 同时经过**卷积层**和**膨胀卷积层**（膨胀率2,4,2），分别得到 `Iconv` 和 `Idconv`，两者相加得到特征 `v`。公式为：`v = Conv(I) + DConv(I)` (p.4)。
    - **特征融合与输出**：将全局注意力 `attention` 与局部特征 `v` 进行矩阵乘法，得到 `O_attention`。然后将原始输入 `I`、局部特征 `v` 和 `O_attention` 进行加权求和，再经过一个前馈层（卷积+点卷积）得到最终输出 `O`。公式为：`O_attention = attention ⊗ v`, `Ô = I + v + α * O_attention`, `O = Conv(Ô) + PW(Ô)` (p.4)。这里 `α` 是一个可学习权重。
- **关键模块2：UCDC模块**（p.4）
    - **目的**：处理经过CLFT模块后、已过滤大部分噪声的深层特征（分辨率小），进行更精细的特征提取。
    - **结构**：一个U型结构，由两个卷积层和三个膨胀卷积层（膨胀率2,4,2）组成，并使用跳跃连接防止信息丢失。
    - **工作机制**：先使用**大感受野**的膨胀卷积层（膨胀率逐渐增大）处理特征图，过滤目标周围的噪声；此时目标在特征图中已极小。随后使用**小感受野**的卷积层，以更精细地提取目标特征。
- **训练方式**：使用SoftIoU损失函数，AdamW优化器，poly学习率衰减策略，并采用了**深度监督**训练策略（p.4）。
- **推理流程**：红外图像输入编码器，依次通过卷积模块和三个CLFT模块进行特征提取和增强；特征图经过跳跃连接送入解码器，先通过UCDC模块进行深层特征精细化，再通过卷积模块逐步上采样并融合，最终由点卷积头输出分割掩码。
- **与已有方法的差异**：不同于单纯并行CNN和Transformer（如RKFormer），ABC通过CLFT模块中的BAM和特征融合机制，实现了**局部和全局特征的深度交互**。UCDC模块针对红外检测任务中深层特征“干净但粗糙”的特点，进行了针对性的精细化设计，而非简单的上采样。
## 实验

- **训练方式**：使用SoftIoU损失函数，AdamW优化器，poly学习率衰减策略，并采用了**深度监督**训练策略（p.4）。
- **推理流程**：红外图像输入编码器，依次通过卷积模块和三个CLFT模块进行特征提取和增强；特征图经过跳跃连接送入解码器，先通过UCDC模块进行深层特征精细化，再通过卷积模块逐步上采样并融合，最终由点卷积头输出分割掩码。
- **与已有方法的差异**：不同于单纯并行CNN和Transformer（如RKFormer），ABC通过CLFT模块中的BAM和特征融合机制，实现了**局部和全局特征的深度交互**。UCDC模块针对红外检测任务中深层特征“干净但粗糙”的特点，进行了针对性的精细化设计，而非简单的上采样。
