## 研究背景与动机

- **为什么要做**：图像去模糊是一个重要的底层视觉任务。基于CNN的方法虽然取得进展，但其卷积操作具有空间不变性和局部性，无法有效建模图像内容的全局上下文和空间变化特性。Transformer通过全局注意力机制能建模长距离依赖，在图像去模糊中已显示出潜力。
- **之前方法的问题**：
    1.  **CNN的局限性**：卷积操作是局部操作，无法有效建模全局上下文。增大模型容量并不总能带来性能提升。
    2.  **Transformer的局限性**：传统Transformer的缩放点积注意力计算存在**二次方**的空间和时间复杂度（O(N²)），难以处理高分辨率图像。虽然现有方法（如Restormer）通过在特征深度维度计算注意力来降低复杂度，但未能充分利用空间信息。
- **作者想解决的核心矛盾**：如何在享受Transformer全局建模能力的同时，**克服其计算复杂度高的瓶颈**，并设计出更适合图像去模糊（恢复清晰细节）的特征处理模块（FFN）。
## 关键贡献

论文的具体贡献如下：
1.  **提出了高效频域自注意力求解器（FSAS）**：利用卷积定理（空间域的卷积等于频域的逐元素乘法），通过快速傅里叶变换（FFT）和逆变换（IFFT）在频域计算注意力，将注意力图的计算复杂度从O(N²)降低到O(N log N)（对每个特征通道）。
2.  **提出了判别性频域前馈网络（DFFN）**：受JPEG压缩算法启发，在FFN中引入一个可学习的量化矩阵，通过门控机制自适应地决定特征中哪些低频和高频信息应被保留，以更好地恢复清晰图像。
3.  **设计了不对称的编码器-解码器网络架构**：通过实验和分析发现，浅层特征（通常在编码器）仍包含模糊，对其应用全局注意力效果不佳；而深层特征（通常在解码器）更清晰。因此，将FSAS模块**仅用于解码器**，形成不对称架构，以优化性能。
4.  **系统分析了频域Transformer对去模糊的促进作用**：从理论和实验上证明，在频域探索Transformer特性能够有效促进模糊去除。
## 方法

- **整体框架**：提出一个端到端的、基于编码器-解码器的非对称网络（如图2a所示）。网络包含多个阶段，每个阶段由基本模块堆叠而成。**编码器**仅包含DFFN模块，而**解码器**同时包含FSAS和DFFN模块。网络采用跳跃连接，并最终通过一个全局残差连接（式8）输出恢复图像。
- **输入输出**：输入为模糊图像B，输出为估计的清晰图像I，满足 I = N(B) + B，其中N是不对称网络。
- **关键模块一：频率域自注意力求解器（FSAS）**（如图2b）
    1.  **输入**：特征图X (H×W×C)。
    2.  **计算**：先通过1x1点卷积和3x3深度卷积生成Query (Fq)和Key (Fk)特征。对Fq和Fk进行**快速傅里叶变换（FFT）**。
    3.  **核心机制**：在频域计算注意力图A。传统注意力在空间域计算QK^T（矩阵乘，O(N²)），而FSAS在频域计算：`A = F^{-1}( F(Fq) * F(Fk)^* )`，其中`F(·)`为FFT，`*`为复共轭，`F^{-1}(·)`为逆FFT。这本质上是利用卷积定理，将空间域的“相关计算”转化为频域的“逐元素乘法”，大幅降低计算量。
    4.  **输出**：对注意力图A进行LayerNorm后，与Value特征Fv进行逐元素乘法（式5），再通过1x1卷积并与原始输入X相加，得到输出X_att。
    5.  **差异**：与Restormer等空间域Transformer相比，避免了复杂的矩阵乘法，计算更高效。
- **关键模块二：判别性频域前馈网络（DFFN）**（如图2c）
    1.  **输入**：FSAS的输出特征X_att。
    2.  **核心机制**：受JPEG压缩算法启发。首先将特征图分割成8x8的块（Patch Unfolding），对每个块进行FFT变换到频域（X_f1）。然后，用一个**可学习的量化矩阵W**与频域特征X_f1进行逐元素乘法（式7），实现频率选择。这个W矩阵在网络训练中与其他参数一起学习。
    3.  **输出**：将加权后的频域特征逆变换回空间域，经过块合并（Patch Folding）和一个GEGLU激活函数处理后，与输入X_att相加，得到最终输出。
    3.  **差异**：与标准FFN（如GeLU或ReLU）不同，DFFN通过JPEG压缩的“逆过程”思想，显式地、判别性地对不同频率分量进行加权，更针对性地保留对去模糊有用的频率信息。
- **模块连接**：编码器由多个DFFN模块级联组成，解码器由多个（FSAS + DFFN）组合模块级联组成。编码器和解码器之间通过跳跃连接传递特征。
- **训练方式**：使用Adam优化器，初始学习率10^{-3}，采用余弦退火策略，最小学习率10^{-7}。损失函数沿用先前工作[4]。输入图像块大小为256x256，批大小为16。数据增强策略参考[30]。量化矩阵W的尺寸为[batch_size, channel_num, 8, 8]，与其他参数联合训练。
- **推理流程**：将整个模糊图像输入训练好的网络，直接输出清晰图像。
- **与已有方法的差异**：
    1.  与**CNN类方法**（如MIMO-Unet+）相比，引入了全局注意力（FSAS）来建模长距离依赖。
    2.  与**空间域Transformer**（如Restormer）相比，将注意力计算移到频域，降低了复杂度；同时用DFFN替代了标准FFN。
    3.  与**其他高效Transformer**（如在深度维度计算的Restormer）相比，FSAS在空间-频率域计算，能更好地利用空间信息。
    4.  **网络结构**上，采用不对称设计，将昂贵的FSAS模块仅用于解码器，是其特色。

## 局限

- **计算效率依赖FFT实现**：作者指出，PyTorch的FFT实现未优化，导致其运行时速度优势未完全体现。这依赖于深度学习框架对底层算子的支持。
- **频域操作的潜在敏感性**：频域方法对图像中的高频细节（如噪声、纹理）敏感，虽然DFFN试图进行频率选择，但在极端模糊或复杂退化情况下，其鲁棒性有待进一步验证。
- **实验设置**：消融实验结果在提供的PDF文本中未明确给出，无法直观判断各模块（FSAS、DFFN、非对称设计）的独立贡献程度。
- **数据集依赖**：方法主要在合成模糊数据集（GoPro）和真实模糊数据集（RealBlur）上验证，对于其他类型（如运动模糊、散焦模糊）或更复杂的复合模糊，其泛化性需进一步考察。
- **复现风险**：实现细节较多（如FFT/IFFT的准确使用、DFFN中JPEG相关操作的具体实现、量化矩阵W的初始化与学习），需要仔细参照作者公开的代码。

    2.  **核心机制**：受JPEG压缩算法启发。首先将特征图分割成8x8的块（Patch Unfolding），对每个块进行FFT变换到频域（X_f1）。然后，用一个**可学习的量化矩阵W**与频域特征X_f1进行逐元素乘法（式7），实现频率选择。这个W矩阵在网络训练中与其他参数一起学习。
    3.  **输出**：将加权后的频域特征逆变换回空间域，经过块合并（Patch Folding）和一个GEGLU激活函数处理后，与输入X_att相加，得到最终输出。
    3.  **差异**：与标准FFN（如GeLU或ReLU）不同，DFFN通过JPEG压缩的“逆过程”思想，显式地、判别性地对不同频率分量进行加权，更针对性地保留对去模糊有用的频率信息。
- **模块连接**：编码器由多个DFFN模块级联组成，解码器由多个（FSAS + DFFN）组合模块级联组成。编码器和解码器之间通过跳跃连接传递特征。
- **训练方式**：使用Adam优化器，初始学习率10^{-3}，采用余弦退火策略，最小学习率10^{-7}。损失函数沿用先前工作[4]。输入图像块大小为256x256，批大小为16。数据增强策略参考[30]。量化矩阵W的尺寸为[batch_size, channel_num, 8, 8]，与其他参数联合训练。
- **推理流程**：将整个模糊图像输入训练好的网络，直接输出清晰图像。
- **与已有方法的差异**：
    1.  与**CNN类方法**（如MIMO-Unet+）相比，引入了全局注意力（FSAS）来建模长距离依赖。
    2.  与**空间域Transformer**（如Restormer）相比，将注意力计算移到频域，降低了复杂度；同时用DFFN替代了标准FFN。
    3.  与**其他高效Transformer**（如在深度维度计算的Restormer）相比，FSAS在空间-频率域计算，能更好地利用空间信息。
    4.  **网络结构**上，采用不对称设计，将昂贵的FSAS模块仅用于解码器，是其特色。
