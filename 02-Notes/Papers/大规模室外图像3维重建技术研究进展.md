## 方法

本文是综述，其“方法”部分即对所回顾技术体系的详解。核心是介绍大规模室外图像3D重建的标准流水线。

*   **整体框架：** 整个重建流程被分解为四个串行的子过程：**图像检索 -> 图像特征点匹配 -> 运动恢复结构（SfM）-> 多视图立体（MVS）**。这个框架是连接所有具体技术的主线。
*   **输入输出：** 输入是一组无序的2D多视角图像；输出是场景的稠密三维点云（后续可进行表面重建和纹理映射，但本文重点在点云生成）。
*   **关键模块与连接：**
    1.  **图像检索（Image Retrieval）：** 从大量图像中找出具有场景重叠的图像对，避免无谓的全局匹配。
        *   **传统方法：** 主要基于**词汇树（Vocabulary Tree）**，通过TF-IDF和倒排文件高效计算图像相似度。缺点是建树需大量内存和调参。
        *   **连接：** 其输出是后续特征匹配阶段的图像对列表。
    2.  **图像特征点匹配（Image Feature Matching）：** 在图像对之间建立像素级对应关系。
        *   **传统方法：** 分为四步：a) **检测**（如SIFT, FAST）；b) **描述**（梯度统计描述子如SIFT, HOG，或二进制描述子如ORB, BRIEF）；c) **匹配**（最近邻搜索或图匹配）；d) **误匹配过滤**（如Lowe比率测试、RANSAC结合极线几何约束）。
        *   **连接：** 输出的特征点对应关系是SfM阶段的输入，用于估计相机位姿和3D点。
    3.  **运动恢复结构（SfM）：** 核心步骤，估计相机位姿（外参）和场景稀疏3D点云。
        *   **传统方法：** 主要分为三种范式：
            *   **增量式SfM：** 流程为：初始对选取 -> 相对位姿估计与三角化 -> 逐幅图像注册（PnP） -> 反复的**捆绑调整**优化。代表系统有VisualSfM， COLMAP。缺点是误差累积、效率低、依赖初始对。
            *   **全局式SfM：** 流程为：全局旋转估计 -> 全局平移估计 -> 三角化与一次捆绑调整。优点是能平均分配误差、效率高。缺点是平移估计对外点敏感、优化问题非凸。
            *   **分布式SfM：** 流程为：图像聚类 -> 子重建（用增量式SfM） -> 模型融合。旨在结合增量式的鲁棒性和全局式的效率，实现大规模并行重建。
        *   **连接：** 输出的相机位姿和稀疏点云是MVS阶段的输入。
    4.  **多视图立体（MVS）：** 在已知相机位姿的基础上，估计场景的稠密几何（稠密点云）。
        *   **传统方法：** 主流是**深度图融合法**，流程为：参照图像选取 -> **深度图估计**（基于光度一致性，如NCC） -> **深度图提炼**（剔除不一致深度） -> **深度图融合**（去冗余生成点云）。
*   **数学公式或机制的直观解释：** 文中提到了一些关键概念，如SfM中优化目标是最小化**重投影误差**，MVS中深度图估计是最大化图像块间的**光度一致性**（通过NCC等度量）。这些是标准的几何视觉原理。
*   **训练/推理流程：** 对于传统方法，主要是算法流程；对于深度学习方法，文中提及了CNN在特征提取、匹配、深度估计等子任务上的应用，但未深入描述具体训练细节。
