> Object detection in natural images has achieved remarkable results over the years. However, a similar progress has not yet been observed in aerial object detection due to several challenges, such as high resolution images, instances scale variation, class imbalance etc. We show the performance of two-stage, one-stage and attention based object detectors on the iSAID dataset. Furthermore, we describe some modifications and analysis performed for different models — in two stage detector: introduced weighted attention based FPN, class balanced sampler and density prediction head; in one stage detector: used weighted focal loss and introduced FPN; in attention based detector: compare single, multi-scale attention and demonstrate effect of different backbones. ## 研究背景与动机

- **为什么要做**：自然图像目标检测已取得显著进展，但航空图像目标检测受限于一系列特有挑战——**高分辨率图像、实例尺度变化巨大、类别分布不平衡、对象分布不均**——发展相对滞后。论文明确指出该问题之所以值得研究，是因为其在**国防（defence）、林业（forestry）、城市规划（city planning）**等领域具有重要应用价值（Introduction, p.1）。
- **之前方法的问题**：通用目标检测器直接应用于航空图像时性能不理想。标准 FPN 在处理航空图像中**极大幅度的尺度变化**（实例尺寸从 10×10px 到 300×300px）时仍力不从心；标准的损失函数与采样策略难以应对严重的长尾类别不平衡；模型也缺乏对实例周围**上下文/密度**信息的建模能力。
- **核心矛盾**：**通用检测器设计与航空图像特殊性之间的矛盾**。论文强调"由于模型架构差异巨大，同一种修改未必适用于所有架构"，因此选择对两阶段、一阶段、注意力三类检测器分别做针对性适配，而非提出单一新模型。

## 关键贡献

1.  **针对两阶段检测器（Faster R-CNN）的三项改进**：加权注意力 FPN、简单类别平衡采样器、密度预测头（详见下文）。
2.  **加权注意力 FPN（Weighted Attention-based FPN）**：将高分辨率特征图信息以通道注意力（受 Squeeze-Excitation 与 CBAM 启发）的形式向下传递，并为各输出特征图引入经验权重 `wt1=1.5, wt2=2, wt3=2.5, wt4=3`（即 `wt4>wt3>wt2>wt1`），以兼顾大/中/小物体（p.2-5, 图2）。
3.  **简单类别平衡采样器**：在 RoI 头中按数据集统计把类别分为 frequent/common/rare 三组，对 256 个提议中的 64 个前景按 rare 24、common 20、frequent 20 平衡采样，缓解长尾分布（p.2-4）。
4.  **密度预测头（Density Prediction Head）**：借用自 Adaptive NMS [11] 的密度预测头，但**用于不同目标**——以 5×5 卷积聚合实例周围上下文，监督信号为实例 `i` 与其它实例的最大 IoU `di := max_{j∈G, i≠j} IoU(bi, bj)`，平滑 L1 损失训练。作者声称是**首个将密度预测头用于航空图像**的工作（p.2-3, 图3）。
5.  **一阶段检测器（YOLOv5）探索**：使用加权焦点损失（调 α、γ）应对不平衡，并尝试引入 FPN 处理多尺度（p.3-5）。
6.  **基于注意力检测器（Deformable DETR）分析**：比较单尺度 vs 多尺度注意力、ResNet-50 vs ResNet-101 骨干，以及尝试使用更早的 backbone 层（p.3-5+，后者在提取缓存处被截断）。
7.  **系统性比较研究**：在 iSAID 上统一对比三类检测器，给出各自在航空场景的优缺点。

## 方法

本文在 iSAID 数据集上，对三类主流检测架构进行了应用与改进。

**1. 两阶段检测器：改进的 Faster R-CNN**
- **整体框架**：基于 **Detectron2** 框架实现，骨干为 **ResNet-101 + FPN**。在标准 Faster R-CNN（RPN + RoI pooling + 分类/回归小卷积网络）基础上做三项修改。
- **关键模块与改进**：
    - **加权注意力 FPN**（处理尺度变化）：论文先指出"小物体更易在高分辨率层 P5 识别、中物体在 P4/P3、大物体在低分辨率层 P2/P3"，据此将高分辨率特征图信息**以通道注意力的形式向下（低分辨率层）传递**（借鉴 SE-block 与 CBAM）。但该改动带来的 mAP 提升**主要体现在中、大物体**上；为同时改善小物体，又为各输出特征图加上一组小权重，经验设为 **wt1=1.5, wt2=2, wt3=2.5, wt4=3**（`wt4>wt3>wt2>wt1`）（p.2, 4-5, 图2）。
    - **类别平衡采样器**（处理长尾）：在 RoI 头按统计把类别分为 frequent/common/rare 三组。RoI 头取 **256 个提议**，其中通常 **25%（64 个）为前景**；作者确保从 **rare 选 24 个、common 与 frequent 各选 20 个**，使各组采样均衡，降低对常见类的偏置（p.2-4）。
    - **密度预测头**（建模上下文/密度，对小物体尤其有益）：放在 **RPN** 中。把分类分支、回归分支的特征图与一个 **1×1 卷积**的输出沿通道堆叠，再接一个 **5×5 卷积**聚合邻域信息。真实密度标签 `di := max_{j∈G, i≠j} IoU(bi, bj)`（实例 `i` 与其它实例的最大边框 IoU），用**平滑 L1 损失**训练。该结构源自 Adaptive NMS [11]，但本文用途不同；作者声称是首个用于航空图像的工作（p.2-3, 图3）。
- **训练设置**：批量大小 2，学习率 0.0025，动量 0.9，权重衰减 0.0001，γ=0.1，迭代 **100,000** 次（p.4）。

**2. 一阶段检测器：YOLOv5**
- **整体框架**：YOLOv5，由 **CSPDarknet 骨干 + PANet 颈部 + YOLO 检测头**组成。
- **数据处理**：
    - 将 iSAID 的 **COCO JSON 标注转换为 YOLO 所需的 TXT 格式**（每张图一份同名 txt；另用一段 JavaScript 代码把图像名替换为条目 id 生成输出 json）。
    - **背景图像减少实验**：YOLO 把未标注图像当作背景以减少误报（这与忽略此类图的其它模型不同）。训练集标注/未标注为 16384/67703，验证集 6049/22487（表1）。在分辨率 640、批量 16 下，全量一个 epoch 约 31 分钟，仅用标注图（背景置 0）则降至 6.24 分钟/epoch。表2 三组对比（5 epochs，mAP@.5:.95）：全量 84087 张 → **0.3314**（179m）；标注+10%未标注 18018 张 → **0.3448**（43m）；仅标注 16384 张 → **0.3811**（40m）。**仅用标注图既精度最高又最快**（p.5, 表1/表2）。
- **关键模块与改进**：
    - **加权焦点损失**（应对不平衡）：焦点损失有两个可调参数（论文记为 α、γ，PDF 中符号丢失）——其一增大使模型更关注难分类别，其一增大则对标注量少的类别赋更高权重。表3 最佳：(参数=2.0, 0.25) 时 mAP@.5=**0.689**、mAP@.5:.95=**0.469**；(1.5, 0.25) 时为 0.685/0.466（p.5, 表3）。
    - **引入 FPN**：受尺度变化驱动在 YOLOv5 上加 FPN，加入后验证集观察到 **mAP=0.422**（p.5）。
- **实验结果**：在分辨率 640、批量 16、50 epochs 下对比"标准 YOLOv5L / 焦点损失版 / FPN 版"（图6/图9）：精度与 mAP@.5:.95 上 **YOLOv5L 最高**；mAP@.5 上**焦点损失版更好**；**FPN 版在所有指标上最低**（p.5）。

**3. 基于注意力的检测器：Deformable DETR**
- **整体框架**：Deformable DETR [19]，结合 **DETR**（基于 Transformer 的端到端集合预测检测器，用二分匹配的集合级全局损失 + 编解码器架构，去除 NMS/anchor 等手工组件）与**可变形卷积网络 DCN [3]**（通过为采样位置学习额外偏移以增强几何变换建模），以缓解 DETR 收敛慢、小物体检测差的问题（p.3-4, 图4）。
- **关键机制**：多尺度可变形注意力只关注特征图上**一小组采样位置**（类似关注物体极值点 / 边界，并兼顾物体内部像素以判类别），在保持关系建模能力的同时实现快收敛、低计算与低内存，可视为对手工 FPN 与低效全注意力的替代（p.3-4）。
- **训练设置**：受算力限制，默认批量 6、**15 epochs**，编解码器学习率 2e-4、骨干 2e-5，每 7 个 epoch 学习率乘 0.5 衰减；平均训练时间约 **18-25 小时**（p.5）。
- **分析与改进**：
    - **单尺度（baseline）**：ImageNet 预训练 ResNet-50 骨干，取最后卷积层 7×7×2048 特征送入编解码器，mAP=**0.303**，接近 Faster R-CNN 基线（仅从零训 15 epochs）（p.5）。
    - **多尺度注意力**：编码器使用骨干 Conv3-5 层（外加 stride=2 的 Conv5），各层通道投影到 256。结果**小/中物体 mAP 提升约 20%**（因 iSAID 中小、中尺寸物体远多于大物体）；因显存开销大，批量降到 4（p.5, 图7）。
    - **骨干网络影响（ResNet-50→ResNet-101）**：单尺度时**中等物体提升约 20%、其余仅 7-9%**；多尺度时**中等物体提升约 10%、其余约 3%**。作者归因于 iSAID 分辨率更高，且 R50/R101 主要差在 Conv3 深度，故收益集中在中等物体（p.5）。
    - **更早的 backbone 层**：作为下一步修改尝试使用 CNN 更早的层——**此处提取缓存被截断（原文 31755 字符，缓存仅含前 25000，该实验结论未覆盖，待核）**。

## 实验

- **数据集**：**iSAID** [16]，专为航空图像目标检测/语义/实例分割构建。包含 **2,806** 张卫星高分辨率图像、**665,451** 个密集标注实例、**15** 个类别，沿用 MS COCO 标注格式（边框 + 像素级）。受输入尺寸限制，原图被裁成 **800×800px 重叠块**。实例尺寸范围 **10×10px ~ 300×300px**，同类内部也存在大尺度差异；图1 给出各类实例数（呈明显长尾，如 small vehicle 远多于 bridge/helicopter/roundabout 等）（p.1-2, 图1）。
- **评价指标**：**mAP**，含 mAP@.5:.95、mAP@.5。
- **主实验结果**：
    - **Faster R-CNN**（消融，验证集，图5）：逐步加入加权注意力 FPN → 类别平衡采样器 → 密度预测头，mAP 逐步上升。其中**加权 FPN 提升显著**；**类别平衡采样器再提升约 0.5 mAP**；**密度预测头对小物体提升更明显**（p.4, 图5）。
    - **YOLOv5**：减少背景图（仅用标注图）显著提升 mAP 并加快训练（0.3811 vs 0.3448 vs 0.3314，表2）；焦点损失调参（2.0, 0.25）得最佳 mAP@.5=0.689、mAP@.5:.95=0.469（表3）；加 FPN 后单独观察到 mAP=0.422，但综合对比中 FPN 版指标最低，YOLOv5L 综合较好（p.5）。
    - **Deformable DETR**：单尺度基线 mAP=0.303；多尺度注意力使小/中物体提升约 20%；换 ResNet-101 进一步提升中等物体（单尺度约 20%、多尺度约 10%）（p.5）。
- **消融实验**：主要在 Faster R-CNN 上做（图5），逐模块验证有效性。
- **效率信息**：未系统报告各模型推理速度/参数量/FLOPs；仅给出 Deformable DETR 平均训练 18-25 小时（p.5）、YOLOv5 各背景比例下每 epoch 训练时间（表1/表2，如全量 31 分钟、仅标注 6.24 分钟）。

## 局限

1.  **数据集单一**：所有实验与结论均基于 **iSAID 一个数据集**，方法在 DOTA、DIOR 等其它航空数据集上的泛化能力未验证。
2.  **训练不充分、可比性弱**：明确受算力/时间限制（论文自述 "limited time and available computing resources"），Deformable DETR 仅 15 epochs、多从零训练，YOLOv5 对比仅 50 epochs，背景实验仅 5 epochs，可能未收敛，难与已优化的公开结果公平比较。
3.  **计算成本未明**：未报告加权注意力 FPN、密度预测头等模块带来的额外参数量/FLOPs/推理时延，不利于部署评估。
4.  **部分结果未解释**：YOLOv5 加 FPN 后单独 mAP=0.422，但在三模型对比中却"所有指标最低"，论文未深入解释这一张力。
5.  **方法假设**：密度预测头依赖数据集本身有丰富的实例间空间关系，对实例稀疏场景收益可能有限。
6.  **技术报告性质**：arXiv v1、含拼写错误，更像课程项目/技术报告而非经同行评审的完整论文，结论需谨慎对待。

## 个人评论

1.  **问题驱动的领域适配范本**：论文不追求新检测器，而是清晰演示如何**针对航空图像三大痛点（尺度、不平衡、密度/上下文）**，对两阶段/一阶段/注意力三类架构分别"打补丁"。这种"一痛点一改造、按架构区别对待"的思路对工程化适配很有参考价值。
2.  **模块设计具体可操作**：加权注意力 FPN（跨尺度信息下传 + 经验权重 1.5/2/2.5/3）、类别平衡采样器（256 提议中 24/20/20 分组采样）、密度预测头（5×5 卷积 + 最大 IoU 监督）都给了可直接复刻的细节，值得借鉴。
3.  **复现友好的工程记录**：YOLOv5 的 COCO→TXT 转换、背景图像减少（仅标注图反而更快更准）、焦点损失调参等记录，是实践层面的宝贵经验。
4.  **Deformable DETR 的早期遥感验证**：较早把 Deformable DETR 用于长尾航空数据，量化了多尺度注意力与更深骨干对小/中物体的增益，为社区提供了初步基准——尽管训练轮数偏少削弱了数值说服力。
5.  **需保留批判态度**：作为技术报告，多处缺少绝对数值表与统一基准对比（很多结论以"提升约 20%"等相对量给出），且 FPN 在 YOLOv5 上的负面结果未解释；引用与复用价值高，但不宜把其数字当作 SOTA 基准。

## 1. 论文定位
本论文属计算机视觉的目标检测方向，聚焦于**航空/遥感图像中的目标检测**。它不是提出全新检测器，而是在大规模航空检测数据集 **iSAID** 上，对**两阶段（Faster R-CNN）、一阶段（YOLOv5）、基于注意力（Deformable DETR）**三类主流检测器做针对性修改与对比，应对航空图像的高分辨率、巨大尺度变化、长尾类别不平衡、实例分布不均等挑战。从内容看，它属于"通用检测器在特定领域（航空）的适配研究"，归在 `C_目标检测_通用与旋转框` 主题下是合理的——其改造对象正是通用水平框检测器（iSAID 用 COCO 式水平框标注，论文未涉及旋转框）；若库内有独立的遥感主题，归入遥感亦无冲突，此处沿用 C。

## 2. 一句话总结
本文在 iSAID 航空数据集上系统评估并改进 Faster R-CNN、YOLOv5、Deformable DETR：两阶段加入加权注意力 FPN、类别平衡采样器、密度预测头；一阶段调焦点损失并引入 FPN；注意力检测器对比单/多尺度注意力与 ResNet-50/101 骨干，给出三类检测器在航空场景下的优劣对比。

## 3. 背景与问题
- **为什么要做**：自然图像检测进展显著，但航空检测因高分辨率、尺度变化大、对象分布不均、类别不平衡等挑战而滞后；其在国防、林业、城市规划等领域应用重要（p.1）。
- **之前方法的问题**：标准 FPN 难以覆盖 10×10px~300×300px 的巨大尺度跨度；标准损失/采样无法应对长尾；模型缺乏对实例周围密度/上下文的建模。
- **核心矛盾**：通用检测器设计 vs 航空图像特殊性。作者强调"架构差异大、同一修改未必通用"，故对三类架构分别适配。

## 4. 核心贡献
1.  Faster R-CNN 三项改进：加权注意力 FPN、类别平衡采样器、密度预测头。
2.  加权注意力 FPN：高分辨率信息以通道注意力（SE/CBAM 启发）向下传递，并加经验权重 wt1=1.5/wt2=2/wt3=2.5/wt4=3。
3.  类别平衡采样器：256 提议、64 前景，rare/common/frequent 各取 24/20/20。
4.  密度预测头：源自 Adaptive NMS，5×5 卷积聚合上下文，监督信号为最大 IoU `di`，平滑 L1；自称首个用于航空图像。
5.  YOLOv5：加权焦点损失调参 + 引入 FPN；背景图像减少实验。
6.  Deformable DETR：单/多尺度注意力、ResNet-50/101 骨干、更早 backbone 层（最后一项在提取缓存中被截断）。
7.  三类检测器的统一对比研究。

## 5. 方法详解
**两阶段 Faster R-CNN（Detectron2 + ResNet-101 FPN）**
- 加权注意力 FPN：依据"小物体在高分辨率层 P5、中物体 P4/P3、大物体 P2/P3"的经验，把高分辨率特征以通道注意力向下传递；该改动主要利好中/大物体，故再为输出特征图加权（wt1=1.5, wt2=2, wt3=2.5, wt4=3）以兼顾小物体（图2）。
- 类别平衡采样器：RoI 头取 256 提议、25%（64）为前景，rare 24 + common 20 + frequent 20，平衡采样防止偏向常见类。
- 密度预测头：置于 RPN，堆叠分类/回归分支特征图与 1×1 卷积输出，接 5×5 卷积聚合邻域；GT 密度 `di := max_{j∈G, i≠j} IoU(bi,bj)`，平滑 L1（图3）。借自 Adaptive NMS [11] 但目标不同。
- 训练：batch 2、lr 0.0025、momentum 0.9、wd 0.0001、γ=0.1、100,000 iters。

**一阶段 YOLOv5（CSPDarknet + PANet + YOLO 头）**
- 预处理：COCO JSON→YOLO TXT；背景图像减少实验——训练集标注/未标注=16384/67703（表1），仅用标注图既快（6.24 vs 31 分钟/epoch）又准（表2：84087→0.3314、18018→0.3448、16384→0.3811，5 epochs，mAP@.5:.95）。
- 焦点损失调参（表3，α/γ 符号在 PDF 中丢失）：(2.0, 0.25)→mAP@.5 0.689 / mAP@.5:.95 0.469 最佳；(1.5, 0.25)→0.685/0.466。
- 引入 FPN：加入后单独观察 mAP=0.422，但三模型对比中 FPN 版各指标最低，YOLOv5L 综合最好（res 640、batch 16、50 epochs，图6/图9）。

**注意力 Deformable DETR（DETR + DCN）**
- 机制：多尺度可变形注意力只采样少量位置，关注物体极值点/边界 + 内部像素，快收敛、省算省存，替代手工 FPN 与全注意力（图4）。
- 训练：batch 6、15 epochs、enc-dec lr 2e-4、backbone lr 2e-5、每 7 epoch ×0.5 衰减；约 18-25 小时。
- 单尺度（ResNet-50，7×7×2048 特征）mAP=0.303，近 Faster R-CNN 基线；多尺度（Conv3-5 + stride-2 Conv5，投影到 256 通道）使小/中物体 +约 20%（batch 降到 4）；ResNet-101 单尺度时中物体 +约 20%、其余 7-9%，多尺度时中物体 +约 10%、其余约 3%；"更早 backbone 层"实验在提取缓存处被截断（待核）。

## 6. 实验与结果
- **数据集**：iSAID，2,806 张卫星高分辨率图、665,451 实例、15 类，COCO 式标注，裁成 800×800px 重叠块，实例 10×10~300×300px，长尾分布（图1）。
- **指标**：mAP、mAP@.5:.95、mAP@.5。
- **Faster R-CNN**（图5 消融）：加权 FPN 显著提升 → 类别平衡采样器再 +约 0.5 mAP → 密度预测头对小物体提升更明显，逐模块累积有效。
- **YOLOv5**：仅用标注图最优（0.3811 vs 0.3448 vs 0.3314，表2）；焦点损失 (2.0,0.25) 得 0.689/0.469（表3）；FPN 版综合最差，YOLOv5L 综合较好。
- **Deformable DETR**：单尺度 0.303；多尺度对小/中物体 +约 20%；ResNet-101 进一步提升中物体（单尺度约 20%、多尺度约 10%）。
- **效率**：未报告推理速度/参数/FLOPs；仅有 Deformable DETR 18-25h、YOLOv5 各背景比例的每 epoch 训练时间。
