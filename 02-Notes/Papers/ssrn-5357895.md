## 研究背景与动机

- **为什么要做**：非法建筑（unauthorized construction / illegal buildings）指未取得市政当局批准就在土地上建造的建筑（p. 209 引言定义）。随着城市快速发展，印度、中国、巴西等发展中国家的违建数量持续增加，对经济与社会稳定构成挑战。过去依赖空间数据库与航空遥感技术来遏制违建，但这些流程需要大量人力去核对数据、消耗可观资源与劳动力，且识别周期长（p. 209）。
- **之前方法的问题**：相关工作（[1]）指出传统变化检测技术——IR_MAD、变化向量分析（CVA）、主成分分析-K-means（PCA-Kmeans）——无法捕捉天线、水箱、太阳能板等细小结构的微小变化（p. 210）。基于卫星图像的方法受图像质量、重访周期长、云层遮挡、成本高等限制（p. 211, 213）；纯人工勘察则速度慢、成本高、不可靠（[13][14]）。深度学习虽提升了自动化程度，但 CNN 类方法计算开销大，且往往只能识别已存在的结构（[2]）。
- **核心矛盾**：**在城市快速扩张背景下，如何实现高效、准确、低成本、实时的违建自动化监测**，以替代资源密集的人工与传统遥感手段。论文用一篇综述来梳理近年各类技术对这一矛盾的回应。

    1.  **深度学习语义分割/目标检测**：含深度通道改进的 UNet-DB（[1]，逐像素检测建筑级与小型 PIC）、基于 YOLOv4 的 YDHNet（[2]）、多尺度卷积+CRF+非对称解码的分割模型（[3]）、改进 Mask R-CNN 估层数（[9]）、U-Net+VGGNet 编码器（[8]）。
    2.  **传统机器学习与图像处理**：K-means 聚类对多时相卫星影像做变化检测（[4]，p. 210）；结构相似性指数 SSI/SSIM + OpenCV 对无人机历史影像做对比（[6]，p. 211）；像素级模糊 XOR 算子 + GIS（[12]）。
    3.  **几何与物理模型**：基于阴影长度+太阳高度角的三角法估算建筑高度（[7][11]，p. 211–212）；基于 LiDAR 的 3D 点云分割识别被遮蔽/伪装结构（[5]，p. 211）。

- **与已有方法的差异**：综述强调融合优于单一技术——例如把对象变化检测 OBCD（用 IR-MAD）与深度学习（用形态学分析）结果合并，可同时覆盖大变化与小复杂变化（[1]，p. 210）。新型数据源如**侧视卫星图像 S2Looking**（off-nadir）能改善深度判断、减少遮挡与阴影干扰、提升配准精度，为变化检测提供新范式（[10]，p. 211–212）。

## 实验

本综述不做统一实验，而是汇总各被引论文在各自任务上的结果（散见于 II. RELATED WORK 与 Table 1）。

- **代表性数据集**：Yangzhou（扬州）无人机影像 2017–2019（[1]）、自建 31 类 14,046 张图像数据集（[2]）、Massachusetts 城市建筑数据集（[3]，据 Table 1）、Tehran 的 IRS-P5 卫星影像 + 市政数据库（[4]）、ISPRS 公共数据集（[5]）、无人机航拍影像（[6]）、Google Earth 高分影像（[7]）、广东新兴县（Xinxing County）开放数据集（[8]，据 Table 1）、GF-2 卫星影像（中国 9 城市，[9]）、S2Looking 双时相数据集（5000 对，[10]）、WorldView-3 VHR 影像（Cardiff, UK，[11]）、GeoEye-1 / IRS-P5 / QuickBird（Tehran, Iran，[12]）、日本建筑数据集（1,506 张，[13]）。
- **关键定量结果（据原文逐篇引述）**：
    - **[4]** Tehran K-means 法：共考察 343 栋建筑，识别出 19 栋在建（占 4 个月内全部建筑变化的 6%）；据市政数据当时实有 24 栋在建，故方法准确率 79%；在违建识别上"4 中识对 3"，准确率 75%。
    - **[8]** U-Net + VGGNet 编码器在小数据集上达 **89.28% 准确率、74.70% IoU**，优于标准 U-Net 与 Mask R-CNN。
    - **[11]** 阴影叠加算法（ASO，Cardiff/WorldView-3）：平均偏差降低 21%，估高准确率 80%。
    - **[12]** 像素级模糊 XOR + GIS（Tehran，三套卫星系统）：GeoEye-1、IRS-P5、QuickBird 的违建检测准确率分别为 **100%、66%、83%**。
    - **[13]** Unet_mini（语义分割 U-Net + 迁移学习 + IoT，日本 1,506 张数据集）：总体准确率 **85.88%**；Class 0（合法建筑）91.90%，Class 1（非法建筑）仅 35.51%（类别极不平衡导致违建类召回低）。
    - **[14]** 北京/上海/广州的时空传感网 + 倾斜立体相机方案：实时自动监测准确率 **>90%**，太阳能供电、无线即时报警，去除全部人工数据处理；对比 UAV 方案仅 60–70%。
    - **[2]** YDHNet（YOLOv4 + DenseNet121 + H-Swish）：以提升 mAP、召回率、F1、精度并降低参数量为目标（提取文本未给出具体数值）。
