## 摘要

## 研究背景与动机

- **为什么做**：云和云影是光学遥感影像中不可避免的干扰，严重影响影像的精确应用。准确的云检测是数据预处理的关键步骤，对提升后续地表信息提取的精度至关重要。
- **之前方法的问题**：
    1.  **通用性差**：传统规则基方法（如Fmask）通常针对特定传感器设计（如Landsat），面对日益增多的多源卫星数据，为每种影像开发独立方法效率低下（见 Table 1， p.3）。
    2.  **精度局限**：规则基方法主要依赖低层光谱和空间特征，在**亮地表（如沙漠、冰雪）区域容易误检**，对**薄云容易漏检**（p.4）。此外，这类方法对辐射定标精度依赖性强，对于缺乏星上定标能力的传感器影像，检测更具挑战性（p.4）。
- **核心矛盾**：如何设计一个**既能适配多种不同传感器和分辨率影像（通用性/可扩展性）**，又能**充分利用影像深层语义特征以克服传统方法在复杂地表和薄云条件下的精度瓶颈**的云检测方法。
## 关键贡献

1.  **提出了MSCFF深度学习模型架构**：设计了一个专用于云和云影检测的全卷积网络，其核心由**对称的编码器-解码器模块**和一个**多尺度特征融合模块**构成（p.7, p.11）。
2.  **创新了对称编解码模块的设计**：该模块借鉴SegNet思想，但通过引入**残差网络单元**和**空洞卷积**进行改进，以提取多尺度、高层次的空间特征，并扩大感受野而不显著增加计算量（p.8, p.9-10）。
3.  **设计了多尺度特征融合模块**：将编码器中六个不同尺度的特征图进行上采样和拼接，然后通过卷积层进行融合，充分利用了从局部细节到全局上下文的多尺度信息用于最终预测（p.6, p.11）。
4.  **构建了全球高分辨率云检测验证数据集**：收集并整理了来自全球不同区域、多种传感器（包括Landsat、高分、Sentinel-2等）、多种地表覆盖类型、包含云和云影标签的影像数据集，并已公开（p.2, p.5）。
5.  **验证了方法的通用性与优越性**：在包含多种传感器的全球数据集上进行实验，结果表明该方法在精度上优于传统的规则基方法和现有的深度学习模型，特别是在亮地表区域（p.2, p.5）。
6.  **实现了端到端的像素级预测**：网络输出是与输入同尺寸的云和云影概率图，通过外部二值化分类器获得最终掩膜，避免了依赖图像分割预处理（p.5-6, p.8）。
## 方法

- **整体框架**：方法分为**模型训练**和**模型测试**两个阶段（见 Fig. 1, p.6）。训练阶段学习模型参数；测试阶段用预训练模型对影像逐块预测，得到云和云影图。
- **输入输出**：
    - **训练输入**：经过预处理的256×256影像块及其对应的云、云影二值标签。
    - **训练输出**：优化的网络参数。
    - **推理输入**：经过同样预处理的影像（可被分割成不同大小的重叠块）。
    - **推理输出**：两张与输入影像块同尺寸的特征图，分别表示云和云影的概率（值在0到1之间），再通过外部二值化得到最终掩膜（p.6-7）。
- **关键模块**：
    1.  **数据预处理**：对影像进行归一化，将其值域缩放到[0,1]。对于能准确辐射定标的影像（如Landsat），使用大气顶反射率；否则使用最大值归一化，以保留原始光谱信息并统一不同源数据格式（p.7）。
    2.  **对称编解码模块**：
        - **编码器**：由一系列“CBRR块”（包含卷积层、批归一化、ReLU和残差连接）组成。前三个CBRR块后接**最大池化层**（2×2, 步长2）进行下采样；后两个CBRR块使用**空洞卷积**（膨胀率分别为2和4）代替池化，以在不降低特征图分辨率的情况下指数级扩大感受野，提取更强的多尺度特征并保留细节（p.9-10）。
        - **解码器**：结构与编码器对称，使用**反卷积层**进行上采样，逐步恢复特征图尺寸。编码器和解码器对应尺度的特征图通过**跳跃连接**进行元素相加，帮助保留空间细节（p.11）。
    3.  **多尺度特征融合模块**：将解码器中**六个不同尺度**的特征图（包括跳跃连接和解码器输出）全部**上采样到相同尺寸**，然后在通道维度上**拼接**，最后通过卷积层进行特征融合，生成最终的预测图（p.6, p.11, Fig. 2）。
- **模块间连接**：输入影像进入编码器，编码器提取的多尺度特征通过跳跃连接传递给解码器。解码器输出的特征与跳跃连接的特征融合后，再经过多尺度特征融合模块，生成最终的云和云影概率图。
- **数学公式/机制直观解释**：
    - **卷积层**：输出特征图 `Y_i = W_i * X + b_i`，其中`*`为离散卷积算子。所有卷积核大小为3×3，并通过零填充保持输出尺寸（p.8）。
    - **空洞卷积**：在卷积核元素间插入“空洞”（膨胀率），以指数级增大感受野 `R = (2^(d+1)-1) × (2^(d+1)-1)`（d为层深度），而不增加参数（p.9-10）。
    - **残差连接**：引入恒等映射 `y = F(x) + x`，缓解深层网络梯度消失，使网络更易训练（p.8）。
- **训练方式**：通过最小化模型预测值与二值标签之间的**损失函数**，迭代优化模型参数（p.6）。具体损失函数未在提供文本中说明。
- **推理流程**：1) 影像预处理；2) 将影像裁剪成相互重叠的图块（如256×256）；3) 逐块输入预训练的MSCFF模型，得到云和云影概率图；4) 对概率图应用外部**二值分类器**（如阈值处理）生成二值掩膜；5) 将重叠图块的掩膜拼接成完整影像的最终掩膜（p.6-7）。
- **和已有方法的差异**：
    1.  **网络类型**：本文的MSCFF是**全卷积网络**，输出像素级映射；而先前的一些深度学习方法（如Mateo-García et al., 2017; Xie et al., 2017）使用全连接层，为整个图像块输出一个类别标签（p.8）。
    2.  **特征利用**：本文通过设计的模块，显式地进行**多尺度特征的提取与融合**，而传统方法和早期深度学习方法可能未能充分、系统地利用多尺度信息。
    3.  **通用性**：本文在模型设计和数据集构建上都面向**多传感器、全球范围**，而大多数现有方法针对特定影像类型和区域（p.4-5）。
- **论文类型特化（遥感类）**：本文聚焦于遥感影像分割任务中的**云/云影检测**。其关键点包括：处理**多种模态和分辨率**的输入数据、设计能够适应不同空间尺度特征的网络结构、以及构建全球分布的验证数据集以评估泛化能力。方法强调在**复杂地表（如亮地表）** 和**薄云**条件下的鲁棒性。

    - **推理输出**：两张与输入影像块同尺寸的特征图，分别表示云和云影的概率（值在0到1之间），再通过外部二值化得到最终掩膜（p.6-7）。
- **关键模块**：
    1.  **数据预处理**：对影像进行归一化，将其值域缩放到[0,1]。对于能准确辐射定标的影像（如Landsat），使用大气顶反射率；否则使用最大值归一化，以保留原始光谱信息并统一不同源数据格式（p.7）。
    2.  **对称编解码模块**：
        - **编码器**：由一系列“CBRR块”（包含卷积层、批归一化、ReLU和残差连接）组成。前三个CBRR块后接**最大池化层**（2×2, 步长2）进行下采样；后两个CBRR块使用**空洞卷积**（膨胀率分别为2和4）代替池化，以在不降低特征图分辨率的情况下指数级扩大感受野，提取更强的多尺度特征并保留细节（p.9-10）。
        - **解码器**：结构与编码器对称，使用**反卷积层**进行上采样，逐步恢复特征图尺寸。编码器和解码器对应尺度的特征图通过**跳跃连接**进行元素相加，帮助保留空间细节（p.11）。
    3.  **多尺度特征融合模块**：将解码器中**六个不同尺度**的特征图（包括跳跃连接和解码器输出）全部**上采样到相同尺寸**，然后在通道维度上**拼接**，最后通过卷积层进行特征融合，生成最终的预测图（p.6, p.11, Fig. 2）。
- **模块间连接**：输入影像进入编码器，编码器提取的多尺度特征通过跳跃连接传递给解码器。解码器输出的特征与跳跃连接的特征融合后，再经过多尺度特征融合模块，生成最终的云和云影概率图。
- **数学公式/机制直观解释**：
    - **卷积层**：输出特征图 `Y_i = W_i * X + b_i`，其中`*`为离散卷积算子。所有卷积核大小为3×3，并通过零填充保持输出尺寸（p.8）。
    - **空洞卷积**：在卷积核元素间插入“空洞”（膨胀率），以指数级增大感受野 `R = (2^(d+1)-1) × (2^(d+1)-1)`（d为层深度），而不增加参数（p.9-10）。
    - **残差连接**：引入恒等映射 `y = F(x) + x`，缓解深层网络梯度消失，使网络更易训练（p.8）。

- **和已有方法的差异**：
