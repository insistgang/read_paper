## 摘要

本文系统地量化评估了Grad-CAM、Grad-CAM++和Eigen-CAM三种常用XAI方法在乳腺X光片（乳腺癌）检测任务中的定位准确性，发现这些方法在相当一部分实例中未能准确解释模型的决策过程。
## 研究背景与动机

- **为什么要做**：深度学习（DL）模型在医学影像诊断（如乳腺癌检测）中表现优异，但其“黑盒”特性引发信任和安全担忧。可解释人工智能（XAI），特别是基于显著性图（Saliency Map）的方法，被广泛用于解释DL模型，但这些方法的有效性缺乏定量评估，多是定性或选择性展示。
- **之前方法的问题**：既往研究对XAI方法的评价主要是定性的（如展示热力图与病灶是否大致吻合），缺乏客观、定量的性能评估。这使得难以判断这些方法在多大程度上可靠地揭示了模型的决策依据。
- **作者想解决的核心矛盾**：XAI方法在医学影像中应用日益普遍，但其**解释的忠实度（faithfulness）和定位的准确性**与临床应用要求之间可能存在巨大差距。本文旨在通过定量评估来揭示这一矛盾。
## 关键贡献

1.  **构建了平衡的乳腺癌数据集**：基于三家医疗机构的数据，构建了一个包含1496例癌症阳性和1496例阴性病例的平衡数据集，并有专家标注的边界框作为地面真值。
2.  **使用改进的深度学习模型**：采用在ImageNet上预训练的ResNet50模型，修改为双通道输入（同时输入MLO和CC视图）和Sigmoid输出层，进行二元分类。
3.  **系统评估三种主流XAI方法**：定量评估了Grad-CAM、Grad-CAM++和Eigen-CAM在乳腺癌检测任务中的性能。
4.  **采用Pointing Game作为定量评估指标**：将XAI评估转化为一个客观问题——显著性图的最大激活点是否落在专家标注的病灶边界框内。
5.  **提供了实际性能基准**：研究发现，即使在模型预测正确的样本上，这三种方法的Pointing Game分数也仅为0.31至0.41，表明其解释能力有限，为领域内XAI方法的有效性提供了重要的基准数据。
## 方法

- **整体框架**：研究流程包括数据准备、深度学习模型训练、XAI方法应用和XAI性能定量评估四个阶段（如图1所示）。
- **输入与输出**：
    - **输入**：同一患者的MLO（中侧斜位）和CC（头尾位）两张乳腺X光片，经过预处理后形成2通道、512x512像素的输入。
    - **模型输出**：一个0到1之间的概率值，表示该患者患有乳腺癌的可能性。
    - **XAI输出**：针对输入图像生成的显著性热力图（Saliency Map）。
- **关键模块与连接**：
    1.  **图像预处理**：使用自定义算法裁剪掉乳腺组织周围的空白区域，并填充/重采样至统一尺寸（512x512），由放射科医生确认裁剪有效性。
    2.  **深度学习模型**：采用**修改的ResNet50**。关键修改包括：（a）**双输入通道**，分别输入MLO和CC视图，以融合互补信息；（b）将最后的全连接层替换为**线性层+Sigmoid激活函数**，用于二元分类和输出概率。
    3.  **XAI方法**：
        - **Grad-CAM**：利用最终卷积层的梯度信息，生成类激活图，高亮对网络输出影响最大的输入区域。其作用维度是**空间维度**，关注最后一层。
        - **Grad-CAM++**：是Grad-CAM的扩展，考虑**多层和多节点信息**，能捕获特征图中的多模态行为，可能提供更详细的解释。
        - **Eigen-CAM**：对最终卷积层特征图的空间维度进行**特征分解（Eigendecomposition）** 来生成激活图，能处理特征图中的负值。
    - 这三种方法都是**事后（post-hoc）** 的、**基于梯度或特征分解**的可视化解释方法，无需修改模型结构。
    4.  **评估模块（Pointing Game）**：评估显著性图与专家标注边界框的对齐程度。计算显著性图中最大激活值的位置是否落在边界框内（允许一个τ=15像素的偏移）。
- **训练方式**：
    - 损失函数：交叉熵损失。
    - 优化器：Adam。
    - 学习率策略：StepLR调度器，初始学习率0.0001，每20个epoch衰减为原来的0.5倍。
    - 训练周期：100个epoch。
    - 批大小：16。
    - 数据增强：随机转置、翻转、平移、缩放、旋转。
- **推理流程**：输入一对MLO/CC图像，模型输出癌症概率。对于癌症阳性病例，提取训练好的模型最后一层卷积特征图，分别应用三种XAI方法生成显著性热力图。最后，使用Pointing Game规则评估热力图最大点与专家边界框的匹配情况。
- **和已有方法的差异**：与大量只做定性展示XAI热力图的研究不同，本文的核心差异在于**系统性地使用定量指标（Pointing Game Score）** 来评估XAI方法的定位准确性，而非主观判断。
## 实验

- **数据集**：来自三家中心的回顾性数据，最终研究样本包含2992名女性（中位年龄49岁）。1496名有病理证实的乳腺癌，1496名BI-RADS 1/2分（阴性）或良性病变。按75%/25%划分为开发集（2244人）和测试集（748人）。
- **对比方法**：本文评估的是三种XAI方法（Grad-CAM, Grad-CAM++, Eigen-CAM）之间的性能，并将它们与专家标注的地面真值进行对比。文中未与其他XAI方法（如LIME、SHAP）进行对比。
- **评价指标**：
    - 模型性能：召回率、精确率、准确率、F1分数。
    - XAI性能：**Pointing Game Score**。公式为：Score = T / (T + F)，其中T是最大激活点落在边界框内的准确实例数，F是不准确的实例数。
- **主实验结果**：
    - 深度学习模型在测试集上的性能：**召回率69%，精确率88%，准确率80%，F1分数0.77**。
    - XAI方法在测试集所有癌症患者中的Pointing Game Score：**Grad-CAM 0.41, Grad-CAM++ 0.30, Eigen-CAM 0.35**。
    - 在模型预测正确的（真阳性）癌症患者中，分数略有提升：**Grad-CAM 0.41, Grad-CAM++ 0.31, Eigen-CAM 0.36**。
    - 统计检验（Kruskal-Wallis测试）显示三种方法间无显著差异。

## 局限

- **方法适用场景**：基于显著性的XAI方法可能不适合需要精确定位微小病灶（如微钙化）或病灶边界模糊的场景，本研究结果已暗示其定位精度有限。
- **实验充分性**：评估仅使用了Pointing Game这一种指标，可能无法全面反映XAI方法的其他方面（如稳定性、对比类敏感性）。模型性能（召回率69%）本身不算特别高，可能影响XAI评估的上限。
- **数据集**：尽管构建了平衡数据集，但数据来源于单一大学医院系统（尽管有三个中心），可能存在选择偏倚。数据集规模（~3000例）在当今深度学习标准下不算特别大。
- **计算成本**：PDF文本中未明确说明模型训练和XAI生成的计算开销。
- **假设依赖**：评估严重依赖于三位放射科专家共识绘制的边界框作为“黄金标准”，但病灶的精确边界本身可能存在主观性。
- **复现风险**：专家标注耗时且需要专业知识，复现成本较高。图像预处理的具体算法细节未完全公开。
