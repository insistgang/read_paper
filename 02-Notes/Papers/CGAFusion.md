## 研究背景与动机

- **为什么要做：** 雾天图像的视觉质量严重下降，影响后续高层视觉任务，因此需要有效的去雾算法。基于深度学习的端到端方法已成为主流。
- **之前方法的问题：** 1) 普通的香草卷积在特征提取时没有融入任何先验知识（如暗通道先验、梯度先验），限制了其表达能力和建模能力。2) 现有方法大多只关注**图像层面**的雾气分布不均（厚雾/薄雾），而忽略了**特征层面**不同通道中编码的雾气信息的不均匀性，这导致了特征利用效率不高。
- **核心矛盾：** 如何在不显著增加模型复杂度和计算成本的前提下，有效地将传统图像处理中的有用先验（如梯度信息）融入深度神经网络，并同时处理图像和特征两个层面的不均匀性问题。
## 关键贡献

1.  **设计了细节增强卷积（DEConv）：** 它包含五个并行的卷积层（一个香草卷积VC和四个差分卷积：中心差分卷积CDC、角度差分卷积ADC、水平差分卷积HDC、垂直差分卷积VDC），首次将差分卷积引入图像去雾任务。DEConv能够将梯度等先验信息显式编码到卷积层中，增强特征表示能力。通过重参数化技巧，可以在推理阶段将DEConv等效转换为一个标准卷积，**没有额外的参数和计算开销**。
2.  **提出了内容引导注意力（CGA）机制：** CGA是一个两步注意力生成器，能够为特征图的**每个通道**生成一个独特的空间重要性图（SIM）。它首先利用空间和通道注意力生成粗略的SIM，然后利用输入特征的“内容”来指导，细化出精细的、通道特定的SIM。这能同时应对图像级和特征级的不均匀性。
3.  **提出了基于CGA的融合方案：** 利用CGA模块来自适应地融合编码器部分的低层特征和对应的高层特征，解决感受野不匹配问题，增强信息流和梯度流。
4.  **构建了完整的DEA-Net：** 结合DEConv和CGA，构建了一个名为DEA-Net的端到端去雾网络，在多个基准数据集上取得了SOTA性能，以仅3.653M的参数量在SOTS-indoor数据集上将PSNR提升至超过41dB。
## 方法

### 整体框架
DEA-Net是一个**三层次的编码器-解码器架构**，如图2(a)所示。它由三部分组成：**编码器部分**、**特征变换部分**和**解码器部分**。核心的特征变换部分使用堆叠的**细节增强注意力块（DEAB）**来学习无雾特征。在编码器和解码器中使用的是**细节增强块（DEB）**，它是DEAB的简化版（不含CGA模块）。

### 输入与输出
- **输入：** 雾天图像 `I ∈ R^{3×H×W}`
- **输出：** 恢复后的无雾图像 `J ∈ R^{3×H×W}`

### 关键模块
1.  **细节增强卷积（DEConv）：**
    - **结构：** 由5个并行的3×3卷积层构成（图3）：1个香草卷积（VC）和4个差分卷积（CDC, ADC, HDC, VDC）。
    - **机制：** 香草卷积获取强度级信息。差分卷积通过计算像素对之间的差值来显式编码先验信息。例如，**水平差分卷积（HDC）**（图4）通过计算水平相邻像素的差值，将水平梯度先验编码到卷积核中，生成的等效核类似于Sobel等传统边缘检测算子。各卷积的输出特征图被直接相加。
    - **重参数化：** 在训练完成后，利用卷积的线性可加性，将5个并行卷积的权重对应位置相加，合并成一个标准的3×3卷积核 `K_cvt`（公式1，图5）。这使得推理时DEConv的计算成本与一个标准卷积完全相同。
    - **与已有方法的差异：** 不同于仅使用香草卷积或通过增加网络深度/宽度来提升性能，DEConv将领域先验（梯度）直接嵌入卷积操作本身，在保持效率的同时增强了特征提取的针对性。

2.  **内容引导注意力（CGA）：**
    - **作用维度：** CGA作用于空间和通道维度，生成**通道特异性的空间注意力图**。
    - **机制（两步生成）：**
        a. **粗略生成：** 对输入特征图，分别应用空间注意力（如[19]）和通道注意力（如[20]）模块，生成初始的（粗略的）空间重要性图（SIM）。
        b. **精细细化：** 利用输入特征图**每个通道**的“内容”信息，对粗略SIM进行细化，为每个通道生成一个唯一的、精细的SIM。这确保了模型能够关注每个通道中特征编码的独特重要区域。
    - **可插入性：** 论文强调CGA作为一个通用的基础模块，可以插入到各种网络中用于提升性能。
    - **计算量 vs 效果：** CGA增加了额外的计算步骤（两个注意力模块及细化操作），但论文认为其带来的性能提升是显著的，并通过U-net结构在低分辨率空间进行主要计算来平衡效率。

3.  **细节增强注意力块（DEAB）与细节增强块（DEB）：**
    - **DEB（图2(b)）：** 结构为 `DEConv -> 3×3 Conv -> ReLU -> DEConv -> 3×3 Conv -> ReLU`，并有一个跳跃连接（元素相加）。
    - **DEAB（图2(c)）：** 在DEB的基础上，增加了CGA模块和另一个跳跃连接。具体为 `DEConv -> 3×3 Conv -> ReLU -> CGA -> (与输入相乘) -> DEConv -> 3×3 Conv -> ReLU`。

4.  **基于CGA的融合方案（图2(d)）：**
    - **目的：** 融合编码器的低层特征 `F_low` 和解码器对应的高层特征 `F_high`。
    - **机制：** 使用CGA模块处理低层特征 `F_low`，生成一个权重图 `W`。然后通过 `F_fused = F_low * W + F_high * (1 - W)` 进行自适应融合，而不是简单的相加或拼接，以解决感受野不匹配问题。

### 模块连接
整体网络流程（图2(a)）：输入雾图经过编码器逐步下采样，提取特征 `F1, F2`，然后进入由多个DEAB组成的特征变换部分进行深度处理得到 `F3`，最后经过解码器逐步上采样并融合（使用CGA融合方案）恢复细节，输出无雾图。DEB块部署在编码器和解码器，DEAB块部署在核心的特征变换部分。

### 训练方式
- 训练阶段，网络中的DEConv作为五个独立的并行卷积进行训练和梯度更新。
- 损失函数：论文中未在提供的文本中明确说明（PDF文本中未找到），但从图像去雾任务的一般做法推断，应为像素级的L1或L2损失。

### 推理流程
- 推理阶段，首先通过重参数化技巧，将网络中所有DEConv块的五个卷积核合并为一个标准卷积核，从而将DEAB/DEB简化为包含标准卷积的结构。
- 然后，用这个轻量化后的网络进行前向传播，快速得到去雾结果。重参数化加速了训练和测试过程。

1.  **思想融合：** 将传统图像处理中的**先验知识**（梯度）以可学习的方式无缝嵌入到深度神经网络的卷积操作中（DEConv），并解决了由此带来的参数和计算量问题。这种“重新设计卷积核”的思路对做底层视觉任务（如去噪、超分）的研究者很有启发。

    - **与已有方法的差异：** 不同于仅使用香草卷积或通过增加网络深度/宽度来提升性能，DEConv将领域先验（梯度）直接嵌入卷积操作本身，在保持效率的同时增强了特征提取的针对性。

2.  **内容引导注意力（CGA）：**
    - **作用维度：** CGA作用于空间和通道维度，生成**通道特异性的空间注意力图**。
    - **机制（两步生成）：**
        a. **粗略生成：** 对输入特征图，分别应用空间注意力（如[19]）和通道注意力（如[20]）模块，生成初始的（粗略的）空间重要性图（SIM）。
        b. **精细细化：** 利用输入特征图**每个通道**的“内容”信息，对粗略SIM进行细化，为每个通道生成一个唯一的、精细的SIM。这确保了模型能够关注每个通道中特征编码的独特重要区域。
    - **可插入性：** 论文强调CGA作为一个通用的基础模块，可以插入到各种网络中用于提升性能。
    - **计算量 vs 效果：** CGA增加了额外的计算步骤（两个注意力模块及细化操作），但论文认为其带来的性能提升是显著的，并通过U-net结构在低分辨率空间进行主要计算来平衡效率。

3.  **细节增强注意力块（DEAB）与细节增强块（DEB）：**
    - **DEB（图2(b)）：** 结构为 `DEConv -> 3×3 Conv -> ReLU -> DEConv -> 3×3 Conv -> ReLU`，并有一个跳跃连接（元素相加）。
    - **DEAB（图2(c)）：** 在DEB的基础上，增加了CGA模块和另一个跳跃连接。具体为 `DEConv -> 3×3 Conv -> ReLU -> CGA -> (与输入相乘) -> DEConv -> 3×3 Conv -> ReLU`。

4.  **基于CGA的融合方案（图2(d)）：**
    - **目的：** 融合编码器的低层特征 `F_low` 和解码器对应的高层特征 `F_high`。
    - **机制：** 使用CGA模块处理低层特征 `F_low`，生成一个权重图 `W`。然后通过 `F_fused = F_low * W + F_high * (1 - W)` 进行自适应融合，而不是简单的相加或拼接，以解决感受野不匹配问题。

### 模块连接
整体网络流程（图2(a)）：输入雾图经过编码器逐步下采样，提取特征 `F1, F2`，然后进入由多个DEAB组成的特征变换部分进行深度处理得到 `F3`，最后经过解码器逐步上采样并融合（使用CGA融合方案）恢复细节，输出无雾图。DEB块部署在编码器和解码器，DEAB块部署在核心的特征变换部分。

### 训练方式
- 训练阶段，网络中的DEConv作为五个独立的并行卷积进行训练和梯度更新。
- 损失函数：论文中未在提供的文本中明确说明（PDF文本中未找到），但从图像去雾任务的一般做法推断，应为像素级的L1或L2损失。

### 推理流程

- 然后，用这个轻量化后的网络进行前向传播，快速得到去雾结果。重参数化加速了训练和测试过程。
