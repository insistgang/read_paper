> In this paper, we address the issues of insufficient accuracy and frequent identity switching in the multi-target tracking algorithm DeepSORT by proposing two improvement strategies. First, we optimize the appearance feature extraction process by training a lightweight appearance extraction network (OSNet) on a vehicle re-identification dataset. This makes the appearance features better suited for the vehicle tracking model required in our paper. Second, we improve the metric of motion features by using the GIOU metric in place of the original IOU distance metric. The optimized tracking algorithm using GIOU achieves effective improvements in tracking precision and accuracy. This allows for the stable tracking of vehicles and reduces the occurrence of the identity-switching phenomenon to a certain extent.

## 研究背景与动机

- **为什么做**：车辆检测与跟踪是自动驾驶与智能交通系统（ITS）的关键技术，目标是让系统在视频序列中分析理解车辆行为、获取语义信息，从而在少/无人工干预下完成检测跟踪，提升道路安全与通行效率。多目标跟踪（MOT）是计算机视觉的基础任务，广泛用于自动驾驶、监控、行为识别。
- **之前方法的问题**：传统跟踪方法（Mean Shift、KCF 等相关滤波、角点检测、SIFT/SURF、卡尔曼滤波等运动模型法）依赖手工特征，在简单场景有效，但在外观变化、遮挡、复杂动态场景下表现不佳。深度学习方法虽成为主流，但经典 DeepSORT 的预训练外观模型是针对**行人**设计的，直接用于**车辆**时辨别力不足；在车辆密集、外观高度相似的交通流中容易出现身份混淆与频繁切换。
- **核心矛盾**：如何在保证实时性的前提下，提升跟踪对车辆外观的辨别能力，并改进运动状态匹配机制，实现复杂交通场景下多车辆的稳定、准确跟踪。
- **引言中综述的相关工作**（提取文本明确给出）：Bae 等[10] 深度外观学习 + 在线迁移学习；Kim 等[11] 将状态估计/轨迹管理/杂波抑制等纳入贝叶斯递归的在线 MOT；Yang 等[12] 把压缩感知特征用于 MDP 跟踪框架（结合压缩跟踪与光流、卡尔曼预测，用 P-N 学习更新判别外观模型）；Qiu 等[13] 改进 GMM + 稀疏去噪自编码器（DAE）的车辆跟踪；Wang 等[14] 基于无监督学习的孪生相关滤波跟踪（多帧验证 + 代价敏感损失）；Lee 等[15] 改进 EfficientNet 主干 + FPN 特征融合的单目 MOT，在 UA-DETRAC 上超越多数 SOTA 且推理快；Peng 等[16] 约束神经架构搜索（Constrained-NAS）做多模态融合 MOT，KITTI 上精度 89.59%、延迟 < 80 ms。

## 关键贡献

1.  **优化外观特征提取**：用在车辆重识别（re-ID）数据集上训练的轻量级网络 **OSNet** 替换 DeepSORT 中针对行人识别的外观特征提取网络（将原本为行人识别设计的目标特征提取网络迁移并重训为车辆重识别网络），使特征更适配车辆跟踪。
2.  **改进运动特征度量**：将 DeepSORT 中原始的 **IOU 距离度量替换为 GIOU**（广义交并比）度量，提升运动状态匹配的准确性。
3.  **优化目标检测器**：针对复杂交通场景对 **YOLOv8** 检测算法做四项改进——(1) 用轻量级 **FasterNet** 替换部分主干以提速；(2) 引入无参数注意力 **SimAM** 增强重要车辆特征；(3) 新增 **160×160 小目标检测头** 提升小车检测精度；(4) 引入 **WIOUv1** 损失优化边界框回归。
4.  **验证模型有效性**：在转换后的 **UA-DETRAC** 跟踪数据集上实验，改进后模型 **MOTA、IDF1 分别提升 4.6%、5.9%**，有效减少 ID 切换。

## 方法

### 整体框架
框架分为**车辆检测**与**多目标跟踪**两部分，采用 Tracking-by-Detection 范式。先用改进 YOLOv8 对视频帧检测出车辆框与置信度；再将检测结果送入改进 DeepSORT 跟踪器，跟踪器融合**外观特征**（OSNet 提取）与**运动特征**（卡尔曼滤波预测 + GIOU 度量），通过级联匹配与匈牙利算法完成帧间数据关联，输出带稳定 ID 的车辆轨迹。

### 输入与输出
- **输入**：连续视频帧序列。
- **输出**：每帧中所有被跟踪车辆的边界框及其持久化身份标识（ID）。

### 关键模块与连接
1.  **改进的 YOLOv8 检测器（第 2 节，提取文本覆盖充分）**：
    - **基线选择**：YOLOv8 提供 n/s/m/l/x 五种尺度变体；为兼顾精度与速度、避免简单任务用过重模型，作者以相对轻量的小模型作为改进基线。
    - **主干网络**：用 **FasterNet** 替换原 CSPDarknet，其核心是**部分卷积（PConv）**，减少冗余计算与内存访问，在多种设备上保持精度的同时提速（结构见原文 Figure 2）。
    - **小目标检测头**：在原 80×80、40×40 之外新增 **160×160** 特征图检测头。具体连接（提取文本明确）：主干中 FasterNetBlock 第 2 层的 80×80 特征图，与 Neck 上采样后的特征层经 C2f 模块融合，形成富含小目标信息的层；再与 FasterNetBlock 第 1 层输出的 160×160 特征图在通道维拼接，最后由 C2f 输出专门的小目标检测头，增强对远离监控相机的小车的捕获能力。
    - **SimAM 注意力**：引入 **Simple parameter-free Attention Module（SimAM）**。它在特征图上计算**三维**注意力权重（不像传统注意力只在通道或空间单独建模），具可解释性且**无额外参数**，对轻量化网络很关键。机制三步：(1) 特征变换——用简单变换计算各位置重要性分数；(2) 特征缩放——按分数与预设阈值做（可能非线性的）缩放；(3) 特征重加权——用缩放后分数加权原特征图，强化关键特征点响应。
    - **损失函数演进**：原模型用 **CIoU**（兼顾长宽比与中心距，但对小/低质量标注框有局限）→ 引入 **EIOU（Focal EIOU）** 加静态聚焦机制，但未充分利用非单调潜力 → 最终采用 **WIoU（WIOUv1）**，通过**动态非单调聚焦机制**评估锚框质量、由 IoU 评估转向离群度评估，减少几何因素的过度惩罚、降低训练干扰，增强对小目标与低质量标注框的泛化。提取文本给出公式 1-3：
      - 式(1) `L_IoU = 1 − IoU = 1 − W_i·H_i / S_u`（交集面积 / 并集面积）；
      - 式(2) `L_WIoUv1 = R_WIoU · L_IoU`；
      - 式(3) `R_WIoU = exp( ((x − x_gt)² + (y − y_gt)²) / (W_g² + H_g²)* )`（预测框与真值框中心距，归一化到最小包围框尺度；`*` 表示梯度分离/detach，避免该项产生有害梯度）。

2.  **改进的 DeepSORT 跟踪器（第 3-4 节；提取缓存未覆盖正文，以下据引言/摘要与原文后续页线索）**：
    - **外观特征模型**：用 **OSNet** 替换原行人 re-ID 模型，在车辆 re-ID 数据集（据原文后续页为 **VeRi-776**，提取缓存未覆盖，待核）上迁移训练，学习有区分度的车辆外观特征。
    - **运动特征度量**：计算检测框与预测轨迹的运动距离时用 **GIOU 距离** 替代 **IOU 距离**；GIOU 在两框不重叠时仍能反映相对位置，提供更合理的运动相似性度量。
    - **模块连接**：每步先做**级联匹配**（优先匹配出现更频繁的轨迹），综合**外观特征余弦距离**与**运动特征 GIOU 距离**；未匹配的检测与轨迹再经 IOU 关联做第二次匹配。（具体加权方式提取缓存未覆盖，待核。）

### 训练方式
- 检测器（改进 YOLOv8）与外观提取器（OSNet）**分开训练**。
- OSNet 在车辆重识别数据集上迁移训练（据原文后续页为 VeRi-776，每辆车由 2–18 个不同相机拍摄；提取缓存未覆盖，待核）。
- 实验环境（据原文后续页 Table 2：Windows 10 / AMD Ryzen 9 5950X / NVIDIA RTX 3090Ti；提取缓存未覆盖，待核）。

### 推理流程
视频帧 → 改进 YOLOv8 输出车辆检测框 → OSNet 对每个检测框提取外观特征向量 → 卡尔曼滤波预测已有轨迹当前帧位置 → 综合外观距离与 GIOU 运动距离、用匈牙利算法匹配 → 更新匹配轨迹、为未匹配检测建新轨迹、删除久未匹配轨迹 → 输出当前帧跟踪结果。

### 与已有方法的差异
- **与原始 DeepSORT**：核心差异是外观模型（行人 → 车辆 OSNet）与运动度量（IOU → GIOU）。
- **与其他车辆跟踪方法**：提供端到端优化方案，不仅改跟踪器，还针对任务优化上游检测器（YOLOv8 四项改进），是系统性工程优化。

## 3. 背景与问题
- **为什么做**：车辆检测跟踪是自动驾驶与 ITS 的关键技术，MOT 是 CV 基础任务（自动驾驶/监控/行为识别）。
- **之前方法的问题**：传统手工特征法（Mean Shift、KCF、SIFT/SURF、卡尔曼等）在简单场景有效、复杂动态场景失效；经典 DeepSORT 外观模型为**行人**设计，用于**车辆**辨别力不足，密集相似车流中身份易混淆切换。
- **核心矛盾**：在保实时的前提下，同时提升外观辨别力与运动匹配精度。
- 引言系统综述了 Bae[10]/Kim[11]/Yang[12]/Qiu[13]/Wang[14]/Lee[15]/Peng[16] 等深度学习 MOT 工作（详见上文研究背景节）。

## 4. 核心贡献
1.  **外观**：车辆 re-ID 训练的轻量级 OSNet 替换行人 re-ID 外观网络。
2.  **运动**：IOU 距离 → GIOU 距离度量。
3.  **检测器**：YOLOv8 四改——FasterNet 主干、SimAM 无参注意力、160×160 小目标头、WIOUv1 损失。
4.  **验证**：UA-DETRAC 上 MOTA +4.6%、IDF1 +5.9%，减少 ID 切换。

## 5. 方法详解
### 整体框架
改进 YOLOv8 检测车辆框 → 改进 DeepSORT 融合外观（OSNet）+ 运动（卡尔曼 + GIOU）→ 级联匹配 + 匈牙利算法关联 → 输出带稳定 ID 的轨迹。

### 输入与输出
- 输入：连续视频帧。
- 输出：每帧车辆框 + 持久化 ID。

### 关键模块与连接（检测器部分提取文本覆盖充分）
1.  **改进 YOLOv8**：
    - 基线取 n/s/m/l/x 中相对轻量的小模型，兼顾精度与速度。
    - **FasterNet** 替换 CSPDarknet，核心 **PConv** 减少冗余计算与内存访问、提速保精度。
    - **160×160 小目标头**：FasterNetBlock 第 2 层的 80×80 特征 + Neck 上采样经 C2f 融合 → 再与第 1 层 160×160 特征通道拼接 → C2f 输出专用小目标检测头，强化远处小车定位。
    - **SimAM**：无参数注意力，在特征图上算三维注意力权重；三步——重要性打分 / 缩放 / 重加权，强化关键特征响应。
    - **损失**：CIoU → EIOU(Focal，静态聚焦) → **WIOUv1**（动态非单调聚焦，IoU 评估转离群度评估，减少几何过惩罚）。公式 1-3：`L_IoU=1−IoU=1−W_iH_i/S_u`；`L_WIoUv1=R_WIoU·L_IoU`；`R_WIoU=exp(((x−x_gt)²+(y−y_gt)²)/(W_g²+H_g²)*)`（中心距按最小包围框归一，`*` 表示梯度分离）。
2.  **改进 DeepSORT（提取缓存未覆盖正文，据引言/摘要 + 后续页线索）**：
    - **OSNet** 在车辆 re-ID 数据集（据原文后续页为 VeRi-776，提取缓存未覆盖，待核）上迁移训练替换行人外观模型。
    - 运动距离 **IOU → GIOU**（不重叠时仍提供有意义度量）。
    - 级联匹配综合外观余弦距离 + 运动 GIOU 距离；未匹配再 IOU 二次关联（加权细节待核原文）。

### 训练方式
检测器与 OSNet 分开训练；OSNet 在车辆 re-ID（VeRi-776，待核）上迁移训练；实验环境据后续页 Table 2 为 Windows10 / Ryzen 9 5950X / RTX 3090Ti（提取缓存未覆盖，待核）。

### 推理流程
帧 → YOLOv8 检测 → OSNet 提外观 → 卡尔曼预测 → 外观+GIOU 距离 + 匈牙利匹配 → 更新/新建/删除轨迹 → 输出。

### 与已有方法的差异
- 对 DeepSORT：外观（行人→车辆 OSNet）+ 运动（IOU→GIOU）。
- 对其他车辆跟踪：端到端同时优化检测器与跟踪器的系统性工程方案。
