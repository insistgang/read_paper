## 摘要

本文提出了一种两步走的医学图像分类方法：首先利用预训练深度网络提取图像特征并用判别分析（DA）降维，然后将降维后的特征与临床变量融合，从而在数据稀缺的情况下提升分类性能，并增强模型的可解释性。
## 研究背景与动机

- **为什么做**：临床实践中，影像科医生解读图像（如X光片）时严重依赖临床信息（如症状、病史、检验值），纯图像信息往往具有非特异性。现有深度学习模型大多仅使用图像像素数据，忽略了这种关键的临床上下文，限制了其临床适用性和准确性。
- **之前方法的问题**：早期深度学习模型将医学图像分析视为单一模态（像素数据）问题，未能融合多源信息。虽有研究尝试融合，但方法较为简单（如直接拼接高维特征与临床变量），效果不佳。例如，直接将ResNet50提取的1024维特征与少量临床变量拼接，会导致临床信息被高维特征“淹没”，提升微乎其微（甚至不到1%）。此外，简单的池化降维可能丢失关键判别信息。
- **核心矛盾**：医学图像分类需要融合多模态信息（图像特征+临床变量），但预训练模型提取的特征维度极高（如1024/2048），在医学数据稀缺的背景下，直接融合会带来严重的维度灾难和信息失衡，导致临床变量的作用被掩盖，模型易过拟合。
## 关键贡献

1.  **提出一个新颖的两步框架**：结合预训练深度网络（如ResNet18， ViT）的特征提取与判别分析（DA）的降维，为临床变量的融入创造合适条件。
2.  **引入判别分析（DA）进行特征降维**：相较于常用的主成分分析（PCA），DA在降维时能最大化类间差异、最小化类内差异，更好地保留对分类任务至关重要的判别信息。
3.  **开发了适用于降维特征的类激活图（CAM）可视化方法**：传统CAM无法直接应用于降维后的特征空间，本文提出了新的CAM生成方式，用于可视化模型在低维特征空间中关注的疾病相关区域，增强了方法的可解释性。
4.  **在多个实际医学数据集上验证了方法的有效性**：在肺结核（Tuberculosis）和皮肤病（Dermatology）分类任务上，所提方法超越了现有先进方法，并与PCA进行了全面对比，证实了DA的优越性。
## 方法

- **整体框架**：如图1所示，方法包含三个主要阶段：**特征提取、特征降维与融合、分类预测**。
- **输入输出**：输入为医学图像 `I_i` 及其对应的临床变量向量 `v_i`；输出为图像的类别预测（如疾病类型）。
- **关键模块**：
    1.  **预训练特征提取器**：使用在ImageNet上预训练的深度网络（如ResNet18, VGGNet, ViT）作为固定特征提取器，**不进行微调**。输入图像 `I_i` 被映射到其倒数第二个全连接层输出的 `M` 维特征空间，得到特征向量 `y_i`（维度M通常为512/1024/2048）。
    2.  **判别分析（DA）降维模块**：针对高维特征 `y_i`，利用DA学习一个投影矩阵 `P`，将其投影到一个低维（L维，`L << M`）子空间，得到 `ȳ_i = P y_i`。DA的核心目标是最大化类间散度 `S_B` 和最小化类内散度 `S_W` 的比值（Fisher准则），并能递归地找到多个正交的判别方向，克服了传统方法在二分类下只能得到一个投影方向的限制。
    3.  **特征融合模块**：将降维后的图像特征 `ȳ_i` 与临床变量 `v_i` 进行融合，得到最终用于分类的特征向量 `z_i`。论文提出了两种融合策略：
        - **策略一（简单拼接）**：直接拼接，`z_i = [ȳ_i^T, v_i^T]^T`。
        - **策略二（先嵌入再降维）**：先用基础模型（如BERT）将临床变量文本转换为嵌入向量，再对嵌入进行DA降维，最后与 `ȳ_i` 拼接。论文认为对于当前数据集中简单的临床变量，该策略可能不会带来显著提升。
    4.  **分类器**：融合后的特征 `z_i` 被输入到一个分类器（如支持向量机SVM或一个全连接层）中进行最终类别预测。
- **模块连接**：流程是串联的：`图像 I → 预训练网络 → 高维特征 y → DA降维 → 低维特征 ȳ → (融合) 临床变量 v → 融合特征 z → 分类器 → 预测`。
- **数学机制直观解释**：DA通过求解一个优化问题，找到一组投影方向，使得不同类别的数据点投影后尽可能分开（类间距离大），而同一类别的数据点尽可能聚集（类内距离小）。这相当于为分类任务找到了一个最“清晰”的低维视角。
- **训练方式**：**仅训练DA模型和最终的分类器**。预训练网络参数固定，不参与训练。DA的投影矩阵 `P` 和分类器（如SVM）使用训练集数据学习得到。
- **推理流程**：新图像输入后，依次通过固定的预训练网络、DA投影矩阵 `P`，然后与临床变量拼接，最后由训练好的分类器输出预测结果。
- **与已有方法的差异**：与直接在原始高维特征或池化后特征上拼接临床变量的方法相比，本文的关键差异在于使用**判别分析（DA）** 进行有监督的降维。DA利用标签信息，确保降维后的特征空间对分类任务是最优的，同时极大地压缩了维度，防止了临床变量被“淹没”，这是其优于PCA（无监督）和简单池化（无监督，可能丢失信息）的核心所在。
