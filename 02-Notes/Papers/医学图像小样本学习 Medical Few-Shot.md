## 研究背景与动机

- **为什么要做**：在医学影像领域，标注数据稀缺是普遍现象（小样本问题）。当使用预训练深度神经网络提取特征时，得到的特征维度（如512维）可能接近甚至大于可用的样本数量，这被称为“小样本，高维”问题。
- **之前方法有什么问题**：传统上，常用基于奇异值分解（SVD）的主成分分析（PCA）进行降维。然而，SVD是一种方差保持技术，更适合单模态、高斯分布的数据。而用于分类的医学影像特征数据通常是多模态的，因此SVD可能丢弃对分类至关重要的判别信息。
- **核心矛盾**：**数据稀缺性**与**特征高维性**之间的矛盾。在小样本场景下，直接使用高维特征会导致维数灾难，而使用不恰当的降维方法（如SVD）又可能损失关键分类信息。作者旨在找到能在此极端约束下有效保留判别信息的降维方法。

## 关键贡献

1.  **提出并系统评估了一个基于子空间表示的医学图像小样本学习框架**：该框架使用预训练ResNet18提取特征，并通过子空间投影进行降维，最后使用KNN分类器进行分类。
2.  **明确指出SVD在小样本医学影像分类任务中的不足**：通过理论和实验阐明，SVD基于方差的降维在数据具有多模态判别结构时效果不佳。
3.  **引入并验证了判别分析（DA）作为显著更优的替代方案**：在14个数据集上，DA子空间在13个上显著优于原始特征空间，在所有14个上显著优于SVD子空间。
4.  **引入并验证了非负矩阵分解（NMF）作为具有竞争力的替代方案**：发现NMF子空间在多类和二类问题上普遍优于原始特征空间，性能与SVD相当或略优，且具有生成稀疏、局部化表示的潜力。

## 方法

- **整体框架**：一个两阶段流程。第一阶段：使用在ImageNet上预训练的ResNet18模型提取每张医学图像的512维特征向量（取自倒数第二层）。第二阶段：将这些高维特征投影到低维子空间，然后使用分类器（主要为KNN）进行分类。核心在于如何构建这个“低维子空间”。(p. 6, Figure 1)
- **关键模块与连接**：
    1.  **特征提取器**：预训练ResNet18，固定参数，不微调。输入为经标准化的图像，输出512维向量。
    2.  **子空间降维模块**：
        - **SVD/PCA**：对特征矩阵进行奇异值分解，选择最大的前k个奇异值对应的子空间。这是一个方差保持过程。
        - **判别分析（DA）**：
            - **多类问题**：求解广义特征值问题 `S_B d = λ S_W d`，其中`S_B`是类间散度矩阵，`S_W`是类内散度矩阵。当`S_W`奇异时（小样本常见），使用正则化 `Ŝ_W = S_W + δ I`。目标是找到最大化类间方差同时最小化类内方差的投影方向。(p. 4)
            - **二分类问题**：可以生成多个有序的判别方向`{d_n}`，每个方向对应一个“判别值”`γ_n`，用于衡量该方向的判别力。算法见Algorithm 1。(p. 4, 5)
        - **非负矩阵分解（NMF）**：将特征矩阵`Y`分解为两个非负矩阵`K`和`X`的乘积 (`Y ≈ KX`)，通过最小化Frobenius范数 `‖Y - KX‖_F^2` 实现。使用乘法更新规则进行优化。`X`即为降维后的表示。(p. 5)
        - **监督NMF（SNMF）**：在NMF的目标函数中加入一个logistic回归损失项，使得降维过程同时考虑重构误差和分类判别性。主要用于二分类。(p. 15)
    3.  **分类器**：主要使用K-最近邻（KNN），K取1, 5, 10, 15的平均结果。也测试了支持向量机（SVM）。(p. 7)
- **数学公式直观解释**：
    - **DA**：`S_B d = λ S_W d` 可以理解为寻找一个方向`d`，使得在这个方向上，不同类别的中心点（由`S_B`捕捉）尽可能分开，而同一类别的样本点（由`S_W`捕捉）尽可能聚集。
    - **NMF**：`Y ≈ KX` 可以理解为每个数据样本（`Y`的一列）是由一些“基向量”（`K`的列）以非负系数（`X`的对应列）组合而成。这种非负约束导致了基于部分的、局部化的表示。
- **训练方式**：
    - 整个框架的训练主要集中在子空间投影矩阵的学习上。特征提取器（ResNet18）是预训练好且固定的。
    - DA和NMF都是在提供的小样本训练集上学习投影矩阵。
    - 对于NMF和SNMF，迭代次数设为3000以确保收敛。(p. 7)
- **推理流程**：给定一张新图像 -> 通过ResNet18提取512维特征 -> 使用训练好的投影矩阵将特征映射到低维子空间 -> 将低维特征输入KNN（或SVM）分类器 -> 得到类别预测。
- **和已有方法的差异**：
    - **与直接使用预训练特征对比**：本文认为在小样本下，直接使用512维特征效果不佳，降维是必要的。
    - **与SVD对比**：SVD是无监督的、方差保持的方法，本文论证了其对分类任务的不适用性。
    - **与特征选择对比**：本文还对比了Boruta等特征选择方法，发现其不如DA/NMF等降维方法稳定有效。
    - **与端到端小样本学习方法对比**：本文在附录中与原型网络（Prototypical Network）进行了对比，展示了基于子空间的方法在某些数据集上的优势。

## 实验

- **数据集**：共14个医学图像数据集，涵盖乳腺癌、脑肿瘤、新冠肺炎、糖尿病视网膜病变等11种疾病，模态包括X光、CT、MRI和显微镜图像。类别数从2到11不等。(p. 7, 8, Table 1)
- **对比方法**：
    1.  基线：原始512维特征空间。
    2.  降维方法：SVD (PCA)、DA、NMF、监督NMF (SNMF)。
    3.  特征选择方法：Boruta。
    4.  其他：流形学习方法Isomap；预训练模型与随机初始化模型。
    5.  其他小样本学习方法：原型网络（附录中）。(p. 8, 10, 12, 15-17)
- **评价指标**：分类准确率（Accuracy），以10次随机采样的平均值 ± 标准差表示。
- **主实验结果**：
    - **DA vs. SVD**：在14个数据集中，DA子空间（维度3）在13个上显著优于原始特征空间，在所有14个上显著优于SVD子空间（p. 8, Table 2）。例如，在BrainTumor数据集上，准确率分别为：原始特征空间 68.63±4.17%，SVD 54.63±4.73%，DA 73.80±3.52%。
    - **NMF作为替代方案**：NMF子空间（维度30）在多类和二类问题上普遍优于原始特征空间，性能与SVD相当或略优（如二分类中SNMF略优于NMF）。(p. 10, 11, Table 3, Table 4)
    - **与原型网络对比**：在“C-way 5-shot”设置下，在14个数据集上的比较显示，论文提出的基于DA/NMF子空间的方法在某些数据集（如BrainTumor）上显著优于原型网络，而在其他数据集上则表现相当或略低。(p. 17, Table 6)
- **消融/泛化实验**：
    - **维度影响**：DA性能随投影维度增加而稳定提升并始终优于SVD。NMF在达到一定维度（如30）后性能趋于稳定。(p. 8, 11, Figure 2, Figure 4)
    - **数据集大小影响**：使用仅0.7%的全数据集进行训练，DA的结果与使用全数据集训练的结果高度可比，而SVD则表现不佳，这凸显了DA在极小样本下的鲁棒性。(p. 10, Figure 3)
    - **特征提取器影响**：预训练模型优于随机初始化模型，但随机初始化模型提取的特征经DA降维后性能下降不显著，表明DA能保留特征中的判别属性。(p. 12, Figure 6)
    - **稳定性**：NMF在不同随机初始化下表现稳定，重建误差随维度增加而下降。(p. 11, Figure 5)

## 局限

- **方法局限**：
    - **DA的维度上限**：在多类问题中，DA子空间的最大维度被限制为类别数减一（`C-1`）。这在类别数很少（如二分类）时可能过于受限。(p. 14)
    - **NMF的监督扩展**：本文提出的监督NMF（SNMF）目前仅限于二分类问题，如何有效地将其扩展到多分类问题是一个未解决的挑战。(p. 14)
    - **对特定数据分布的假设**：DA的效果可能依赖于数据的判别信息主要存在于类均值差异中的假设。当分类信息更依赖于方差结构时，DA可能不理想。(p. 14)
- **实验局限**：
    - **分类器固定**：主要使用KNN，虽然也测试了SVM，但未深入探索降维方法与不同分类器的交互影响。
    - **计算成本未讨论**：论文未比较各降维方法（特别是迭代的NMF）的计算时间和收敛速度，这在实际应用中是一个重要考量。
    - **临床验证缺失**：所有实验都是在标准数据集上进行的，缺乏在真实临床工作流中的验证。(p. 14)

            - **多类问题**：求解广义特征值问题 `S_B d = λ S_W d`，其中`S_B`是类间散度矩阵，`S_W`是类内散度矩阵。当`S_W`奇异时（小样本常见），使用正则化 `Ŝ_W = S_W + δ I`。目标是找到最大化类间方差同时最小化类内方差的投影方向。(p. 4)
            - **二分类问题**：可以生成多个有序的判别方向`{d_n}`，每个方向对应一个“判别值”`γ_n`，用于衡量该方向的判别力。算法见Algorithm 1。(p. 4, 5)
        - **非负矩阵分解（NMF）**：将特征矩阵`Y`分解为两个非负矩阵`K`和`X`的乘积 (`Y ≈ KX`)，通过最小化Frobenius范数 `‖Y - KX‖_F^2` 实现。使用乘法更新规则进行优化。`X`即为降维后的表示。(p. 5)
        - **监督NMF（SNMF）**：在NMF的目标函数中加入一个logistic回归损失项，使得降维过程同时考虑重构误差和分类判别性。主要用于二分类。(p. 15)
    3.  **分类器**：主要使用K-最近邻（KNN），K取1, 5, 10, 15的平均结果。也测试了支持向量机（SVM）。(p. 7)
- **数学公式直观解释**：
    - **DA**：`S_B d = λ S_W d` 可以理解为寻找一个方向`d`，使得在这个方向上，不同类别的中心点（由`S_B`捕捉）尽可能分开，而同一类别的样本点（由`S_W`捕捉）尽可能聚集。
    - **NMF**：`Y ≈ KX` 可以理解为每个数据样本（`Y`的一列）是由一些“基向量”（`K`的列）以非负系数（`X`的对应列）组合而成。这种非负约束导致了基于部分的、局部化的表示。
- **训练方式**：
    - 整个框架的训练主要集中在子空间投影矩阵的学习上。特征提取器（ResNet18）是预训练好且固定的。
    - DA和NMF都是在提供的小样本训练集上学习投影矩阵。
    - 对于NMF和SNMF，迭代次数设为3000以确保收敛。(p. 7)
- **推理流程**：给定一张新图像 -> 通过ResNet18提取512维特征 -> 使用训练好的投影矩阵将特征映射到低维子空间 -> 将低维特征输入KNN（或SVM）分类器 -> 得到类别预测。
- **和已有方法的差异**：
    - **与直接使用预训练特征对比**：本文认为在小样本下，直接使用512维特征效果不佳，降维是必要的。
    - **与SVD对比**：SVD是无监督的、方差保持的方法，本文论证了其对分类任务的不适用性。
    - **与特征选择对比**：本文还对比了Boruta等特征选择方法，发现其不如DA/NMF等降维方法稳定有效。
    - **与端到端小样本学习方法对比**：本文在附录中与原型网络（Prototypical Network）进行了对比，展示了基于子空间的方法在某些数据集上的优势。

## 8. 局限与问题
- **方法局限**：
    - **DA的维度上限**：在多类问题中，DA子空间的最大维度被限制为类别数减一（`C-1`）。这在类别数很少（如二分类）时可能过于受限。(p. 14)
    - **NMF的监督扩展**：本文提出的监督NMF（SNMF）目前仅限于二分类问题，如何有效地将其扩展到多分类问题是一个未解决的挑战。(p. 14)
    - **对特定数据分布的假设**：DA的效果可能依赖于数据的判别信息主要存在于类均值差异中的假设。当分类信息更依赖于方差结构时，DA可能不理想。(p. 14)
- **实验局限**：
    - **分类器固定**：主要使用KNN，虽然也测试了SVM，但未深入探索降维方法与不同分类器的交互影响。
