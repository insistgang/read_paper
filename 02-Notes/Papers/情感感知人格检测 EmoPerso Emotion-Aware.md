## 研究背景与动机

- **为什么要做**：认知科学（如CAPS理论）表明，人格（长期行为模式）与情感（短期心理状态）在不同认知时间尺度上相互作用并共同影响人类行为。然而，在NLP领域，大多数现有人格检测方法将情感和人格视为独立变量，忽视了它们的内在联系。此外，获取高质量的人格标注数据既昂贵又困难，制约了监督学习模型的发展。
- **之前方法的问题**：
    1. **依赖大量标注数据**：传统深度学习方法和基于提示工程的LLM方法都高度依赖大规模、高质量的人格标注数据集，而这类数据稀缺且标注成本高。
    2. **忽视人格-情感交互**：现有方法（如简单的多任务学习）未能有效建模人格特质与细粒度情感表达之间的复杂、非对称且上下文依赖的关联。
    3. **情感建模粗糙**：部分研究使用情感或情感特征，但多为粗粒度的情感极性（积极/消极），未能利用心理学中更丰富的情感分类（如Ekman的基本情绪理论）。
- **核心矛盾**：如何在缺乏显式情感标注和人格标注数据稀缺的情况下，有效建模并利用人格与情感之间的深层关联来提升人格检测的准确性。
## 关键贡献

1.  **提出EmoPerso框架**：一个新颖的自监督联合学习框架，用于人格与情感的协同建模。
2.  **设计LLM驱动的文本增强**：采用风格条件化改写和上下文特征补全两种机制，通过生成式LLM进行数据增强，提升模型的泛化能力。
3.  **引入自监督多任务学习（MTL）**：将人格预测（4个二元分类任务）和情感预测（多标签分类任务）联合优化。情感标签并非人工标注，而是通过模型从文本中的心理语言线索（如情感词汇、标点符号）中推断出的伪标签。
4.  **设计跨注意力交互模块**：构建了一个两阶段交互机制，首先通过多头跨注意力让人格表征查询文本标记，然后通过情感条件调制层对具有心理显著性的特征进行加权，实现细粒度的人格-情感特征对齐。
5.  **集成自教学推理（STaR）策略**：利用STaR生成个性化推理链，并通过信息增益和互信息指标进行筛选，以增强情感特征与人格特质之间的语义耦合，提升推理质量。
6.  **实验验证有效性**：在两个基准数据集上的实验表明，EmoPerso优于现有的最先进模型。
## 方法

**整体框架**：EmoPerso是一个端到端的自监督框架，主要包含四个核心模块：文本增强、多任务学习、人格-情感交互和推理链优化。其整体架构如图2所示。

**输入输出**：
- **输入**：用户在社交媒体上的文本帖子序列 `X = (x1, x2, ..., xT)`。
- **输出**：用户在四个维度上的MBTI人格类型预测（I/E, S/N, T/F, P/J）。

**关键模块与连接**：
1.  **文本增强**：首先，对输入文本 `X` 进行增强，生成多样化变体 `X̃`，以缓解数据稀疏问题。
    - **风格条件化改写**：使用LLM根据控制信号 `sj`（如正式性、表达性、简洁性）将原文本改写为不同风格的变体 `X'(j)`。为了增加多样性，采用核采样（top-p sampling）而非确定性生成。
    - **上下文特征补全**：随机遮蔽文本中的部分片段，然后让LLM根据上下文预测被遮蔽的内容 `ˆxm`。
    - **语义保真**：为了保证增强文本与原文本语义一致性，引入基于KL散度的正则化损失 `L_KL` 和风格分类损失 `L_style`。增强损失为 `L_gen = λ_style * L_style + λ_KL * L_KL`。

2.  **多任务学习**：将增强后的文本 `X̃` 输入一个LLM编码器，得到隐藏表示 `H`。通过注意力池化机制（公式1）将 `H` 聚合为全局表示 `z`。
    - **人格预测**：将 `z` 通过一个MLP投影为人格表征 `z_pers`，然后通过一个线性层和sigmoid激活函数，预测4个MBTI维度的二元概率 `pc`。损失函数为二元交叉熵 `L_pers`（公式2）。
    - **情感预测**：将 `z` 通过另一个MLP投影为情感表征 `z_emo`，用于预测 `Ce` 个情感类别的多标签概率 `˜pc`。**关键点在于，这些情感标签 `yc` 是伪标签**，由模型从文本中的情感线索（如情感形容词、强化词、标点使用等）中自动生成，而非外部提供。损失函数为多标签二元交叉熵 `L_emo`（公式3）。
    - **联合优化**：MTL损失 `L_MTL = λ_pers * L_pers + λ_emo * L_emo`。

3.  **人格-情感交互**：
    - **跨注意力**：将MTL阶段得到的人格表征 `z_pers` 作为查询（Query），将LLM编码器输出的文本标记序列 `H` 作为键（Key）和值（Value），进行多头跨注意力计算（公式5,6）。这一步让人格特征主动“查找”文本中相关的上下文信息，得到细化的标记表征 `H̃`。
    - **情感条件调制**：基于MTL阶段得到的情感表征 `z_emo`，计算一个针对每个标记的权重向量 `β`，然后对跨注意力的输出 `H̃` 进行加权求和，得到最终的人格表征 `z_pers_tilde`。这实现了用情感语境来“高亮”对人格判断更重要的文本特征。
    - **一致性损失**：引入跨注意力损失 `L_cross = 1 - cos(z_pers_tilde, z_emo)`，以对齐人格导向和情感导向的特征。

4.  **推理链优化**：为了进一步增强推理能力，集成自教学推理（STaR）策略。
    - **生成推理链**：针对输入文本 `X`，利用LLM生成推理链集合 `R`。
    - **选择与嵌入**：使用情感表征 `z_emo` 对这些推理链进行评分（例如基于信息增益或互信息），选择最优推理链 `r*`，并将其嵌入为 `z_r`。
    - **最终预测**：将交互后的人格表征 `z_pers_tilde` 与推理链嵌入 `z_r` 结合，得到最终表征 `z_final`，用于最终的人格推断 `ŷ_pers`。相应的损失为 `L_star`。

**数学公式/机制的直观解释**：
- **注意力池化（公式1）**：相当于一个可训练的加权求和，让模型学习关注文本中与人格/情感最相关的词或短语，而不是简单平均。
- **跨注意力（公式5,6）**：人格特征作为“问题”，文本序列作为“答案库”，通过计算相似度找到文本中最相关的部分。
- **情感条件调制**：相当于一个“聚光灯”，由情感特征控制，照亮文本中对当前人格判断最有情感信息的区域。

**训练方式**：端到端联合训练，总损失函数为 `L_total = λ_MTL * L_MTL + λ_cross * L_cross + λ_star * L_star`。算法伪代码如算法1所示。

**推理流程**：对于新文本，依次经过LLM编码、注意力池化、MTL表征分解、跨注意力交互、情感调制、推理链选择（可选）和最终分类。

**与已有方法的差异**：
- 与**传统深度学习方法**（如LSTM, Transformer）相比：EmoPerso不依赖大量标注数据，通过自监督和LLM增强解决数据问题，并显式建模情感交互。
- 与**LLM驱动方法**（如基于提示的GPT-4）相比：EmoPerso不满足于浅层模式匹配，而是通过自监督MTL和跨注意力，让模型内化人格与情感的依赖关系，实现更深层的认知推理。

- **输入**：用户在社交媒体上的文本帖子序列 `X = (x1, x2, ..., xT)`。
- **输出**：用户在四个维度上的MBTI人格类型预测（I/E, S/N, T/F, P/J）。

**关键模块与连接**：
1.  **文本增强**：首先，对输入文本 `X` 进行增强，生成多样化变体 `X̃`，以缓解数据稀疏问题。
    - **风格条件化改写**：使用LLM根据控制信号 `sj`（如正式性、表达性、简洁性）将原文本改写为不同风格的变体 `X'(j)`。为了增加多样性，采用核采样（top-p sampling）而非确定性生成。
    - **上下文特征补全**：随机遮蔽文本中的部分片段，然后让LLM根据上下文预测被遮蔽的内容 `ˆxm`。
    - **语义保真**：为了保证增强文本与原文本语义一致性，引入基于KL散度的正则化损失 `L_KL` 和风格分类损失 `L_style`。增强损失为 `L_gen = λ_style * L_style + λ_KL * L_KL`。

2.  **多任务学习**：将增强后的文本 `X̃` 输入一个LLM编码器，得到隐藏表示 `H`。通过注意力池化机制（公式1）将 `H` 聚合为全局表示 `z`。
    - **人格预测**：将 `z` 通过一个MLP投影为人格表征 `z_pers`，然后通过一个线性层和sigmoid激活函数，预测4个MBTI维度的二元概率 `pc`。损失函数为二元交叉熵 `L_pers`（公式2）。
    - **情感预测**：将 `z` 通过另一个MLP投影为情感表征 `z_emo`，用于预测 `Ce` 个情感类别的多标签概率 `˜pc`。**关键点在于，这些情感标签 `yc` 是伪标签**，由模型从文本中的情感线索（如情感形容词、强化词、标点使用等）中自动生成，而非外部提供。损失函数为多标签二元交叉熵 `L_emo`（公式3）。
    - **联合优化**：MTL损失 `L_MTL = λ_pers * L_pers + λ_emo * L_emo`。

3.  **人格-情感交互**：
    - **跨注意力**：将MTL阶段得到的人格表征 `z_pers` 作为查询（Query），将LLM编码器输出的文本标记序列 `H` 作为键（Key）和值（Value），进行多头跨注意力计算（公式5,6）。这一步让人格特征主动“查找”文本中相关的上下文信息，得到细化的标记表征 `H̃`。
    - **情感条件调制**：基于MTL阶段得到的情感表征 `z_emo`，计算一个针对每个标记的权重向量 `β`，然后对跨注意力的输出 `H̃` 进行加权求和，得到最终的人格表征 `z_pers_tilde`。这实现了用情感语境来“高亮”对人格判断更重要的文本特征。
    - **一致性损失**：引入跨注意力损失 `L_cross = 1 - cos(z_pers_tilde, z_emo)`，以对齐人格导向和情感导向的特征。

4.  **推理链优化**：为了进一步增强推理能力，集成自教学推理（STaR）策略。
    - **生成推理链**：针对输入文本 `X`，利用LLM生成推理链集合 `R`。
    - **选择与嵌入**：使用情感表征 `z_emo` 对这些推理链进行评分（例如基于信息增益或互信息），选择最优推理链 `r*`，并将其嵌入为 `z_r`。
    - **最终预测**：将交互后的人格表征 `z_pers_tilde` 与推理链嵌入 `z_r` 结合，得到最终表征 `z_final`，用于最终的人格推断 `ŷ_pers`。相应的损失为 `L_star`。

**数学公式/机制的直观解释**：
- **注意力池化（公式1）**：相当于一个可训练的加权求和，让模型学习关注文本中与人格/情感最相关的词或短语，而不是简单平均。
- **跨注意力（公式5,6）**：人格特征作为“问题”，文本序列作为“答案库”，通过计算相似度找到文本中最相关的部分。
- **情感条件调制**：相当于一个“聚光灯”，由情感特征控制，照亮文本中对当前人格判断最有情感信息的区域。

**训练方式**：端到端联合训练，总损失函数为 `L_total = λ_MTL * L_MTL + λ_cross * L_cross + λ_star * L_star`。算法伪代码如算法1所示。

**推理流程**：对于新文本，依次经过LLM编码、注意力池化、MTL表征分解、跨注意力交互、情感调制、推理链选择（可选）和最终分类。
