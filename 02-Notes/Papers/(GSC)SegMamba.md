## 研究背景与动机

- **为什么要做**: 准确的3D医学图像分割对辅助诊断至关重要，而扩大模型感受野以提取全局信息是提升分割性能的关键。
- **之前方法有什么问题**:
    1.  **CNN-based方法**: 如3D UX-Net使用大卷积核（7x7x7）来扩大感受野，但由于卷积的局部性，仍然难以有效建模全局关系。
    2.  **Transformer-based方法**: 如UNETR、SwinUNETR，利用自注意力机制提取全局信息，取得了很好效果。但处理高分辨率3D医学图像时，自注意力的二次方计算复杂度（与序列长度平方相关）导致了显著的计算负担和速度下降。
- **作者想解决的核心矛盾**: **在3D医学图像分割中，如何同时实现高效的长程（全局）依赖建模与低计算/内存开销**。作者希望找到一种既能像Transformer一样建模全局关系，又能像CNN一样保持计算效率的方法。

## 方法

### 整体框架
SegMamba采用**U形编码器-解码器**结构。编码器由“Stem层”和多个“Tri-orientated Spatial Mamba (TSMamba) Block”及下采样层构成，用于提取多尺度全局特征。解码器是基于卷积的，通过跳跃连接复用编码器特征。**（整体框架见论文图2，p.4）**

### 输入与输出
- **输入**: 3D医学体积图像 `I ∈ R^{C×D×H×W}`。
- **输出**: 逐像素的分割结果。

### 关键模块详解
#### a) Stem层
- 使用一个**7x7x7**的大卷积核、步长为2、填充为3的深度可分离卷积层，将输入特征下采样并映射到48通道，得到第一个尺度的特征 `z_0 ∈ R^{48×D/2×H/2×W/2}`。**（p.4）**

#### b) TSMamba Block
这是编码器的核心模块，由多个堆叠的“基础单元”组成。每个基础单元的计算流程如公式(1)所示**（p.4）**:
`ẑ_l_m = GSC(z_l_m)`
`z̃_l_m = ToM(LN(ẑ_l_m)) + ẑ_l_m` （残差连接）
`z_{l+1}_m = MLP(LN(z̃_l_m)) + z̃_l_m` （残差连接）
其中，`GSC`和`ToM`是本文设计的两个核心算子。

#### c) 门控空间卷积（GSC）模块
- **目的**: 在将3D特征展平成1D序列进行Mamba建模之前，先提取其**空间维度**的上下文关系。
- **结构与机制**:
    1.  输入特征 `z` 分别经过两个并行的卷积块：一个使用 **3x3x3** 卷积核，另一个使用 **1x1x1** 卷积核。每个卷积块包含Layer Norm、卷积和非线性激活。
    2.  将两个分支的输出进行**逐元素相乘**，形成一个“门控”机制，用1x1卷积分支的输出来控制3x3卷积分支的信息流。
    3.  最后再通过一个卷积块进行特征融合，并与原始输入进行**残差连接**。
- **公式**: `GSC(z) = z + C_{3×3×3}(C_{3×3×3}(z) · C_{1×1×1}(z))` **（p.5）**
- **直观理解**: 类似于一个空间注意力或门控单元，增强了对局部空间模式的建模能力，为后续的序列建模提供更丰富的空间特征。

#### d) 三向Mamba（ToM）模块
- **目的**: 从三个不同的空间方向对3D特征进行全局序列建模。
- **机制**: 将3D输入特征 `z` 沿三个方向展平（flatten）成1D序列，然后分别用**Mamba层**进行建模，最后将三个方向的输出特征相加融合。
    1.  **前向方向** (`f`): 按照固定的顺序（如先X后Y再Z）扫描整个体积。
    2.  **反向方向** (`r`): 与前向顺序相反。
    3.  **跨切片方向** (`s`): 论文未详述具体扫描顺序，可能是按切片（如Z轴）与其他轴交错的顺序。
- **公式**: `ToM(z) = Mamba(z_f) + Mamba(z_r) + Mamba(z_s)` **（p.5）**
- **与已有方法的差异**:
    - **与CNN**: 替代了卷积的局部操作，实现了对整个体积的全局信息建模。
    - **与Transformer**: 使用了Mamba层，其核心是基于SSM的选择机制，计算复杂度与序列长度呈**线性关系**，而自注意力是二次关系，因此处理长序列（如26万）时效率极高。
    - **与单向Mamba**: 通过多方向扫描（类似双向RNN），弥补了Mamba单向扫描可能丢失部分上下文信息的不足，更全面地捕捉了3D空间依赖。

### 训练方式
- **实现框架**: Pytorch 2.0.1, Monai 1.2.0。
- **数据输入**: 从3D体积中随机裁剪 **128x128x128** 的patch。
- **优化器**: SGD，初始学习率 **1e-2**，衰减率 **1e-5**，多项式学习率调度器。
- **损失函数**: 交叉熵损失。
- **训练轮次**: 1000 epochs。
- **数据增强**: 包括亮度、伽马、旋转、缩放、镜像和弹性变形。
- **硬件**: 4块 NVIDIA A100 GPU。
- **数据划分**: 70% 训练，10% 验证，20% 测试。**（p.6）**

### 推理流程
在推理时，输入完整的3D体积图像（或经过滑动窗口裁剪），通过训练好的SegMamba网络，编码器提取多尺度全局特征，解码器结合跳跃连接的特征，最终输出每个体素的类别预测概率图。
## 实验

### 使用的数据集
1.  **BraTS2023**: 1251个3D脑部MRI体积，包含四种模态，分割目标为全肿瘤(WT)、肿瘤核心(TC)、增强肿瘤(ET)。
2.  **AIIB2023**: 120个高分辨率CT扫描，用于气道分割。
3.  **CRC-500** (本文提出): 500个3D结直肠癌CT扫描，带有专家标注。

### 对比方法
- **CNN-based**: SegresNet, 3D UX-Net, MedNeXt
- **Transformer-based**: UNETR, SwinUNETR, SwinUNETR-V2

### 评价指标
- **分割精度**: Dice相似系数 (Dice↑), 95%豪斯多夫距离 (HD95↓)。
- **气道专用**: 交并比 (IoU↑), 探测长度比 (DLR↑), 探测分支比 (DBR↑)。

### 主实验结果
- **BraTS2023 (p.6, Table 2)**: SegMamba在所有三个子任务(WT, TC, ET)上均取得**最高Dice和最低HD95**。例如，平均Dice为 **91.32%**，超越最佳CNN方法UX-Net (89.69%) 和最佳Transformer方法SwinUNETR-V2 (89.39%)。
- **AIIB2023 (p.6, Table 2)**: SegMamba在气道树IoU (88.59%)、DLR (70.21%) 和 DBR (61.33%) 上均为最优，表明其分割连续性更好。
- **CRC-500 (p.7, Table 3)**: 在挑战性的结直肠癌分割任务上，SegMamba取得**最高Dice (48.02%) 和最低HD95 (30.89)**。

### 消融实验
- **GSC和ToM模块有效性 (p.7, Table 4)**:
    - 基础Mamba (M1): Dice 45.34%
    - 加入GSC (M2): Dice 46.65% (↑2.88%)，证明空间卷积增强有效。
    - 加入ToM (M3): Dice 47.22% (↑1.22%)，证明三向建模进一步提升。
    - **同时使用GSC和ToM (Ours)**: Dice **48.02%**，效果最佳。
- **全局建模模块效率对比 (p.8, Table 5)**:
    - 大卷积核卷积 (M4): 训练内存18852M，推理时间1.92 case/s
    - Swin Transformer (M5): 训练内存34000M，推理时间1.68 case/s
    - 自注意力 (M6): **内存溢出(OOM)**
    - **TSMamba (Ours)**: 训练内存**17976M**，推理时间**1.51 case/s**。在序列长度高达262k时，内存和速度均优于Transformer方法，且是唯一可行的全局建模方案。

- **结构与机制**:
    1.  输入特征 `z` 分别经过两个并行的卷积块：一个使用 **3x3x3** 卷积核，另一个使用 **1x1x1** 卷积核。每个卷积块包含Layer Norm、卷积和非线性激活。
    2.  将两个分支的输出进行**逐元素相乘**，形成一个“门控”机制，用1x1卷积分支的输出来控制3x3卷积分支的信息流。
    3.  最后再通过一个卷积块进行特征融合，并与原始输入进行**残差连接**。
- **公式**: `GSC(z) = z + C_{3×3×3}(C_{3×3×3}(z) · C_{1×1×1}(z))` **（p.5）**
- **直观理解**: 类似于一个空间注意力或门控单元，增强了对局部空间模式的建模能力，为后续的序列建模提供更丰富的空间特征。

#### d) 三向Mamba（ToM）模块
- **目的**: 从三个不同的空间方向对3D特征进行全局序列建模。
- **机制**: 将3D输入特征 `z` 沿三个方向展平（flatten）成1D序列，然后分别用**Mamba层**进行建模，最后将三个方向的输出特征相加融合。
    1.  **前向方向** (`f`): 按照固定的顺序（如先X后Y再Z）扫描整个体积。
    2.  **反向方向** (`r`): 与前向顺序相反。
    3.  **跨切片方向** (`s`): 论文未详述具体扫描顺序，可能是按切片（如Z轴）与其他轴交错的顺序。
- **公式**: `ToM(z) = Mamba(z_f) + Mamba(z_r) + Mamba(z_s)` **（p.5）**
- **与已有方法的差异**:
    - **与CNN**: 替代了卷积的局部操作，实现了对整个体积的全局信息建模。
    - **与Transformer**: 使用了Mamba层，其核心是基于SSM的选择机制，计算复杂度与序列长度呈**线性关系**，而自注意力是二次关系，因此处理长序列（如26万）时效率极高。
    - **与单向Mamba**: 通过多方向扫描（类似双向RNN），弥补了Mamba单向扫描可能丢失部分上下文信息的不足，更全面地捕捉了3D空间依赖。

### 训练方式
- **实现框架**: Pytorch 2.0.1, Monai 1.2.0。
- **数据输入**: 从3D体积中随机裁剪 **128x128x128** 的patch。
- **优化器**: SGD，初始学习率 **1e-2**，衰减率 **1e-5**，多项式学习率调度器。
- **损失函数**: 交叉熵损失。
- **训练轮次**: 1000 epochs。
- **数据增强**: 包括亮度、伽马、旋转、缩放、镜像和弹性变形。
- **硬件**: 4块 NVIDIA A100 GPU。
- **数据划分**: 70% 训练，10% 验证，20% 测试。**（p.6）**
