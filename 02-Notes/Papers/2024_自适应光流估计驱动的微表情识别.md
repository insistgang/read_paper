## 摘要

**英文原摘要（据 PDF 提取文本整理，修复空格与连字符断裂）：**

> Micro-expressions are brief, subtle facial muscle movements that accidentally signal emotions when the person tries to hide their true inner feelings. Micro-expressions are more responsive to a person's true feelings and motivations than macro-expressions. Micro-expression recognition aims to analyze and identify automatically the emotional category of the research object from the stressful movement of the facial muscles, which has an important application value in lie detection, psychological diagnosis, and other aspects. In the early development of micro-expression recognition, local binary patterns and optical flow were widely used as features for training traditional machine learning models. However, existing micro-expression recognition methods usually extract the optical flow information offline, which relies on existing optical flow estimation techniques and suffers from the insufficient description of subtle expressions and neglect of static facial expression information, which restricts the recognition effect of the model. Therefore, this study proposes a micro-expression recognition network based on adaptive optical flow estimation (AdaMER), which realizes optical flow estimation and micro-expression classification to learn micro-expression-related motion features through parallel association adaptively. On a composite dataset built from SMIC, SAMM, and CASME II, our method achieves 82.89% UF1 and 85.95% UAR on the whole dataset, improving over the latest method FRL-DGT by 1.77% and 4.85% respectively.

## 研究背景与动机

- **为什么要做**：微表情是压抑/管理真实情感时意外流露的情绪信号，通常仅持续 1/25～1/3 秒（Ekman & Friesen, 1975），难以掩盖、更能传达真实内心，故广泛用于谎言检测、心理诊断。但微表情持续时间短、表达强度低，须经专门培训的心理学专家才能鉴别，极大限制了应用范围，因此需要计算机视觉自动识别。
- **现有方法的两条路线**：1) 基于特征工程的方法（LBP、LBP-TOP、LBP-SIP、光流/Bi-WOOF/MDMO 等），严重依赖人工设计经验，难以充分挖掘微表情特征；2) 基于数据驱动学习的方法，又分为直接学顶点帧视觉特征（仅靠顶点帧难获足够判别特征）与基于光流的动态特征学习。
- **之前方法有什么问题**：现有基于光流的深度学习方法通常**离线**用通用光流估计技术（如 TV-L1）预先提取光流再分类，存在两个问题：1) 通用光流估计对微表情**细微运动不敏感**，描述能力不足；2) **忽略静态面部表情信息**，限制特征表达能力。最新的自适应动态特征学习工作（Nguyen 2023 的 DMA、Fan 2023 的 SCViT、Zhai 2023 的 FRL-DGT）多以**自监督方式**约束动态信息生成，缺少外部知识的引入与监督，且受限于数据增广方式。
- **核心矛盾/思路**：让模型**自适应地、端到端地**学习与微表情相关的运动特征，同时引入**外部光流知识（TV-L1）作为监督**约束动态特征生成，并以微表情分类任务作为动态特征校正与信息注入网络，使生成的运动特征蕴含微表情判别信息；并充分融合静态与动态信息提升识别精度。

## 关键贡献

1.  **密集差分编码器 + 运动增强模块（MEM）**：针对面部肌肉运动特点，提出密集差分编码器（DSDE），通过运动增强模块实现不同尺度面部差分信息的交互与聚合，采用跨尺度运动（差分信息）传递机制结合不同尺度帧间差分信息，逐渐增强面部细微运动蕴含的语义信息，克服现有光流估计方法对细微运动不敏感、防止细微运动信息在深度网络传输中丢失的问题。
2.  **端到端多任务统一模型**：提出端到端的面部运动光流估计与微表情识别多任务学习统一模型，以光流估计作为正则化条件，引入外部光流知识（TV-L1）作为指导信息，同时实现自适应光流估计与微表情分类，增强模型泛化能力。
3.  **CNN 与 Transformer 特征融合**：为增强鲁棒性，将卷积块组成的编码器提取的微表情语义特征与视觉 Transformer 提取的判别性特征进行融合，提高特征表达能力，进一步提升识别性能。

## 方法

- **整体框架（AdaMER）**：由三部分组成——数据预处理、微表情自适应光流估计与学习、微表情分类。整体是一个**多任务学习**框架，并行联立优化光流估计与分类两个目标。
- **输入输出**：数据预处理含**帧采样**与**基准光流生成**。帧采样从视频序列中选择**起始帧与顶点帧相邻 5 帧间**构成的图像对 `(X1, X2)`；对采样两帧用 **TV-L1（Zach 等, 2007）** 计算帧间光流作为外部监督知识。此外加载数据时，以一定概率用视频序列中随机选择的、包含运动信息的两帧替换起始帧/顶点帧图像对（数据增广，防过拟合）。输出是微表情类别标签。
- **关键模块与连接**：
    1.  **密集差分编码器 DSDE（§2.1.1）**：三路分支。共享参数分支用 **ResNet18 前 4 层** 处理起始帧 `X1`、顶点帧 `X2`，提取静态特征 `f1, f2`；差分分支处理差分图 `X3 = BN(X2 - X1)`，提取动态特征 `f3`。`Fl(·)`、`Gl(·)` 分别为共享分支与差分分支第 l 个卷积层操作。
    2.  **运动增强模块 MEM（§2.1.2）**：加在差分图特征提取分支上完成层间信息交互，防止细微差分信息在网络传播中丢失。流程：先算层内差分 `fd = BN(f2 - f1)`（顶点帧与起始帧间位移动态特征）；考虑差分图 `X3` 可能含头部运动等非表情信息，用**空间注意力模块 SA（Woo 等, 2018）** 让模型关注面部运动区域，`f̃3 = Conv(ReLU(Conv(f'3 × f3)))`（含 1×1 卷积与 ReLU）；再拼接增强 `fm = Concat(fd, f̃3)`。编码器最终输出 `fmd = Concat(f2, fm, fd)`（顶点帧静态特征 + 差分增强特征 + 层内差分特征）。
    3.  **解码器（§2.1.3）**：用光流重构任务对编码器正则化。借鉴 **UNet（Ronneberger 等, 2015）的 Skip-connection**：差分编码器输出的多层次位移特征 `fm` 经 1×1 卷积通道减半，与上采样预测结果沿通道拼接，再经 1×1 卷积降维作下层转置卷积输出，保留低层特征，重建预测光流。
    4.  **视觉 Transformer（§2.2.1）**：利用 FACS 中表情与面部运动单元（AU）的对应关系，但避免运动单元定位依赖关键点的复杂计算，改用 ViT 以块间全局依赖逼近运动单元。将预测光流图 `Opr` 分割成不重叠局部区域，线性投影映射到 D 维嵌入并加可学习位置嵌入与类别 Token `oc`：`O0 = [oc, o1pE,...,oNpE] + Eps`。经多头自注意力 + MLP 的 Transformer 层（`O'l = MSA(LN(Ol-1)) + Ol-1`，`Ol = MLP(LN(O'l)) + O'l`），取最后一层类别 Token 输出作为判别特征 `flt = oc`。
    5.  **特征融合与分类（§2.2.2）**：`f'md = Flatten(Maxpool(Conv(fmd)))`，与 ViT 特征拼接得 `ffs = Concat(f'md, flt)`，送全连接分类。
- **损失函数（§2.3）**：
    - **光流估计监督**：端点误差损失 `Lep = (upr - ugt)² + (vpr - vgt)²`，约束预测光流与 TV-L1 基准光流（水平 u / 垂直 v 位移）的欧氏距离。微表情数据集无真值光流，故用 TV-L1 作外部基准引导。
    - **分类监督**：对 ViT 特征 `flt` 用交叉熵 `Lcl = -1/N · Σ log p(yi|FC(flt))`；对融合特征 `ffs` 用交叉熵 `Lfs = -1/N · Σ log p(yi|FC(ffs))`。
    - **信息保持**：用 **KL 散度损失** `Lk(f1, fd) = Σ f1·log(f1/fd)`，最大化最后一层静态视觉特征与动态差分特征的差异性，促使充分挖掘静态与动态信息（运动强度低的两帧近似中性表情，KL 抑制无关信息）。
    - **总损失**：`Lt = Lep + λ1·Lcl + λ2·Lfs + λ3·Lk`，超参 **λ1 = 0.7、λ2 = 0.7、λ3 = 0.0002**。
- **训练方式（§3.2.1）**：先在复合数据集上**光流估计预训练**，再同时进行光流估计与表情分类。Adam 优化器，初始学习率 **10⁻⁵**，动量 0.9，迭代 **100** 次；批量大小复合集 30、CASME II 40；图像调整为 **224×224**；ViT 深度 2、头数 8；SMIC 无顶点帧标注，用 CapsuleNet（Van Quang 等, 2019）的顶点帧标注。实验环境：Intel Xeon 4210R CPU、Ubuntu 20.04、NVIDIA RTX 3090。
- **与已有方法的差异**：与使用**离线光流**的方法（FeatRef、SLSTT 等）不同，本文端到端自适应学习光流，光流估计作为任务被监督优化；与以**自监督**方式学位移的方法（DMA、SCViT、FRL-DGT）不同，本文引入**外部光流知识 TV-L1 作显式监督**并融合分类任务指导，使运动特征更具判别性。
- **论文类型特化（特征提取与融合类）**：核心在于**自适应运动特征提取 + CNN/Transformer 多源信息融合**，关注如何设计编码器（密集差分 + 运动增强）增强对细微运动的敏感度，并用 ViT 全局建模挖掘运动特征中的判别信息。

## 实验

- **数据集（§3.1）**：SMIC（Li 等, 2013，16 名参与者，640×480，选高速相机样本，3 类：positive/negative/surprise）、CASME II（Yan 等, 2014，247 个样本，26 名参与者，200 fps，640×480，5 类：happiness/repression/surprise/disgust/other）、SAMM（Davison 等, 2018，159 个样本，200 fps，2040×1088，7 类）。复合数据集按 MEGC2019 标准把 CASME II 与 SAMM 表情重标为与 SMIC 相同的 3 类常见情绪。评估策略：**留一被试交叉验证（LOSO）**。
- **对比方法**：Bi-WOOF（传统光流）、OFF-ApexNet、Dual Inception、RCN、FeatRef、SLSTT、MSMMT（传统光流+深度学习）以及基于自适应位移生成的 FRL-DGT。
- **评价指标**：复合数据集用非加权 F1（**UF1**）与非加权平均召回率（**UAR**）；单数据集用准确率（**ACC**）与宏 F1（macroF1）。
- **主实验结果（表 1）**：AdaMER 在复合数据集（FULL）、SMIC、CASME II 上均最优，SAMM 上次优。
    - **FULL**：UF1 = **82.89%**、UAR = **85.95%**
    - **SMIC**：UF1 = 78.16%、UAR = 80.89%
    - **CASME II**：UF1 = **94.52%**、UAR = **96.02%**（远超现有方法）
    - **SAMM**：UF1 = 73.24%、UAR = 75.83%（次优，FRL-DGT 的 77.2/75.8 更高/相当）
    - 与各方法对比（FULL，UF1/UAR 提升）：vs Bi-WOOF **+19.93%/+23.68%**；vs FeatRef **+4.51%/+7.63%**；vs SLSTT **+1.29%/+6.95%**（首个纯 Transformer 工作，说明 CNN+Transformer 融合更优）；vs MSMMT **+1.29%/+4.04%**；vs **FRL-DGT +1.77%/+4.85%**（且本文未用运动放大技术）。
- **可视化分析（§3.3）**：图 4 给出复合集与 CASME II 混淆矩阵。复合集 3 类识别准确率差距较小；CASME II 上模型在 surprise/happiness 表现好（能捕捉眉毛与嘴角运动），但 repression 易被误判为 happiness，因二者涉及相似 AU（AU12、AU15、AU14、AU17）。
- **消融实验（表 2，CASME II 单数据集，ACC/F1）**：DSDE=密集差分编码器，AI=顶点帧，DI=帧间差分图，OI+AI=含运动信息两帧。
    - 方法 1（仅 AI 经 ResNet18）：ACC = 0.5331、F1 = 0.4708（最差，仅空间特征难捕捉细微变化）。
    - 方法 2（DI 输入）：ACC = 0.6116（比顶点帧 **+7.85%**，证明时序运动信息有帮助）。
    - 方法 3（OI+AI，DSDE/光流/融合均关）：ACC = 0.7396、F1 = 0.7238。
    - 方法 4（OI+AI + DSDE + 光流估计）：ACC = 0.7686、F1 = 0.7429。
    - 方法 5（OI+AI + DSDE + 光流估计 + 特征融合，完整模型）：ACC = **0.7727**、F1 = **0.7772**（逐步引入各模块性能递增，证实设计合理）。
- **效率信息（§3.3）**：从读取两幅含运动信息图像到输出光流预测，TV-L1 用时 **0.2113 s**，AdaMER 自适应光流仅 **0.1194 s**，更快，佐证研究自适应光流估计的必要性。

## 局限

- **外部监督的局限性**：用 TV-L1 生成的光流作监督基准，但论文自承 TV-L1 本身对微表情估计不精确，只能在分类任务共同约束下缓解，仍是潜在限制。
- **计算成本**：模型同时含复杂编码器、解码器与视觉 Transformer，相对仅用分类分支的方法计算量/参数量更大（提取文本未给出具体参数量/FLOPs，待核）。
- **数据集依赖性**：在 SAMM 上仅次优（UF1 73.24% 低于 FRL-DGT 的 77.2%），说明在不同数据集上的泛化/数据特性依赖存在差异。
- **假设依赖**：假设微表情可由起始帧与顶点帧图像对有效表征，且头部运动等干扰能被 MEM/空间注意力有效抑制；在头部运动剧烈、面部遮挡等极端情况下性能可能受影响（属合理推断，提取文本未做专门极端场景分析）。

## 个人评论

1.  **思想价值**：把光流估计从**离线预处理步骤**转变为与识别任务**联合优化的目标**，并用外部光流知识做显式监督——这是介于"纯自监督位移学习"（FRL-DGT 路线）与"离线光流"两端之间的一条折中路线，启发我们可为特定任务量身定制运动特征提取器，而非依赖通用工具。
2.  **技术价值**：DSDE + MEM 是一个具体可迁移的设计，用层内差分 `fd` + 空间注意力增强 `f̃3` 在不同网络层级保留并放大细微帧间差分。这一"跨尺度差分传递"思路对眼动分析、精细动作识别等需捕捉微小运动的任务有借鉴价值。用 KL 散度刻意拉大静态/动态特征差异以"逼"模型同时用好两路信息，是个值得记住的小技巧。
3.  **实验证据**：消融逐项验证（顶点帧 < 差分图 < +DSDE < +光流估计 < +融合）链条清晰；与 SLSTT（纯 Transformer）、MSMMT（多尺度 Transformer）的对比量化了 CNN 语义特征与 Transformer 全局判别特征的互补性。值得注意 CASME II 上 UF1/UAR（94.52/96.02）远高于复合集与 SAMM，提示方法可能更适配高帧率、标注完整的数据集。

# 论文精读

## 1. 论文定位
这篇论文属于计算机视觉与情感计算交叉领域，研究方向为**微表情识别**（《中国图象图形学报》2024, 29(10): 3060-3073）。它解决的核心问题是：现有微表情识别方法在光流特征提取上依赖**离线通用光流估计**（如 TV-L1），对细微面部肌肉运动表征能力不足，且忽略静态面部信息。论文归在 `J_人脸_表情_伪造_情感`（人脸表情/微表情分析）主题下。

## 2. 一句话总结
本文提出 AdaMER，通过端到端**并行联立**训练"自适应光流估计 + 微表情分类"两个任务、并以 TV-L1 外部光流作显式监督，学习更精确的面部细微运动特征，在 SMIC/CASME II/SAMM 复合数据集上取得 UF1 82.89%、UAR 85.95% 的最优性能。

## 3. 背景与问题
- **为什么要做**：微表情仅持续 1/25～1/3 秒、强度低，须专家鉴别，限制应用；用计算机视觉自动识别有谎言检测、心理诊断等价值。
- **之前方法的问题**：1) 特征工程（LBP/LBP-TOP/光流/Bi-WOOF/MDMO）依赖经验，难充分挖掘；2) 数据驱动方法中，仅用顶点帧难获足够判别特征，而基于光流的方法**离线**用通用光流估计预提取光流，对细微运动不敏感且忽略静态信息；3) 最新自适应工作（DMA、SCViT、FRL-DGT）多为**自监督**，缺外部知识监督，受限于数据增广。
- **核心矛盾**：如何端到端自适应学习与微表情相关的运动特征（而非依赖不精确的通用光流），并融合静态与动态信息提升精度——同时引入外部光流知识做监督来稳住动态特征生成。

## 4. 核心贡献
1.  **密集差分编码器 + 运动增强模块（MEM）**：跨尺度差分信息交互聚合，逐层增强细微运动语义，防止信息在深网中丢失。
2.  **端到端光流估计 + 微表情识别多任务统一模型**：以光流估计为正则化，引入 TV-L1 外部知识指导，同时实现自适应光流估计与分类，增强泛化。
3.  **CNN + 视觉 Transformer 特征融合**：编码器语义特征与 ViT 判别特征融合，提升表达能力与识别性能。

## 5. 方法详解
- **整体框架（AdaMER）**：数据预处理（帧采样 + TV-L1 基准光流生成）→ 微表情自适应光流估计与学习（密集差分编码—解码器）→ 微表情分类（ViT + 融合 + 分类器）。多任务并行优化。
- **输入输出**：输入起始帧与顶点帧相邻 5 帧间构成的图像对 `(X1, X2)`（训练时以一定概率用含运动信息的随机两帧替换以增广）；输出类别标签。
- **密集差分编码器 DSDE**：三路分支，共享 ResNet18 前 4 层提 `f1, f2`（静态），差分分支处理 `X3 = BN(X2 - X1)` 提 `f3`（动态）。
- **运动增强模块 MEM**：层内差分 `fd = BN(f2 - f1)`；空间注意力 SA（Woo 2018，含 1×1 Conv + ReLU）增强动态特征得 `f̃3 = Conv(ReLU(Conv(f'3 × f3)))`；拼接 `fm = Concat(fd, f̃3)`。编码器输出 `fmd = Concat(f2, fm, fd)`。用 KL 散度 `Lk(f1, fd) = Σ f1·log(f1/fd)` 拉大静态/动态特征差异。
- **解码器**：UNet Skip-connection（`fm` 经 1×1 卷积通道减半，与上采样结果拼接再降维），重建预测光流 `Opr`；端点误差损失 `Lep = (upr-ugt)² + (vpr-vgt)²` 对齐 TV-L1 基准光流。
- **视觉 Transformer**：光流图 `Opr` 分块 + 线性投影 + 位置嵌入 + 类别 Token `oc`，`O0 = [oc, o1pE,...,oNpE] + Eps`；`O'l = MSA(LN(Ol-1)) + Ol-1`，`Ol = MLP(LN(O'l)) + O'l`；取 `flt = oc`。深度 2、头数 8。
- **特征融合与分类**：`f'md = Flatten(Maxpool(Conv(fmd)))`，`ffs = Concat(f'md, flt)`；交叉熵 `Lcl`（对 `flt`）与 `Lfs`（对 `ffs`）。
- **总损失**：`Lt = Lep + λ1·Lcl + λ2·Lfs + λ3·Lk`，λ1=0.7、λ2=0.7、λ3=0.0002。
- **训练**：先在复合数据集光流估计预训练，再联合训练；Adam，lr=1e-5，动量 0.9，100 epoch，批量 30(复合)/40(CASME II)，输入 224×224，SMIC 顶点帧用 CapsuleNet 标注；RTX 3090。
- **与已有方法差异**：相对离线光流（FeatRef/SLSTT）端到端自适应学光流；相对自监督位移（DMA/SCViT/FRL-DGT）引入 TV-L1 外部显式监督 + 分类任务指导，使运动特征更判别。

## 6. 实验与结果

- **主结果（表 1）**：FULL UF1 82.89% / UAR 85.95%；SMIC 78.16/80.89；CASME II 94.52/96.02（最优且远超）；SAMM 73.24/75.83（次优）。提升：vs Bi-WOOF +19.93/+23.68，vs FeatRef +4.51/+7.63，vs SLSTT +1.29/+6.95，vs MSMMT +1.29/+4.04，vs FRL-DGT **+1.77/+4.85**。
